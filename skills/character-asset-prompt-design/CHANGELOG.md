## 2026-08-28 v1.3.0 符号出图顺序 + 自包含原则 + 变体标题印记标注

- 用户需求（《满月囚笼》莱拉/凯尔工作线收尾反馈）三项：
  1. **符号出图顺序分级（CHR-15）**：T1 叙事符号（印记/符文，形态需先确认）→ 符号设计图章节**前置到原始外观之前**（先出设计图再出角色）；T2 定位标记（痣/疤，仅需定位）→ 区域特写章节**后置到变体之后**（先出角色再锁位）。判定口诀"生成角色前需确认形态→T1 前置；只需确认在哪→T2 后置"。
  2. **提示词自包含原则（CAP-10，无关内容禁令强化）**：**单看提示词本身无法理解的内容 = 无关内容**。禁入代码块：①外部资产引用（如"（形态与辉光如《符号设计图 §M1》所示）"）→ 改写为符号形态直接自描述；②名字标签（如"莱拉·原始外观"标题行、@莱拉·原始外观）→ 移出代码块、身份用描述性语言；③工具操作指令（@哪张图）→ 锚定统一写"与参考图完全一致"，@ 由块外标题提醒；④文档内部交叉引用。自检：逐句问"单看这一句模型能理解吗"。
  3. **变体标题印记标注（CAP-11）**：凡符号需全外观固定的角色，变体块外标题加"· 记得参考印记生成"（英文 Reference the mark sheet when generating），提醒生成时 @ 符号资产图。
- 同步改动：mark-system.md 新增 CHR-15 + 五/六节引用写法改自描述；prompt-anatomy.md CAP-01① 标题行改画幅行、CAP-02① 锚定段去 @名字、CAP-03 英文锚定段改写、CAP-08 保持、新增 CAP-10/11、CAP-09 章节位置改 T1 前置 T2 后置；SKILL.md 铁律增 #11、铁律#10 改、流水线 S2/S5 更新、§3 文档结构更新（T1 置前/T2 置后）；preflight 增项 21/22/23（共 23 项）。

## 2026-08-28 v1.2.0 角色符号系统（CHR-14）：身上的特殊符号独立登记与出图

- 用户需求：角色身上的符文/纹身/痣/疤在后续剧情与连镜中易「变来变去」，须当作独立子资产锁死形态与位置。
- 新增 `rules/mark-system.md`（CHR-14 角色符号系统）：
  1. **符号分级 T1/T2**：T1 叙事符号（符文/纹身/徽记/烙印，需设计形态）→ 独立「符号设计图」；T2 定位标记（痣/疤/雀斑/天然胎记，无需设计）→「区域特写」锁位置。
  2. **T1 符文设计图规范**：画幅 1:1、正交平铺不含身体、可贴回任意姿态；**背景对比法则**——浅色符文→暗色背景、深色符文→浅色背景（用户明确约定）；复合符文组给单符+组索引或总图。
  3. **T2 区域特写规范**：默认 16:9 极端特写（或 3:4），须框入符号+2~3 解剖地标（喉结/下颌线/锁骨）锁位置。
  4. **符号注册表置顶**：文档最前段列全部符号（名/类型/解剖位置/分级/设计物段落引用）；无符号写「无」。
  5. **原始外观⑦段引用设计图/特写**，保证立绘与独立图形态一致、不各画各的。
  6. **变体继承/遮挡/激活态**：每变体重锚符号位置；被衣物遮挡显式注明不可见；符文激活态=变更段只加辉光、锚定基础设计图；颜色漂移量化；对称符双侧一致。
  7. **下游连镜 @ 引用**：视频/连镜提示词对每个符号 @ 其设计图/特写并声明一致，是防跨镜头漂移的落地方式。
  8. 与场景母题一致（同源符文跨文档引用 CHR-11）。
- `prompt-anatomy.md` 新增 **CAP-09 符号资产章节**：注册表/设计图/特写/原始外观引用/变体继承的标准写法与中英骨架。
- `SKILL.md`：全局铁律增 #10（符号必登记出图）；流水线 S2/S5 纳入符号建模与编译；§3 文档结构加入符号注册表(置顶)+符号资产章节；File Map 增 mark-system.md；description 修正「默认 16:9」（原误写 21:9，与 CVC-03 对齐）。

## 2026-08-28 v1.0.0 初版（T1）

- 来源：用户在场景资产技能（script-asset-prompt-design v1.1.0）实战后的方法论迁移需求 + 角色资产特有工作流（首个外观文生图、其余外观图生图锚定参考图）。
- 建立 CHR（01~13）/ CAP（01~07）/ CVC（01~05）三模块规则体系 + 16 项 preflight 内容门。
- 核心资产：
  - 外观系统建模：一角色 = 原始外观（唯一 T2I）+ 变体树（CHR-03/04）；
  - 身份锚两层模型：锚定层/变更层，防脸漂（CHR-05、CVC-01）；
  - 变体五段结构：锚定段→变更段→保持段→画面控制段→负面清单（CAP-02）；
  - 变体分类学五型：服装/年龄/状态/形态/光线（CHR-06）；
  - 编辑漂移防护：只写变更项+保持段声明+负面清单第4层（CVC-05、CAP-07）；
  - 跨文档一致性：S0 检测/角色重复三选项/亲缘与场景关联/母题索引「角色资产」区块（CHR-09~13）。
- 画面控制段沿用场景技能 VIS-02 的"高光成面/负空间/避免脏碎花累"，针对角色改写为皮肤与布料版本（CVC-02）。
