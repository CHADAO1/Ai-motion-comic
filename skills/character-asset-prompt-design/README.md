# character-asset-prompt-design — 剧本角色资产提示词设计师

把剧本角色提炼成**原始外观文生图提示词 + 变体外观图生图（图片编辑）提示词**的成组体系（中英双版，角色立绘固定 **9:16** 竖幅真人写实电影风格、**不随管线变化**（PP-C1）；管线预设 P1-P4 与风格调性见 `rules/PIPELINE_PRESETS.md`；场景资产画幅归场景技能管）。

## 角色统一构图基准（全角色恒定）

全身像、居中笔直站立、双手自然下垂、双手无手持物、平面柔光、浅灰色背景——原始外观与全部变体共用，保证参考图根稳定、跨角色可并排对照（CVC-03）。另内置**比例与真人感强化 token 库**（CVC-06）：头身比例/真人皮肤/服饰无毛边/细节集中，分插进 T2I 对应段，专治 T2I 角色比例失真与塑料感。

## 核心理念

- **一角色一原始外观**：每个角色只出一份完整文生图提示词（最高频/最具辨识度的形象）；脸在这里定死，不再另立 T2I。
- **其余外观全部参考衍生**：换装/年龄/状态/形态/光线变体一律写"参考@原始外观"的图生图提示词——用户在生图工具里 @ 参考图，提示词负责锚定+变更。
- **身份锚两层模型**：锚定层（脸/发/瞳/体型/印记）不可侵犯，全变体逐字复用；变更层才允许改。
- **编辑漂移防护**：变体只写变更项、保持段声明其余不变、负面清单加防漂移层——防止 AI 编辑时"顺手改脸"。
- **剧本证据优先**：每个元素有出处；设计延展显式声明（⚠️+锚点）。
- **跨文档一致性**：同角色新变体必须锚定既有原始外观；亲缘角色共享家族锚 token；角色环境复用场景母题；登记母题索引「角色资产」区块。
