# 交付前内容门 — Preflight（角色资产）

使用原则：①验收用要素计数（几份提示词/几段结构），每项 ✅ 绑定具体证据；②禁字数下限（短而全即合格）；③"已检查/无问题"按未检查处理。

逐项全 ✅ 才可交付，❌ 项当份/当阶段返工：
