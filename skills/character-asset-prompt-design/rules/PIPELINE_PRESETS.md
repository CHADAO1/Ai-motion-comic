# 规则模块 — 管线预设（角色资产专用）

> 开工前读本文件，确定管线 ID。**角色立绘画幅统一 9:16 竖幅，不随管线变化**（理由见 PP-C1）；管线只影响**风格调性 / 人物类型 / 变体重点**。
> 与 `cinematic-seedance-director/rules/PIPELINE_PRESETS.md` 同源，画幅/时长/模型/语言四项常量以那边为准。

## PP-C1 角色立绘画幅：固定 9:16 竖幅（管线无关）

| 管线 | 视频画幅 | **角色立绘画幅** | 理由 |
|---|---|---|---|
| P1 国内下沉中老年 | 9:16 | **9:16** | 与视频一致 |
| P2 国内女频恋爱 | 16:9 | **9:16** | 角色图是**全身参考图**，竖幅信息量最大，横用可裁 |

- 场景资产画幅才需要跟随管线（P1=9:16 / P2/P3=16:9 / P4=21:9），归 `script-asset-prompt-design` 管。

## PP-C2 各管线的角色风格调性

### P1 国内·下沉中老年

| 项 | 设定 |
|---|---|
| 人物类型 | 中老年为主（40-75 岁），含青年配角；**长相要"生活化"，不要网红脸** |
| 服装调性 | 朴素实用：针织开衫、棉布衬衫、老式夹克、布鞋；**忌奢侈品堆砌**（观众不买账） |
| 皮肤质感 | **保留真实纹理**：皱纹、老年斑、粗大毛孔；忌磨皮美颜（下沉观众要"像我身边的人"） |
| 色调 | 低饱和、偏暖；忌冷艳高级感 |
| 变体重点 | 年龄变化（回忆段）、落魄/体面对比、病号服、丧服 |
| 禁忌 | 不要韩式滤镜感、不要网红妆容、不要夸张美瞳 |

### P2 国内·女频恋爱

| 项 | 设定 |
|---|---|
| 人物类型 | 20-32 岁青年；男主重"苏感"，女主重"可代入感" |
| 服装调性 | 都市质感：垂坠感大衣、针织连衣裙、剪裁西装；**材质要写清楚**（羊绒/真丝/棉麻） |
| 皮肤质感 | 清透自然，轻微保留肤质；忌重度磨皮 |
| 色调 | 奶油感/低对比柔和；夜景可带霓虹反射 |
| 变体重点 | 换装（约会/职场/居家）、情绪光变体（暖光回忆 vs 冷光现实）、微伤/落泪 |
| 禁忌 | 不要影楼写真感、不要浓妆、不要让女主过于惊艳（要可代入） |

### P3 国内·女频诡异恐怖

| 项 | 设定 |
|---|---|
| 人物类型 | 20-32 岁青年；**女主以"惊恐反应"为核心资产** |
| 服装调性 | 日常便装为主（睡衣/家居服/通勤装）——日常感越强，被侵入时越恐怖 |
| 皮肤质感 | 真实偏冷；惊恐变体要能表现"脸色发白、冷汗、嘴唇失血色" |
| 色调 | 冷青/暗绿/惨白；主卡仍用平面柔光浅灰背景（保证可用性），惊恐变体可转冷调 |
| 变体重点 | **惊恐变体（必备）**：瞳孔放大/脸色惨白/冷汗/嘴唇颤抖；受伤变体（无血腥，见 HOR-05）；"日常 vs 异常"双状态 |
| 禁忌 | 无血浆、无伤口特写、无宗教符号、无儿童受惊形象（见 `cinematic-seedance-director/rules/horror-suspense.md` HOR-05） |

### P4 海外

沿用原有默认：真人写实电影风格、低饱和，按剧本世界观设定走，无额外题材约束。

## PP-C3 管线判定

与 cinematic-seedance-director 同规则（PP-02）：用户明示 > 题材映射 > 提问确认。**国内主力默认 P1**。

角色技能通常在视频提示词之前使用，若上游已定管线则沿用；未定则按上述规则判定或提问。

## PP-C4 交付标注

角色文档开头须写明本次管线，例如：

```
> 管线：P1（国内·下沉中老年）｜角色立绘画幅 9:16（固定，不随管线变化）｜风格调性：生活化真实、低饱和暖调
```
