# 规则模块 — CHR 角色外观系统（怎么"想"）

作用域：S1~S4 阶段的全部思维方法。编号前缀 CHR（CHR-09~13 见 cross-doc.md）。

## CHR-01 角色证据考古

角色的视觉信息比场景更散，四类来源缺一不可：
1. **出场描写行**：△动作行里的外貌/服装直接描写（最硬的证据）；
2. **服装与状态行**：换装、受伤、变身、进化的过程描写（变体的直接依据）；
3. **台词与 OS**：角色自述或旁白中的外貌信息（如"白发根根转为金色"）；
4. **他人反应行**：侧面烘托的辨识特征（如守卫见到黑纹变色而恐惧——证明黑纹是强辨识印记）。

输出证据清单：每条注明集-场号 + 原文摘录，禁止凭印象概括。

## CHR-02 证据三级分级

| 等级 | 含义 | 处理 |
|---|---|---|
| ✅ 剧本明确 | 有直接描写（如"白发根根转为金色"） | 按原文还原 |
| ✅ 可由剧本提炼 | 散落信息拼合（多次"黑纹漫过半张脸"→黑纹范围/动态） | 拼合后设计，注明拼合来源 |
| ⚠️ 视觉延展 | 剧本未定义具体形态（如只写"古法符牌"，未写材质造型） | 显式声明"此为视觉延展"+锚点台词，禁止与原文冲突 |

交付物中⚠️项单独列出，让用户知道哪些是还原、哪些是设计。

## CHR-03 外观系统建模（一角色 = 原始外观 + 变体树）

- 角色的所有外观不是并列关系，而是**一棵以原始外观为根的衍生树**：

```
原始外观（唯一文生图，脸在这里定死）
   ├── 服装变体（图生图：换装/仪式袍/婚裙……）
   ├── 年龄变体（图生图：18岁版/千年闪回……）
   ├── 状态变体（图生图：战损/雨夜/黑纹漫脸……）
   ├── 形态变体（图生图：狼形/进化体……）
   └── 光线变体（图生图：满月夜/火把侧光……）
```

- 每个变体必须绑定：集-场号 + 触发事件 + 变更内容一句话。
- 没有剧情绑定的变体是装饰——要么删掉，要么合并进相近变体。
- 输出外观树总览表：`外观 | 类型 | ID | 绑定集-场 | 触发事件 | 变更一句话 | 证据等级`。

## CHR-04 原始外观选择标准

原始外观 = 该角色**最高频出现、最具辨识度、信息量最大**的一套形象，**不必然是首次出场形象**：

- 判断优先级：出场次数 > 标志性（观众想到该角色的默认形象）> 剧照价值。
- 剧本有明确"标志性形象"描写（某符牌从不离身、某发色被反复强调）的，优先纳入原始外观。
- 原始外观一旦确定并生成，**不再另立第二份文生图**——脸只能定一次，后续全靠参考图衍生。

## CHR-05 身份锚（Identity Anchor）——两层模型

把角色特征拆成两层：

| 层 | 内容 | 处理 |
|---|---|---|
| **锚定层（不可变）** | 脸型五官关系 / 发色发型 / 瞳色 / 肤色与体型 / 标志性印记（疤、纹路、符牌等） | token 化，全变体逐字复用 |
| **变更层（可变）** | 服装 / 年龄化程度 / 伤污状态 / 形态阶段 / 环境光线 | 变体提示词只描写这一层 |

规则：
1. 变体只动变更层；锚定层一律写"与参考图完全一致"，**不做全脸重述**——重述=重新解释=漂移入口。
2. 允许复述**最关键的 2~3 个锚token**（如发色+瞳色+印记）作双重保险，其余交给参考图。
3. 剧本明确的锚变化（如"白发转金发"是剧情事件）不算漂移，按 CHR-06 对应变体处理，并注明证据出处。

## CHR-06 变体分类学（五型）

| 类型 | 变更项 | 不变项 | 典型剧本触发 |
|---|---|---|---|
| 服装变体 | 服装材质/层次/颜色/剪裁/合身度/破损程度 | 脸/发/瞳/体型/印记 | 换素白祭袍、换婚裙 |
| 年龄变体 | 面部轮廓成熟度/皮肤质感/头身比例/气质 | 五官相对关系/瞳色/发色/印记 | 18岁版、千年闪回 |
| 状态变体 | 血污/尘土/湿发/织物撕裂/情绪极端表情 | 面部身份特征/服装结构 | 战损、雨夜、黑纹漫脸 |
| 形态变体 | 形态阶段（人↔兽↔进化体）/新增特征叠加 | 瞳色；毛色从发色推导；气质延续 | 狼形、金焰形态 |
| 光线变体 | 光源/色温/时段 | 全部身份锚 + 服装 | 满月夜、火把侧光 |

- **形态变体的跨形态锚**：瞳色保持；毛色从发色/发纹推导；体型气质延续。人→狼不是"另一个人"，是"同一个人的另一形态"。
- **进化/升级是叠加不是替换**：原特征保留 + 新增（如黑纹范围扩大而非消失；白发转金发属于剧本明写的替换型例外，须注明证据）。

## CHR-07 外观即剧情状态（叙事绑定与剧透提示）

- 外观变体本质是**剧情状态的可视化**：素白祭袍=被献祭、白发转金=本源入体。变体清单按剧情时间排序。
- 剧透提示（弱化版，不必像场景组那样严格）：终局状态变体（进化体/仪式状态/死亡妆造）注明绑定剧集，提醒不要在早期集数镜头中提前使用。
- **服装材质必须与世界观/场景母题一致**：中世纪黑暗奇幻→粗纺/皮革/毛皮/银器；禁止现代面料（尼龙/漆光/拉链/印花T恤）。与场景文档的材质母题（如灰石、银器冷白）对齐。

## CHR-08 原始外观的背景与构图策略

- 原始外观默认**浅灰色平面背景 + 平面柔光**（全角色统一，见 CVC-03 构图基准），原因：
  1. 后续全部变体以它为参考图，干净平面背景让图生图时的环境串扰最小；
  2. 均匀柔光不带戏剧性阴影，脸部与服装结构还原最稳；
  3. 角色即视觉主体，无环境元素争夺细节预算。
- 构图统一：**全身像、居中笔直站立、双手自然下垂、双手无手持物**（含少量头顶/脚下留白便于裁切）——剧情道具一律"藏袖/不露出"处理，剧情姿态（交叠双手、负伤跪地等）属表演层，在视频提示词阶段叠加。
- 若用户要求场景内立绘：环境母题必须从场景文档复用（CHR-11 场景关联），禁止另起一套环境；此时统一构图声明需注明让位于场景构图。
