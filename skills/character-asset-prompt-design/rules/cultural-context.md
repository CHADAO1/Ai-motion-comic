# 规则模块 — ETH 文化·时代·族群考古（角色怎么"不像套皮亚洲脸/套皮白人"）

作用域：S1 证据考古内嵌的「文化坐标定位」，贯穿 S2~S5 身份锚、原始外观、变体、符号的**五官 / 肤色发质 / 服装 / 语言个性**决策。编号前缀 ETH。
> 一句话：**先把"这个角色是给谁看、活在哪片文化里、什么种族什么人"定死，再定他长什么样、穿什么、怎么说话。** 提示词必须有强化族群特征的五官与服装描述，禁止产出一个"任何市场都能套的模板脸"。

## ETH-01 市场-时代-族群定位（S1 第一件事，强制）

产出角色前先读剧本，建立四坐标，写进文档开头（紧跟管线标注之后，PP-C4 下方）「文化坐标」行：

| 坐标 | 判定来源（读剧本） | 输出 |
|---|---|---|
| **观众群体** | 平台/管线、剧本语言（中/英）、题材受众 | 国内下沉中老年 / 国内年轻女性 / 海外欧美 / 其他 |
| **时代背景** | 剧本时代信息（现代/架空/中世纪/民国等），取△动作行服装与称谓线索 | 锁定年代，勿空泛写"古代" |
| **地域文化** | 人名 / 地名 / 称谓 / 习俗 / 饮食 / 建筑 | 锁定文化原型（北欧/西欧/东欧/东亚/北美原住民/中东等） |
| **族群/种族** | 角色人名线索 + 肤色/发质/骨相/五官直接或间接描写 | 锁定可画像的族群（北欧高加索/南欧/斯拉夫/拉丁/南亚/非裔等） |

- 定位结果决定角色资产的全部特征决策；**观众群体为 P4 海外/欧美时，默认按欧美本土文化做**（ETH-06）。
- 无法判定时按管线默认（见 PIPELINE_PRESETS PP-C2），但须写清；禁止因"看不出"就画成通用混血网红脸。

## ETH-02 族群五官强化（提示词必含，非可选项）

**每个角色的原始外观身份锚段，必须显式描述其族群的辨识五官**，禁止用"一张好看的脸/立体五官"这类无差别描述糊弄。

| 族群原型 | 强化描述示例（英文提示词可直用） |
|---|---|
| 北欧/日耳曼 | 高颧骨、窄长脸、淡蓝或灰蓝瞳、金白或浅亚麻发、淡眉、面部棱角分明 |
| 高加索-西欧/凯尔特 | 深眼窝、高眉弓、冷调肤色、红棕/深金发、雀斑、浅瞳 |
| 斯拉夫/东欧 | 浅瞳（蓝/灰）、高平颧、宽额头、偏浅肤色、浅棕/金发 |
| 拉丁/地中海 | 橄榄肤、深棕近黑发、深褐瞳、浓眉、面部柔和圆润 |
| 非裔/非洲裔 | 深色肤质各深浅梯度、卷曲紧密发质或辫发/雷鬼、鼻翼与唇部丰厚立体、深褐瞳 |
| 南亚/印度次大陆 | 中等到深暖棕肤、浓密黑直或微卷发、深棕瞳、五官线条柔和 |
| 东亚（国内管线用） | 按 P1/P2/P3 地域风格：眼型/肤色/骨相生活化，P1 忌网红整容脸 |

- 强化方式：用"**不是X而是Y**"句式（CAP-04）锁族群，如 `high cheekbones and a long narrow Nordic face, NOT a generic East-Asian idol face`；肤色/发质/瞳色/骨相四个维度至少落 3 个。
- **五官族群特征进锚定层**（CHR-05），原始外观定死后全变体复用——换装/变老都不能改成另一个族群的脸。
- 若剧本人种线索与观众市场冲突（如欧美市场但角色设定为亚裔），**以剧本角色设定为准**，风格调性按市场；反之剧本含糊时按市场主流族群并标注判断依据（如欧美市场配角默认白人为主流，但主创姓名提示非裔则按非裔做）。

## ETH-03 肤色/发质/骨相的文化正确性

- 肤色不是一个"色号"，是**带文化语境的生命质感**：北欧月白冷调 vs 地中海暖调被晒肤色 vs 非裔深色高光，用"不是塑料色而是带真实肤质层次"表述。
- 发质要和族群配套：金直发是北欧常见，但"深色小卷发+深肤"更偏非裔/拉丁——别让模型把卷发安到北欧脸上或反之。
- **骨相/五官比例**（眼距、颧位、下颌、唇厚度）比肤色更能区分族群，是防"套皮脸"的关键——每角色至少写 2 个骨相特征。
- P1 下沉中老年观众：生活化真实骨相（皱纹/眼袋），严禁网红锥子脸整容感；即便剧里"年轻貌美"也要是人味的美不是 AI 模板美（对照 PP-C2/P1 禁忌）。

## ETH-04 民族服装/发型/纹身装饰的文化正确性

服装、发型、头饰、纹身、首饰必须对应角色的**时代 + 地域 + 民族 + 身份**（场景技能有对应文化规则：材质就地取材 + 年代工艺；本技能服装材质须与之对齐）：

| 年代-文化 | 应出现 | 禁现代混搭 |
|---|---|---|
| 中世纪北欧 | 亚麻/羊毛束腰外衣、皮甲、毛皮斗篷、盘发或编发、银质胸针/狼牙 | 化纤、拉链、印花 T 恤、现代皮夹克 |
| 维多利亚英美 | 束身衣+多层裙/燕尾服、蕾丝、高领、复杂发髻 | 露脐、塑料首饰、运动鞋 |
| 当代欧美 | 按当地区域与人物阶层穿搭 | 把中式穿着/妆造硬安到白人角色 |
| 中国民国/古代 | 旗袍/长衫/汉服对应年代形制 | 朝代错乱混搭 |

- 服装用词要**实**（given type 有史料基础），不写"复古风/民族风"这种含糊标签。
- 纹身/头饰等**有文化语义的符号**：先判断是否触发 `rules/mark-system.md` 的符号注册表（CHR-14）——宗教/部族/身份徽记类按 T1 出独立符号设计图，避免 AI 乱造文化符号。
- 服装材质与角色所在场景的材质母题必须一致（CHR-07）：中世纪角色穿麻毛皮，不穿进一个满是现代塑料的中世纪城堡。

## ETH-05 语言个性与说话习惯档案（服务台词/配音，不进视觉代码块）

角色"说话习惯 / 语言特点 / 性格"在资产文档里另立一节「语言个性档案」，**作为下游台词、配音（character-voice-design）与视频提示词的文化输入**，不写进视觉提示词代码块：

| 维度 | 提炼自剧本 | 作用 |
|---|---|---|
| 口音/方言基底 | 台词用词、地域设定 | P4 欧美按地域口音（美国南/英伦/苏格兰/东欧腔）；国内按地域语感 |
| 用词习惯 | 角色惯用词/语气词/称呼 | 傲慢者用短句命令式，怯懦者用犹豫句+敬语 |
| 语言节奏/性格 | 句长、打断、冷场 | 反哺视频提示词的表演强度与表情 |
| 禁忌/口头禅 | 反复出现的表达 | 一致性锚，防 AI 台词漂移 |

- **P4 欧美题材强调"地道而非翻译腔"**：台词/用词要像英文母语者说话，不是中文直译的书面感（配合 script-cinema-optimizer 的本土化逻辑）。
- 该档案在文档里以表格呈现，方便下游技能取用。

## ETH-06 美式原生原则（P4 欧美题材强制）

- 当剧本判定为**欧美市场/欧美题材**（如《女巫与狼王》），把角色当作**一部当地电影的主角**来做：选角脸型、发型、穿搭、言谈，都按美/欧真实演员与生活质感，**不是"中国人想象中的欧美"**。
- 常见"假欧美"要拆掉：白人角色却带中式柔光美颜、东亚审美的大眼睛小脸、中式服装剪裁西化后挂在白人身上、把欧美中产拍成中国偶像剧主角。
- 判断尺度：**换一个该文化的本地人看这个角色，会不会觉得"这人就是我身边/我那个年代的人"**——是，才合格。
- 宗教/文化敏感符号（十字架、凯尔特结、部族图腾等）谨慎处理：有剧情依据才用，且按真实文化语义，不空摆当装饰（参照 script-content-audit 合规）。

## ETH-07 各管线族群/语言定位（与场景技能四管线文化坐标对应）

| 管线 | 观众 | 角色族群默认 | 说话语言 |
|---|---|---|---|
| P1 下沉中老年 | 国内中老年 | 中国人·市井面容（生活化） | 中文，口语化，忌书面腔 |
| P2 女频恋爱 | 国内年轻女性 | 中国人·都市青年 | 中文，甜宠对白 |
| P3 女频恐怖 | 国内年轻女性 | 中国人·日常青年 | 中文 |
| P4 海外 | 剧本地域 | 按剧本族群（欧美默认本土族群） | 英文（P4）等剧本语言 |

> 无论哪条管线，**必须从剧本里挖角色特点**，不靠脸谱化刻板印象堆料——性格、经历、身份要能落到可视觉化的气质/姿态/着装细节上。

## ETH-08 从剧本挖角色特点（反脸谱化）

设计提示词前，用剧本证据给角色"做人设三问"，答案必须来自剧本原文而非刻板印象：

1. **他经历了什么**（童年/创伤/执念）→ 外化到眼神、疤痕、体态、磨损的衣物；
2. **他在人群中的位置**（贵/贱/孤/众）→ 外化到服装档次、配饰、肤色保养（养尊处优 vs 风餐露宿）；
3. **他的性格底色**（狠/怯/傲/忍）→ 外化到体态、表情基线、常用姿态（这在视觉资产里做"基线表情/体态"备注，最终表演层由视频提示词叠加）。

- 每个角色至少 1 个"只有这个角色才有的可视觉特征"（源自剧本具体事件，如旧伤疤、特定的常年旧衣、家族印记），避免同一剧里角色互为换头。
- 特征要能进身份锚（CHR-05）并被全变体继承，作为跨集连镜的一致性锚。
