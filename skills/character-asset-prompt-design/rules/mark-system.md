# 规则模块 — CHR-14/15 角色符号系统（怎么锁死身上的特殊符号）

作用域：S1~S5 阶段中，凡角色身体上存在「有造型/有位置」的特殊符号（符文、纹身、氏族徽记、烙印、痣、疤、雀斑、天然胎记）时必修。编号前缀沿用 CHR。

## 为什么需要

角色身上的符文/纹身/印记/痣/疤，在后续换装、年龄、状态变体与视频连镜里极易「变来变去」——同一枚符文在不同镜头形状漂移、痣的位置乱跳。根因是：这些符号没被当作独立资产锁定，而是每次随立绘/变体被模型「重新发挥」。本规则把「身上符号」提升为一类**需显式登记 + 独立出图的子资产**，从源头固定形态与位置。

> 用户原话意图：符文这类要设计的 → 单独出一张符文设计图；痣这类不用设计的 → 出一张区域特写锁位置。二者都「在角色提示词文档最前面列出来，按剧本设计/锁定」。

---

## 一、符号分级（两步判定，决定出什么图）

**第 1 步 · 这符号要不要设计形态？**
- **要**（有特定造型/含义/文化母题，剧本或视觉延展定义了它长什么样）→ **T1 叙事符号**，出独立「符号设计图」。
- **不要**（痣/疤/雀斑/天然胎记，形态由生理决定，无需设计）→ **T2 定位标记**，出「区域特写」锁位置。

**第 2 步 · T1 再细分用途**
- 符文 / 魔法阵 / 氏族徽记 / 烙印印记 → 独立设计图（平铺正交，见下）。
- 装饰性纹身（纯美学、无剧情含义）→ 仍出设计图保证纹样一致，注册表标「装饰级」。

判定以剧本明写为准；剧本只提「某符文」未定义形态 → 标 ⚠️视觉延展 + 锚点台词，按 CHR-02 处理。

---

## 二、T1 · 符号设计图（Narrative Mark Design Sheet）

**用途**：把符号从身体上「摘下来」，做一张可复用的平面参考卡。角色立绘与全部变体里的符号都以此图为准，杜绝形态漂移。

**画幅**：**1:1**（正方形设计卡，便于作图标/贴图引用）。

**构图**：正交平铺（orthographic, flat, front-facing），符号居中、占画面约 70%，**不含身体/肢体/透视**，纯符号本体 + 背景。这样下游可把它「贴回」任意姿态的身体部位。

**背景对比法则**（用户明确约定）：
- 浅色符文（亮银 / 白 / 浅金 / 发光浅色）→ **暗色背景**（深灰 / 近黑），最大化可读；
- 深色符文（黑 / 暗红 / 深紫 / 墨色）→ **浅色背景**（浅灰 / 米白），同上。
- 辉光类符文（自身发光）→ 暗背景下加柔光晕；浅背景下加轻微投影以区分层次。

**设计依据**：基于剧本对符号进行设计——形态（线型 / 几何 / 拟生物）、含义（它代表什么）、颜色、辉光强度、材质感（雕刻 / 刺青 / 燃烧 / 流体渗出）。剧本未定义具体形态的项标 ⚠️视觉延展 + 锚点。

**复合符文组**：一枚角色若有多枚符文（如构成三角形 / 星座排布），两种方式：
- 单符成组：每枚各出 1:1 设计图，附「组索引」说明相对位置与整体构图；
- 或出一张「符文组总图」（仍可 1:1）展示完整排布，再对关键单符补局部。

**位置锚点（必写，防漂移）**：设计图之外，在注册表与原始外观里记录该符在身体上的精确解剖位置（见第六节）。

中英双版（CAP-03），代码块纯净（CAP-08）。

---

## 三、T2 · 区域特写（Region Close-up，定位锁定）

**用途**：痣/疤/雀斑/天然胎记无需设计形态，但要在连镜中位置不跳。出一张**该区域极端特写**提示词，把「符号 + 周围解剖地标」一起框住，位置从此唯一。

**画幅**：默认 **9:16**（与角色立绘一致便于对齐裁剪，2026-08-29 随角色卡改竖幅）；若需更紧的特写可用 **3:4**。构图为 extreme close-up，符号居中偏侧、周围带可辨识地标。

**地标法则**：特写必须同时包含符号与 2~3 个解剖地标（如颈部痣 → 喉结 + 下颌线 + 锁骨端点），地标是把「位置」说死的锚。

**分类**：痣（mole）/ 疤（scar，含陈旧与新鲜）/ 雀斑（freckles 成片）/ 天然胎记（birthmark）。

中英双版，纯净正文。

---

## 四、文档结构 · 符号注册表（置顶）

在角色文档**最前面**（跨文档关联说明之后、外观树之前）放一张「角色符号注册表」：

```
| # | 符号名 | 类型 | 位置（解剖锚点） | 分级 | 设计物（段落引用） |
|---|---|---|---|---|---|
| 1 | 月牙胎记 | 胎记 | 左肩锁骨上方约 3cm | T2 | 区域特写 §M2 |
| 2 | 银月符文 | 符文 | 左手掌心 | T1 | 符号设计图 §M1 |
```

- 注册表是「符号资产清单」，下游（视频连镜）据此逐符号 @ 对应图。
- 类型列填：符文 / 纹身 / 徽记 / 烙印 / 胎记 / 痣 / 疤 / 雀斑。
- 无特殊符号的角色，注册表写「无（本角色身上无 T1/T2 符号）」，并跳过五/六/七节。

---

## 五、原始外观中的符号引用

原始外观 T2I 提示词⑦体态与印记段要提到符号。**提示词块内必须把符号形态直接自描述出来**（CAP-10 自包含原则：模型拿不到设计图文档，引用编号等于噪音），写法：

`左手掌心浮起一枚银月符文：银白细线、圆月与缺角几何交织，边缘柔润如月华，素日极淡、激活泛银光；`

`左肩一枚月牙形浅色胎记，锁骨上方约 3cm、朝肩颈交界，浅褐、边缘柔和。`

→ 形态描述与设计图逐项一致（颜色/线型/边缘/辉光），立绘与独立图永远一致，不各画各的。
→ 提示词内该描述**前一行写占位标识 `@{符号名}`**（CAP-12；如 `@银白月裔印记`），中英版同位，用户替换为设计图。
→ 设计图编号（§M1 等）只出现在文档表格、设计依据说明与变体标题标注（CAP-10）中，**永不进入提示词代码块**。

---

## 六、变体中的符号继承、遮挡与激活

- **继承**：每个变体锚定段 / 保持段必须重锚符号位置（「左肩月牙胎记与参考图完全一致」），禁止变体里让符号消失或移位。**提示词块内一律用「与参考图完全一致」锚定**（模型能理解参考图），不引用设计图编号（CAP-10）；印记行前写占位标识 `@{符号名}`（CAP-12）。
- **遮挡**：符号被衣物 / 发型盖住 → 显式注明「被衣领遮挡不可见」，不要凭空抹掉。
- **激活态**：符文平时淡 / 隐，剧情点发光 → 原始外观 = 淡痕（或不可见），设计图 = 符文全貌，变体 = 激活态（变更段只加辉光强度，锚定基础设计图）。标记激活绑定的集-场号。
- **颜色漂移**：符文颜色随状态变化 → 变体锚定基础色 + 变更段量化色移（如「由银白转为灼红」）。
- **对称 / 镜像**：双臂同符、正反对称 → 设计图给单符，变体声明「双侧一致」。

---

## 七、下游连镜用法（防跨镜头漂移的根本手段）

生成视频 / 连镜提示词时，对每个 T1 符号 **@ 其「符号设计图」**、每个 T2 符号 **@ 其「区域特写」**，并在镜头描述里声明「符号形态 / 位置与参考图一致」——这是用户「防止后续剧情符号变来变去」的落地方式。

---

## 八、与场景母题的一致性

若角色符文与某场景的纹章 / 符文同源（如氏族纹章 = 城堡纹饰），跨文档引用场景母题（CHR-11），禁止另起一套符号系统。

---

## 九、CHR-15 符号出图顺序（T1 前置 / T2 后置）

**问题**：符号资产章节若排在角色提示词之后，按文档顺序生成时会「先出角色、后出符号」——而角色的形态描述（⑦段）依赖符号设计图，顺序反了。按符号特性分级决定生成顺序：

- **T1 叙事符号 → 角色上面（前置）**：凡「形态需要设计、角色生成前必须确认」的符号（印记 / 符文 / 徽记 / 烙印），**符号资产章节排在原始外观之前**。生成流程：先出 1:1 符号设计图 → 再出角色立绘（形态已锁定，立绘直接自描述引用）。
- **T2 定位标记 → 角色下面（后置）**：凡「仅需定位、无需设计形态」的符号（痣 / 疤 / 雀斑 / 胎记），**区域特写章节排在原始外观之后**。生成流程：先出角色立绘（标记随角色自然带出）→ 再出区域特写锁位置，供连镜 @ 使用。

**判定口诀：生成角色前需要先确认它的形态 → T1 前置；只需确认它在哪 → T2 后置。**

- 同一角色同时有 T1 与 T2：T1 章节全部前置（各设计图连续编排在原始外观之前），T2 章节全部后置（各特写连续编排在变体之后）。
- 文档结构顺序（对齐 SKILL.md §3）：
  `符号注册表(置顶) → 外观树/身份锚 → 【T1 符号设计图章节】→ 原始外观 → 变体×N → 【T2 区域特写章节】→ 衔接说明`。
