# 规则模块 — CAP 提示词结构（怎么"写"）

作用域：S5 编译阶段。编号前缀 CAP。

## CAP-01 原始外观·文生图十段结构（全角色唯一一份 T2I）

```
① 标题行          画幅行｜9:16（代码块内只写模型可理解的技术参数；角色名·外观名标签移出代码块，放在块外文档标题——CAP-10）
② 风格定位与用途  真人写实电影 + 角色一句话定位（身份/气质/在故事中的分量，用描述性语言，不写人名标签）
③ 身份锚总述      全身总体印象：年龄感/体型/肤色/姿态气质关键词
                  + 统一构图声明（居中笔直站立、双手自然下垂、无手持物）
                  + 比例强化 token（CVC-06）
④ 面部            五官关系/脸型/瞳色/肤质 + 真人感皮肤 token（CVC-06）
⑤ 发型发色        长度/质感/色相/自然垂坠方式（用"不是X而是Y"防俗套，CAP-04）
⑥ 服装层          材质/层次/颜色/剪裁/磨损度（量化，CAP-05；材质对齐世界观，CHR-07）
                  + 服饰真人感 token（CVC-06：衣摆自然下垂、袖口下摆无毛边、饰品结构精细）
⑦ 体态与印记      统一站姿（CVC-03）/标志性印记（符牌/疤/纹）的位置与量化描述——形态直接自描述（CHR-14/15，CAP-10）
⑧ 背景与光        浅灰色平面背景 + 平面柔光（CVC-03/CHR-08）+ 细节集中 token（CVC-06）
⑨ 摄影术语块      photorealistic, live-action portrait, cinematic lighting,
                  85mm portrait lens, subtle film grain, high dynamic range,
                  restrained color grading, premium theatrical movie still
⑩ 负面清单        三层 + 角色专属项（CAP-07）
```

> ③④⑥⑧ 中的强化 token 从 CVC-06 token 库取，**分插进对应段**，不整块堆在结尾。
> 提示词正文内禁止出现证据标注与规则编号（CAP-08）。

## CAP-02 变体·图生图五段结构（核心差异）

```
① 锚定段    段首 @{角色名}原始外观 占位（CAP-12）；身份与原始外观参考图完全一致：
            面部、发型、发色、瞳色、肤色与体型与参考图完全一致。
            [符号类：印记/纹身与参考图完全一致（参考图已含符号）；仅描述位置与状态变化，不引用编号；符号行前加 @{符号名} 占位（CAP-12）]
            [仅复述 2~3 个最关键锚 token 作双重保险]
② 变更段    只写本次变化，用变更动词开头（CAP-06），逐项描述变更目标的
            材质/颜色/剪裁/程度（量化，CAP-05）
③ 保持段    除上述变更外，其余一切保持参考图原样（服装其余部分/配饰/构图/背景）
④ 画面控制段  简化版（CVC-02）
⑤ 负面清单  四层（CAP-07，含编辑漂移层）
```

- 变体提示词**远短于**原始外观：身份交给参考图，笔墨全部花在变更层。
- **禁止在变体里重述全身**——那等于让模型重新画一遍，脸必漂。
- 一个变体只承载一类变更（CHR-06 一型）；复合变更（仪式=换袍+化妆）须逐项分列、逐项量化。

### 示例（凯尔·战损变体，节选，展示格式感）

```
【身份锚定】
@凯尔原始外观
面部、黑色短发、深灰近黑的瞳色、高瘦结实的体型与原始外观参考图完全一致。
@左颈黑纹
左颈黑色狼形印记与参考图完全一致（仅变更段描述其状态变化，不重述形态）。

【变更】
为他增添战斗后状态：左侧眉骨新添一道渗血的横向擦伤，长度约三厘米；
深色亚麻衬衫左肩至左袖撕裂两处，裂口边缘磨损起毛；
下颌与左颧骨沾少量干涸血迹与尘土；
黑色纹路自左颈蔓延至左侧下颌线（较参考图的小臂范围扩大）。

【保持】
除上述变更外，发型、服装其余部分、配饰（古法符牌）、构图与背景
保持参考图原样。

【画面控制】
血迹与尘土的高光保持柔和、成面，不出现碎亮点。
未变更区域保持参考图的皮肤与布料质感，不新增纹理细节。

不要改变面部特征，不要改变发型与发色，不要改变瞳色，
不要改变体型，不要新增未描述的配饰，不要改变未提及的服装部分。
```
> 生成前在生图工具中 @ 原始外观参考图（有符号时另 @ 符号设计图，见 CAP-10 标题标注）——@ 哪张图是工具操作，不进提示词正文。

## CAP-03 中英双版分工

- **英文版是生成主力**：术语化 + 大写段落标题强调（IDENTITY LOCK / CHANGE / KEEP / Do NOT...）。
- 中文版供用户审阅、供中文模型使用；两版信息量等价、逐段对应。
- 变体锚定段英文版固定起头：`Identity (face, hair, eye color, skin, build) remains exactly identical to the reference image.`（角色名标签不进正文；段首写 `@{角色名}原始外观` 中文占位标识供用户定位替换——CAP-12，CAP-10 唯一例外）。
- 英文版内禁止混入中文残留（交付前用正则 `[A-Za-z][一-龥]` 自检）。

## CAP-04 "不是X，而是Y"句式（角色版）

先排掉模型最常见的俗套联想，再给正确方向：

> 头发"不是柔顺广告光泽，而是略有毛糙的真实发丝质感"
> 皮甲"不是漆光塑料感，而是磨损哑光的陈旧皮革"
> 黑纹"不是整齐的纹身图案，而是从皮下渗出、边缘不规则的龟裂纹"
> 肌肤"不是磨皮滤镜的瓷肌，而是带真实毛孔与轻微风霜感的皮肤"

公式：`不是 [俗套A]，也不是 [俗套B]，而是 [正确形态 + 程度限定词]`。

## CAP-05 量化约束与位置锚定

- 印记/伤痕必须**定位 + 量化**："左眉骨一道约两厘米的旧疤""黑纹从指缝蔓延至小臂""黑纹漫过右侧半张脸"。
- 破损程度量化："裙摆下缘两三处撕裂""肩线一道纵向裂口"。
- 服装件数与层次量化："三层：内衬亚麻衫、外罩深灰毛呢长袍、腰间皮质束带"。
- 禁止"一些/许多/大量"式模糊量词。

## CAP-06 变更动词与克制表达

- 变更动词表（变更段句首固定用）：
  `换上 / 为她（他）换 / 调整为 / 增添 / 移除 / 推移至（年龄）/ 蔓延至（状态范围）`。
- 范围限定词紧随其后：`仅 / 只 / 其余保持不变`，把变更锁死在意图范围内（配合 CVC-05）。
- 年龄推移写**目标状态**而非口号："年轻约18岁的版本：面部轮廓更窄、皮肤更紧致、气质更青涩"，不写"变年轻"了事。
- 状态程度用递进词序：`轻微 > 明显 > 彻底`，对应剧情强度（CHR-07）。

## CAP-07 负面清单（原始三层 + 变体第四层）

**原始外观**（三层，同场景技能）：
1. **内容层**：按角色定制（不要其他人物、不要现代元素、不要文本水印……）
2. **风格层**：不要游戏CG、动漫风、概念插画、网红滤镜感、cosplay 塑料感……
3. **质感层**：不要过高饱和、强锐化、塑料皮肤、过度磨皮、脏碎花累的 AI 感……

**变体**加第 4 层——**编辑漂移层**（防参考图编辑时"顺手改脸"，I2I 特有）：

4. `不要改变面部特征，不要改变发型与发色，不要改变瞳色，不要改变体型，
   不要替换或新增未描述的配饰，不要改变未提及的服装部分。`

注意：负面清单是兜底，主力永远是锚定段+保持段的正向声明（CVC-04）。

## CAP-08 提示词正文纯净性

代码块内的提示词正文是**可直接粘贴进生图工具的成品**，里面出现任何与画面生成无关的内容都会污染生成结果。禁止入内：

1. **证据标注**：✅/⚠️/行号/集-场号（如"（✅40/49/64）"）——证据只存在于文档的表格、证据分级清单与说明段；
2. **规则编号与技能名**：CHR-xx/CAP-xx/CVC-xx/技能名——它们是给人看的设计依据，不是给生图模型看的；
3. **延展声明**："（⚠️视觉延展）""（脸发瞳为视觉延展……非剧本明写）"之类——声明写在文档说明段；
4. **剧情解释与变更理由**："因此""依据剧本第X集"——提示词只描述画面本身。

**判定口诀：删掉该内容若不影响生成结果 → 删；若影响画面 → 留。**
例："洁白婚裙（✅40/49/64）" → 删标注留"洁白婚裙"；"居中笔直站立" → 留（影响构图）。

## CAP-10 提示词自包含原则（无关内容禁令，用户约定）

**无关内容的定义：单看提示词本身无法理解的内容，就是无关内容。** 生图模型只能看到本提示词块——它不认识角色名、不认剧名、不认任何外部资产编号。凡是需要"上下文/文档/其他图片"才能理解的词句，一律禁入代码块。

**四类典型无关内容（禁入）：**

1. **外部资产引用**：`（形态与辉光如《符号设计图 §M1》所示）`、`保持符号设计图 §M2 原样`、`依 §M2 龟裂母题`——模型不知道《符号设计图 §M1》是什么。→ 改写为**形态直接自描述**："纤细弦月形银白月纹，素日极淡、激活泛银光"。
2. **名字标签**：`莱拉·原始外观`、`凯尔·原始外观`、`@莱拉·原始外观`——模型不认识谁是莱拉。→ 标题行只留画幅等技术参数（移出代码块放块外标题）；定位身份用**描述性语言**（"纯血月裔新娘""被诅咒守护封印百年的男人"）。
3. **工具操作指令**：`参考图：@xxx` 之类的说明性长句（告诉用户 @ 哪张图的提示语）——@ 哪张图是用户在生图工具里完成的动作，不是模型能理解的画面内容。→ 锚定统一写"与参考图完全一致"（模型能理解"参考图"）；需要贴参考图的位点写 **CAP-12 占位标识 `@资产名`**（唯一例外，用户替换后删除），块外标题另加 CAP-11 标注双重提醒。
4. **文档内部交叉引用**：`见 §3`、`参考上方章节`——块内没有章节概念。

**自检**：逐句问"单看这一句，生图模型能理解吗？"——不能 → 删或改写为自包含描述。
**唯一例外**：CAP-12 参考图占位标识 `@资产名`（用户明确要求保留，用于定位贴参考图）。
例："左颈侧一枚银白月裔命定印记（形态与辉光如《符号设计图 §M1》所示）" → "左颈侧一枚纤细弦月形银白月纹印记，素日极淡、激活泛银光"。

## CAP-11 变体标题印记标注（有符号角色的防忘提醒）

凡符号（T1/T2）需在角色全部外观固定的，每个变体块的**块外标题**末尾加固定标注，提醒生成时 @ 对应资产图：

```
### 莱拉-祭袍（服装型 · 23-1）· 记得参考印记生成
### Kael-Wolf Form (form type · ⚠️extension) · Reference the mark sheet when generating
```

- 标注位置：markdown 块外标题（`### …`），**不进代码块**（保持正文纯净，CAP-08/10）。
- 标注格式：`· 记得参考印记生成`（中文）/ `· Reference the mark sheet when generating`（英文）。
- 有多个符号时写 `· 记得参考印记+黑纹生成`（列出全部需 @ 的符号资产名）。
- 无符号角色不标注；符号仅单处出现的角色（如只有原始外观）也不强制。

## CAP-09 符号资产章节（凡有符号必修，T1 前置 / T2 后置）

章节位置（按 CHR-15 出图顺序）：**符号注册表紧接跨文档关联说明、置于外观树之前**（文档最前段之一）；**T1 符号设计图章节排在原始外观之前**（先确认形态再出角色），**T2 区域特写章节排在变体之后**（先出角色再锁位置）。全部规则见 `rules/mark-system.md` CHR-14/15。

文档结构顺序：
`符号注册表(置顶) → 外观树 → 身份锚表 → 【T1 符号设计图章节】→ 原始外观 → 变体×N → 【T2 区域特写章节】→ 衔接说明`

**① 符号注册表（置顶表格）**

```
| # | 符号名 | 类型 | 位置（解剖锚点） | 分级 | 设计物（段落引用） |
|---|---|---|---|---|---|
| 1 | 月牙胎记 | 胎记 | 左肩锁骨上方约 3cm | T2 | 区域特写 §M2 |
| 2 | 银月符文 | 符文 | 左手掌心 | T1 | 符号设计图 §M1 |
```

- 无符号角色写一行：`无（本角色身上无 T1/T2 符号）`，跳过本节余下内容。
- 类型填：符文 / 纹身 / 徽记 / 烙印 / 胎记 / 痣 / 疤 / 雀斑。

**② T1 符号设计图（每枚叙事符号一张，1:1，中英双版）**

```
标题：{符号名}·符号设计图｜1:1
【设计依据】形态/含义/颜色/辉光/材质（剧本明写或 ⚠️视觉延展+锚点）
【构图】正交平铺，符号居中占约 70%，不含身体/肢体/透视
【背景】浅色符文→暗色背景 / 深色符文→浅色背景（按 CHR-14 背景对比法则）
【英文版】orthographic flat front view, the mark centered and filling ~70%,
          no body, no perspective; [light rune → dark background / dark rune → light background]
【负面清单】不要身体部位，不要透视变形，不要额外装饰元素
```

**③ T2 区域特写（每枚定位标记一张，默认 16:9 极端特写，中英双版）**

```
标题：{符号名}·区域特写｜9:16（或 3:4 更紧特写）
【构图】extreme close-up of {区域}，符号居中偏侧，同时框入 2~3 个解剖地标

【英文版】extreme close-up of the {region}, the {mark} centered slightly off,

          that pin its exact position
【负面清单】不要改变符号位置，不要额外修饰，不要模糊地标
```

## CAP-12 参考图占位标识（@资产名，用户约定 2026-08-29）

提示词中一切需要贴参考图的位点，**必须在该位置写一行中文占位标识 `@资产名`**——用户使用英文提示词为主，靠中文占位定位"这里要贴哪张图"，生成时把该行替换为对应参考图。

**写法与位置：**

| 提示词类型 | 位点 | 占位标识 |
|---|---|---|
| T2I 原始外观（含符号时） | ⑦体态与印记段的符号描述前 | `@{符号名}`（如 `@银白月裔印记`） |
| I2I 变体 | 锚定段段首 | `@{角色名}原始外观`（如 `@莱拉原始外观`） |
| I2I 变体（含符号时） | 锚定段印记行前 | `@{符号名}` |

**规则：**

1. 占位标识是 **CAP-10 无关内容禁令的唯一例外**——它不描述画面，但用户明确要求保留；替换后删除该行，不残留。
2. **中英版同位置同内容**：占位本身就是中文，英文版同样写 `@银白月裔印记`（不译成英文），用户在英文块里也能一眼定位。
3. 占位标识只写裸 `@资产名` 一行，禁止写成说明句（如"参考图：请在此处 @ 印记设计图"）。
4. 符号资产章节（T1 设计图 / T2 特写）自身不引用任何图，**无占位**。
5. 块外标题的 CAP-11「记得参考印记生成」标注保留，与占位标识构成双重提醒。
6. 命名与符号注册表/文档 ID 一致（`莱拉-原始` → `@莱拉原始外观`；`银白月裔印记` → 注册表同名）。
