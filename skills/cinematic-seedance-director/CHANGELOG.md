## [3.1.11] 2026-09-14 LINK-05 衔接 ≠ 缓冲：删时长不删接法

**动机**：同项目同一场戏，用户先反馈"中间缓冲太久"（上一版因此删掉了捡杆/走路/假安全整段），紧接着反馈——

> 「衔接呢，衔接呢，不同片段之间的衔接去哪了，还有不需要动不动两三秒的缓冲，非常拖节奏」

根因：执行者把**缓冲**（用时长填空白）和**衔接**（用切点接画面）当成同一件事，删缓冲时连衔接一起删了。`LINK-01/02` 早已规定"默认靠镜头设计与剪辑衔接""每段结尾设计可切点"，但**没有一条规则明确"删缓冲时衔接必须留下"**，也没给"位移怎么在不加时长的情况下交代"的标准做法。

**变更点**：
1. `rules/continuity-state.md` 新增 **LINK-05 衔接 ≠ 缓冲：删时长，不删接法**——
   - 对照表：缓冲（要砍，代价 2–3 秒/处）vs 衔接（必留，代价 0 秒）；判据=删掉这几句剧情是否仍连得上。
   - 规则一：每段必写入点（承接状态）+ 出点（末帧定格 + 切点类型），只占文字不占秒数。
   - 规则二：位移靠"上段末触发拍 + 动作刚启动"→ 下段首直接"人已在那儿"，禁止为衔接补走路镜头（含正/反例）。
   - 规则三：收尾一律末帧定格（0.3–0.5s 一格），删"慢慢安静/渐渐停下来/僵持两秒"；**明确例外**——CLOSE-01 台词收尾镜（0.5–1s）是技术保险，不属缓冲。
   - 规则四：状态守恒表（道具/门开合/光源）随段重申，防模型悄悄改背景。
2. `review/preflight.md`「空间与站位」新增三项硬性自检：逐段接缝表已出（入点/出点/切点类型三要素）、位移无走路镜头、缓冲已清除。

**影响文件**：`rules/continuity-state.md`（新增 LINK-05，编号只增不复用）、`review/preflight.md`（新增三项自检）。

## [3.1.10] 2026-09-14 HOR-07 补丁：反击"站着不动的微表情式惊恐"

**动机**：处理《别出声，跑！》54-2 旧校舍公厕（P3）时，按 HOR-07 写的"两级惊恐反应"（瞳孔骤缩/倒吸气/后蹭半步等微事件）在实际生成里全部退化成**人偶**——用户原话："所有分镜里面你给的反应都太呆板了，人物一动不动，表情也只有轻微变化"。根因：HOR-07 只规定了**微表情分级**，没规定**身体位移**、**多人之间的物理接触**和**反应结束后的收束拍**；写作者（AI）为求"写实"而不断往微事件里叠细节，反而把角色钉在原地。

**变更点**（`rules/horror-suspense.md` HOR-07 下新增四条补丁）：
1. **HOR-07a 身体位移是硬指标**：每个反应镜头里每个角色必须有一次看得见的位移或姿态改变（后退一步半/撞人/踉跄/跌坐/蹲下/滑坐靠墙）；表情与身体同时发生。附实测翻车写法与通过写法对照。
2. **HOR-07b 接触链**：多人惊吓必须写成连锁——A 猛退撞在 B 身上 → B 被撞得一激灵 → B 反应 → B 收住后扶 A。没有物理接触的多人反应，即使错峰也像排练。
3. **HOR-07c 三拍结构**：瞬时 → 连锁 → **收住**；收住分两向（镇静过来 / 垮下去）。"被吓一跳然后镇静过来"是同一个人身上的两拍。
4. **HOR-07d 同集三场不重复**：反应类型换成 **退 / 崩 / 垮**。
5. `review/preflight.md` P3 专项第 ⑤ 项：扩写为逐角色核对 HOR-07a~d。

**影响文件**：`rules/horror-suspense.md`（HOR-07 下新增 a/b/c/d，编号只增不复用）、`review/preflight.md`（P3 专项 ⑤ 项扩写）。
