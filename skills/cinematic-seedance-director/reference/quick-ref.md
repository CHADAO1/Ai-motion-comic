# 速查模块 — 表演与镜头语言（原 §19 附录）

> 编译时可选速查表，不要求每次全用；按当前段落最需要的部分取用。注意：本技能定位是"导演感知型"——用户已给明确导演方案时优先服从，本表只在补全最低导演意图时提供专业参照。与 references/ 下各文件内容保持一致（SHOT_LANGUAGE / RHYTHM_CONTROL / PROMPT_PATTERNS）。

## §1 情绪 → 身体微事件目录（替代"震惊/愤怒/自信"式标签）

| 情绪 | 可执行身体微事件 |
|------|------|
| 悲伤 | 双肩下沉、眼睑微垂、呼吸深长而不规则、咬肌绷紧、指节泛白、眼眶湿润泛光（未流泪）、嘴唇微启又闭合 |
| 愤怒 | 颞肌鼓起、鼻翼扩张、呼吸急促从鼻腔、双拳紧握、下颌前推、颈部血管可见、眼睛收窄凝视 |
| 恐惧 | 瞳孔放大、呼吸浅快、肩膀上提内收、手指微颤、肤色泛白、舔唇、后退半步 |
| 震惊 | 全身僵直、瞳孔骤缩后放大、呼吸暂停、嘴微张、手中动作停止 |
| 焦虑 | 目光频繁移位、手指无意识搓捻、咬唇、重心在双脚间转移、频繁吞咽、肩膀紧绷 |
| 压抑 | 表面平静但颞肌鼓起、呼吸刻意放缓、指甲掐入掌心、颈部绷紧、吞咽频率增加 |
| 喜悦 | 眼角细纹收紧、颧肌上推、呼吸轻快、肩膀放松、身体重心前移 |

## §2 微表情参考（Ekman 7 种 + 真假笑）

每种表情写"关键面部信号 + 泄漏点（0.2-0.5s 不受控泄漏）"，并明确**真假笑属性**。
- 真笑（Duchenne）= 颧大肌 + 眼轮匝肌同时收缩（眼带笑）；假笑（社会性）= 仅颧大肌（嘴角扬但眼不笑）。AI 默认生成假笑，需真笑时明确写"眼轮匝肌收缩、眼角出现鱼尾纹"。
- 完整对照表见 references/PROMPT_PATTERNS.md §3.5。

## §3 景别速查

| 术语 | 覆盖范围 | 情绪功能 |
|------|------|------|
| 大远景 | 人物是环境中的小点 | 建立尺度、孤独、史诗 |
| 远景/全景 | 全身 + 环境 / 全身 | 建立地理、空间关系 |
| 中远景/中景 | 膝上 / 腰上 | 社交距离、对话 |
| 中近景 | 胸上 | 亲密、对话强度 |
| 近景 | 头肩 | 情绪穿透、微表情 |
| 特写 | 面部占画面 70%+ | 内心、压抑情绪、揭示 |
| 大特写 | 眼/嘴/手/物 | 关键细节、强迫性聚焦 |

推进规则：普通对话 中景→中近景→近景（情绪升温）；动作 大远景→远景→中景→中近景快速压缩→远景释放；揭示 用突然跳到特写的大景别跳变；崩溃 近景→特写→大特写。

## §4 焦段与光圈

- 14-24mm 超广角：畸变、宏大、不安；F8+ 深景深，适合大尺度建筑/动作冲击。
- 28-35mm 广角：环境叙事、人在环境中；自然主义。
- 40-50mm 标准：最接近人眼透视、纪录片中性；对话/写实。
- 75-100mm 中长焦：压缩纵深、人像唯美；情绪特写。
- F1.2-1.8 浅景深：梦幻孤立、记忆/梦境；F2-2.8 对话情绪特写；F8-11 深景深：一切清晰、临床压迫。

## §5 构图与角度速查

| 构图 | 使用场景 |
|------|------|
| 三分法 | 标准对话、建立镜头（主体在竖三分线，负空间在视线对侧） |
| 对称构图 | 秩序、压迫、Kubrick 式不安（走廊/机构空间） |
| 引导线 | 走廊/道路/栏杆引导视线到主体 |
| 框中框 | 门框/窗框/拱框形成次级画框——窥视、困囿 |
| 负空间 | 主体只占 10-30%，余为空旷——孤独/未知威胁 |
| 前景遮挡 | 物体部分遮挡主体——窥视、分离感、写实 |
| 荷兰角（5-25°） | 失衡、威胁、精神错乱 |
| 纵深调度 | 前/中/后景三层同时有叙事信息（全景/长镜） |

角度：仰拍→主体高大压迫（反派权力/英雄）；俯拍→主体渺小脆弱（被监视/被困）；平视→平等真实；鸟瞰→命运视角/调度。

## §6 摄影机运动速查（CAM-01 + CAM-02~08）

### §6.1 八类摄影机基元（CAM-02）

任何摄影机运动都拆为八类基元，写镜头时**至少写清用哪几类**：

| 基元 | 中英 | Seedance 提示词写法示例 |
|---|---|---|
| **前进** | forward / push in | 摄影机缓缓前推，从半身逐渐推到面部特写 |
| **后退** | backward / pull out | 摄影机匀速后拉，逐渐露出房间全景 |
| **侧移** | pan / tracking / crab | 摄影机沿人物右侧平行侧移，保持半身景别 |
| **环绕** | orbit / arc | 摄影机以人物为圆心做180°环绕 |
| **升降** | boom up/down / crane | 摄影机从齐胸高度缓升至俯视 |
| **偏航** | yaw / pan left-right | 摄影机向右偏航跟随人物视线 |
| **俯仰** | tilt up-down | 摄影机向上俯仰，从脚尖扫至面部 |
| **惯性** | inertia / coast / whip | 摄影机随人物惯性自然减速停稳 |

> 一条镜头只允许一个**主基元**+一个**辅基元**，避免堆砌。详见 `rules/camera-motion.md` CAM-02。

### §6.2 摄影机运动 → 情绪功能（CAM-01 强化）

| 运动 | 情绪功能 |
|------|------|
| 固定 | 秩序、Fincher 式控制、庄严静止 |
| 缓推（0.5-1mm/秒感） | 亲密积累、内在压力、时间拉长 |
| 缓拉 | 孤立释放、语境扩展 |
| 环绕 | 角色研究、空间沉浸 |
| 呼吸手持 | 亲密写实、焦虑但非混乱（轻微摇摆） |
| 抖动手持 | 战斗/恐慌/迷失 |
| 撞推/甩摇 | 突然强调、能量转场 |
| 升降 | 揭示尺度、权力/情绪升降 |

**匹配原则**：冷静→固定或缓推；渐紧→缓推加速；恐慌→抖动手持；愤怒→激进手持/快速跟拍；悲伤→固定或缓拉；摄影机运动与角色呼吸节奏同步可制造潜意识共情（平静 4 秒吸/4 秒呼）。

### §6.3 镜头呼吸感（CAM-04）

写"真实拍摄"质感的三种手法：

- **略微提前/滞后**：摄影机比人物动作早 0.3-0.5 秒启动，或在人物停止后仍运动 0.3-0.5 秒再停
- **允许短暂遮挡**：前景人物/物体短时挡住镜头（"前景人物入画短暂遮挡镜头"）
- **允许短暂失焦**：快速运镜后允许 0.2-0.5 秒失焦再合焦

不要追求"每一帧都对焦/无遮挡/完美顺滑"——AI 会渲染成 CG 感，没有实拍呼吸。

### §6.4 光影写法速查（CAM-05）

写镜头必含五要素：

1. **主光源**（单一，最多一辅光）：台灯/壁炉/月亮/路灯/手电/法术辉光
2. **光影方向**：从哪射向哪（"主光源在人物右上方 45°，向左下方投射"）
3. **人物与光源相对位置**：脸朝向主光/背对/侧对
4. **环境光/人脸光随镜头变化**：摄影机环绕时光影分布必然变化（必须显式写）
5. **避免"光粘脸"**：光源是固定的，镜头动 →人脸光必变化

### §6.5 时序分段编排（CAM-08，**关键**）

Seedance 提示词的**实战最佳实践**——视频是时长受限的，需把动作/摄影机按时间窗显式切分。时间标签语法：

- `**0-2秒：**` / `**2-5秒：**` / `**5-8秒：**` / `**8-10秒：**`
- **单段内不超过 3 个时间窗**
- 每窗必含三要素：**人物动作 + 摄影机状态 + 二者同步关系**

**模板**：

```text
【镜头1】5秒
⚠️约5秒。
机位：24mm超广角 / 低机位贴近两人。
构图：浅景深，前景不时掠过虚化的湿草/树叶/兵器。

**0-2秒：**A右手长剑由下向上反手回挑，兵刃碰撞瞬间金属震颤、雨水从剑锋上炸开；
摄影机紧贴兵刃横向掠过，金属震颤与雨水飞溅同步入镜。
**2-5秒：**A右手剑顺势向左划弧横扫，冰冷兵刃几乎贴B的下颌与湿发横擦而过；
摄影机随剑弧向左跟拍，从低机位缓升至肩部高度。
```

**节奏匹配**：

- 快节奏动作戏：密集短窗（2-3 秒一个）
- 情绪戏：稀疏长窗（5-8 秒一个）
- 摄影机节奏与人物节奏共振

**反模式**：

- ❌ 长镜头无时间窗分块——Seedance 会让所有动作挤前 3 秒
- ❌ 时间窗内只写人物动作不写摄影机——摄影机会僵在原地

### §6.6 背景人物行为速查（CAM-07）

按"职业/身份 → 典型行为"对应：

| 类型 | 生活化行为 |
|---|---|
| 制服警察/保安 | 警戒维持边界、偶尔观察围观居民、调整对讲机 |
| 医护人员 | 低声交谈、检查仪表、调整设备 |
| 记者 | 压低声音交谈、拿塑料杯盖外带咖啡 |
| 普通居民 | 警戒带外探头、低语、举起/放下手机、躲避视线 |
| 侍者/服务员 | 托盘擦桌、斟酒、低声报单 |
| 学生/上班族 | 看手机、戴耳机低头走、看表赶路 |

**三原则**：独立+不完全同步；少数可短暂静止；服务于氛围不抢戏。

## §7 节奏弧线类型

| 弧线 | 结构 | 适用 |
|------|------|------|
| 慢燃 | 长镜（8-15s）→ 峰值突降至短镜（3-5s） | 惊悚调查、逼近危险 |
| 渐强 | 镜头逐段变短（8s→6s→4s→2s） | 爆炸前奏、时间线汇聚 |
| 脉冲 | 长镜（6-10s）与短冲击镜（1-2s）交替 | 暴力打断平静、喜剧节奏 |
| 持续音 | 单长镜内部调度变化，无切 | 沉浸、仪式、人物研究 |
| 自由落体 | 受控（4-6s）崩塌为快速混乱（0.5-1s） | 战斗、灾难、失控 |
| 呼吸空间 | 紧张（4-5s）与释放（8-12s）交替 | 情感对峙、浪漫张力 |

要点：高潮后必须有至少一个长镜（8-15s）做情绪恢复；镜头时长递减=压力上升，递增=释放。写长叙事段落时可在镜头规划里标注节奏走向。

## §8 失败模式 → 对策速查

| 失败模式 | 对策（写入失败模式警告/负面约束） |
|------|------|
| 身份漂移（跨切变脸） | "角色、道具、环境每个镜头完全一致。禁身份漂移。" + 每镜重申服装 |
| 服装混淆 | 每个镜头重申各角色精确服装 |
| 光溢 | "禁止[色]溢打在人物皮肤和服装上" |
| 广角畸变 | "禁桶形畸变、禁枕形畸变、禁鱼眼效果" |
| 多余镜头 | "严格只有 N 个镜头——禁止添加额外镜头" |
| 焦点漂移 | "焦平面严格锁定在[对象]——禁 rack focus、禁 autofocus 跳变" |
| 道具悬浮 | "禁漂浮道具——[道具]必须有支撑或手持" |
| 手部混乱 | 明确手指数量与动作 |
| 比例失真 | 每镜重申高度与距离 |
| 空背景 | 明确背景活动或"完全寂静"的缺席感 |
| 起始表情缺失（中性脸） | 每个角色首镜显式写明起始表情（眉/眼/嘴角/呼吸微事件），由当下情绪推导；"不继承表情"≠留白 |
