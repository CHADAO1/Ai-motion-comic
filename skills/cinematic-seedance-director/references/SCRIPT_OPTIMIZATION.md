# Script Optimization Reference

> The hidden feature guide for script optimization — triggered by "剧本优化" (4 characters).
> This module transforms a raw script into a production-ready screenplay with world-class emotional depth, visual specificity, character dynamism, and narrative logic.

---

## 1. Four Optimization Dimensions

### 1.1 画面情绪丰富 (Enriching Visual Emotion)

**Problem:** Amateur scripts write emotion as labels — "他很伤心" / "她看起来很生气". This tells; it doesn't show.

**Solution:** Convert every emotional label into a cascade of visual, physical, environmental cues that a camera can capture.

#### Before (Amateur)
```
小明站在窗前，很伤心。外面下着雨。
```

#### After (Professional)
```
小明站在窗前，双肩微微下沉，像有什么重物从肩胛骨上缓缓卸下。右手悬在窗玻璃上，指尖触到冰凉的表面又收回，留下一个短暂的雾痕。窗外雨势渐密，雨水沿玻璃流下，将城市灯火扭曲成流动的色块投射在他脸上。他的呼吸深长而不规则——一次漫长的吸气后，胸腔缓慢塌陷，空气从鼻腔带出一丝颤抖。眼眶泛红但未流泪，泪水积聚在眼眶使眼球开始泛光。嘴唇微启，停在要说什么的位置，最终只是轻轻闭合，下颌咬肌绷紧又松开。
```

#### Enrichment Checklist
- [ ] **环境映射情绪** — 天气、光线、温度、声音是否与角色内心状态形成呼应或反差？
- [ ] **道具承载情绪** — 角色手中的物品如何反映心理状态（紧握/松开/无意识摩挲）？
- [ ] **身体语言替代标签** — "悲伤"→双肩下沉+呼吸深长+眼眶泛红;"愤怒"→颞肌鼓起+双拳紧握+鼻翼扩张
- [ ] **微表情时间线** — 情绪不是瞬间的，是一个从萌芽→积聚→释放→余波的完整弧线（至少3-5拍）
- [ ] **空间感受化** — 角色对空间的感知是否被情绪扭曲？（孤独时房间显得空旷，恐惧时墙壁显得逼仄）

### 1.2 剧情扩写 (Plot Expansion / Beat Elaboration)

**Problem:** Under-written scenes skip the micro-beats that make actions feel earned and real. "他走到门口，打开了门" is a skeleton — the flesh is missing.

**Solution:** Expand each story beat into a chain of physical micro-actions, each carrying subtext.

#### Before (Amateur)
```
张警官走到门口，敲门。没有人应。他推开门走了进去。
```

#### After (Professional)
```
张警官走到402室门前，脚步在走廊尽头放缓。走廊灯管发出微弱的电流嗡鸣，在他头顶投下不稳定的冷白光。他站定在门前，目光扫过门框——锁舌槽有新鲜摩擦痕迹。他抬手敲门，三下，间隔均匀——这是职业习惯，不是焦急。等待。走廊尽头某处水管发出一声闷响。他又敲了三下，力度稍增。沉默。

他低头看了一眼手表——下午3:47。右手下沉到腰间，手指碰了碰枪套的搭扣——不是要拔枪，是一种无意识的安全确认。左手尝试门把。门把是凉的，金属的，转动时有一丝不正常的松旷——锁舌已经被破坏过。门向内推开十厘米，铰链发出一声低沉的呻吟。一股陈旧空气涌出——灰尘、纸张、和某种他暂时无法辨认的甜腻气息。

他没有立刻进入。身体微微侧转，背贴门框，用门扇作为掩体探头扫视室内——这是训练刻进骨头里的反应。视野从门缝切入：玄关鞋柜，一只倒伏的女式拖鞋。客厅一角可见——沙发扶手上的毯子团皱着，茶几上的水杯还有水，杯壁有水珠。没有声音。没有呼吸声。

他推开门，走了进去。
```

#### Expansion Checklist
- [ ] **动作分解为微动作链** — 每个"他做了X"拆解为3-5个物理步骤，每步带触觉/视觉/听觉细节
- [ ] **环境作为叙事者** — 环境细节（痕迹、气味、温度）在角色之前就讲述故事
- [ ] **职业本能嵌入** — 角色的职业身份如何影响其行为模式（警察的安全确认、医生的卫生习惯、军人的环境扫描）
- [ ] **感官全覆盖** — 视觉/听觉/触觉/嗅觉/温度感，至少覆盖3种感官
- [ ] **节奏张力** — 扩写不是加水稀释，是在动作之间插入呼吸、犹豫、评估的微节拍

### 1.3 人物表情动态 (Character Expression Dynamics)

**Problem:** Scripts treat faces as static masks — "她笑了笑" / "他皱了皱眉". Real human faces are in constant motion, emotions layering and shifting in real time.

**Solution:** Write facial performance as a choreographed sequence of micro-movements, each timed to an emotional beat.

#### Before (Amateur)
```
小美听到这话，笑了笑，但眼神里有一丝悲伤。
```

#### After (Professional)
```
小美听到这话，面部经历了一场不到三秒的微型风暴：

第一拍——嘴角上扬。这是一次条件反射式的社交微笑，颧大肌收缩，但眼轮匝肌纹丝未动——一个完美的假笑，训练有素的成年人都会的那种。

第二拍——假笑持续了0.8秒，然后嘴角的力量像断了线的风筝般松开。上唇微微回收，露出门牙边缘又遮住。笑容不是消失的，是塌陷的。

第三拍——眼轮匝肌开始真正介入，但不是微笑的那种收缩——是眶隔脂肪被向上推挤的微弱运动，眼睑下缘泛起一层极淡的红。眉毛的内1/3有0.5毫米的下沉——这个角度在解剖学上叫"眉内侧上提"（medial brow lift的反向），是悲伤最诚实的微表情标志，保罗·艾克曼在跨文化研究中标记过。

第四拍——她眨了一次眼，比正常频率慢0.3秒。眼睑合拢时睫毛颤动了一下——可能是泪膜在重新分布。眼睛再次睁开时，瞳孔下方有一层极薄的水光，但远未到流泪的程度。

第五拍——她用右手的食指和拇指捏了捏鼻梁，这个动作的表面理由是揉鼻子的疲劳感，实际功能是遮挡面部0.5秒，给情绪一个不被观察的喘息窗口。手放下时，表情已经重新组装完毕——嘴角挂着一个比刚才更深、更真实的微弧，但眼底的水光已经被她眨走了。

"我没事。"她说。声音平稳，气息从鼻腔出来，但句尾有一个极微弱的气声泄漏——声带在闭合和松开之间犹豫了一瞬。
```

#### Expression Dynamics Checklist
- [ ] **情绪分层** — 表面情绪（假笑）vs 真实情绪（悲伤），两者在同一张脸上同时存在或先后交替
- [ ] **面部肌肉精确命名** — 不要只写"笑了"，写颧大肌/眼轮匝肌/颞肌/咬肌/眉内侧上提，给AI可执行的具体肌肉指令
- [ ] **时间拍数** — 每个表情变化分解为3-7拍，每拍标注持续时间和触发原因
- [ ] **微表情泄漏** — 在控制的表面之下，0.2-0.5秒的微表情泄漏真实情绪（艾克曼微表情体系）
- [ ] **补偿动作** — 角色如何用手部动作（捏鼻梁/遮嘴/揉眼）来掩饰面部情绪泄漏
- [ ] **声带细节** — 声音的物理表现（气息位置/声带闭合状态/句尾气声泄漏）作为表情的延伸

### 1.4 逻辑关系优化 (Narrative Logic Optimization)

**Problem:** Scripts often have motivation gaps, cause-effect leaps, and character inconsistencies that break immersion.

**Solution:** Audit and fortify the narrative logic chain — every action must be motivated, every consequence must be earned, every character must behave consistently with their established psychology.

#### Logic Audit Categories

**A. 动机链补全 (Motivation Chain Completion)**
```
Before: 小明突然决定去调查那个废弃工厂。

Problem: 为什么是"突然"？什么驱动了这个决定？

After: 小明翻到父亲的旧笔记本，第23页被折角。页面上只有一行字，反复描了三次："别去西郊那栋楼。" 他盯着这行字看了很久，然后用橡皮试图擦掉——墨迹太深，只把纸擦出了毛边。他把笔记本合上，又打开，又合上。第三次打开时，他的手指停在被擦得模糊的"西郊"两个字上。

他站起来，从衣帽架后面拽出那件已经积灰的外套。
```

**B. 因果链加固 (Cause-Effect Fortification)**
```
Before: 她离开了他。三天后他去了酒吧。

Problem: "三天后"发生了什么？她为什么离开？他为什么去酒吧而不是别的地方？

After: 她在周二下午离开，带走了衣柜里属于她的那一半——挂衣杆突然空出的半段比任何争吵都更刺眼。周三他没出门，把所有窗帘拉上，在沙发上坐了一整天，手机在她离开前最后发的消息页面停留，屏幕反复亮起又熄灭。周四他开始收拾她没带走的东西——一个马克杯、三本书、一双拖鞋——每拿起一样就停在手里很久。周五傍晚，天暗下来时，他发现冰箱里还有她两周前做的咖喱，保鲜膜上有她用记号笔写的"热一下就能吃"。他关上冰箱门，拿起钥匙。

去了街角那间酒吧——不是因为爱喝酒，是因为那间酒吧的酒杯和她送他的那套一模一样。
```

**C. 角色一致性审计 (Character Consistency Audit)**
```
Check: 角色在第3场表现怯懦，第7场突然英勇——中间的心理转折点在哪里？

Fix: 在第5场插入一个触发转变的事件——他目睹了某个不公正，或听到了某句话，
      使他的恐惧被更大的情绪（愤怒/愧疚/爱）所覆盖。恐惧没有消失，
      它被另一种更强的情绪暂时压制了——这才是真实的角色弧线。
```

**D. 场景过渡逻辑 (Scene Transition Logic)**
```
Check: 场景A（白天·办公室）到场景B（夜晚·家中）——中间的时间缺口发生了什么？

Fix: 不需要全写出来，但需要一个"桥接暗示"——
      场景A末尾: 他看了看手表，3:15。"今天得早点回去。"
      场景B开头: 家门口，他放下公文包，走廊灯是声控的，亮起时照出他疲惫的脸。
      暗示了：提前下班 → 通勤 → 到家 → 疲惫。观众的大脑自动填充了中间过程。
```

**E. 信息递进逻辑 (Information Reveal Logic)**
```
Check: 观众在第X场知道了什么？在Y场又知道了什么？信息揭露是否有序递进？

Fix: 梳理信息揭露时间线——确保:
      - 每条关键信息的揭露都有一个"铺垫→暗示→揭示→影响"的完整弧
      - 不存在"突然全知道"的跳变
      - 不存在"已经知道了却又表现得不知道"的不一致
```

#### Logic Audit Checklist
- [ ] 每个重大决定是否有前置动机（不是"突然"）
- [ ] 每个因果关系是否有中间步骤（A→?→B中的"?"是否被暗示）
- [ ] 角色行为是否与已建立的心理档案一致（如不一致是否有转折事件支撑）
- [ ] 场景过渡是否有桥接暗示
- [ ] 信息揭露是否有序递进
- [ ] 对话是否回应了前文信息（而非各说各话）
- [ ] 时间线是否自洽

## 2. The Optimization Workflow

### Phase 1 — Diagnostic Scan (诊断扫描)

Read the entire script. Output a diagnostic report organized by the 4 dimensions:

```
═══════════════════════════════════════════════════
剧本优化诊断报告
═══════════════════════════════════════════════════

【画面情绪】
场景3: "小明很伤心" — 情绪以标签形式呈现，缺乏可视化
场景7: "气氛紧张" — 环境未承载情绪，仅靠叙述标注
场景12: "她笑了" — 未描写笑容的真实/虚假属性

【剧情扩写】
场景3: "他走到窗前" — 动作骨架化，无微动作链
场景5: "他们交谈了一会" — 整段对话被跳过
场景9: "她离开了" — 离开过程完全省略

【人物表情动态】
场景1: 小美"笑了笑" — 静态表情，无时间拍数
场景6: 张警官"皱眉" — 无肌肉层级的微表情分解
场景11: "他看起来很生气" — 标签替代表演

【逻辑关系】
场景2→3: 时间跳跃无桥接暗示
场景4: 小明突然决定调查 — 动机缺失
场景8: 角色从怯懦到英勇 — 无转折事件支撑
```

End Phase 1 with: *"诊断完成。是否需要对全部问题进行优化？还是指定某些维度/场景？"*

### Phase 2 — Optimization Proposal (优化提案)

For each diagnosed issue, propose a specific rewrite. Group by scene, not by dimension (a scene may have issues in multiple dimensions):

```
═══════════════════════════════════════════════════
场景3 优化提案
═══════════════════════════════════════════════════

原文本:
> 小明站在窗前，很伤心。外面下着雨。他看了看手表，决定出去走走。

优化维度: 画面情绪 + 剧情扩写 + 人物表情动态

优化后文本:
> [完整优化后的文本]

优化说明:
• 画面情绪: 将"很伤心"分解为双肩下沉+呼吸深长不规则+眼眶泛红+嘴唇微启又闭合，5拍弧线
• 剧情扩写: "看了看手表"扩展为触觉(表盘玻璃温度)+视觉(指针位置)+认知(时间意义的联想)
• 人物表情动态: 添加面部微表情4拍——嘴角条件反射式上扬→塌陷→眼轮匝肌泛红→眨眼时睫毛颤动
```

### Phase 3 — Full Optimized Script (完整优化剧本)

Apply all approved optimizations. Output the complete optimized script as a `.txt` file.

Structure:
```
═══════════════════════════════════════════════════
优化剧本 | [标题]
优化维度: 画面情绪 · 剧情扩写 · 人物表情动态 · 逻辑关系
═══════════════════════════════════════════════════

场景1 | INT. [位置] — [时间]
[优化后的完整场景文本]

场景2 | EXT. [位置] — [时间]
[优化后的完整场景文本]

...

═══════════════════════════════════════════════════
优化摘要:
• 画面情绪: N处标签情绪替换为可视化描写
• 剧情扩写: N处骨架动作扩展为微动作链
• 人物表情动态: N处静态表情分解为多拍微表情序列
• 逻辑关系: N处动机/因果/过渡/一致性修复
═══════════════════════════════════════════════════
```

## 3. Optimization Quality Standards

### Emotional Enrichment Standards
- Every emotion label ("伤心"/"生气"/"害怕") MUST be replaced with at least 3 physical micro-events
- Every environment description MUST interact with the character's emotional state (mirror/contrast/distort)
- Every prop the character touches MUST reflect their internal state (grip pressure/withdrawal/unconscious fidgeting)

### Plot Expansion Standards
- Every action shorter than 2 sentences MUST be expanded to include at least 3 sensory channels (visual/auditory/tactile/olfactory/thermal)
- Every scene transition MUST include at least 1 bridging detail (time marker/environmental shift/object carry-over)
- Every "they talked" or "they went" summary MUST be expanded into at least 3 physical micro-steps

### Expression Dynamics Standards
- Every facial expression MUST be decomposed into at least 3 timed beats (①②③)
- Every smile MUST be categorized as genuine (Duchenne: 眼轮匝肌参与) or fake (social: 仅颧大肌)
- Every suppressed emotion MUST include at least 1 micro-expression leak (0.2-0.5s involuntary display)
- Every emotional masking gesture MUST be noted (touching nose/covering mouth/rubbing eye as emotional camouflage)

### Logic Optimization Standards
- Every "突然" (suddenly) in character motivation MUST be replaced with a triggering event
- Every scene time-gap MUST have a bridging implication (dialogue cue/object carry-over/environmental change)
- Every character behavior change MUST have a documented turning point (event + emotional override)
- Every key information MUST follow the "铺垫→暗示→揭示→影响" progression

## 4. Paul Ekman Micro-Expression Reference

For character expression dynamics, draw from the 7 universal micro-expressions:

| Emotion | Key Facial Signal | Duration | Leakage Point |
|---------|-------------------|----------|----------------|
| 悲伤 (Sadness) | 眉内侧上提 + 上眼睑微提 + 嘴角下拉 | 0.5-3s | 眉头持续内拧 |
| 愤怒 (Anger) | 眉下拉聚拢 + 眼睑收紧 + 嘴唇紧抿或张口露齿 | 0.2-0.5s | 颞肌可见鼓起 |
| 恐惧 (Fear) | 眉上提聚拢 + 眼睛睁大 + 嘴微张唇角向两侧拉 | 0.2-0.5s | 上眼睑白圈暴露增加 |
| 惊讶 (Surprise) | 眉上提 + 眼睛睁大 + 嘴张 | 0.2-1s (最短微表情) | 与恐惧的区别: 无聚拢 |
| 厌恶 (Disgust) | 鼻翼皱起 + 上唇上提 + 下唇下推 | 0.5-2s | 鼻唇沟加深 |
| 轻蔑 (Contempt) | 单侧嘴角上提（不对称） | 0.5-2s | 仅一侧颧大肌收缩 |
| 快乐 (Joy) | 眼轮匝肌收缩（鱼尾纹收紧）+ 颧大肌上推 + 嘴角上扬 | 持续性 | 眼部参与度区分真假笑 |

### Duchenne Smile (真笑) vs Social Smile (假笑)
- **Duchenne (真):** 颧大肌 + 眼轮匝肌同时收缩 → 眼角出现鱼尾纹，面颊上推
- **Social (假):** 仅颧大肌收缩 → 嘴角上扬但眼部无参与，目光不"笑"
- **在剧本中标注:** 优化时明确标注每个笑容的真假属性，让演员和AI都有可执行的指令

## 5. Optimization vs Prompt Generation

| Aspect | 剧本转提示词 (6字触发) | 剧本优化 (4字触发) |
|--------|------------------------|---------------------|
| Input | 完成度较高的剧本 | 任意状态的剧本（含草稿） |
| Output | Seedance 提示词列表 | 优化后的完整剧本 |
| Focus | 镜头语言、构图、节奏 | 画面情绪、剧情扩写、表情动态、逻辑关系 |
| Relationship | 可在优化后的剧本上运行 | 优化后的剧本可继续转为提示词 |
| Workflow | 3-phase: 解析→匹配→生成 | 3-phase: 诊断→提案→输出 |

### Recommended Workflow
1. 用户上传草稿剧本 → 触发"剧本优化" → 获得优化剧本
2. 用优化后的剧本 → 触发"剧本转提示词" → 获得电影级 Seedance 提示词

两个功能形成完整的从草稿到提示词的创作流水线。
