# 审查模块 C2 — Audit 执行审查机制（硬性，防遗漏）

> Preflight 审**产物内容**；本模块审**执行完整性**——强制步骤是否真的执行过。两套审查都要过，缺一不可。规则编号 AUD-*。

## AUD-01 审查时机（两段式：中途 + 终审）

1. **中途审查** — 固定在 S3（空间图）之后、S4 写提示词之前。只审 A 组（A1–A4：记事本 / 反推缓存 / 空间图 / 站位逻辑）。缺项立即补执行，全部 ✅ 才进 S4。
2. **终审** — 固定在 S4 输出后、交付前最后一步。审全清单（A1–A14，含 A9b）+ Preflight 全项。全部 ✅ 且审查报告已输出，才可交付。

## AUD-03 审查报告（随交付强制输出，缺失即未完成）

终审通过后，**必须在交付说明中输出审查报告**：逐项列出 A1–A14（含 A9a/A9b）的 ✅/❌ 与证据，保存到 `{剧本目录}\pipeline\06_审查报告.md`。规则：

- 任一项 ❌ → **先补执行，再重跑该项直到 ✅**，禁止带着 ❌ 交付。
- 补执行改动过提示词 → 按 AUD-04 重跑全流程。
- **证据形式约束**：可计算项（时长/条数/路径）必须引用脚本原始输出、JSON 字段值或磁盘路径，禁止转述；A8/A9/A11 多段任务以《逐段验收表》为证据载体（模板见 workflows/mode1-prompt.md §S4.1）；空泛结论（"已检查""无问题"）按未检查处理。
- **审查报告缺失 = 审查被跳过 = 任务未完成，禁止交付。** 交付内容里没看到审查报告时，必须立即返回补审查，不能直接结束。

## AUD-04 审查再触发（防漏中漏）

以下任一情况发生，重新执行本模块全流程后再交付：
- 任何提示词段落被修改 / 重写
- 拆段方案变化（段数 / 分界点 / 时长变化）
- 空间图被重新生成或站位调整
- 资产图 / 反推缓存新增或替换

## AUD-05 补执行规则

审查发现缺项时，直接补做该步骤（不是口头确认"已执行"）：
- 没读记事本 → 立即读，把历史反馈纳入本次编译，重跑 A1。
- 没查缓存 → 立即查：有则读取，无则反推并写入缓存，重跑 A2。
- 没出空间图 → 立即生成三件套并按图审查站位，重跑 A3–A4。
- 没对账 → 立即逐镜列出画面角色与资产锁定比对，补锁缺失角色，重跑 A5–A6。
- 没估时 / 路由错 / 漏收尾镜 → 立即按 TIME / RT / CLOSE 修正，重跑 A9–A11。
- 漏台词（门1 门2 报缺失）→ 立即按 TIME-05b 补齐拆段表 beats / 提示词配音指令 / 台词表，重跑 A9b 与 A13。
- 没生成台词中英对照 TXT，或 TXT 与修订后提示词不同步（条目/段头时长对不上）→ 立即按 TXT-01 逐条收录/重同步并更新 TXT，重跑 A13。
- 补执行后提示词有变化 → 按 AUD-04 重跑全流程。
- 全部补完后更新 `pipeline\manifest.json` 对应 stage status。

## AUD-06 适用范围

- Mode 1（剧本转提示词）：本模块全流程强制。
- Mode 2（剧本优化）：强制三阶段完整性（诊断 → 提案 → 完整优化，见 workflows/mode2-script-opt.md），交付时附三阶段完成声明；优化结果转入 Mode 1 时自动触发本模块全流程。
