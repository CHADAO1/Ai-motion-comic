# 审查模块 C1 — Preflight 内容检查清单

> Stage S6 第一道门：审**产物内容**。逐项过，任何一项不过先修复再输出。括号内是规则出处（rules/*.md 的规则编号），需要细则时才去读对应模块。

## 使用原则（防形式化通过）

1. **完整性以要素计数为准**——七要素是否逐项在位、表演弧线是否≥3拍、关键句是否六参数齐全、文件是否三件套。**禁止以最低字数为标准**：提示词长短由内容决定，短而全即合格。
2. **每个 ✅ 必须附可核查证据**：文件路径 / 脚本原始输出 / 具体数值 / 角色名单。"已检查""无问题"这类空泛结论视为未检查。
3. **多段任务必须附《逐段验收表》**（模板见 workflows/mode1-prompt.md §S4.1），作为时长/站位/收尾镜各项的证据载体。
