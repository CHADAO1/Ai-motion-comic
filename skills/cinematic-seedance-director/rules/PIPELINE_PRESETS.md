# 规则模块 R0 — 管线预设（Pipeline Presets）

> **本文件是所有常量（画幅 / 时长 / 模型 / 语言 / 题材）的唯一事实源。**
> 总控在开工第一步（S0 之前）读本文件，确定本次任务的管线 ID，后续所有阶段一律按该管线的常量执行。
> 规则编号 PP-*。

## PP-01 四套管线速查

| ID | 管线名称 | 画幅 | 单段落时长 | 模型 | 语言 | 题材 | 受众 |
|----|---------|------|-----------|------|------|------|------|
| **P1** | 国内·下沉中老年 | **9:16** | **12–15 秒（硬）** | **Seedance 2.0** | **中文** | 家庭伦理 / 亲情 / 逆袭 / 婆媳 / 养老 | 30 岁+ 下沉市场 |
| **P2** | 国内·女频恋爱 | **16:9** | **12–15 秒（硬）** | **Seedance 2.0** | **中文** | 青春 / 都市恋爱 / 甜宠 / 虐恋 | 年轻女性 |
| **P3** | 国内·女频诡异恐怖 | **16:9** | **12–15 秒（硬）** | **Seedance 2.0** | **中文** | 悬疑 / 恐怖 / 诡异 / 灵异 | 年轻女性 |
| **P4** | 海外（出海） | **21:9** | **≤30 秒** | **Seedance 2.5** | **英文** | 出海长片制式 | 海外观众 |

- P1/P2/P3 统称**国内管线**，一律 Seedance 2.0 + 中文台词。
- P4 为**海外管线**，保持本技能原始出厂默认值（2.5 / ≤30s / 21:9 / 英文）。
- ⚠️ **国内管线（P1/P2/P3）的每段时长硬性落在 12–15 秒**，无例外（含过场段）。这是用户长期要求，**不得下调、不得因压缩总时长而越界**。段数由内容量决定（`段数 ∈ [ceil(内容量/15), floor(内容量/12)]`），详见 timeline-splitting.md **TIME-02b / TIME-02c**。

## PP-02 管线判定（强制执行，不得跳过）

开工时按以下顺序确定管线：

1. **用户明示** → 直接采用（"用 P1"、"下沉管线"、"女频恐怖"等表述均算明示）。
2. **用户说了题材或平台** → 按题材映射：
   - 家庭伦理 / 亲情 / 婆媳 / 逆袭 / 养老 / 中老年 → **P1**
   - 青春 / 校园 / 都市恋爱 / 甜宠 / 虐恋 / 霸总 → **P2**
   - 悬疑 / 恐怖 / 诡异 / 灵异 / 惊悚 → **P3**
   - 出海 / 海外 / YouTube / 英文剧本 → **P4**
3. **完全没说** → **必须向用户提问确认，禁止擅自假设**。提问模板：
   > "这次走哪条管线？① 国内下沉中老年（9:16 / 12-15s）② 国内女频恋爱（16:9 / 12-15s）③ 国内女频诡异恐怖（16:9 / 12-15s）④ 海外出海（21:9 / ≤30s）"

> ⚠️ 用户偏好记录：银时的主力管线是 **P1（国内下沉中老年）**。仅在用户明确提及其他题材时才切换。

## PP-03 各管线详细参数

### P1 国内·下沉中老年

| 项 | 值 |
|---|---|
| 画幅 | 9:16（竖屏，1080×1920 起） |
| 单段落时长 | **12–15 秒（硬性）** |
| 模型 | Seedance 2.0（单次上限 15s，正好覆盖） |
| 语言 | 中文台词为主，口型按中文 |
| 受众心理 | 下沉市场 30 岁+；**节奏要慢、情绪要足、因果要直白**，不要文艺留白 |
| 镜头偏好 | 中近景为主，特写给情绪；少用大远景（竖屏看不清） |
| 表演强度 | **放大一档**：下沉市场吃"明牌情绪"，微表情要足够可读 |
| 色调 | 偏暖、饱和度适中，忌阴间冷调 |
| 开场 | 必须劲爆、抓人（3 秒内出冲突或悬念） |
| 结尾 | 悬念型 / 爽剧型钩子，保留存 |

### P2 国内·女频恋爱

| 项 | 值 |
|---|---|
| 画幅 | 16:9（横屏） |
| 单段落时长 | **12–15 秒（硬性）** |
| 模型 | Seedance 2.0 |
| 语言 | 中文 |
| 受众心理 | 年轻女性；**氛围感 > 剧情**，磕点是第一生产力 |
| 镜头偏好 | 双人同框过肩、正反打；大量浅景深柔焦特写 |
| 表演强度 | 克制、眼神戏；男主"苏感"靠光影和微表情，不靠台词量 |
| 色调 | 清透、奶油感 / 都市夜景霓虹；低对比柔和 |
| 音乐联想 | 编译提示词时可在声音设计段预留抒情配乐位 |

### P3 国内·女频诡异恐怖

| 项 | 值 |
|---|---|
| 画幅 | 16:9（横屏） |
| 单段落时长 | **12–15 秒（硬性）** |
| 模型 | Seedance 2.0 |
| 语言 | 中文 |
| 受众心理 | 年轻女性；**要的是"吓一跳 + 细思极恐"，不是血腥** |
| 镜头偏好 | 手持晃动 / 监控视角 / 长镜头留白；黑暗中留大量负空间 |
| 表演强度 | 惊恐反应分两级：① 瞬间惊吓（快）② 后知后觉的毛骨悚然（慢） |
| 色调 | 低照度冷青/暗绿；光源单一（手机光/手电/走廊灯） |
| 强制约束 | **见 rules/horror-suspense.md（HOR-*），恐怖题材必读** |
| 合规红线 | 平台对恐怖题材审核更严，**必须过 script-content-audit 的国内平台规则集** |

### P4 海外（出海）

| 项 | 值 |
|---|---|
| 画幅 | 21:9 |
| 单段落时长 | ≤30 秒一次生成，不拆 |
| 模型 | Seedance 2.5 |
| 语言 | 英文台词 + 中英对照 TXT（剪辑用） |
| 文化坐标 | **按剧本地域做（非默认套壳）**：欧美题材（如《女巫与狼王》）须按该地时代+地域的材质/建筑/服装/道具与文化语感走，当作"本地导演拍给本地观众"，见 `script-asset-prompt-design/rules/cultural-context.md`（CUL-*）与 `character-asset-prompt-design/rules/cultural-context.md`（ETH-*） |
| 其他 | 沿用 rules/routing.md RT-04（2.5 编译原则）与全部原有默认值 |

## PP-04 常量随管线切换的清单（改动时全局同步）

切换管线时以下常量必须全部同步，缺一处即视为未切换：

| 常量 | 出现文件 |
|------|---------|
| 画幅 | SKILL.md 铁律1 / rules/purity-wording.md / review/preflight.md / references/PROMPT_PATTERNS.md |
| 单段时长上限 | rules/timeline-splitting.md / rules/routing.md / review/audit.md A9 |
| 模型版本 | rules/routing.md / manifest.json `model` 字段 |
| 台词语言 | rules/dialogue-sound.md（P4 才出中英对照 TXT，P1-P3 只出中文台词表） |
| 估时脚本参数 | `scripts/estimate_timeline.mjs --model 2.0`（段上限由 `--model` 决定，**不要传 `--max-seconds`**） |

## PP-05 manifest 记录

`pipeline\manifest.json` 必须写入管线信息：

```json
{
  "script": "剧本名",
  "mode": "1",
  "pipeline": "P1",
  "aspectRatio": "9:16",
  "maxSeconds": 15,
  "model": "2.0",
  "language": "zh",
  "stages": { "...": "..." }
}
```

- 已有 manifest 但缺 `pipeline` 字段 → 视为未定管线，回填后再继续。
- 用户中途要求换管线 → 按 SKILL.md §5 回退机制，受影响 stage 全部置 pending 重跑。
