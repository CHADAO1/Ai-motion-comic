# 规则模块 R5 — 摄影机运动方法论与时序编排（CAM-02~08 / SEQ-*）

> 总控在 Stage S4（镜头编译）和 S5（提示词组装）读本文件。
> 与 shots-action.md 的 CAM-01（镜头编译：摄影机运动作为七要素之一）互补——CAM-01 给"摄影机运动作为一行元素"，本文件给"如何写出有信息动机的摄影机运动"。
> 速查见 `reference/quick-ref.md` §6（八类摄影机基元 + 时序分段编排示例）。

## 核心思想（与 CAM-01 同源，与图1方法论同步）

画面里不只有"人物的动机"，**摄影机也有自己的信息动机**——它是观众的"眼睛"，是另一个角色。把摄影机想成"贴近人物飞行的虚拟无人机"，每次运动都要服务于观众带入/情绪推进/信息揭示。无目的的横移、环绕、旋转、随机推拉会让镜头"空转"，观众视线无处安放。

## CAM-02 摄影机八类基元（基础词汇）

任何摄影机运动都拆解为这八类基元的组合（来源：图1方法论#1）。写镜头时**至少写清用哪几类**，不要写"运动推进"这种泛词。

| 基元 | 中英 | 典型场景 | Seedance 写法示例 |
|---|---|---|---|
| **前进** | forward / push in | 揭示、逼近、进入情绪 | `摄影机缓缓前推，从半身逐渐推到面部特写` |
| **后退** | backward / pull out | 孤立、收束、揭出更大语境 | `摄影机匀速后拉，逐渐露出房间全景` |
| **侧移** | pan / tracking / crab | 平行跟随、空间扫过 | `摄影机沿人物右侧平行侧移，保持半身景别` |
| **环绕** | orbit / arc | 角色研究、揭示360°空间 | `摄影机以人物为圆心做180°环绕` |
| **升降** | boom up/down / crane / pedestal | 权力变化、尺度揭示 | `摄影机从齐胸高度缓升至俯视` |
| **偏航** | yaw / pan left-right | 视线跟拍、注意力转移 | `摄影机向右偏航跟随人物视线` |
| **俯仰** | tilt up/down | 仰望/俯视、情绪转折 | `摄影机向上俯仰，从脚尖扫至面部` |
| **惯性** | inertia / coast / whip | 收势、甩切、转场 | `摄影机随人物惯性自然减速停稳` |

> 一条镜头内可叠加多类（如"前推+右偏航"= 边逼近边跟视线），但每条镜头只允许一个**主基元**和一个**辅基元**，避免堆砌。

## CAM-03 摄影机运动的触发原因（强化 CAM-01）

摄影机运动**必须有触发**——来自下列至少一类：

1. **声音触发**：有人说话/有环境音/有撞击声→ 镜头随声源运动
2. **视线触发**：A 看向 B → 镜头随 A 的视线方向移向 B
3. **人物动作触发**：人物开始移动 → 镜头跟；人物停止 → 镜头停止
4. **特效触发**：能量场展开/法术爆发 → 镜头拉远揭全貌，或推近到能量中心
5. **注意力转移**：观众注意力应从 A 移到 B → 镜头做引导性运动

**禁止**：无意义横移、单纯环绕 360°、随机推拉只为"显得动态"。Seedance 容易把这类空转镜头渲染成"摄影机无目的飘移"，破坏叙事节奏。

## CAM-04 保留镜头呼吸感（来源：图1方法论#2）

真实摄影有"提前/滞后"，AI 视频提示词里**显式写出来**反而能帮模型保持"真实拍摄感"：

- **略微提前 / 滞后**：摄影机比人物动作早 0.3-0.5 秒启动，或在人物停止后仍运动 0.3-0.5 秒再停
- **允许短暂遮挡**：人物或前景物体短时挡住镜头（如从树后绕出、人物走过镜头前），可写"前景人物入画短暂遮挡镜头"
- **允许短暂失焦**：快速运镜后允许 0.2-0.5 秒的失焦再合焦（"摄影机在急推后面部短暂失焦再对实"）

> 不要追求"每一帧都对焦/无遮挡/完美顺滑"——这种"完美"反而像 CG 动画，没有实拍呼吸。

## CAM-05 光影方向 + 主光源（来源：图1方法论#3）

写镜头时必须明确：

1. **主光源是什么**（单一主光源，最多一辅光）：台灯/壁炉/月亮/路灯/手电/法术辉光等
2. **光影方向**：从哪射向哪（"主光源在人物右上方 45°，向左下方投射"）
3. **人物与光源相对位置**：人物脸朝向主光源/背对主光源/侧对
4. **环境光/人脸光随镜头运动的变化**：摄影机环绕时，主光源不变但人物脸光的明暗分布会变——必须显式写出（如"摄影机环绕到人物背光侧时，半张脸陷入阴影"）
5. **避免"无论怎么走光都跟着人脸"**：光源是固定的，摄影机运动时人物相对光源的位置会变，光影分布**必然变化**

> 写"光从上方柔和洒落"这种绝对静止的光线描述，会让 Seedance 在镜头运动时失去光影变化，模型会让光"粘在脸上"。

## CAM-06 角色空间编号与位置变化（来源：图1方法论#4）

### 角色编号
多角色场景必须给主角编号（A、B、C……），并在镜头全程保持编号一致。台词行也用编号（"A 看向 B" 而非"她看向他"）。

### 空间关系三要素
每个动态镜头**至少写清两个**：

1. **人物间相对距离**：A 在 B 左前方 1.5 米；A 与 B 拉开至 5 米
3. **镜头离人物/地面的距离**：摄影机离 A 约 1.2 米肩高；离地面约 0.3 米低机位
4. **运镜开始→终点的位置变化**：从 A 的中景 → 推到 A 的面部；摄影机起点在 A 身后 → 终点绕到 A 面前

> 写"摄影机向前推"是不够的——必须写清"从哪推到哪，距离变化多少"。

## CAM-07 背景人物生活化（来源：图1方法论#5）

有人的场景**禁止空背景**。背景人物必须有独立、不完全同步的生活化行为，且人数/分布与场景合理。

### 写法模板

按"职业/身份 → 典型行为"对应速查：

| 背景人物类型 | 生活化行为示例 |
|---|---|
| 制服警察 / 保安 | 警戒维持边界、偶尔观察围观居民、调整对讲机 |
| 医护人员 | 低声交谈、检查仪表、调整设备 |
| 记者 | 压低声音交谈、拿塑料杯盖的外带咖啡、对镜头比划 |
| 普通居民 | 警戒带外探头、低语、举起或放下手机、躲避视线 |
| 侍者 / 服务员 | 托盘擦桌、斟酒、低声报单 |
| 学生 / 上班族 | 看手机、戴耳机低头走、看表赶路 |

### 三原则

1. **独立 + 不完全同步**：每个人做自己的事，节奏错开，不要集体"东张西望"
2. **少量可短暂静止**：少数人短时间内保持静止可以（"少数人可短时间保持静止，不要求所有背景人物持续运动"——避免模型让整个背景僵掉）
3. **服务于氛围**：背景人物的行为应烘托氛围，不要抢戏（警察场景不要写"警察在笑谈"）

## CAM-08 时序分段编排（来源：图2方法论，SEQ-* 配套）

> 这一节是 Seedance 2.0/2.5 提示词的**实战最佳实践**——视频是时长受限的（12-15 秒/段 或 ≤30 秒），需要把镜头内的动作/摄影机/台词**显式按时间窗切分**，让模型逐段执行。

### 时间标签语法

按动作/镜头自然切分点写时间窗，常用：

- `**0-2秒：**`（开镜前 2 秒）
- `**2-5秒：**`（中段）
- `**5-8秒：**`（后续）
- `**8-10秒：**`（收尾）

时间窗长度可按节奏调整，但**单段内不要超过 3 个时间窗**（3 个以上模型会乱）。两段衔接处要写"切换"——`⚠️约X秒后——硬切至下一段。` 或 `摄影机持续跟拍进入下一段`。

### 每个时间窗内必含三要素

1. **人物动作**：具体动作（"右手由下向上反手回挑长柄"）
2. **摄影机状态**：运动或静止（"摄影机紧贴兵刃横向掠过"）
3. **人物与镜头的同步**：动作结束 = 镜头到达某位置（"人物蹬地横扫的同时，摄影机已沿泥地横移至其右肩"）

### 时序编排模板

```text
【镜头1】5秒
⚠️约5秒。
机位：24mm超广角 / 低机位贴近两人。
构图：浅景深，前景不时掠过虚化的湿草/树叶/兵器。
景深：浅景深，兵器保持清晰，背景化入冷雾。

**0-2秒：**A右手长剑由下向上反手回挑，兵刃碰撞瞬间金属震颤、雨水从剑锋上炸开；
摄影机紧贴兵刃横向掠过，金属震颤与雨水飞溅同步入镜。
**2-5秒：**A右手剑顺势向左划弧横扫，冰冷兵刃几乎贴B的下颌与湿发横擦而过；
摄影机随剑弧向左跟拍，从低机位缓升至肩部高度。
```

### 节奏匹配原则

- **段落时长包络**：每段时间窗长度按管线允许段长调整——P1-P3 每段 ≤15 秒、P4 每段 ≤30 秒（见 rules/PIPELINE_PRESETS.md）
- **时间窗密度**：快节奏动作戏用密集短窗（2-3 秒一个）；情绪戏用稀疏长窗（5-8 秒一个）
- **节奏共振**：摄影机运动节奏与人物动作节奏共振（急促动作 → 急促运动/短窗；绵长情绪 → 缓慢运动/长窗）

## 反模式（Seedance 易翻车）

- ❌ 写"摄影机运动推进"——不告诉模型怎么推进（CAM-02 缺）
- ❌ 写"摄影机跟随人物"——没有触发原因（CAM-03 缺）
- ❌ 长镜头无时间窗分块（CAM-08 缺）——Seedance 会让所有动作挤在前 3 秒
- ❌ 写"光从上方洒落"后镜头大范围运动（CAM-05 缺）——光会"粘脸"
- ❌ 写"围观群众看着事件"——没具体行为（CAM-07 缺）——模型会让群众僵立
- ❌ 时间窗内只写人物动作不写摄影机状态（CAM-08 缺）——摄影机会僵在原地
