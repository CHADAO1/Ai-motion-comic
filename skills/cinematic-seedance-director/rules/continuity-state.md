# 规则模块 R6 — 片段衔接与状态守恒

> 总控在 Stage S2（拆段）与 S4 读本文件。规则编号 LINK-/SPLIT-/CLOSE-/ANCHOR-/CON-/VFX-/DEST-*。

## 默认衔接方式（LINK-01）

默认通过镜头设计与剪辑衔接，不默认用上一段尾帧续接。
- 优先手法：动作匹配、视线匹配、屏幕方向连续、声音桥、遮挡切、前景擦镜、运动模糊切点、蒙太奇匹配。
- 只有真正需要保持同一连续长镜头或精确状态难以重建时，才优先使用上一段实际尾帧/连续性图。

## 段尾可切点（LINK-02）

每段结尾设计可切点：动作刚启动、动作横穿画面、遮挡达到峰值、视线落点、声音触发、碰撞瞬间、人物进出画面。

## 拆分多段的站位约束（SPLIT-01，重要）

把一整段剧情拆成多段提示词时，**每一段都必须写清所有在场人物的站位**，不能只写本段剧情出镜的那几个人：
- 上一段镜头里和主角站在相近位置的人，本段即使"剧情上无关"也**仍然可能在画面内**（除非特写/景别能保证看不到他们）。漏写会让模型默认他们不存在或站位漂移，导致连镜后人物凭空消失/瞬移/错位。
- 写法：在空间布局段把**所有未出画**的人物一并列出站位（谁在哪个方位、相对主角多远、在做什么收尾动作或保持什么姿态），然后注明"本段不入画"或"保持该站位不移动"。
- **只有明确出画**的人物才可以不写。判断标准：景别是特写/极近景且构图保证画面内只有主角；或剧情上该人物已离开画面（走出/被遮挡/切走）。拿不准就写，写了不吃亏。
- 本段不出戏、但身体部分可能入画（如站在画面边缘露出一半）的人物，也要写清其站位与姿态。
- 更优做法：拆分方案定稿后，先列出"全集人物站位总表"，每段从总表带入本段仍出画人物的站位，保证跨段位置连续。
- 跨段站位一律场景基准表述，禁止"起始=段1…"写法（spatial-assets.md DIR-01）；段间状态继承在段首镜头内重述（shots-action.md SHOT-03）。

## 段尾收尾镜（CLOSE-01，以台词结尾必加，硬性）

若一段（或整段结尾）**以台词收尾**，平台常掐在最后一个单词上、声音突然切断。已验证：**单独追加一格无台词的收尾镜最稳**：
- 强制条件：任何一段以台词结束，必须**在最后追加一格独立收尾镜**，禁止让台词的直接结束当作视频终点。
- ⚠️ **必须切镜**：收尾镜必须是**新的独立镜头**（新的景别/拍摄角度/时间码），切到另一个画面。**禁止在台词格末尾用逗号接续追加动作**——平台对"台词后同镜追加动作"几乎不听，只会吞掉动作或仍掐在台词尾。切镜是唯一有效方式。
- 收尾镜内容：无台词、纯余韵动作/静默反应，落在"话已说完之后"的状态上——角色望着某处、喉咙滚动、脱力垂手、画面停留片刻。吃 0.5-1 秒缓冲，计入时长估算（估时脚本已自动预留 0.75s 并标记 `needsClosingShot`）。
- 多段拆分时同样适用：每段各自以台词结尾的部分都要各自收尾镜收口，不能只在最后一段加。
- 2.5 长镜中：若整体以台词收束，时间码末尾也要留 0.5-1 秒给收尾镜（台词在 B-1 秒说完，最后一段为新镜头或同镜切点做静默余韵）。

## 剧情完整性（ANCHOR-01，重要）

每个剧本剧情事件都要有明确落点，防止"拆散到看不出"式的隐性省略：
- 一个连贯剧情动作若被拆进多个镜头分别描述，必须在提示词开头用一句话点明完整剧情事件，再分镜头细化。
- 写法规范：场景概述/本段目标先写"<一句话完整复述本段剧情>"，确保它独立成句、可被单独检索到。
- "完整性锚点"同时服务于人类复核——这是例外于纯净规则的正当保留项（它描述的是画面内容本身，不是对话反馈）。

## 状态与数量守恒（CON-01）

复杂镜头按状态机处理。例：初始4张符箓 → 3张命中护卫并核销 → 形成3套锁链 → 第4张被劈碎并核销 → 不能生成第5张。
- 武器、人物、伤势、场景破坏、特效都要守恒。
- 掉落武器留在明确位置。昏迷人物不能无说明站起。贯穿伤不能自动恢复。倒塌摊位不能下一镜自动复原。已核销特效不能无故重新出现。
- 可直接使用："数量从3张变为0张""由0套形成3套""本片段不重新出现"。

## 特效（VFX-01）

- 重要特效至少明确：**来源 → 形成 → 几何形态 → 颜色/材质 → 运动方向 → 接触 → 物理反馈 → 残留 → 核销**。
- 不要只写"出现金光""出现术流"。不要用光球、爆炸、巨大法阵、满屏粒子替代已定义特效。需要瞬时变化时可写"一至两帧内完成"。

## 特效首尾配对（VFX-02）

剧本中的异象/能量元素必须"来源镜头 + 去向镜头"成对出现：
- 首次出现：先给产生源头（自伤口/法阵/器物发出），再写运动与抵达。删掉来源镜头，后续每一次出现都会显得凭空突兀。
- 跨场再现：与首次保持同色、同形态、同运动语言，让观众靠视觉一致性认出"这是同一个东西"。
- 元素退场要有消散或去向描述，不留悬空引用。

## 特效动态动词（VFX-03）

能量/光效的运动用动词描述，不用静态几何状态：
- ✅ "涌出／飞向／缠上／漫过／卷向"
- ❌ "绷得笔直""指向城堡""排成一线"（静帧思维，生成结果呆滞）
- 方向感由"动词＋目标物"给出，不靠几何姿态描述。

## 场景破坏（DEST-01）

不要只写"撞毁摊位"。写清：撞击 → 主支柱/承重架断裂 → 木架/货台折倒 → 棚布拖落 → 陶器/货物坠落 → 尘土碎片沿原运动方向继续。多次破坏不要复制完全相同动画。

## 位移因果（LINK-03，重要）

角色位置发生任何变化（进出场、跨地点移动、脱离原群体），文本必须给出屏幕上可见的触发事件＋至少一拍动作过程，禁止"上一拍在 A 处、下一拍已在 B 处"：
- 合格触发：他人邀请/命令、追赶、护送、惊觉后起身等；"怎么停下了？"式的一问也算触发拍。
- 载具进出链（硬性）：载具停稳（触发）→ 开门/掀帘 → 落地 → 观察/对话。封闭载具内的人物不得直接执行车外动作。
- 自驾能力需有交代（本人会驾驭／被教授／畜力自走三选一），否则"独自驾车"是逻辑洞。

## 体位连续（LINK-04）

同一场景内，角色的体位（坐/立/蹲/卧）与所处位置（车内/车外/墙边/马上）每一拍都必须与上一拍吻合：
- 写"立在原地"之前，必须先有"下车站定"的过程拍。
- 改写与优化时禁止无声改变体位——这是比道具守恒更高频的穿帮源。

## 衔接 ≠ 缓冲：删时长，不删接法（LINK-05，实战补丁 2026-09-14）

**事故教训（《便利店》54-2 旧校舍公厕）**：用户反馈"中间缓冲太久、非常拖节奏"→ 执行者把"捡杆 / 走路 / 假安全 3 秒"整段删除 → 用户随即反馈：

> 「衔接呢，衔接呢，不同片段之间的衔接去哪了」

根因：把"缓冲"和"衔接"当成了同一件事，删缓冲时连衔接一起删了。

**两者必须分开判断：**

| | 缓冲（要砍） | 衔接（必留） |
|---|---|---|
| 本质 | 用**时长**填空白：走路、弯腰捡物、站着僵持、慢镜余韵 | 用**切点**接画面：动作匹配、视线匹配、声音桥、接触瞬间、景别切换 |
| 代价 | 每处 2–3 秒，一场戏白丢 10 秒以上 | **0 秒**，接缝本身不占画面时间 |
| 判据 | 删掉这几句后剧情仍连得上 → 它是缓冲 | 两镜之间没人交代"人怎么从 A 到了 B" → 衔接缺失 |

**规则一：衔接用切点做，不占时长，且每处接缝都必须有。** 每段提示词写两句话：**入点**（承接上一段的哪个状态：人站哪、手里有什么、门开着还是关着）+ **出点**（末帧定格在哪一格 + 交给下一段的切点类型）。这两句只占文字，不占秒数。

**规则二：位移靠"触发拍 + 动作启动切"，不靠走路镜头。** 标准做法——上一段末帧给**位移的因**（听到声音、被人叫、看见什么）并落在**动作刚启动**（人正在起身/转头，LINK-02 可切点）；下一段首帧直接从"人已经在那儿"起手，中间的走动省略。观众认因果，不认步数。
- ✅ 上段末：门缝合上，深处传来门轴轻响，三人同时转头、其中一人撑地起身 → 下段首：三人已站在那扇门前两米，门正被推开。
- ❌ 上段末：三人站在原地；下段首：三人站在另一扇门前（缺触发拍，观感=瞬移）。
- ❌ 为衔接补一个 3 秒走路镜头（把切点问题当成长度问题）。

**规则三：收尾一律"末帧定格"，不是"慢慢收"。** "三个人慢慢安静下来""动作渐渐停下来""僵持两秒"都要删，改成"画面定在这一格就切"。定格是 0.3–0.5 秒的一格，不是 2–3 秒的过程。
- 例外：CLOSE-01 的**台词收尾镜**（0.5–1 秒无台词余韵）是"防平台掐台词"的技术保险，不是叙事缓冲，**不受本条约束**。

**规则四：状态守恒表随段重申。** 跨段不许变的东西（道具在哪、各扇门开合状态、光源状态），每段"必须保持"里都要重写一遍。不写，模型会把背景里的门悄悄关上、把地上的道具变没（CON-01 的跨段版本）。
