# 规则模块 R13 — 文戏表演引擎（DRA-*）

> 总控在 Stage S4（提示词组装）读本文件。**当剧本含文戏/情绪戏/对白戏时硬性生效**（武戏见 shots-action.md ACT-*，恐怖见 horror-suspense.md HOR-*）。
> 来源：视频提示词工业化生成工作流 V1.9.3「文戏表演引擎」。

## DRA-01 文戏四不写（硬性）

1. **不写情绪标签**——禁止只写"悲伤/愤怒/崩溃/心动/委屈"
2. **不写结果**——禁止"一步到位"的表情（直接哭/直接怒）
3. **不写抽象心理**——禁止 `他想 / 她觉得 / 他意识到 / 她心中`
4. **不写不可拍物**——每个描写都要过三问：摄影机拍得到吗？麦克风录得到吗？演员用身体哪部分演出来？

## DRA-02 情绪过程弧线（六段机制，硬性）

文戏不能直接写结果情绪，必须写**情绪进入脸、呼吸、声音和身体的过程**：

```text
触发事件 → 第一认知反应 → 身体泄漏 → 压抑/伪装 → 失控点 → 情绪残留
```

### 15 秒文戏默认时间轴（可套用）

| 时间 | 阶段 | 写法 |
|---|---|---|
| 00:00-00:01 | 控制住的脸 | 呼吸稳定，表情中性 |
| 00:01-00:03 | 触发信息进入 | 眼神先停 |
| 00:03-00:05 | 理解发生 | 嘴唇、下眼睑或呼吸开始变化 |
| 00:05-00:07 | 情绪进入身体 | 喉咙吞咽或下颌收紧 |
| 00:07-00:09 | 试图压住 | 声音变轻、变慢或变硬 |
| 00:09-00:11 | 第一次失控 | 停顿、颤音或眼眶湿润 |
| 00:11-00:13 | 情绪不可否认 | 但动作仍克制 |
| 00:13-00:15 | 情绪残留 | 不要只停在一个表情姿势 |

### 短时长文戏（组时长不足 15s 时）

| 时长 | 表演弧线 |
|---|---|
| 5 秒 | 中性 → 触发 → 第一反应 |
| 8 秒 | 中性 → 触发 → 认知 → 泄漏 |
| 10 秒 | 中性 → 触发 → 反应 → 压抑 → 残留 |

## DRA-03 文戏机制六型（禁一套公式打天下）

不要所有文戏都套"触发→失控"。按戏剧功能选择机制：

| 机制 | 情绪走向 | 适用场景 | 常见风险 |
|---|---|---|---|
| **压抑型** | 越痛越安静 | 告别、亲情、旧伤 | 空白无变化 |
| **反讽型** | 嘴在笑，眼已冷 | 背叛、失望、体面分手 | 假笑过度 |
| **延迟型** | 当场无反应，最后一秒才塌 | 真相揭示、噩耗 | 前段太木 |
| **权力型** | 谁先动情，谁先输 | 对峙、谈判、复仇 | 反派邪笑脸谱化 |
| **空白型** | 表情很少，靠呼吸和停顿 | 创伤、麻木、极端疲惫 | 毫无递进 |
| **回暖型** | 防御慢慢松开 | 和解、安慰、久别重逢 | 突然亲密 |

## DRA-04 微表情字段库（按部位取用）

| 部位 | 可用描述（每镜头最多取 3 个锚点） |
|---|---|
| 眼睛 | 聚焦、失焦、变亮、变暗、停住、重新盯住、视线偏移 |
| 下眼睑 | 发红、轻颤、绷紧、微微上抬 |
| 眉 | 眉峰压低、眉尾松开、眉心收紧 |
| 嘴唇 | 抿紧、微张、颤动、笑意未达眼底、唇线绷直、张口欲言又止 |
| 下颌 | 收紧、放松失败、咬肌绷起 |
| 喉咙 | 吞咽、卡住、说话前换气 |
| 呼吸 | 变浅、停一拍、变重、不稳、胸口起伏明显 |
| 身体 | 肩膀微僵、指尖收紧、指节泛白、后背发僵、身体微晃却站稳 |

**微表情锚点上限**：单镜头 ≤ 3 个（见 DRA-05）。

## DRA-05 文戏降噪公式 1+3+1+1（硬性）

文戏提示词必须从"全量控制"转为"**重点控制**"。AIGC 更容易执行**清晰的少量锚点**，而非密集的表情清单。

每个文戏镜头生成前先确定：

| 项目 | 限制 | 示例 |
|---|---|---|
| **1 个核心情绪机制** | 只选 1 个 | 迟来的理解 / 压住的愤怒 / 假笑崩塌 |
| **3 个微表情锚点** | 最多 3 个 | 眼神停住 + 喉咙吞咽 + 嘴唇压紧 |
| **1 个声音节奏重点** | 只选 1 个 | 省略号卡住 / 问号尾音上扬 / 句号压低落地 |
| **1 个镜头语言目的** | 只选 1 个 | 不切走让观众看见压抑 / 用前景遮挡制造隔阂 |

**禁止**：
- 同一镜头塞入 5 个以上微表情变化
- 每个镜头都写完整 15 秒情绪弧线
- 负面词超过当前组真实风险（导致重点稀释）

## DRA-06 节奏留白规则（硬性）

以下情况**必须预留 0.5-2 秒**留白：

| 触发点 | 留白要求 |
|---|---|
| 问句之后 | 看对方反应，尾音不要立刻切走 |
| 省略号之后 | 允许喉咙、呼吸、眼神完成停顿 |
| 真相揭示之后 | 先让角色不反应，再让理解进入眼睛 |
| 告别句之后 | 让句号落地，留情绪残留 |
| 道歉/感谢之后 | 不要马上用下句覆盖 |

## DRA-07 镜头语言目的表（每个文戏镜头必须有目的）

禁止为了"好看"随机切特写，也禁止没有目的地多机位覆盖。

| 戏剧目的 | 镜头策略 | 禁止 |
|---|---|---|
| 让观众看见压抑 | 固定特写，不切走，保留呼吸 | 快切打断表演 |
| 表达关系隔阂 | 前景遮挡、门框/玻璃/纱帘 | 无依据改变站位 |
| 表达权力压迫 | 低幅度推近、视线高度差 | 夸张仰拍/俯拍 |
| 表达孤立 | 单人置于画面偏侧，留大面积负空间 | 所有镜头都居中对称 |
| 表达迟来的理解 | 先中近景稳定，再极慢推近到眼睛 | 立刻哭喊 |
| 表达体面崩塌 | 正常构图逐渐变得更紧 | — |
| 表达未说出口 | 切在嘴唇微张前后，但不切走 | — |

## DRA-08 文戏镜头策略速查

| 场景 | 推荐镜头 |
|---|---|
| 克制告别 | 固定近景 / slow push 特写 |
| 压抑对峙 | 过肩近景 / 中近景反打 |
| 迟疑告白 | 眼平近景 / 微推 |
| 崩溃边缘 | 稳定特写 / 极慢推近 |
| 冷静威胁 | 固定中近景 / 低幅度推近 |
| 沉默反应 | 特写 / 不切走 / 保留呼吸 |

**文戏限制**：
- 不要随机切走环境空镜
- 不要用大幅度运镜稀释表演
- 不要让演员频繁转身、走动、拿道具
- 微表情重要时，镜头必须稳定、焦点必须锁脸
- 重要台词后必须留反应，不要立刻切下一句
- **每个镜头只服务一个戏剧目的**

## DRA-09 动作结构五层模板（含动作戏通用）

每个涉及人物动态的镜头，动作描述必须包含五层：

```text
1 起始状态：动作开始前的姿态/位置
2 主动作：核心动作（仅 1 个，自然动词）
3 辅助动态：伴随的次要动作（衣袖摆动、手指收紧、眼神偏移）
4 身体联动：主动作引发的其他部位变化（抬头时肩膀微动、转身时上身跟随）
5 结束状态：动作完成后的最终姿态与情绪
```

**格式要求**：按"起始 → 主动作+辅助+联动 → 结束"顺序书写，不可跳跃。

**示例**：
> "沈青瓷原本低头站立，短暂停顿后缓缓抬起头。随着头部抬起，视线慢慢上移，肩膀有轻微带动。动作过程中，发丝因抬头而后坠，衣领产生自然褶皱。最后她抬眼看向前方，神情停在克制状态。"

**动作描写简化规则**：
- 用自然动词：伸手、拿起、放下、转身、抬眼、低头、走近、后退、扑出
- 可加单修饰词：缓慢、快速、用力、轻柔、猛地
- **禁止比喻/文学夸张**："像被踩了尾巴一样""犹如铁钳般""五指深陷"——AI 无法理解修辞，会导致肢体畸形
- 禁止写"幅度、速度、起止、轨迹、关节逐节弯曲"等精细化描述
- **单镜头主动作 ≤1 个，辅助动态 ≤1 个**；禁止频繁切换姿势

## DRA-10 步态五型（人物差异化）

不同人物的走路方式必须差异化，不得统一写"向前走去"：

| 步态 | 写法 | 适用 |
|---|---|---|
| 端庄步态 | 步伐沉稳，速度较慢，身体平稳，动作安静克制 | 宫廷女子、贵族、正式场合 |
| 谨慎步态 | 步伐放轻，动作克制，速度缓慢，姿态警觉 | 夜晚古街、发现异常、进入危险场景 |
| 压迫感步态 | 每一步都很稳，重心平稳前移，肩膀略微下压 | 反派、高手登场、逼近目标 |
| 疲惫步态 | 步伐沉重，肩膀下垂，动作比平时更慢 | 受伤、失落、逃亡后 |
| 轻快步态 | 脚步有节奏，身体随步伐产生轻微起伏 | 少女、轻松场景、明亮氛围 |

**身体联动（禁止单部位孤立动作）**：
- 抬头 → 肩膀产生轻微变化，视线随之上移
- 转头 → 肩膀和上半身跟随小幅度转动
- 抬手 → 肩膀带动手臂上抬，衣袖自然下垂
- 转身 → 先偏头，肩膀跟随，上半身缓缓转动，衣摆自然牵拉

## DRA-11 多人 Blocking 四要素（文戏/对峙硬性）

人物关系不能只靠台词说明，必须转成**镜头里的空间关系**。每个双人/多人镜头必须明确：

1. **绝对坐标锚定**——谁在画面左侧（通常主动方）、谁在右侧（防守方）；同场戏跨镜头**禁止随意翻转左右**
2. **空间纵深与高低位势**——谁在前景（主导）、谁在后景（旁观/被隔绝）；谁高位（俯视压迫）、谁低位（仰视隐忍）
3. **领地互动与视线指向**——谁缓慢靠近试探、谁稳立原地；说话者视线/头部朝向**必须指向对话人的绝对坐标**；不看对方时必须交代具体无效落点（"垂落看向桌面"），**禁止视线乱飘**
4. **动作先后顺序**——按"角色A先完成 X → 角色B随后做出 Y 回应 → 两人产生 Z 互动"顺序书写，不可混为一谈

**检查法**：去掉台词，仅看站位和视线，也要能看出人物关系。

**示例**：
> ❌ 不要写：裴砚辞偏心柳如眉
> ✅ 要写：柳如眉坐在软榻低位，裴砚辞站在她身侧半步位置，身体偏向她形成保护姿态，沈惊鸿独自站在堂中，被隔在外侧

## DRA-12 文戏自检（交付前必过）

- [ ] 无情绪标签、无结果式表情、无抽象心理词（DRA-01）
- [ ] 情绪写成六段过程弧线，或按短时长模板降档（DRA-02）
- [ ] 已按戏剧功能选定机制（六型之一），非套同一公式（DRA-03）
- [ ] 每镜头符合 1+3+1+1（DRA-05），微表情锚点 ≤3
- [ ] 问句/省略号/真相/告别/道歉后已留白 0.5-2 秒（DRA-06）
- [ ] 每个文戏镜头有明确镜头语言目的（DRA-07）
- [ ] 动作按五层结构写，无修辞比喻，主动作 ≤1（DRA-09）
- [ ] 人物步态差异化，身体联动齐备（DRA-10）
- [ ] 多人戏 Blocking 四要素齐备，去掉台词仍能看出关系（DRA-11）
- [ ] 强/中/弱约束已分层（VO-08）
