# 规则模块 R10 — 女频诡异恐怖题材（P3 管线专用）

> **仅 P3 管线（国内·女频诡异恐怖）时读本文件**，在 S4 编译提示词前读。规则编号 HOR-*。
> 基础镜头语言仍遵循 shots-action.md / SHOT_LANGUAGE.md，本文件只覆盖恐怖题材的专属决策。

## HOR-01 恐怖三要素（至少命中两条，否则不吓人）

| 要素 | 做法 | 提示词写法示例 |
|---|---|---|
| **威胁未知性** | 只给局部/轮廓/声音，不给全貌 | "画面右侧黑暗中露出一截苍白手指，其余隐没在阴影里" |
| **安全空间被侵入** | 卧室/卫生间/被窝/车内等私密空间出现异样 | "她闭上眼后，床尾的被子缓慢凹陷下去一块" |
| **日常物异化** | 镜子/电视/手机/照片/玩偶产生细微错误 | "镜中的她比现实慢了半拍才抬起头" |

- 反例（禁止）：直接给怪物全貌正面特写——观众一秒出戏，且审核风险高。

## HOR-02 惊吓节奏（12-15s 段内的标准结构）

```
0–4s   铺垫：日常动作 + 环境异常（观众察觉不对）
4–7s   静默：声音抽空，画面几乎静止（关键！静默是恐惧放大器）
7–9s   爆发：异变/出现/声音炸开（1-2 秒，快）
9-15s  余韵：角色反应 + 未解释的残留（细思极恐靠这段）
```

- **静默段必须写进提示词的声音设计段**：`环境音完全消失，仅剩极轻微的电流底噪`。
- 爆发段用**硬切或快速推镜**，不要用慢动作（慢动作会削弱惊吓）。
- 余韵段留"未解决"信息：门还在轻轻晃动 / 手机屏幕自己亮起 / 镜中多了一个影子。

## HOR-03 光源与色彩（P3 强制）

- **单一光源原则**：每段只保留一个主光源（手机屏光 / 手电 / 走廊感应灯 / 月光 / 电视雪花光）。
- **负空间必须留足**：画面 40% 以上为暗部，但按 SCENE-01 措辞规则——写"低照度、仅透出微弱轮廓"，**禁止写"纯黑/死黑"**。
- 色调：冷青 / 暗绿 / 惨白；饱和度压低，避免高饱和（高饱和会变成"惊悚片海报感"而非恐惧）。
- 光源闪烁要写清触发逻辑（接触不良 / 电压不稳 / 被遮挡），不要无理由闪。

## HOR-04 视角选择（按效果选，不要每段都用手持）

| 视角 | 效果 | 适用 |
|---|---|---|
| 第一人称 POV | 代入感最强，女主视角 | 探索、发现 |
| 监控/猫眼/手机录像 | 旁观无力感 + 画幅框中框 | 揭示、悬念 |
| 过肩偷窥（摄影机在角色身后障碍物后） | 危险临近的无力感 | 追赶、潜伏 |
| 固定长镜（不动） | 让观众自己扫视画面找异常 | 房间空镜、细思极恐 |
| 手持晃动 | 慌乱、真实感 | 逃跑、崩溃（**不要全片都用**） |

## HOR-05 合规红线（国内平台，硬性）

> 恐怖题材是审核重灾区，**以下任何一条命中即打回重写**。

1. **不能有真正的鬼/超自然实体存在**：结局必须能落地为——人为作案 / 精神幻觉 / 梦境 / 误会 / 机械故障。
2. **禁止血腥**：无血液飞溅、无伤口特写、无断肢、无尸体特写（沿用 SAFE-01/02）。恐怖靠氛围不靠血浆。
3. **禁止儿童/孕妇受害或受惊画面**（SAFE-04 加严：恐怖题材里连"小孩背影出现在诡异场景"都避免）。
4. **禁止宗教/民俗恐怖具象化**：不出现真实宗教符号被亵渎、不出现具体民间诅咒仪式的操作细节。
5. **禁止自杀/自残的具体呈现**（可暗示，不可展现过程）。
6. **禁止把诡异归因于精神疾病患者"就是凶手"** 这类污名化设定。
7. 全片立意必须正向：邪不压正，作恶者须付出代价或真相大白。

## HOR-06 声音设计（恐怖片一半靠声音）

- 静默段：`环境音完全消失，仅剩极轻微的电流底噪`（比完全无声更恐怖）。
- 低频：20-60Hz 低频嗡鸣铺垫不安。
- 高频：爆发瞬间用短促高频（金属刮擦 / 玻璃碎 / 尖叫）。
- 日常声异化：水龙头滴水节奏突然加快 / 儿歌八音盒走调 / 钟表滴答与画面不同步。
- **禁止 BGM 全片铺满**——恐怖片留白比配乐重要（NEG-01 默认无 BGM 依然成立）。

## HOR-07 表演：两级惊恐反应

| 级别 | 表现 | 时长 |
|---|---|---|
| **一级·瞬间惊吓** | 瞳孔骤缩、肩膀猛然一抖、倒抽一口气、后退半步 | 0.5–1s，快 |
| **二级·后知后觉** | 缓慢转头、呼吸失控、手指僵硬、眼神不敢移开、喉咙滚动 | 3–5s，慢 |

- 两级连写才有层次：**先抖一下，再慢慢意识到那是什么**。
- 禁止写"她很害怕"这类结果式标签（PERF-01）；全部走身体微事件。

### HOR-07a 身体位移是硬指标（实战补丁，2026-09-14）

**只写微表情 = 生成出一排站着的人偶。** 每个反应镜头里，每个角色必须有一次**看得见的身体位移或姿态改变**：后退一步半、撞到人身上、踉跄半步、跌坐、蹲下、滑坐到墙根。

- ❌ 实测翻车写法："她僵住，握杆的手停在半空；他抬手扶她手肘；另一个人后蹭半步"——用户反馈：**人物一动不动、表情只有轻微变化，太呆板**。
- ✅ 通过写法："她上半身猛向后一缩、右脚后跨一大步、后背重重撞在身后男生的胸口上；男生被撞得往后一顿、肩膀猛地一提、踉跄半步扶墙"。
- 表情同步放大：眼睛睁到最大、嘴张开、脸色瞬间发白——**表情和身体同时发生**，不是只有脸在动。

### HOR-07b 接触链：恐惧要靠身体传下去（实战补丁）

多人同框的惊吓，必须写成**连锁**而不是"各演各的"：一个人的反应要产生物理后果落到下一个人身上，下一个人因此产生他自己的反应。

标准链：**A 猛退 → 撞在 B 身上 → B 被撞得一激灵（倒吸气、踉跄、扶墙）→ B 反应 → B 收住后去扶 A**。
没有物理接触的多人反应，即使错峰也显得像排练。

### HOR-07c 三拍结构：瞬时 → 连锁 → 收住（实战补丁）

每个角色的惊恐反应走满三拍，缺第三拍就"假"：

1. **瞬时（0–1s）**：表情炸开 + 身体大幅动作。
2. **连锁（0.5–2s）**：位移、撞人、被撞、脱手掉东西。
3. **收住（2s 之后）**：两种走向——
   - **镇静过来**：肩膀放平、重心收回、手扶住同伴、视线重新看回危险源（男性保护者角色适用）；
   - **垮下去**：肩膀塌掉、膝盖一软蹲下、滑坐在地、靠墙、低头大口喘气（长时间紧绷之后的崩）。

用户原话："邓子文应该也被吓一跳然后镇静过来"——**"被吓"和"镇静过来"是同一个人身上的两拍**，不能只写前者。

### HOR-07d 同集内三种反应类型不重复（实战补丁）

一集里连续三场惊吓，反应类型必须换：**退 / 崩 / 垮**（例如第二场是后退撞人、第三场是崩掉跌坐、第四场是垮下来蹲坐）。三段都用"瞪大眼睛后退"会立刻显假。

## HOR-08 负面约束模板（P3 每段必带）

```
禁血浆。禁伤口特写。禁断肢。禁尸体面部特写。
禁宗教符号。禁真实诅咒仪式。禁儿童受惊画面。
禁jump scare连续使用（相邻两段不得重复同一惊吓手法）。
禁全程手持晃动。禁高饱和色调。禁慢动作惊吓。
禁字幕。禁水印。禁BGM铺满。
```

## HOR-09 悬念经济学（恐怖版）

- 每个诡异元素**首次出现只给 30% 信息**（局部/影子/声音），中段给 60%，高潮才给 100%。
- 同一手法一集内不重复：用过"镜中延迟"就别再用"背后多一个人"。
- 每集留一个**未解释的钩子**在最后 2 秒（这也符合 P1-P3 通用的"悬念型结尾"偏好）。
