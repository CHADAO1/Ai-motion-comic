# 规则模块 R15 — 三层负面词体系（NEG-*，扩充）

> 总控在 Stage S4（负面约束段）读本文件。与 shots-action.md 的 NEG-01~04 配合使用（NEG-01~04 讲"固定负面项/重点锁定/镜头数量/天体光源"，本文件讲"**分层结构 + 失败模式 + 降噪**"）。
> 来源：视频提示词工业化生成工作流 V1.9.3 负面词规范。

## NEG-05 三层负面词结构（硬性）

每个剧本必须**根据类型动态生成**负面词，且必须包含三层：

```text
Layer 1 基础负面词：所有类型通用
Layer 2 类型专属负面词：根据剧本类型选配
Layer 3 场景专属负面词：根据当前场景动态生成
```

**输出格式**（写在每组末尾）：
```text
【负面词】
Layer 1 基础负面词：……
Layer 2 类型专属负面词：……
Layer 3 本组专属负面词：……
```

## NEG-06 Layer 1 基础负面词（每部戏通用）

避免手部畸形、避免脸部变形、避免比例失调、避免透视错误、避免模糊失焦、避免噪点过多、避免过度磨皮、避免字幕、避免水印、避免多余角色。

**即梦专属基础负面指令**（英文，固定加在提示词末尾）：
`no srt, no music, no deform, no morph, no extra limbs, no blurry eyes, no unnatural pose, no sharpening`

## NEG-07 Layer 2 类型专属负面词

### 文戏类型专属
避免突然大哭、避免表情一步到位、避免夸张瞪眼、避免全程喊叫、避免嘴型与台词节奏不匹配、避免假笑过度、避免无情绪递进的空白表情、避免突然亲密。

### 标点专属
避免忽略省略号停顿、避免问句尾音无变化、避免感叹号变成失控尖叫、避免破折号没有中断感、避免逗号没有真实换气、避免句号没有落点。

### 情绪类型失败模式表（按情绪选配）

| 情绪类型 | 最容易失败 | 必须约束 |
|---|---|---|
| **哭戏** | 太早落泪、五官扭曲、泪流满面 | 避免开场掉泪，泪水只到眼眶；五官不扭曲 |
| **怒戏** | 全程吼叫、动作过大 | 声音压低变慢，重音加重；动作克制 |
| **心动** | 油腻、偶像剧化、过度表演 | 只用眼神停顿、呼吸慢一拍 |
| **威胁** | 邪笑、脸谱化反派 | 表情更静，尾音下压 |
| **告别** | 煽情过度、台词太满 | 句号落地后留白，动作少 |
| **和解** | 突然拥抱、情绪转暖过快 | 防御先松一点，不立刻亲密 |
| **麻木** | 演成面瘫 | 表情少但呼吸、眼神焦点要有变化 |

### 动作/武戏类型专属
避免动作复制粘贴、避免格挡无物理结果、避免攻击方停在原地看戏、避免慢动作滥用、避免武器复制。

### 恐怖悬疑类型专属（配合 HOR-*）
避免血浆飞溅、避免创口特写、避免突兀惊吓音效、避免鬼脸直给。

## NEG-08 Layer 3 场景专属负面词（按场景动态生成）

示例对照表：

| 场景类型 | 场景专属负面词 |
|---|---|
| 家庭文戏 | 避免煽情过度，避免刻意的泪光特写 |
| 爱情文戏 | 避免突然亲吻，避免油腻眼神 |
| 对峙背叛 | 避免开场大吼，避免反派邪笑 |
| 沉默反应 | 避免空白无变化，避免频繁眨眼 |
| 崩溃边缘 | 避免开场直接崩溃，避免夸张捶地 |
| 追逐动作 | 避免跑步姿势僵硬，避免背景人流静止 |
| 恐怖探索 | 避免光源跳跃，避免怪物直给正脸 |

## NEG-09 负面词降噪公式（硬性）

**负面词要短而准**——优先保留当前**最容易翻车的 5-8 条**，不要把所有负面词机械堆满（会稀释权重）。

```text
本组只保留：基础质量 2-3 条 + 类型失败 2-3 条 + 标点/表演风险 1-2 条
```

**禁止**：负面词超过当前组真实风险，导致重点稀释。

## NEG-10 正面落点配对（与 SAFE-06 一致）

每条负面约束必须配**正面画面落点**——写该有的画面，而不只是喊禁止。

| ❌ 只禁止 | ✅ 禁止 + 正面落点 |
|---|---|
| "不要哭得太夸张" | "泪水停在下眼睑，眼眶泛红但不滚落，嘴唇压紧" |
| "不要全程喊叫" | "声音压低、语速放慢，重音落在'从来'二字" |
| "不要突然拥抱" | "两人保持半步距离，视线短暂相接后各自移开" |

## NEG-11 负面词自检（交付前必过）

- [ ] 三层结构完整（基础 + 类型 + 本组专属），无缺层
- [ ] 每层条目数符合降噪公式（总计 5-8 条优先）
- [ ] 已包含即梦专属英文负面指令（no srt / no music / no deform…）
- [ ] 情绪类戏已配对应失败模式约束（NEG-07 表）
- [ ] 每条负面约束均有正面画面落点
- [ ] 未照抄通用列表，Layer 2/3 已按本剧类型与场景定制
- [ ] 镜头数量约束已含（NEG-03）
