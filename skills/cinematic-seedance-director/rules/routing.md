# 规则模块 R1 — 模型路由（Seedance 2.0 vs 2.5）

> 总控在 Stage S1（估时）与 S4（提示词）前读本文件。规则编号 RT-*。

## RT-01 差异速查（官方口径 + 实测）

| 维度 | Seedance 2.0 | Seedance 2.5 |
|---|---|---|
| 单次时长 | 最多 15 秒 | 最多 30 秒（一次生成，非拼接） |
| 参考输入 | 最多 15（9 图 + 3 视频 + 3 音频） | 最多 50（30 图 + 10 视频 + 10 音频） |
| 分辨率 | 最高 4K | 早期 API 上限 720p（按渠道确认） |
| 光照物理 | 均匀照明（易塑料感/死鱼眼） | 方向光物理、逐特征光照 |
| 编辑能力 | 编辑/扩展变体 | 时间戳级编辑（只改某处其余不动） |
| 3D 参考 | 不支持 | R2V：白模/绿幕动画控制运镜走位 |
| 语言 | 多语言音频 | 20 语言口型同步 + 本地化 |
| 成本 | 便宜 | 更贵（更长 + 更多参考 = 更高算力） |

- **2.5 强项**：长镜一镜到底（进入→动作→台词→落地一气呵成）、50 参考跨序列锁定角色脸/服装/声音、方向光物理（解决塑料感/悬浮打击/变脸）。
- **2.0 强项**：4K + 便宜，短而稳的片段、文戏/特写完全够用。
- ⚠️ **陷阱（RT-02）**：2.5 的 "180 秒/分钟级" 是**多次扩展拼接**（multi-round extension），不是一次生成。路由判断依据**单次 30 秒**这一真实上限，营销数字不计入。
- **R2V（白模/绿幕参考）**是 2.5 隐藏能力，需要额外建模成本，当前提示词编译阶段用不上；若用户后续提供白模动画，可用于锁多人走位。

## RT-03 路由决策（按管线，常量源见 PIPELINE_PRESETS.md PP-01）

> **默认 2.5 仅适用于 P4 海外管线。国内三条管线（P1/P2/P3）一律 2.0。**

| 管线 | 模型 | 单段上限 | 拆段规则 |
|---|---|---|---|
| P1 国内下沉中老年 | **2.0** | 15s | **每段 12–15s（硬性，PP-01）**；超 15s 按剧情断点拆多个 ≤15s 段 |
| P2 国内女频恋爱 | **2.0** | 15s | 同上 |
| P3 国内女频诡异恐怖 | **2.0** | 15s | 同上 |
| P4 海外 | 2.5 | 30s | 30s 内一次生成不拆分（用户偏好已固定：避免拆段连镜/站位问题）；超 30s 才按剧情自然断点拆多个 ≤30s 独立段 |

- 国内管线（P1-P3）**不许因为"想省事一次生成"就偷偷换 2.5**——2.0 的 15s 上限是硬约束。
- P4 海外管线：2.5 一次覆盖 30s 内完整剧情，优先不拆。
- 用户临时点名要另一个模型 → 以用户本次指令为准，但须在 manifest 记录并提示"与当前管线默认值不符"。

## RT-04 2.5 编译原则

更强指令遵循，适合具体导演意图、空间关系、长连续场景和拍摄计划式 Prompt。
- 适用：复杂多人连续追逐/战斗、长镜头、空间关系密集的段落。**这种段落尽量不拆**——拆太多会出现连镜和站位问题。
- 时长可达 30 秒；编译原则：
  - 明确空间 / 明确机位 / 明确动作因果 / 明确表演过程
  - 使用粗粒度时间码控制结构（镜头XX｜起始—结束秒）
  - 因果极严格时才在单镜内部细分时间；不机械给每个微动作分秒
- 用户未要求慢动作时：风格段写"正常速度"，负面约束写"不要慢动作"。

## RT-05 2.0 编译原则

4–15 秒，自主补镜、补调度、补节奏倾向更强。**更便宜**。
- 适用：简单短镜头、文戏/对峙/台词为主的段落。
- 编译原则：锁定核心事件、强制空间、关键镜头和结束状态；普通内部衔接可留自主空间；不把 2.5 长篇拍摄计划原样套用。
