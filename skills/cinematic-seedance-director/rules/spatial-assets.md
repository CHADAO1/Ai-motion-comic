# 规则模块 R3 — 空间、资产与站位图

> 总控在 Stage S3（空间图）与 S4（提示词空间布局段）读本文件。规则编号 ASSET-/CACHE-/SPAT-/BLOCK-/DIR-/SVG-/FACE-/AXIS-*。

## 资产职责（ASSET-01）

禁止把所有资产无差别塞入 Prompt，每个资产要明确职责：
- **正式人物资产**：身份、面容、发型、服装、体型、固定识别点。
- **武器资产**：外轮廓、比例、握持方式、材质、结构。
- **构图主资产**：摄影机、人物画框位置、前中后景、透视、遮挡、空间结构。
- **连续性参考**：某一瞬间的姿态、朝向、道具、伤势、光线和位置；不能替代正式人物资产。
- **场景资产**：建筑、街道、摊位、材质、空间尺度。
- **色卡**：只负责综合色调、冷暖层级和颜色关系，不继承白底、文字、标题、排版、色块。
- **音频参考**：只锁定音色时必须写"只锁定自然音色，不继承原台词内容和背景声"。

标准写法："使用@资产锁定……；只继承……，不继承……"。如存在多个构图参考，必须声明优先级或"唯一构图主资产"。多张资产按顺序排队：先场景图（站位优先级最高），再角色图。

## 反推缓存（CACHE-01，写站位/表演前先查）

- **缓存位置**：`{剧本目录}\资产图\_反推缓存\`，每个资产图对应一个同名 `.txt`。
- **流程**：
  1. 写提示词前，找出本段涉及的资产图（场景图 + 角色图）；多张时按 ASSET-01 排队。
  2. 查缓存：`.txt` 已存在 → 直接读取使用，**不重复反推**。
  3. `.txt` 不存在 → 派子代理反推该图（一次一张，禁止并行），把结果写入同名 `.txt`，再继续下一张。
  4. **场景图** → 约束角色**站位**（物体方位、出口/光源位置、打斗空间）；**角色图** → 约束角色**行为**（服饰可被拉扯处、鞋型/裙摆对动作限制、配饰晃动、可用表演动作点）。
  5. 缓存内容不满足需要时，续问同一个反推子代理只补缺项，结果**追加**到 `.txt`。

## 空间布局 + 资产锁定

### SPAT-01 出现即锁定（硬性）
只要一段提示词里出现了某个角色（包括仅站位、仅边缘入画、仅作背景），空间布局段就必须同时给该角色 **@资产引用 + 文字特征约束**，二者缺一不可。只写站位不给参考图 = 模型没有外观依据，会乱生成或与上段形象不一致。
- 参考图继承写法：`使用@角色名图——只继承<外观/服装/体型特征>，不继承<姿势/表情/背景>`；站桩角色额外注明"本段只保持站位，不做动作"。

### SPAT-02 起始表情显式化（硬性）
每个出场角色的文字特征约束必须**同时给出起始表情**——由该角色此刻的情绪状态推导（例：塞拉初逛空间站街道=好奇/惊叹；女仆例行引导=克制得体）。参考图"不继承表情"，提示词不写起始表情时模型默认中性面无表情脸，首镜即出戏。特写/中近景角色必须写起始表情；远景站桩角色可只写情绪基调。起始表情是表演弧线的基线。

### SPAT-03 逆向空间检查（硬性）
不能只锁"剧本写了动作的角色"。凡**空间逻辑上必然入画/可见**的角色也要锁定——门开/进入新空间后镜头带到的室内已有人物、同场景站桩者、镜中/窗中/舷窗倒影可能出现的角色。判断方法：逐镜做"画面里能看到谁"的空间推演，凡视线可达者一律锁定，不因剧本没写动作而豁免。（典型失败：门开后未锁门内已有人物，下一段他们凭空出现。）

### SPAT-04 移除条件
特写/极近景下**确认完全不出画**的角色，才可以从资产锁定和站位描述中移除。

## 空间布局写法（BLOCK-01）

2+ 角色或环境互动显著时：

```
⚠️空间布局：
@image1（角色A）：站在画面中央偏左（三分线左竖线），面朝右侧窗户，距窗户约3米。
@image2（角色B）：站在@image1右后方2米处，身体半侧朝向@image1，被@image1的身体部分遮挡。
窗户：画面右侧，光源来自窗外城市灯火。
```

- 用精确的米数标距离；标注谁面向哪个方向；标注谁遮挡谁。
- 单人场景：标注角色相对关键环境要素的位置。
- **DIR-01 场景基准（硬性）**：位置只用场景要素作基准（"婴儿床东侧""床前西南地面""门旁"），**禁止"起始=段1到达位""承接段2末"这类跨段编号引用**——模型看不到段编号。段间状态继承改在段首镜头内以场景基准重述。
- **DIR-02 双重方位参照（硬性）**：每一处位置/方位必须同时给两套参照，缺一不可——
  - ① **上下左右前后中央**（视频 AI 实际能执行的主参照，先写）；
  - ② **东南西北**（世界方向定名，保证跨镜头/跨段一致，并列标注）。
  - 禁止只写东南西北而缺上下左右前后（例：只写"街道北端""向西移动"= 不合格）。
  - 标准写法：`后墙（北）巨大观景舷窗`、`右墙（东）自动门`、`面朝北（画面纵深方向）`、`向西（画面左侧）移动`。
  - 全段首次给出世界方向时须写明**换算基准**：`本段面向北时，左=西、右=东、上=高空/画面上方、下=地面/画面下方、北=画面纵深方向（远）、南=画面近端方向（近）`。

## 站位空间图三件套（SVG-01，硬性，每段提示词配套）

出提示词前为每个场景/段落生成站位空间图，存于 `{剧本目录}\空间图\`：
1. **`{段名}_空间图.svg`** — 俯视空间图（保留源文件，可再编辑/再转 PNG）。
2. **`{段名}_空间图.png`** — Edge headless 转换（平台/人看）。
3. **`{段名}_空间说明.md`** — 纯文本版空间说明（读文本即可理解空间，无需渲染）。

### SVG-02 图形规范（给视频 AI 直接做站位参考）
- **虚线圆 = 起始位置**（带"·起始"文字），**实心圆 = 到达位置**；移动路径用带箭头的实线。
- **朝向 = 角色圆上的粗箭头 + 文字**（如"面朝门(南)""面向塞拉(西)"），同角色色。**不画视线线**。
- 静态角色标"起始=到达，无移动"。
- 标注场景要素（门/窗/沙发/茶几/走廊）与机位 C1-C4。
- **起始位置必须对应剧情动作**：禁止把到达位置当起始位置（例：门内是进门后的位置，起始圆必须画在门外走廊）。
- 空间图用途：站位审查依据 + 视频 AI 站位参考 + 后续重建空间的存档（间隔多天后读图即可重建空间）。

### SVG-03 SVG 技术要求
- 必须带闭合标签 `</svg>`（否则浏览器报 "Premature end of data in tag svg"）。
- 用 Python 2.7 生成时按字节写 utf-8（`open(path,'wb').write(svg_bytes)`，不要 `.encode()` 二次转码）。
- PNG 转换，按可用性择一（**先试 A，A 不可用再走 B**）：
  - **A｜Edge headless**：`--screenshot` 带 `--user-data-dir=<临时目录>` 避免 profile 锁；窗口尺寸与 SVG viewBox 一致。
  - **B｜同源绘制（本机已验证的兜底，推荐）**：当环境无 Edge/无头浏览器、或路径为中文 UNC（`\\192.168.x.x\中文目录\`）时，headless 截图常失败。改为**一份场景图（scene graph）→ 渲染两次**：同一份图元列表（rect/line/poly/circle/text）既输出 SVG 文本，也用 Pillow 画 PNG（本机 Python 环境需已安装 Pillow）。图元列表保证两版**像素一致**，不会出现"SVG 改了 PNG 没跟上"。绘图中间件写 ASCII 路径，UNC 中文路径只作命令行参数传入——Windows 下 `.ps1`/`.bat` 里的非 ASCII 路径会乱码，禁止脚本文件方案。
- 空间图是**剖面图（立面）**还是**俯视图**，取决于空间本身：单层房间用俯视；贯通多层的楼梯井/电梯井用剖面（楼层为纵轴、楼梯折线为内容），否则一层压一层看不出来。

### SVG-04 执行顺序（硬性门）+ 补救
①生成三件套 → ②核对站位逻辑（起始合理/跨段无瞬移/衔接移动归因明确/逆向必入画者已在图中）→ ③以核对后的空间关系写提示词空间布局段。**空间图未生成或未核对，不得进入 S4 写提示词**——写前先查 `{剧本目录}\空间图\` 是否已有本段三件套，没有就先补。
漏做补救：若提示词已交付才补图，须回查提示词空间约束与空间图逐项一致（不一致以图为准改提示词），并把核对结论写进 `{段名}_空间说明.md`。

## 角色朝向声明（FACE-01）
- 一段提示词中，第一个镜头写明角色朝向后，后续镜头只要朝向不变**不必重复声明**——视频 AI 默认延续。
- 视频 AI 只在动作发生转向时判断朝向：动作含转身/转向时必须写明转向后的朝向与面对对象（如"身体右转90度，面朝自动门内"），否则 AI 大概率让角色转向镜头。
- 概括：**朝向不变 → 不重复写；朝向改变 → 必须写清转向后的面对对象**。
- 需要正面拍脸时，才把机位置于角色正前方并写明"面朝镜头"。

## 世界空间表（AXIS-01）

动作片在写镜头前先建立：
- 场景主轴 / 关系轴 / 人物世界位置
- 攻击方向 / 反震方向 / 飞行方向
- 场景左右结构 / 摄影机位于轴线哪一侧

- 必须区分：人物自身左/右、世界左/右、画框左/右。
- 高风险动作尽量同时写世界方向和屏幕结果。
- 不要无意越轴或反转人物左右位置。
- 如果镜头进入攻击轴，必须解释镜头与目标的关系，例如："摄影机后方正是精灵女，因此剑尖对准镜头即代表对准精灵女。"
