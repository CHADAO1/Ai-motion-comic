# 规则模块 R12 — 配音指令与音色标签（VO-*）

> 总控在 Stage S4（提示词组装）与台词交付环节读本文件。当剧本需要**配音指令**（即梦全能参考配音 / 后期配音 / TTS）时硬性生效。
> 国内 P1-P3：中文配音指令；海外 P4：英文台词 + 中英对照 TXT，配音指令按英文口音/音色描述。
> 来源：即梦 Seedance 全能参考提示词工程 + 工业化工作流 V1.9.3 标点表演体系。

## VO-01 配音指令固定格式（硬性，五段式）

```text
【配音指令：角色名｜精准音色标签｜音色核心特质｜状态（XX/XX）｜语气（XX/XX/XX）：台词原文】
```

| 字段 | 要求 |
|---|---|
| 角色名 | 必须与分镜组内标注的角色名**完全一致** |
| 精准音色标签 | 必须取自 VO-03 标准音色标签库，禁模糊标签 |
| 音色核心特质 | 与标签强匹配的人设补充（如"温润深情""心机深沉""正直严厉"） |
| 状态 | 括号内标当下情绪/肢体状态，多项用 `/` 分隔 |
| 语气 | 括号内标语速/语调/语气细节，多项用 `/` 分隔 |
| 台词原文 | 冒号后直接跟**原文原句**，不得改字/缩写/增减 |

**背景音补充**（可选，仅可在结尾追加，不得破坏核心格式）：
```text
【配音指令：顾云庭｜温润公子音｜温润深情、沉稳内敛｜状态（欣喜/温柔）｜语气（语速慢/饱含爱意）：婉清，我来接你过门啦！｜背景音：喜庆鼓乐、宾客模糊交谈声】
```

## VO-02 台词与内心 OS 处理（硬性）

1. **台词只能使用输入文案原句**——不得改字、缩写、增减；超长必须拆分至多个镜头，单镜头单条配音指令
2. **无台词镜头**必须固定标注 `【配音指令：无】`——禁止省略或模糊
3. **内心 OS**：
   - 按**正常台词**输出配音指令（保证声线统一），并在「状态」或「语气」栏加 **【内心独白】** 标签
   - 内心 OS 必须**视觉外化**：通过动作、景别切换、视线变化体现，不得只靠声音
   - ❌ 禁止写成 `【配音指令：无】` 或直接省略
4. 绝对值禁止出现：`同前 / 同上 / 默认 / 略` 等省略形式

## VO-04 标点 → 表演映射（硬性，文戏核心）

台词标点不是排版符号，是**表演节拍**。禁止删除、替换或合并原标点。

| 标点 | 表演含义 | 提示词写法 |
|---|---|---|
| `，` | 小停顿、试探、思考 | 停顿 0.2-0.5 秒，眼神轻移 |
| `。` | 情绪落地、克制、冷淡 | 尾音下落或收住，表情收束 |
| `！` | 重音加压、警告、震惊 | 指定重音词，**避免全程大喊** |
| `？` | 怀疑、试探、脆弱追问 | 尾音轻微上扬，眼神寻找 |
| `？！` | 质问加爆点 | 只用于强烈指控或震惊 |
| `……` | 情绪卡在喉咙里 | 呼吸中断、吞咽、嘴唇微张 |
| `——` | 转折、打断、真相延迟 | 前半句被截断，后半句另起 |
| `～` | 柔软、亲近、撒娇、轻 | 尾音拉软（严肃文戏慎用） |
| `、` | 并列节奏、压迫式列举 | 每个并列词轻压重音 |

**声音行为公式**：`音量 + 语速 + 呼吸 + 停顿位置 + 重音位置 + 尾音`

**示例**：
> "你真的……从来没信过我吗？"
> → 省略号处喉咙卡住 0.5 秒，"从来"轻重音，问号尾音上扬后迅速收住；声音变轻、气息不稳，眼神先停住再向下偏移，嘴唇微张但没有立刻继续说。

## VO-05 语速表与台词时长公式（硬性）

**七档语速表**（比 TIME-01 的单档口径更细，本表优先）：

| 类型 | 语速 | 适用场景 |
|---|---|---|
| 舒缓抒情温柔对话 | 3.0 字/秒 | 告白、安慰、柔和回忆 |
| 沉思安静内心独白 | 3.2 字/秒 | 心理独白、迟疑 |
| 默认正常情节对白 | 4.4 字/秒 | 日常对话 |
| 剧情推进对白 | 4.6 字/秒 | 信息推进 |
| 客观叙事旁白 | 4.8 字/秒 | 无强情绪旁白 |
| 紧张对峙激烈冲突 | 5.0 字/秒 | 争执、逼问 |
| 慌乱惊恐急促情绪 | 5.5 字/秒 | 逃跑、惊恐 |

**公式（硬性下限）**：
```text
镜头时长 ≥ 台词字数 ÷ 语速 + 必要停顿 + 表情反应时间
```

**附加规则**：
- 单组台词总时长 ≤ 组时长 × 80%（留出动作展示时间，防音画不同步）
- 不要把 15 秒填满台词——**必须留出沉默、反应、眼神变化**
- 含省略号/破折号/问号的台词，**必须额外预留停顿和尾音时间**
- 同一镜头内允许至多两条配音指令，但必须按各自字数和节奏**叠加计算**总时长

## VO-07 脸·声·词同步（硬性）

每句台词必须至少绑定三项：**表情状态 + 声音状态 + 标点节奏**。

**禁止冲突**：`脸在崩溃大哭，声音却稳定冷静`——除非剧情明确是伪装，且**写清伪装机制**（如"强装镇定，声线刻意压平但尾音发颤"）。

## VO-08 AIGC 强弱约束分层（硬性）

写提示词时必须区分哪些是视频模型强约束、哪些只服务配音/后期：

| 层级 | 内容 | 写法 |
|---|---|---|
| **强约束** | 人物、场景、镜头、景别、动作、脸部可见变化、嘴型节奏 | 必须写进镜头主体动作 + 关键约束 |
| **中约束** | 呼吸、停顿、眼神、手指小动作、表演节奏 | 写成 2-3 个可见锚点 |
| **弱约束/后期参考** | 音量、重音、尾音、声线质感 | 写入音频规范，**不强行当画面约束** |

> 注意：声音细节主要服务**嘴型节奏、配音和后期**，不要当成视频模型的强画面约束——否则会挤占画面描述的权重。

- **国内 P1-P3**：出《中文台词表》（段号/角色/台词/时长/音色标签）供配音与剪辑

- 交付文档必含：台词提取表 + 台词标点与语音表演拆解表 + 逐句台词声音表演表
