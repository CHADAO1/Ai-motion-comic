# 工作流模块 W2 — Mode 2：剧本优化

> 完整方法论见 references/SCRIPT_OPTIMIZATION.md（4 维度 before/after 示例、Ekman 微表情表、质量标准）。本文件只定义流程与交付要求。3 个 Phase，不要压缩。

## 优化维度

1. **画面情绪丰富** — 把情绪标签（"他很伤心"）转成镜头可捕捉的视觉/物理/环境线索级联
2. **剧情扩写** — 把骨架动作（"他走到门口"）扩成带感官细节与潜台词的物理微动作链
3. **人物表情动态** — 把面部表演编成定时微动作序列（Ekman 微表情系统，Duchenne 真笑 vs 社会性假笑区分）
4. **逻辑关系优化** — 审计并强化动机链、因果链、角色一致性、场景过渡、信息揭示逻辑

## Phase 1 — 诊断扫描
读整个剧本，按 4 维度输出诊断报告，列出每个问题的场景号与简述。以 *"诊断完成。是否需要对全部问题进行优化？还是指定某些维度/场景？"* 结尾。

## Phase 2 — 优化提案
对每个诊断问题（按场景分组）给出改写方案，显示 before/after 文本 + 优化说明（说明处理了哪些维度、如何处理）。

## Phase 3 — 完整优化剧本
应用所有批准的优化。输出完整优化剧本（.txt），末尾附优化摘要（各维度计数）。产物同样遵守 PUR-03/04：优化后剧本是独立成品文本，不含反馈/理由/括号注释。

## 优化质量标准（每次改写强制执行）
- 每个情绪标签替换为至少 3 个物理微事件
- 每个动作扩写覆盖至少 3 个感官通道（视觉/听觉/触觉/嗅觉/温度）
- 每个面部表情分解为至少 3 个定时节拍（①②③）
- 每个"突然"动机替换为触发事件
- 每个场景时间跳跃给过渡暗示
- 每个角色行为变化给记录的转折点
- 角色位移有屏幕内触发事件、体位逐拍连续（LINK-03/04）；异象特效来源与去向成对、用动态动词（VFX-02/03）；出场配角有收尾交代（PERF-04）；亲密接触进度保真（PERF-05）；效果光不用天体光源词（NEG-04）

## 交付与衔接
- Mode 2 交付时附**三阶段完成声明**（诊断 → 提案 → 完整优化，缺一不可，见总控 Audit 适用范围）。
- 用户接着要"转提示词"时，以优化后剧本为输入进入 Mode 1 流水线 S0，自动触发完整审查流程。
