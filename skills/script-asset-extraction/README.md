# script-asset-extraction — 剧本资产提取师

把剧本变成 AI 电影前期可用的**视觉资产总表**：角色、道具、场景、特效四类资产，每个"上镜可见的外观单元"一行（含状态拆分与连镜风险评级），输出带说明页的 Excel。

## 触发表
| 模式 | 中文触发 | 英文触发 |
|---|---|---|
| Mode 1 全量提取 | 剧本资产、资产提取、资产总表、角色资产、场景资产、道具资产、连镜分析 | asset extraction |
| Mode 2 增量更新 | 更新资产表、资产增量更新、新版剧本资产 | update asset sheet |

## 在 OpenCode 中使用
对包含剧本的目录说"帮我提取这个剧本的资产/生成资产总表"，技能自动进入 Mode 1 流水线：
S0 源转文本(docx 免依赖解析) → S1 逐场出场流水 → S2 按 rules 归纳 assets.json → S3 脚本出《资产总表.xlsx》→ S4 预检报告。
产物：`{剧本目录}\outputs\资产总表.xlsx`（Sheet1 总表 13 列；Sheet2 字段说明+统计+建议）。

## 在其他工具中使用
按宿主能力降级，共享同一套产物约定：
- 能读文件+跑 node：按 `SKILL.md` 总控调度全流程；
- 只能读文件：把 SKILL.md §3 阶段表 + rules/*.md 全文贴给模型执行；
- 只能贴文本：贴 SKILL.md + 当前阶段的单个规则模块。

## 目录结构
见 `SKILL.md` §5 File Map。核心：`rules/` 五个领域模块（编号规则），`scripts/build_xlsx.mjs` 出表脚本，`review/preflight.md` 交付门。

## 最易踩的坑 TOP
1. 只抽样不通读 → 高风险资产漏登记（铁律 1）。
2. 把台词提到但没拍出来的变化建成行（CHA-06）。
3. 文字道具不抄文字内容 → 后期字迹穿帮（PRP-02）。
4. 场景只建整体不拆视角 → 大厅门口每集长得不一样（SCN-02）。
5. 特效长在角色描述里不单独归类 → 黑雾每集形态漂移（FXR-01）。
6. 手工编 xlsx 不走脚本 → 列结构漂移、统计缺失（铁律 4）。
7. 出现次数凭印象填 → 与流水账对不上（TBL-05）。
8. 音色需求误入本技能 → 本技能只做 voiceRef 关联引用。
