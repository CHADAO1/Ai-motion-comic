# 审查模块 C1 — Preflight 内容检查清单

## 使用原则
1. 完整性以要素计数为准（几类资产/几行/几个高风险），禁止最低字数标准——短而全即合格。
2. 每个 ✅ 必须附可核查证据：磁盘路径/脚本输出行/数值/名单；"已检查""无问题""符合要求"按未检查处理。
3. 任一项 ❌ → 当场返工对应 Stage，重跑受影响项后再交付。

## 分组清单
### A 覆盖完整性
- [ ] 流水账覆盖全部集数：首场与末场场次号在 01_出场流水.md 中可核对（SKILL.md S1）
- [ ] 角色盘点数 = 流水账出现过的角色名数（CHA-01），多出的名字列入豁免或补档
- [ ] assets.json 四数组 characters/props/scenes/fx 均非空且 JSON.parse 通过（TBL-07）

### B 拆分正确性
- [ ] 每个立档角色有基础形象行（CHA-04）；抽查 ≥3 个角色的状态维度核对表逐项过（CHA-02）
- [ ] 状态命名可一眼区分（CHA-03）；角色基础行的音色关联列已填或留空有因（CHA-05）
- [ ] 文字可读道具全部建档并抄录关键文字（PRP-02）
- [ ] 场景阶段状态变化已拆 V 行（SCN-03）；反复出现的空间节点已有独立 V 行（SCN-02）
- [ ] 存在物理衔接的视角/道具已互相注明对位关系（SCN-05）
- [ ] 身体附着/能力/环境三类特效均已独立 FX 行（FXR-01）且载体可回引（FXR-02）
- [ ] 特效强弱状态已记录（FXR-03）；成对特效已注明需同源生成（FXR-04）

### C 评级与判定
- [ ] 所有 risk=高 的行 needRef=是（TBL-03/TBL-04）
- [ ] 跨场次复用判定复核：同场连续出现未被误判为跨场（PRP-03）
- [ ] 制式群演道具已合并通用档（PRP-06）；转移类道具 owner 链完整（PRP-05）
- [ ] 豁免清单非空时：每条豁免满足 PRP-04 三条件且有流水留痕
- [ ] 时段氛围字段无空白高风险行（SCN-06）
- [ ] 出现次数与流水账一致（TBL-05）：抽 ≥5 行人工复核

### D 交付物
- [ ] outputs\资产总表.xlsx 存在；build_xlsx.mjs 统计行数 = assets.json 展开行数
- [ ] xlsx 完整性：Expand-Archive 解包成功且 sheet1.xml 行数一致

- [ ] 交付报告含：资产计数、高风险清单、豁免清单、使用建议

### E 名称一致性

- [ ] 表内无同义异拼：抽查 ≥2 个角色名 + ≥2 个专名的全文一致性
