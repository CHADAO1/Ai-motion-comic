# 规则模块 R4 — 特效资产

> 总控在 S2 读本文件。规则编号 FXR-*。发光纹路、能量雾、结界这类"长在角色/场景上的效果"如果每集长得不一样，比道具穿帮更显眼，必须独立归类锁定。

## FXR-01 特效独立归类（硬性）
以下类型必须建 `FX-nn` 行，不得只写在角色或场景描述里：
①身体附着特效（诅咒纹路/命定印记/瞳色变化）；
②能力表现特效（黑雾/治愈之光/灵力光球/护盾）；
③环境型特效（结界屏障/法阵发光/传送黑雾）。
正例：凯尔诅咒纹路建 `FX-nn` 并在各状态行 note 引用；反例：把"黑雾"只写成凯尔基础描述的一个形容词。

## FXR-02 载体交叉引用（硬性）
每个 FX 行的 `carrier` 写清附着载体（哪个人/哪个面/哪个区域），并在相关角色状态行、场景 V 行的 note 里回引 FX 的 ID，双向可跳。

## FXR-03 强弱状态记录（重要）
特效的强度/颜色/范围变化（收敛平复 ↔ 大面积蔓延；微光 ↔ 爆发）在 look 内用分号列举成对状态；若某强度态反复出现且需要单独参考图，复制整行为新 FX 行并在 note 说明拆分原因。

## FXR-04 成对一致性（重要）
双人联动特效（印记同步亮起、双色光线缠绕、双力融合）必须在 note 注明"成对出现、两侧需同源生成"，提示使用者一次性生成含双方的参考图，避免左右不一致。
