# script-asset-prompt-design — 剧本场景资产文生图提示词设计师

把剧本场景提炼成**成组的、世界观统一的**真人写实电影风格文生图提示词（中英双版；画幅按管线：P1 下沉中老年 9:16 / P2 女频恋爱 16:9 / P3 女频恐怖 16:9 / P4 海外 21:9，见 rules/PIPELINE_PRESETS.md）。

## 核心理念

- **一个场景 = 一套空间组**：单场景升维为有纵深的空间系统（外缘→主体→异变→核心→真相），每层绑定剧情节点。
- **剧本证据优先**：每个视觉元素有出处；设计延展必须显式声明（⚠️视觉延展+锚点）。
- **悬念经济学**：信息量随剧情递进（世界观→异常→秘密→核心→真相），做视觉剧透检查。
- **母题锁定 + 渐变设计**：统一视觉母题与光色语义，相邻张渐变而非跳变，保证"看上去是一个地方"。
- **画面控制**：高光成面不成点、负空间是构图资产、细节预算集中在焦点——避免脏碎花累的 AI 感。
- **跨文档一致性（SPC-09）**：场景常分次、跨对话生成，故生成前先 S0 检测已有文档——场景重复走"满足/不同机位/剧本冲突"三选项，资产相关则沿用旧文档精确母题 token；全项目共享 `母题索引.md` 与连续性 ID，保证跨文档"一个地方"。

## 在流水线中的位置

上游：script-asset-extraction（资产清单）→ **本技能**（场景文生图提示词）→ 下游：cinematic-seedance-director（视频提示词）。

## 使用方式

对加载器说触发词即可，如："帮我把剧本里 XX 场景做成文生图提示词"、"场景提示词"、"资产提示词"。

## 跨文档一致性（务必遵守）

- 生成**任何新场景前**先 `glob outputs/场景提示词/**/*.md` 检测已有文档（S0），并按 SPC-09 处理场景重复 / 资产相关。
- 每个场景文档首次生成后，向 `outputs/场景提示词/母题索引.md` 追加一行（视角 ID + 母题 token + 关联），供后续任务快速检索、避免重读全文。
- 详细规则见 `rules/cross-doc.md`（SPC-09）。
