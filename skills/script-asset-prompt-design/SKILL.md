# 剧本场景资产提示词设计 — 总控调度器

把剧本场景变成"同一世界观下的成组文生图提示词"。**本文件只做调度**：执行到哪个阶段读哪个规则文件，禁止凭记忆跳过读取。

## 0. 定位与边界（流水线中的位置）

```
script-asset-extraction（资产清单 Excel）
        ↓ 提供资产清单与连镜风险
【本技能】剧本场景 → 成组文生图提示词（中英双版）
        ↓ 提供视觉锚点与母题
cinematic-seedance-director（Seedance 视频提示词）
```

上游清单非必需：有剧本原文即可独立运行。

## 1. 全局铁律

1. **先证据后设计**：任何视觉元素必须有剧本出处，或明确标注"⚠️视觉延展"并给出锚点依据（SPC-02）。
2. **场景以组为单位交付**：一个地名=一套空间组，禁止孤立单张（SPC-03）。
3. **一图一义**：每张图只讲一件事，信息量随剧情递进（SPC-05）。
4. **画幅与调性按管线（PP-S1）**：开工先读 `rules/PIPELINE_PRESETS.md` 定管线——P1 下沉中老年 9:16 / P2 女频恋爱 16:9 / P3 女频恐怖 16:9 / P4 海外 21:9；真人写实电影风格、低饱和不变，用户指定除外（VIS-03）。**用户未说且题材无法判定时必须提问**。**同时按 `rules/cultural-context.md`（CUL-01~08，2026-09-04 新增）做文化坐标定位**：判定市场×时代×地域，建筑/材质/服装道具/语言环境必须与剧本时代地域吻合（CUL-03~07），P4 欧美题材按"本地导演拍给本地观众"原生制作（CUL-08），全管线禁跨文化串味。
5. **反馈转译为正向描述**：用户反馈（如"高光过碎"）必须转译为系统级正向约束段落，禁止把否定式反馈原文写进提示词（VIS-04）。
6. **中英双版同时交付**，结构完全对应（PRM-02）。
7. **交付必须过 review/preflight.md 全 ✅**，并附空间组总览表。
8. **生成前先做 S0 跨文档检测**（SPC-09）：`glob outputs/场景提示词/**/*.md` 判断新场景与已有文档是"场景重复"还是"资产相关"，按三选项/资产相关规则处理；跨文档引用一律用连续性 ID（空间组-层字母）；首次生成后向 `母题索引.md` 追加登记行。
9. **提示词自包含（无关内容禁令）**（PRM-08）：代码块内只允许"单看提示词本身就能理解"的内容——禁外部文档/资产引用（如《母题索引》、连续性 ID"城堡-C"）、禁工具操作指令（@哪张图）、禁证据标注/规则编号/剧情解释；跨文档一致性只体现在块外说明与 ID 标注，画面本身全部自描述。

## 2. 流水线（单模式）

| Stage | 做什么 | 必读文件 | 输出 | 通过条件 / 失败回退 |
|---|---|---|---|---|
| **S0 跨文档检测** | glob 已有场景文档，判断场景重复/资产相关，按 SPC-09 处理 | rules/cross-doc.md SPC-09 | 关联判定（选项1/2/3 或 资产相关）+ 母题索引登记行 | 未检测直接生成判 ❌（preflight 16）；命中须有关联声明 |
| S1 证据考古 | 检索该场景在剧本中的全部描写，三级分级；**同步做文化坐标定位（CUL-01 市场×时代×地域）** | rules/space-system.md SPC-01~02 + rules/cultural-context.md CUL-01~02 | 证据清单（每条带集-场号+分级）+ 文化坐标行 | 覆盖场景标题行/△动作行/台词与OS三类来源；缺证据回读剧本；文化坐标未判定判 ❌ |
| S2 空间系统建模 | 单场景升维为空间组，分层并绑定剧情节点 | rules/space-system.md SPC-03~04 | 空间组分层表（层名/剧情绑定/证据等级） | 每层有绑定节点；无依据的层删除或标⚠️ |
| S3 悬念排布 | 设计信息量递进链，做视觉剧透检查 | rules/space-system.md SPC-05 | 递进链 + 每集"观众不应看到的元素"清单 | 早期集数不出现后期核心元素（SPC-05） |
| S4 母题锁定 | 统一视觉母题与光色语义 | rules/space-system.md SPC-06~08 | 视觉母题表（树种/岩石/雾/色调/光色语义） | 母题可全组复用且互相不冲突 |
| S5 提示词编译 | 按十段结构产出中英双版提示词 | rules/prompt-anatomy.md 全部 + rules/visual-control.md 全部 | 每层场景一图：中文提示词 + English Prompt | 逐张过 review/preflight.md；❌ 项当张返工 |

## 3. 交付物约定

```
{剧本目录}\outputs\场景提示词\
├── 母题索引.md              ← 项目级 Motif Registry（SPC-09）：每文档首次生成后追加一行
└── {空间组名}\
    ├── 00_空间组总览.md      ← 文化坐标（CUL-01）+ 分层表 + 递进链 + 母题表(含文化坐标行) + 剧透检查 + 串味自检(CUL-06)
    └── {层名}.txt            ← 每层场景一个文件：中英双版提示词
```
> 每个视角用连续性 ID `空间组-层字母`（如 城堡-C）标注；跨文档引用一律用 ID。

## 5. 维护约定

修改任何规则前先读 rules/ 对应文件全文；新增规则写入对应模块并编号（只增不复用），同步登记进 review/preflight.md 清单项；变更记入 CHANGELOG.md。
