# 规则模块 — SPC-09 跨文档一致性（分次生成时的母题复利）

作用域：跨多次对话、按场景逐个生成提示词文档时，保证"新文档"与"已生成文档"属于同一世界。编号 SPC-09，对应流水线 S0 阶段。

## 为什么需要

场景几乎总是一个一个生成，且常跨对话完成。单次任务无法回头改写旧文档，因此一致性不能靠"一次想全"，而要靠**生成前读取已有场景文档**来判断重复与关联，并按规则处理。两类核心情形：

---

## 9.1 场景重复（Scene Overlap）

新场景名 / 空间名与已有文档中的某视角**同名或同空间**。三选一：

- **选项 1 · 已有视角已满足需求**
  既有视角已覆盖剧情需要 → **不再生成**。在新文档"关联文档"头注明：
  `已在《X》文档 Y 视角（ID）生成，本场景引用，无需重出。`

- **选项 2 · 不同机位 / 景别**
  既有视角是另一个镜头（如远景 vs 中景、正厅 vs 柱后）→ 读取既有视角提示词，**逐字提取其母题 token 与连续性约束原文**，在同风格下生成新机位。新文档注明：
  `与《X》Y 视角（ID）同源，本张为 Z 机位展开（SPC-09 选项2）。`
  （两者都是有效视角，可并存；不重出，只展开。）

- **选项 3 · 既有视角与剧本冲突**
  空间错、布景错、连镜冲突等 → 在新文档**正常生成**，并明确标注：
  `《X》Y 视角（ID）有误，以本版本为准`。
  **同时写明具体哪里错**（哪一句描写 / 哪条剧本证据被误用），不能只说"有误"。
  在母题索引"已知冲突"区登记，并便于回头给旧文档加一行：
  `⚠️ 校正见《新文档》Z 视角（SPC-09 选项3）。`

---

## 9.2 资产相关（Asset-Related）

新场景**包含或能看见**一个已生成的资产（例："城堡旁矮树林"若能看见城堡，则城堡是相关资产）→ 该资产部分**必须沿用旧文档的精确视觉 token 生成另一个视角**，不得另起一套风格。新文档注明：
`本图含《X》资产（远景/局部），风格沿用其 A 视角（ID）（SPC-09 资产相关）。`

判定要点：是否"看见旧资产"由剧本空间关系决定，不能凭空假设。若旧文档未涉及该资产外观（如矮树林完全背对城堡、看不见），则不属于资产相关，按普通新场景处理。

---

## 9.3 检测流程（S0，生成前必做）

1. `glob {剧本目录}/outputs/场景提示词/**/*.md`，获取全部已有场景文档。
2. 用新场景名 / 空间名做关键词匹配；命中则读取该文档的"关联文档"头、空间组总览表、母题表，判断属 9.1 还是 9.2。
3. 读取 `母题索引.md`（若存在）可跳过全文阅读，直接拿母题摘要与关联（见 9.4）。
4. 无命中 → 按普通新场景走 S1~S5。
5. **未做 S0 直接生成，视为未过 preflight（检查项 16）**，须回补关联声明。

---

## 9.4 母题索引（Motif Registry）

每个场景文档**首次生成时**向 `{剧本目录}/outputs/场景提示词/母题索引.md` 追加一行：

```
| 空间组 | 视角(层·名·ID) | 核心母题 token | 关联文档 | 备注 |
```

- 母题 token 用可复用短词串，如：`灰石砌筑/狼头纹章(不发光)/烛火暖橙/银器冷白/深色布幔/冷蓝夜雾`。
- "已知冲突 / 待修正"小节登记 9.1-选项3 的冲突；"历史修正记录"小节登记 9.7 的轻微漂移修正。
- 母题索引是轻量索引，新任务优先读它，避免重读全部文档全文。

---

## 9.5 连续性 ID（Continuity ID）

每个视角用 `空间组-层字母` 作稳定 ID（如 `城堡-C`、`宴会厅-B`、`梅拉-A`）。跨文档引用一律用 ID，避免"那个大厅那张图"式歧义。ID 在文档内视角标题与母题索引中双重标注。

---

## 9.6 风格提取铁律

生成 9.1-选项2 或 9.2 的新视角时，新提示词的"连续性约束"段**逐字复用**旧文档的母题 token 与连续性约束原文（仅改机位 / 景别描述），**不重写一套相近但漂移的表述**。这是"看上去一个地方"的硬保障。

---

## 9.7 历史修正的处理（非冲突的漂移）

若发现旧文档确有可统一之处（非剧本冲突，而是两文档各自生成导致的轻微漂移，如某母题一方有、一方无）→ 优先**直接补一笔**到旧文档对应视角（并登记母题索引"历史修正"），而非新文档另立版本。仅在剧本冲突时才走 9.1-选项3。

> 例：城堡-C 先生成未提布幔，后续主宴会厅将布幔定为该大厅专属母题。按 9.7，直接给城堡-C 提示词补入布幔，使其与主宴会厅一致，而不是新文档宣称城堡-C 有误。
