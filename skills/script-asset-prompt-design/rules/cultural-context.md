# 规则模块 — CUL 文化·时代考古（场景怎么"不串味、像本地的"）

作用域：S1 证据考古内嵌的「文化坐标定位」，贯穿 S2~S5 全部材质/建筑/服装/道具母题决策。编号前缀 CUL。
> 一句话：**先判定"给谁看、什么年代、哪片地方"，再决定场景里每一块石料、每一根梁、每一件陈设长什么样。** 禁止跳过文化定位直接画一个"通用中式/通用奇幻"场景——那会做成"套皮片"。

## CUL-01 市场-时代-地域定位（S1 第一件事，强制）

产出提示词前，先读剧本建立三坐标，写进空间组总览表「文化坐标」行：

| 坐标 | 判定来源（读剧本） | 输出 |
|---|---|---|
| **观众群体** | 平台/管线明示、语言（中/英）、题材受众 | 判定为 国内下沉中老年 / 国内年轻女性 / 海外欧美 / 其他地域市场 |
| **时代背景** | 剧本时代信息：现代 / 架空 / 中世纪 / 19 世纪 / 赛博未来 等，取△动作行与道具线索 | 锁定年代区间（宽可到"中世纪黑暗奇幻"，不可空泛写"古代"） |
| **地域文化** | 人名 / 地名 / 习俗 / 饮食 / 自然植被 / 建筑线索 | 锁定文化原型（北欧 / 西欧 / 东欧 / 东亚 / 中东 / 北美 等） |

- **判定输出必须落到"母题表"**（SPC-06）最前一行：`文化坐标：{市场} × {时代} × {地域原型}`，全组每张提示词共享，禁止每层各定各的。
- **无法判定**（剧本既不提示时代也不提示地域）→ 按当前管线默认文化（见 CUL-02），但仍须写清默认值；题材允许跨文化架空时，标注"架空混搭"并说明主导文化（避免无意识混搭成串味）。

## CUL-02 四管线默认文化坐标速查

| 管线 | 市场 | 默认时代 | 默认文化原型 | 说明 |
|---|---|---|---|---|
| **P1** 国内下沉中老年 | 国内 | 当代（2000s-2020s 市井/乡村） | 中式·当下生活化 | 老旧小区/县城/农村，不是都市摩登片 |
| **P2** 国内女频恋爱 | 国内 | 当代都市 | 中式·一二线都市 | 写字楼/商圈/公寓，轻奢但接地气 |
| **P3** 国内女频诡异恐怖 | 国内 | 当代 | 中式·日常居所 | 日常感越强越恐怖；灵异元素不得直白呈现宗教建筑 |
| **P4** 海外 | **剧本地域为准**（如欧美） | **剧本时代为准** | **剧本地域文化原型** | **当"本地导演拍给本地观众"做**（欧美题材=美式/欧式原生，见 CUL-08） |

> 国内管线若剧本是历史/民国/奇幻题材，同样按 CUL-01 重定位，不锁死在"当代"。

## CUL-03 建筑母题文化正确性

每套建筑必须有**明确的年代-地域语法**，且与角色服装（场景技能只定环境，服装见角色技能）时代同步：

| 检查 | 错（串味） | 对（本味） |
|---|---|---|
| 中式古典 | 汉式宫殿配西式廊柱 | 木构斗拱、瓦当、影壁、四合院格局、苏式园林借景 |
| 中式当代 | 江南水乡白墙黑瓦硬安在北方县城 | 北老小区红砖/筒子楼 / 南城中村自建房，窗机空调、晾衣架 |
| 欧洲中世纪 | 古堡内出现哥特尖顶+文艺复兴穹顶混用；现代钢化玻璃 | 罗马式厚墙圆拱 / 哥特尖拱肋顶；木桁架、石砌、彩绘玻璃 |
| 美国西部/边疆 | 欧式石堡在荒漠 | 木框架板房、cattle 栅栏、酒馆双开门、土路马车辙 |
| 欧美当代 | 美式郊区独立屋放中式飞檐 | 木骨架 vinyl siding / brick、坡屋顶、门廊 porch、车道 |

- 建筑"骨骼"（结构/柱式/拱形/屋顶）优先还原；**装饰层**（雕花/壁纸/纹样）是地域指纹，最容易被模型"顺手异化成另一种文化"，负面清单或"不是X而是Y"句式（PRM-03）里锁死。
- 年代允许适度做旧，但做旧必须符合该材质真实老化（石风化/木朽蚀/金属氧化），禁止"把所有古建筑统一调成发霉绿"。

## CUL-04 材质母题文化正确性（就地取材 + 年代工艺）

材质必须回答两个问题：**这地方当时有什么材料**、**用当时工艺能加工成什么样**。

| 年代-地域 | 应出现（就地取材） | 禁现（穿帮材料） |
|---|---|---|
| 中世纪欧洲 | 本地石材、橡木/橡栎木、羊毛、麻布、皮革、锻铁、蜂蜡 | 尼龙/化纤、塑料、钢化玻璃、混凝土预制、铝合金、LED |
| 19 世纪工业期 | 铸铁、砖、钢构、厚玻璃窗格、石膏线 | 塑料、复合材料、大面积玻璃幕墙 |
| 中国明清 | 木、青砖、石灰、纸、瓷、漆、铜铁 | 明显现代五金、塑料窗框 |
| 当代 | 按真实城市材料 | 只要不是这城市/年代实际有的，就是串味 |

- 材质写进提示词时用"**实体名词**"（"粗糙砍凿的花岗岩""风化的白橡木梁"），不写抽象（"有质感的材料"）。
- 每个空间层出现的材质须能**在同一文化坐标下共存**——中世纪地下墓窖可以有锻铁烛台、石砌，但不该冒出白瓷洗手盆。
- 材质母题要与角色技能对齐：场景若用"灰石+银器冷白"，角色配饰也走同一材质语言（跨文档 CHR-11）。

## CUL-05 服装与道具（环境内陈设）文化正确性

场景里的服装（挂置/晾晒/陈列的衣物）、随身道具、陈设，必须和空间使用者的**时代+地域+阶层**匹配：

- 道具服务剧情而非服务"好看"：中式农村家里出现的是农具/搪瓷缸/旧彩电，不是英式下午茶具。
- 阶层一致性：破败出租屋 vs 顶层公寓，器物档次跟着人物设定走，不因 AI 顺手就"所有室内都豪华"。
- 季节/功能一致性：道具要能在该空间合理出现（厨房有锅灶、书房有书架，不是为摆拍堆砌）。
- **语言类环境元素（CUL-07）独立检查**。

## CUL-06 跨文化串味禁令（交付前自检）

完成一组后，逐张做"串味自检"，任一命中即判该张返工：

1. 同一张图内混入 ≥2 种有明显冲突的文化语法（中式飞檐+欧式石柱 / 沙漠清真寺+北欧木屋）。
2. 建筑/材质/服装/道具的年代错位（中世纪石堡出现 LED / 打印机 / 现代塑料椅）。
3. 用"中式审美滤镜"去拍欧美题材（欧美古堡却调成中式古装剧的青灰水墨感、或反之）。
4. 文字/招牌/铭牌用了错误语言（欧美场景出现汉字招牌，见 CUL-07）。
5. 一切"为了惊艳而跨文化堆料"——多文化元素混搭必须有**剧情或世界观依据**，否则一律砍到单一主导文化。

> 自检结论写入空间组总览表"串味自检：通过/未通过"。**P4 欧美题材重点做**——中式套皮欧美是海外观众一眼出戏的第一原因。

## CUL-07 语言环境元素（招牌/文字/装饰符号）

场景中所有**文字载体**（路牌、店面招牌、横幅、印刷品、墙上涂鸦、装饰字母/纹章）必须符合文化坐标：

- P4 欧美 → 英文为主；招牌拼写要真实（不是 pseudo-Latin 乱码）；按地域可含本地语（法语/西语区）。
- P1/P2/P3 国内 → 简体中文；繁体/日文/韩文元素需有剧情理由。
- 字体风格对应年代（中世纪羊皮手抄体 / 维多利亚衬线 / 现代无衬线）。
- 若剧本未指定文字内容，**宁可留白/虚化也不写错字**——模型常生成无意义假文字，在负面清单加"garbled text, fake letters"。

## CUL-08 原生视角（尤其 P4：当本地人拍给本地人看）

- 视觉审美的"导演立场"要和观众一致：P4 欧美题材，想象自己是一位当地导演在给本国观众拍电影——空间尺度（美式大宅 vs 欧式窄巷 vs 亚洲拥挤公寓）、生活习惯（地暖/壁炉/空调的呈现）、审美取向（美式实用粗犷 / 法式优雅 / 北欧极简）都要"本味"。
- 不要在画面里塞"给外国人看的中国符号"式标签，也不要在欧美片里塞"给中国人看的欧美印象"——例如欧洲中世纪的城堡不要拍成迪士尼主题乐园的鲜艳假城堡，要有真实历史质感。
- 判断尺度：**换一个该文化的本地人来看这张图，会不会觉得"这就是我家/我那个年代的场景"**——是，才合格。
