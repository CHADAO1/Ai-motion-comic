# 规则模块 — PRM 提示词结构（怎么"写"）

作用域：S5 编译阶段的提示词结构与语言技法。编号前缀 PRM。

## PRM-01 十段结构（每张提示词按此骨架）

```
① 标题行          场景全称·空间定位｜画幅（按管线 PP-S1：P1=9:16 / P2、P3=16:9 / P4=21:9；如"老宅客厅·黄昏主灯亮起｜9:16"）
② 风格定位与用途  电影风格 + 用途（如"第一集开场建立镜头"）
③ 时空总述        时段/地点/空间位置关系一句话
④ 空间分层        前景→中景→远景依次描述，含视觉引导线（道路/河流/山脊）
⑤ 核心视觉元素    该图的"主角"（如结界、立石），必须用"不是X而是Y"句式定义（PRM-03）
⑥ 环境异常暗示    递进用，极克制的超自然痕迹（"极少量""若有若无"）
⑦ 光线            环境光色温/饱和度/光色语义（SPC-08）
⑧ 氛围关键词      3~5 个情绪词（神秘、压抑、远古感……）
⑨ 摄影术语块      photorealistic, live-action, cinematic lighting, subtle film grain,
                  high dynamic range, restrained color grading, premium theatrical movie still
⑩ 负面清单        三层结构（PRM-06）
```

另加两个独立控制段（VIS-01/VIS-02），置于负面清单之前，各自有标题：
`【连续性约束】`（中文版）/ `CONTINUITY CONSTRAINT:`（英文版）
`【画面控制】`（中文版）/ `CONTROL VISUAL COMPLEXITY.`（英文版，大写起头）

## PRM-02 中英双版分工

- **英文版是生成主力**：术语化表达 + 大写段落标题强调（CONTROL VISUAL COMPLEXITY / CONTINUITY CONSTRAINT / Do NOT...），主流模型对英文术语响应最稳。
- **中文版供用户审阅**、以及供中文文生图模型使用；结构与英文版逐段对应，可适度解释性展开。
- 两版信息量等价：英文版有的约束，中文版不得缺失；反之亦然。
- 标题行双语：中文版用中文场景名，英文版用英文场景名。

## PRM-03 "不是X，而是Y"句式（核心技法）

先排除模型最常见的错误联想，再给正确方向。用于任何容易被画俗的核心元素：

> 结界"不是实体墙，也不是巨大能量罩，而是非常微弱、几乎融入空气的银白色透明波纹"
> 封印结构"不是完整规则的魔法阵，而是由石刻、裂开的环形沟槽和自然岩层共同组成的巨大古代结构"
> 遗迹"不是精致魔法装饰，而是沉重、粗粝、近乎工程建筑般的封印设施"

公式：`不是 [常见俗套A]，也不是 [常见俗套B]，而是 [克制准确的正确形态 + 程度限定词]`。

## PRM-04 量化约束

一切"多少"都给出具体数字或范围，禁止"一些/许多/大量"：

- 立石 → "约七到九根，不形成整齐的完整圆阵，而是自然散落"
- 符文 → "极少量、已严重风化，只有几个局部能够辨认"
- 排列方式也要约束（"自然散落"防对称阵列，"高矮不一"防整齐排列）

## PRM-05 克制表达与光的拟人语义

- 可见性递降词序：`清晰可见 > 若隐若现 > 极其微弱 > 几乎不可见 > 只能感觉到`。越接近核心/真相层的超自然元素，用越靠后的词。
- 光的拟人语义（让光有生命感但不过量）：
  - "像心脏跳动一样偶尔闪烁"
  - "仿佛地下有什么东西正在呼吸"
  - "仿佛山体内部存在一颗缓慢跳动的心脏"
- 保留呼吸感的句式：留出"仿佛/暗示/若有若无"级别的不确定描述，比确定性描述更有电影感。

## PRM-06 负面清单三层

每张提示词末尾的负面清单按三层组织（顺序固定）：

1. **内容层**：不要人物、怪物、现代元素、建筑城市……（按该图剧情位置定制，如开场图加"不要凯尔"）
2. **风格层**：不要游戏CG、动漫风、概念艺术插画、霓虹灯……
3. **质感层**：不要巨大荧光魔法阵、大量发光符文、能量光柱、过度发光、过高饱和……

注意：负面清单是兜底。正文里应当主要靠正向描写把画面引向正确方向（VIS-04），不要把所有约束都堆进负面清单。

## PRM-07 构图与引导线

- 每张明确一个视觉主体 + 一条引导线（山道、树列、石缝、光带）。
- 明确景别：远景建立镜头 / 中远景 / 宽阔中远景。
- 明确相机高度提示（如"镜头高度接近人物视线高度，但画面中不出现人物"）。
- 宽幅（16:9 / 21:9）下强调：主体明确、背景简化、"大面积负空间"；竖幅（9:16，P1）下强调：主体居中偏下、上部留环境层、地面细节入画（下沉观众熟悉的生活空间质感）。

## PRM-08 提示词自包含原则（无关内容禁令，与角色技能 CAP-10 同源）

**无关内容的定义：单看提示词本身无法理解的内容，就是无关内容。** 文生图模型只能看到本提示词块——它不认识场景名、不认连续性 ID、不认任何外部文档。凡是需要"上下文/文档/其他图片"才能理解的词句，一律禁入代码块：

1. **外部资产/文档引用**：`如《母题索引》所示`、`延续 城堡-C 母题`、`（复用封印-D 灰石母题）`——模型不知道"城堡-C"是什么。→ 改为**视觉自描述**："延续灰石冷暗、银器冷白的母题"。
2. **工具操作指令**：`@参考图`、`生成时 @ 封印-D`——@ 哪张图是用户在生图工具里完成的动作，不是模型能理解的画面内容。→ @ 操作写在块外说明；块内只写画面。
3. **文档内部交叉引用**：`见 §3`、`同 00_空间组总览 第X层`——块内没有章节概念。
4. **元信息与证据**：✅/⚠️/行号、SPC-xx/PRM-xx 编号、剧情解释（"因此""依据第X集"）、反馈修正记录（沿用 PUR-03/04 同源规则）。

**自检**：逐句问"单看这一句，生图模型能理解吗？"——不能 → 删或改写为自包含描述。
**判定口诀：删掉该内容若不影响生成结果 → 删；若影响画面 → 留并改写为可直接理解的描述。**
