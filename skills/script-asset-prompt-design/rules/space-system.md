# 规则模块 — SPC 空间系统（怎么"想"）

作用域：S1~S4 阶段的全部思维方法。编号前缀 SPC。

## SPC-01 证据考古

- 场景的空间信息散落在三类位置，缺一不可：
  1. **场景标题行**：如"5-4 夜 外 祭台侧高台"——直接给出时段/内外/地点；
  2. **△动作行**：环境、道具、光线、异常现象的视觉描写；
  3. **台词与 OS**：人物口中的空间信息（如"我百年承受诅咒，就是为了防止有人开启祭坛"——证明该地是长期驻守的封印重地）。
- 输出证据清单：每条注明集-场号 + 原文摘录，禁止凭印象概括。
- **证据考古内嵌「文化坐标定位」（CUL-01）**：清单完成后、进入建模前，先依据证据判定 市场 × 时代 × 地域 三坐标（读 `rules/cultural-context.md` CUL-01~02），后续所有材质/建筑/服装/道具母题必须服从该坐标。

## SPC-02 证据三级分级

每个空间层、每个关键视觉元素必须标注等级：

| 等级 | 含义 | 处理 |
|---|---|---|
| ✅ 剧本明确 | 有直接场景描写（如第5集明确出现"室外祭台/法阵凹槽"） | 按原文还原，细节可适度丰富 |
| ✅ 可由剧本提炼 | 多处散落信息拼合成立（如"结界微光边缘/屏障外沿"拼出外围结界） | 拼合后设计，注明拼合来源 |
| ⚠️ 视觉延展 | 剧本未定义具体形态，仅有间接锚点（如"浩瀚本源自地底喷薄而出"→地下空间形态） | 必须显式向用户声明"此为视觉延展"并给出锚点台词，禁止与原文冲突 |

交付物中⚠️项单独列出，让用户知道哪些是设计、哪些是还原。

## SPC-03 空间组分层

- 用户的"一个场景"（如"封印区域"）几乎总是**一套有纵深的空间系统**，不是一张图。
- 分层维度（按剧本地理选其一或组合）：外→内 / 低→高 / 浅→深 / 明→暗。
- 典型五层结构（可裁剪为三层，不建议超过五层）：
  1. **外缘层**——最合适的开场建立镜头；
  2. **主体层**——角色初次深入的区域；
  3. **异变层**——环境开始"不正常"的第一现场（首次给观众警示信号）；
  4. **核心层**——故事后半段的主舞台，中期才首次完整揭露；
  5. **真相层**——最终解释世界观的地方，最后揭露。
- 空间语法：让整个组形成"越往里越危险/越接近真相"的单向纵深感，观众看任何一张都知道自己在第几层。

## SPC-04 剧情节点绑定

- 每个空间层必须绑定：集-场号 + 出场人物 + 发生事件。
- 没有剧情绑定的层是装饰层——要么删掉，要么合并进相邻层。
- 输出空间组总览表列结构：`层 | 场景名 | 绑定剧集 | 事件 | 证据等级 | 信息量角色`。

## SPC-05 悬念经济学（信息量递进 + 视觉剧透检查）

- 同一空间组内，信息量必须递进，每张图只讲一件事：
  - A 世界观（这里有片森林，有结界）
  - B 异常（结界里面的森林不正常）
  - C 秘密（这里曾封印过某种东西）
  - D 核心（真正的封印中心在山顶）
  - E 真相（山顶祭台只是入口，真正的在被封印之物在山底）
- **视觉剧透检查**（必做）：列出每集"此时观众不应知道的元素"清单。例如第1集的画面不得出现：山顶祭台、巨碑、完整法阵、地下结构——它们属于第5集/第24集的悬念资产。
- 开场镜头的第一观众反应应是疑问（"她为什么来这种地方？"），不是答案（"哦这是封印区"）。

## SPC-06 视觉母题锁定

- 开工前先产出**母题表**，全组所有提示词共享，包含：
  - **文化坐标（CUL-01，置于首行）**：市场 × 时代 × 地域原型，锁定本组材质/建筑/服装道具的年代-地域语法
  - 植物母题（树种+形态，如"高大古老冷杉+少量扭曲枯树"）
  - 岩石/材质母题（如"深灰天然岩石，严重风化"）——材质须就地取材+年代工艺（CUL-04）
  - 大气母题（如"冷蓝灰薄雾"）
  - 色调母题（如"低饱和冷蓝灰夜景"）
  - 光色语义（见 SPC-08）
- 母题 = 一致性的最小单元。宁可母题少而贯穿，不可每张各有一套。

## SPC-07 渐变设计而非切换

- 组内相邻两张必须是"同一地方越走越深"，不是"换了一个场景"：
  - 植物密度渐增，不跳变；
  - 符文/超自然痕迹从无→稀疏→密集，逐级递增；
  - 环境异常从无→暗示→明显。
- **残影技巧**：后一张可在背景保留前一张元素的极弱残影（如 B 的远景里留"一丝银白空气波纹"暗示已跨过结界），让观众潜意识确认空间推进。
- 组内任意两张图放在一起，应能看出是同一片空间的不同深度。

## SPC-08 光色语义系统

- 每种光源绑定一个叙事含义，全组从第一张用到最后一张，例如：
  - 银白微光 = 封印系统本身的运转（克制、冷、若有若无）；
  - 暗红微光 = 被镇压之物的活动（沉、危险、如心跳般脉动）；
  - 冷白月光 = 客观视角/天命。
- **光线纪律**：全组统一环境光基调；色相变化必须渐进且有叙事意义。禁止"A 很暗 → B 突然蓝光满屏 → C 红光满天"式的跳变——那等于宣布换世界。
- 光的强度永远"成面不成点"（细则 VIS-02）。
