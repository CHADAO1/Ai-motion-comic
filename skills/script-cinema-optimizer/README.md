# script-cinema-optimizer — 剧本视听优化器

> 本文件是通用说明；平台内调度入口是 `SKILL.md`，维护入口是 `MAINTENANCE.md`。

## 功能一句话
把对话驱动的中文短剧剧本，按六步流水线改写为面向 YouTube 国际观众的 AI 电影视听驱动剧本。

## 模式与触发
| 模式 | 触发短语 | 功能 |
|---|---|---|
| Mode 1 | 优化剧本 / 剧本转AI电影 / 去OS / 美式雌竞 / 剧本本土化 / 剧本视听化 | 六步流水线：切片→冷读诊断→视听化重写→美式雌竞+双语本土化→视觉概念落地→一致性终审 |

## 在 OpenCode 中使用
放入 `~/.config/opencode/skills/script-cinema-optimizer/`（本技能已在此）。对话中说"优化剧本"等触发词即自动进入 Mode 1。产物落在你指定的工作目录 `pipeline/` 与 `outputs/`。

## 在其他工具中使用
1. 全能宿主（读文件+跑脚本）：以 `SKILL.md` 为入口完整体验。
2. 只能读文件：按总控阶段表"必读文件"列逐段贴入；跳过脚本用手工核查（见 `rules/`）。
3. 只能贴文本：总控 + 当前阶段单个模块拼接；保持一次只带一个阶段的规则。

## 注意事项（最易踩的坑 TOP）
1. 千万别一次性把几万字丢给模型改写——必遗忘、必指令稀释，必须走 S0–S5 分步。
2. 每步产物必须落盘到 `pipeline/`，下一步靠读文件衔接，不靠记忆。
3. "美式雌竞"是改动机与语言，不是删掉女性竞争。
4. 本土化是写时就英文思维预写（双语共生），不是最后翻译改几个词。
5. 模板表情词（瞳孔骤缩/眼底/冷笑）必须替换为角色专属动作。
6. 改完跑 `node scripts/lint_skill.mjs`，exit 1 必须修复。

维护：见 `MAINTENANCE.md`；变更历史：见 `CHANGELOG.md`。
