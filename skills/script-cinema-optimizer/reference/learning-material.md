# 学习资料 — 为什么这种剧本必须改、改哪十个方向

> 本文件是技能的领域依据（"记忆结晶"来源之一）。由用户提供的长篇优化对话提炼而来，供 Stage S1 冷读时对齐判断标准。结论已转化为 `rules/` 的编号规则，本文件只讲"为什么"。

## 一、本质判断
当前剧本是"语言驱动"，而 AI 电影必须是"视听驱动"。参考剧本虽有分镜意识（△ 动作行约占非空行 49%），但仍大量依赖内心独白（OS）+ 解释性对白推进，成品像"广播剧配画面"。面向 YouTube 国际观众时，中文短剧式表达经英语配音/字幕会直接尴尬。

## 二、十个优化方向（已映射规则）
1. 砍 OS，只留开场题点/重大抉择爆发/集尾钩子三类 → `DIAG-01`/`VIS-01`
2. 对白从"交代信息"改"潜台词+权力博弈" → `DIAG-02`/`VIS-02`
3. 解释性台词转无台词场景/动作节拍 → `VIS-03`
4. 女性角色不雌竞工具化（美式改写，非删除）→ `DIAG-03`/`AMZ-01`
5. 世界观不靠字幕+OS 硬解释，改视觉展示 → `DIAG-06`/`VCB-01`
6. 本土化是英文思维预写，非最后翻译 → `AMZ-02`/`AMZ-03`
7. 节奏适配 YouTube：前 10–15 秒冷开场 + 集尾钩子 → `DIAG-05`/`CON-03`
8. 删 AI 模板化描写，建角色专属动作库 → `DIAG-04`/`VIS-04`
9. 角色关系要有"推拉"，不靠印记硬绑 → 见 `VIS-03` 无台词节拍
10. AI 电影适配：写清视觉概念与动作节拍 → `VCB-01`/`VCB-02`

## 三、关键认知：中美"雌竞"底层逻辑不同（用户原疑问解答）
- **国内女频雌竞**：女性价值由男性注意力定价 → 女配动机=抢男人、语言直白羞辱（贱人/狐狸精）、智商偏低、结局毁掉。观众爽点=被打压后碾压式打脸。
- **美国女频女性竞争**：核心是权力结构中的位置争夺 → 女配也有自身地位/野心/资源；敌意包裹在社交礼貌下，用冷暴力/眼神/话里有话；可很有魅力甚至被站 CP；失败常因触碰道德底线而非恋爱脑。
- **结论**：不是删掉梅拉的敌意，而是把动机从"爱伊蒙"改为"自保"，语言从泼妇式改为冷暴力式。观众爱吃"两个女人在同一残酷系统里做出不同选择走向不同命运"，不爱吃"为男人像傻子互撕"。

## 四、为什么必须多步骤（而非一次性改全本）
- 模型对几万字中间段注意力被稀释（中间丢失），改到后半本会忘前半本人设。
- 几十条规则同时下，模型只执行前几条（指令稀释）。
- 多步骤解法：把"靠记忆"换成"靠落盘文件"，每步产物=下一步上下文锚点。
