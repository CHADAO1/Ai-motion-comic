# 审查模块 C2 — Audit 执行审查（硬性）

## 时机：两段式
1. **中途门**：S2/S3/S4 每阶段完成后，只审该阶段对应 Preflight 分组，全 ✅ 才进下一阶段。
2. **终审**：S5 交付前，全清单 + Preflight 全项 + 本表 A1–A6。

## 清单（逐项给可核查证据，禁止空勾）
| # | 审查项 | 证据要求 |
|---|---|---|
| A1 | S0 切片是否真落盘且每场独立可读 | `pipeline/00_slices.md` 路径 + 抽样 1 场可读 |
| A2 | S1 诊断 5 份产物是否齐全 | `01_diagnosis.md` 含人物卡/视觉圣经/问题清单/钩子地图/动作库 |
| A3 | S2 视听化 OS 残留≤20% | 删前/删后 OS 计数（数值） |
| A4 | S3 无中式羞辱词 + 双语可读 | grep 报告（勾引/贱人/粗鄙=0）+ 抽样英文句 |
| A5 | S4 视觉质感+动作节拍 | 抽样 1 超自然场有质感、1 动作戏≥3 拍 |
| A6 | S5 一致性 0 矛盾 + 钩子齐全 | `05_audit.md` 钩子清单 + 矛盾排查结论 |
| A7 | 内容红线无残留：逐场复核 CP-01~CP-17 + OPT-01~05，无飙血/创口/断肢/擦边/受害描写 | grep 报告（飙血/创口/断肢/裂成两半/擦边/强迫=0）+ 抽样 1 冲突场用击倒/化灰写法 |

## 报告：随交付强制输出，缺失=任务未完成
任一项 ❌ → 补执行并重跑该项；改动产物 → 重跑其后续 stage；补执行后更新 `manifest.json`。
终审报告格式（落盘 `pipeline/05_audit.md`）：
```
[AUDIT] 日期
A1 ✅/❌ 证据…
A2 ✅/❌ 证据…
…
结论：通过 / 不通过（回退至 stage X）
```
