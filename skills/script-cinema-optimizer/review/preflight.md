# 审查模块 C1 — Preflight 内容检查清单

## 使用原则
1. 完整性以要素计数为准（几要素/几拍/几件套），禁止最低字数标准——短而全即合格。
2. 每个 ✅ 必须附可核查证据：路径/脚本原始输出/数值/名单；"已检查""无问题"按未检查处理。
3. 多单元任务必附《逐单元验收表》（落盘 `pipeline/`）。

## 分组清单（每项括号标规则出处）
- [ ] 切片完整性
  - [ ] 每场 `E{nn}-S{nn}` 可独立读懂、无悬空指代（`SKILL.md` S0）
  - [ ] 场边界按空行+场景标题切分，无丢失段落
- [ ] 诊断产物（S1 输出 `01_diagnosis.md`）
  - [ ] OS 全数定位并标注保留/删除（`DIAG-01`）
  - [ ] 解释性对白逐条标记（`DIAG-02`）
  - [ ] 中式雌竞段落标记（`DIAG-03`）
  - [ ] 模板表情词频次统计+替换清单（`DIAG-04`）
  - [ ] 每集冷开场+结尾钩子两行地图（`DIAG-05`）
  - [ ] 视觉圣经≥4 设定且各有展示场景（`DIAG-06`）
  - [ ] 角色专属动作库≥2 条/角色（`VIS-04`）
- [ ] 视听化（S2 输出 `02_rewritten/`）
