# 规则模块 R8 — 内容红线与优化阶段改写（OPT-*）

> 红线规范全文在 **script-content-audit 技能 `rules/content-policy.md`**（CP-01~CP-19），本模块只补充**优化阶段**的清除与改写动作，并复用 CP-* 编号。
> 总控在 S2/S3/S4 阶段读本文件；Preflight / Audit 终检时复查 OPT-*。

## 与审核技能的关系
- 优化前**应先**用 script-content-audit 审一遍；本模块是"审后仍可能残留、或重写时新引入"的兜底清除。
- 改写总原则（来自 CP-0）：用"要这样"替代"不要那样"——每条红线都落到**该有的正面画面**，而非只喊禁止。

## CP 红线编号本地索引（定义全文见 script-content-audit 技能 `rules/content-policy.md`）
本技能复用同一套 CP-* 编号；下方为本地定义索引，供 Preflight/Audit 引用，细则以审核技能为准。
- CP-01 婴幼儿/儿童/未成年人及危害其场景 → 完全规避，未成年不入受害叙事
- CP-02 学生制服(JK)/校园未成年暗示/性化 → 校园只走学业友情成长线
- CP-03 孕妇受伤/虐待/流产/暴力 → 孕妇置于安好/被保护框架
- CP-04 捆绑/绑架/囚禁/虐待 → 反派可作恶但须被击败，不教学不直白展现
- CP-05 血腥暴力/霸凌/杀人/折磨恐怖 → 不以血腥为噱头
- CP-06 抽烟/吸毒/烟草/非法药物 → 不美化不教学，落后果/制裁
- CP-07 性暗示/低俗擦边/强迫爱情 → 情感双向自愿尊重
- CP-08 后宫（一男多女暧昧堆叠） → 关系明确单一或边界清晰
- CP-09 伤害/虐待老人 → 老人置于被尊重/被保护框架
- CP-10 女性过度性化/性剥削 → 女性以能力/动机/行动定义
- CP-11 枪支/武器/射击/恐袭/暴力宣传 → 战斗落"制止威胁"，不宣扬暴力
- CP-12 宗教亵渎/侮辱 → 任何信仰中性或尊重呈现
- CP-13 允许的战斗/死亡干洁写法（击倒/化灰/倒地/湮灭）
- CP-14 禁止的血腥视觉（飙血/体液飞溅/创口特写/断肢/劈半）
- CP-15 化灰正确与错误（整体化灰可，裂开再化灰不可）
- CP-16 婴幼儿与孕妇：绝对禁区，无例外
- CP-17 反派可作恶但必须被击败（正向框架，无操作细节）
- CP-18 自杀/自残 → 完全不涉及，或仅心理援助宣传（无方法细节）
- CP-19 仇恨言论 → 无群体贬损，尊重多元

## 优化阶段动作（OPT-*）

### OPT-01 冲突戏改写（S2 视听化 / S4 视觉落地）
- 打斗、杀伤、爆头、入腹**保留张力**，但删除一切飙血、体液飞溅、创口特写、断肢、身体劈半的描写。
- 死亡/重创用：被击倒、砍倒在地、整体化为灰烬、能量湮灭、定格于动作而非创口。
- 受伤只用"踉跄/扶住身体/失去平衡/倒下"等动作与状态表达，不描写创口形态（CP-13~CP-15）。

### OPT-02 亲密 / 情感戏改写（S2 / S3 本土化）
- 情感线建立在双向自愿与相互尊重上；删除强迫爱情、暧昧诱导、擦边特写、女性物化机位（CP-07/CP-10）。

### OPT-03 危险角色保护（S2）
- 婴幼儿、孕妇、老人、孩童**不得置于任何受害叙事**；相关情节整体改写或删除，无例外（CP-01/CP-03/CP-09/CP-16）。

### OPT-04 反派恶行落点（S2 / S5）
- 绑架/囚禁/虐待可作反派行为推进动机，但必须落在"被主角击败 / 被解救"的正向结局；删除可模仿的操作细节、不渲染受害者感官（CP-04/CP-17）。

### OPT-05 其余红线清除（S2 / S3）
- 抽烟/吸毒不美化、不教学，反派落到后果/制裁（CP-06）。
- 武器可作世界观元素，但战斗始终"制止威胁"，不美化真实恐袭、不宣扬暴力（CP-11）。
- 任何信仰中性或尊重呈现，不亵渎不冒犯（CP-12）。
- 情感关系明确单一或边界清晰，无后宫式暧昧堆叠（CP-08）。
- 完全不涉及自杀/自残描写，如触及心理援助仅做求助宣传、不含方法细节（CP-18）。
- 无基于种族/性别/宗教/性取向的仇恨言论或群体贬损，尊重多元（CP-19）。

## 自检
写完逐段读一遍：凡出现"飙血/创口/断肢/裂成两半/擦边/强迫"等词一律改写；凡"禁止X"类否定句，补一句该处正面画面（CP-0）。
