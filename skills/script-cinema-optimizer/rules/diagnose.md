# 规则模块 DIAG — 冷读诊断

> 总控在 Stage S1 读本文件。规则编号 `DIAG-*`。作用域：读全本、只分析不修改，产出 5 份记忆结晶。

## DIAG-01 OS 判定与保留三类（硬性）
内心独白（OS / 画外音）只保留三类，其余 80%+ 删掉，转成动作/表情/道具/闪回：
1. 开场世界观点题（全剧 ≤1–2 处）
2. 重大抉择时的情绪爆发点（每角色 ≤1–2 处）
3. 单集结尾的悬念钩子（每集 ≤1 处）
- 反例：`莱拉 OS：不可能！我马上要参加订婚仪式，怎么会和陌生男人缔结命定羁绊？`（信息可由"她抽手+颈间印记发烫+后退"表达）
- 正例：仅在女主真正面临"献祭 or 反抗"的抉择瞬间留一句 OS 点题。

## DIAG-02 解释性对白识别（硬性）
标记所有"角色把阴谋/计划/设定/动机直接说出口"的台词。这类台词观众不是不能知道，但不能靠角色念剧本。
- 反例：`长老：等把莱拉引到地下祭坛，就说是两族订婚血脉仪式，她不会起疑心的。`
- 正例：长老抹过祭台暗红残迹闻了闻 + 伊蒙展开印有莱拉家族徽记的地图 + 低声"她不能死在仪式前"。

## DIAG-03 中式雌竞识别（硬性）
标记"女性竞争动机=抢男人 + 直白辱骂 + 低智商手段"的段落。判定清单：
- 动机是否仅为"她勾引我男人"
- 语言是否含 贱人/勾引/狐狸精/粗鄙/不要脸/骚
- 手段是否直给（泼水/划脸/推人）且破绽百出等着被打脸
- 角色是否完全围着男主转、无自身目标
命中任一条即标记，交给 `AMZ-01` 改写。

## DIAG-04 模板表情词识别（重要）
标记通用套路情绪描写，统计频次，列替换清单。高频词库：瞳孔骤缩 / 脸色一沉 / 满眼愤怒 / 嘴角勾起冷笑 / 眼底满是复杂 / 神色骤然紧绷 / 不屑 / 嘲弄。
- 这些词本身可用，但全本重复出现会致 AI 生成表情僵硬；每项须有 `VIS-04` 专属动作替代方案。

## DIAG-05 钩子地图（重要）
为每集建两行：冷开场（前 10–15 秒必须用画面抓人，非氛围空镜）与结尾悬念（明确钩子）。标记现有钩子是否被 OS/对话稀释。
- 冷开场正例：满月下女主满手是血跌入林间，身后火光狼嚎，摔倒抬头看见一只手伸来 → 切黑屏"三日前"。
- 结尾钩子示例：命定印记亮起凯尔抓住她的手 / 黑雾包裹莱拉 / 伊蒙喝问"谁在那里"。

## DIAG-06 视觉圣经要素（重要）
为核心设定各配一个"视觉展示场景"，不靠字幕+OS 硬讲。至少覆盖 4 项：
- 命定 Mate：光丝穿过林找到她、两人颈间纹路同步亮、竖瞳收缩
- 纯血月裔：血滴银红透亮、月光下悬浮发光倒流回伤口、泪化光尘
- 黑雾/诅咒：质感（触手 or 丝绸）、颜色、蔓延方式
- 变身：瞬间 or 渐进、形态变化节拍
产物写入 `pipeline/01_diagnosis.md` 的"视觉概念圣经"段，供 S4 调用。
