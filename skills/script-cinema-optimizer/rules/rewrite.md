# 规则模块 VIS / AMZ — 视听化重写 + 美式雌竞与本土化

> 总控在 Stage S2 读 `VIS-*`，Stage S3 读 `AMZ-*`。规则编号前缀 `VIS-*` / `AMZ-*`。作用域：把诊断后的场文本改写为视听驱动、美式受众友好的剧本。

## VIS-01 砍 OS 至三类（硬性，映射 `DIAG-01`）
按 `01_diagnosis.md` 的 OS 定位，删除非三类保留项。保留项也尽量压缩到一句。
- 动作：删前统计 OS 总数，删后残留率必须 ≤20%（`01_diagnosis.md` 已给总数）。

## VIS-02 解释性对白→潜台词+动作（硬性，映射 `DIAG-02`）
每场只留"画面表达不了"的台词，其余信息改用：道具 / 动作 / 表情 / 环境 / 闪回 / 第三方反应。
- 反例：`凯尔：我是为了阻止有人开启祭坛。`
- 正例：凯尔把一张被烧毁的祭坛图塞进火里，盯着灰烬，指节捏白，没有解释。

## VIS-03 每场≥1 无台词节拍（重要）
每集至少设计一个"无台词高潮"或"动作潜台词场景"，30 秒以上纯画面推进。
- 正例（牢墙牵手）：夜，莱拉指尖从裂缝探出；外面凯尔靠墙坐下侧头看那几根手指；他伸手穿过裂缝与她相扣；月光落上交叠指节；莱拉闭眼肩放松；凯尔喉结动了动，什么都没说。

## VIS-04 角色专属动作库（硬性，映射 `DIAG-04`）
为每角色设计 2–3 个替代通用情绪词的小动作，写入 `01_diagnosis.md` 并在 S2 落地：
- 莱拉：紧张时拇指摩挲裙摆/攥婚戒；隐忍时垂眼抿唇
- 凯尔：忍耐时喉结滚动、指节捏白；痛时仰头闭眼
- 伊蒙：生气时先笑再突然变脸；得意时转手中物件
- 梅拉：不安时抚摸自己脖颈；威胁时压低声、凑近耳侧
每处原"瞳孔骤缩/眼底"等须替换为对应角色动作。

## AMZ-01 美式雌竞动机改写（硬性，映射 `DIAG-03`）
保留女性竞争张力，但动机从"抢男人"改为"权力结构中的自保/位置争夺"；语言从泼妇辱骂改为冷暴力/社交压制/话里有话。
- 反例：`梅拉：该死的贱人，你只是一个祭品，竟敢勾引伊蒙！`
- 正例：梅拉把水盆推过去，"擦擦脸。你现在这个样子，连祭品都算不上。"压低声，"伊蒙在我床上说的每句话，都是关于你的血，不是你的脸。"
梅拉敌意来源：莱拉出现动摇了她在城堡里本就不稳的生存位置，而非单纯吃醋。

## AMZ-02 双语共生预写（重要）
写中文台词时并行带英文线（中文主、英文副），按英语母语口语习惯，而非最后翻译。
- 步骤：先写英文台词 → 回译中文 → 中文更短更有力。
- 反例（中式）：`莱拉：你们别想利用我解除封印！`
- 正例：`莱拉：我不会让你们用我来解封。 / Leila: You're not using me to break that seal.`

## AMZ-03 称谓与羞辱词简化（硬性）
- 称谓：美国观众分不清"少主/长老/殿下/妾身"，统一点明职位或名字（长老=Olwen Elder；少主=名字）。
- 羞辱词：删除 贱人/勾引/狐狸精/粗鄙/不要脸/骚，改为美式冷处理（"cursed one" / "you're just a key" / "stay out of this"）。
- 情绪词：把"你竟敢——！我绝不会——！"等夸张句式压成短促有力句。
