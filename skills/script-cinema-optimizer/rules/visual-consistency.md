# 规则模块 VCB / CON — 视觉概念落地 + 一致性终审

> 总控在 Stage S4 读 `VCB-*`，Stage S5 读 `CON-*`。规则编号前缀 `VCB-*` / `CON-*`。作用域：把超自然设定写成可生成质感，并做跨场终审。

## VCB-01 超自然元素质感描述（硬性，映射 `DIAG-06`）
每个核心设定按"视觉圣经"写清可生成参数，避免"黑雾弥漫/月光照耀"这类空词：
- 黑雾：像触手 / 像丝绸？冷蓝还是墨黑？边缘是否卷曲？移动是飘还是涌？
- 月光：银白 / 冷蓝？打在皮肤上的高光形状？
- 命定印记：形态（藤蔓/符文/兽纹）、发光色、亮起节奏（脉冲/常亮/随呼吸）？
- 变身：瞬间 or 渐进？毛发/骨骼/瞳孔的变化节拍？
S4 输出时在每个相关场补一句质感描写，保证全本风格统一。

## VCB-02 动作戏连续节拍（重要）
打斗/冲突不能只写"缠斗一处"，须写清 ≥3 个连续节拍，让 AI 生成有逻辑画面：
- 模板：`伊蒙挥刀劈下 → 凯尔侧身避，黑雾缠刀身 → 伊蒙翻腕割破黑雾，凯尔小臂添血痕 → 凯尔不退反进，黑雾卷伊蒙脚踝猛拽。`
- 节拍要素：起手 / 规避或格挡 / 反制 / （循环）。至少 3 拍。

## CON-01 跨场矛盾检查（硬性）
对照 `01_diagnosis.md` 人物卡/设定，逐场核查：人名、地名、种族设定、伤痕位置、道具归属是否前后一致。
- 例：前面定长老左眼盲，后面不能写"双目炯炯"；凯尔伤在左臂，后面不能变右臂。

## CON-02 性格漂移检查（重要）
核查人物弧线是否连续：隐忍→觉醒的转折是否有铺垫，是否突然 OOC（out of character）。
- 莱拉：前期隐忍克制 → 中期怀疑 → 后期觉醒掌控，中间每步需有事件驱动。
- 梅拉：附庸→被利用觉醒→反水，敌意来源须一致（自保非吃醋）。

## CON-03 钩子留存率（硬性，映射 `DIAG-05`）
逐集核对：前 10–15 秒为冷开场（画面抓人）、结尾有明确悬念钩子。任一缺失即补。
- 交付前输出钩子清单（集号 / 冷开场 / 结尾钩子），作为 `05_audit.md` 证据。
