## [1.9] 2026-09-28 新增 [YT] YouTube 敏感内容十一大类（CP-40 ~ CP-50）

**动机**：银时提交第二份《平台内容审核标准表》，明确为 **YouTube 口径**（第一份为 TikTok）。至此两套平台口径齐备，与 §1.5 对称。核对后发现三处真缺口与一处口径过严：**危险行为整类（CP-49）此前 CP-* 完全缺失**；CP-18"完全不涉及自残自杀"过严且不可执行；"虚构宗教能否写"长期无明确答案。

**变更点**：
- `rules/content-policy.md`：新增 §1.6 `[YT]` CP-40~CP-50 十一类（未成年/性内容/暴力血腥/宗教信仰/仇恨言论/犯罪/政治/医疗健康/自残自杀/**危险行为**/**抽烟吸毒**），每条 ❌/✅/💡 三段式 + 映射 + 平台差异提示；附「增量 ∆ 清点」9 项
- **修订 CP-18**：原"安全边界=完全不涉及"→ 改为"可涉及心理困境剧情，但避免刺激性呈现"，并注明投 TikTok 改按 CP-34（零容忍 + 禁作反转），平台差异首次显性化
- §0.2 标签表 `[YT]` 覆盖扩至 CP-40~50；§0.5 新增【平台政策十一类·[YT]】档；§1 标题、§3 三态对照表同步
- `review/preflight.md`：新增「[YT] 十一类」核查组 12 项；严重度速判零容忍扩至 CP-40/41/42/44/50 + **平台差异复核项**；交付项新增"💡 建议级单列不计违规"
- `SKILL.md`：description 区分两套口径与平台差异；铁律 1 P4-B 加入 CP-40~50 逐条必过；S1 扫描范围；报告模板新增「一·六」节
- `MAINTENANCE.md`：编号段新增 CP-40~CP-50 + **平台差异登记处**

**关键口径**：
1. **💡 = 建议级**：不判违规，列入"建议优化"，**不阻塞交付**。此前规则集没有这一档，容易把建议当违规导致过度删改。
2. **CP-49 危险行为（全新）**：禁可模仿的危险挑战、危险实验、极端行为；剧情可保留但**避免教学化展示**；**涉未成年人的可模仿危险行为升为零容忍**。
3. **CP-43 虚构宗教豁免**（YouTube 明确）：架空宗教体系可自由设计；但 TikTok 版未写明此豁免 → 投 TikTok 仍做去现实指向化。
4. **CP-48 vs CP-34 是本组最重要的平台差异**：YouTube 一般禁止 + 允许心理困境叙事；TikTok 零容忍 + 禁作反转。**投 TikTok 不得援引 CP-48 放行**。
5. **CP-46 政治含"贬低他国、抬高自己"**（💡）：出海爽剧高危区，用架空国名/城市规避。
6. **CP-42 打斗允许但"点到即止"**：不得展示接触瞬间、伤口、血迹、死亡——与 CP-13~17 干洁框架一致，本次以平台原文形式再确认一次。

**兼容性**：编号只增不复用（CP-40~50）；CP-18 为**口径修订**（放宽 + 精确化），非删除；不改变 CP-01~19 其余条目判定。

## [1.8] 2026-09-28 新增 [TT] TikTok 敏感内容十大类（CP-30 ~ CP-39）

**动机**：用户提供《平台内容审核标准表》十类政策原文（**TikTok 社区准则口径**，区别于既有 YouTube 组）（未成年 / 性内容 / 暴力血腥 / 犯罪 / 自残自杀 / 宗教信仰 / 仇恨言论 / 政治 / 医疗健康 / 诈骗欺骗），要求纳入最新合规要求。核对后发现原规则集有 11 处缺口：犯罪内容、政治内容、医疗健康、诈骗欺骗**四类整类缺席**；另有 7 项细分判定缺失——尤其在 AI 短剧高频踩坑处（提示词里的校服/双马尾造成"年龄模糊化"、"控制即爱"的价值兑现、把自杀当反转钩子、犯罪手法以动作链形式泄漏进提示词）。缺一类就等于审核漏一类，补进规则集而非靠临场判断。

**变更点**：
- `rules/content-policy.md`：新增 §1.5 平台敏感内容十大类 CP-30~CP-39，每条含【❌ 判定标准】【✅ 安全边界（豁免须全满足）】【🎬 提示词层自检】【与既有 CP 映射】，并附「相对旧规则的增量 ∆ 清点」11 项；§0.5 新增【平台政策十类】分级档 + "✅ 不是许可证"原则；§1 标题、§3 三态对照表同步纳入 CP-30~39
- `review/preflight.md`：新增「平台敏感内容十大类」核查组 11 项（含通用三问）；严重度速判零容忍清单扩至 CP-30/31/32/34/36；交付项新增"重叠项交叉核对"与"豁免条件已核"；DY 与 CP 范围 → CP-01~26 + CP-30~39
- `SKILL.md`：frontmatter description 补十类；首段扫描范围 + 全局铁律 1（国内/境外两行）+ S1 流程行纳入 CP-30~CP-39，明确"两组重叠从严"；报告模板新增「一·五、平台敏感内容十大类」节，原分级口径行归位
- `MAINTENANCE.md`：编号段新增 CP-30~CP-39 说明，当前止于 CP-39

**关键口径**：
0. **平台标签体系（§0.2 新增）**：`[TT]`=TikTok（CP-30~39）／`[YT]`=YouTube（CP-01~26，含 MFK）／`[DY]`=国内抖音系；无标签条目（CP-0、CP-13~17、CP-20~25）全平台通用。投 TikTok/Reels/短视频 → `[TT]` 逐条必过；投 YouTube → `[TT]` 作从严参照；**多平台分发按最严平台审一遍**。审核前必须先问清"P4-A 还是 P4-B"，两者红线圈不同。
1. §1.5 是 §1 的**政策原文层**（TikTok 版），不是第二套标准；重叠映射（如 CP-01↔CP-30、CP-07↔CP-31、CP-05↔CP-32、CP-18↔CP-34、CP-12↔CP-35、CP-19↔CP-36）**任一判违规即违规**。
2. **✅ 是附带条件的豁免，不是许可证**——"可讲犯罪故事"要求体现调查 + 惩罚/反思；"可写医院剧情"要求无可照做的虚假指导；条件缺失一律退回 ❌。
3. **针对 AI 短剧的三条实操判定**：①年龄模糊化本身违规（年龄暗示词与亲密/受害设定不可并存）；②强迫亲密不得用"她喘着气闭上眼"式写法包装成爱情；③犯罪/诈骗手法常以动作链形式泄漏进提示词，只写结果不写手法。
4. **⚠️ TikTok 比 YouTube 更严的三处**（不得按 YouTube 尺度放行）：①未成年 CP-30——年龄模糊化即违规；②自残自杀 CP-34——YouTube 一般禁止，**TikTok 零容忍**且禁作反转；③弱势人群暴力 CP-32——对女性/老人/残疾人/未成年人的惊悚暴力直接限流下架。
5. CP-37 政治的定位是"一般禁止 + 💡最好回避"——AI 短剧几乎没有非碰不可的题材，涉及特殊题材在国内还要升为重点微短剧备案（DY-01）。

**兼容性**：编号只增不复用（CP-30~39）；不改变 CP-01~CP-19 既有判定，只在其上加严；国内 P1/P2/P3 叠加 DY-* 后，封面/亲密/未成年三项以国内口径为准（更严）。
