# 剧本内容红线审核 — 总控调度器

拿到剧本后**第一步**不是优化、也不是写提示词，而是**先审核**。本技能通读全文，按 `rules/content-policy.md` 的 CP-01~CP-19 红线（十二类硬性禁止 + 自杀/自残 + 仇恨言论）+ **§1.5 `[TT]` TikTok 十大类 CP-30~CP-39**（投 TikTok 逐条必过）+ **§1.6 `[YT]` YouTube 十一大类 CP-40~CP-50**（投 YouTube 逐条必过，比 TikTok 版多「危险行为」「抽烟吸毒」两类）+ 血腥框架逐条扫描。两组与 CP-01~19 重叠时**从严判定**（任一违规即违规）；💡 项记建议优化、不阻塞，并按 CP-20~CP-25 二级管控词库给出建议优化项，产出一份带行号、带风险分级、带正面改写建议的《内容审核报告》。**报告确认无违规且用户完成修改后，才进入 script-cinema-optimizer（优化）或 cinematic-seedance-director（提示词）环节。**

本文件只做调度：执行到某阶段才读取对应 `rules/` / `review/` 模块，禁止凭记忆跳过读取。

## 0. 全局铁律
1. **平台先定（DY-0/CP-0）**：审核前必须先确定发布平台与管线——
   - **国内 P1/P2/P3**（抖音/红果/番茄）`[DY]`：读 `rules/douyin-platform-policy.md`（DY-01~DY-76）+ 叠加 `rules/content-policy.md` 通用底线（CP-01~CP-25、CP-30~CP-39，CP-16 不分平台）。
   - **境外 P4**：仅读 `rules/content-policy.md`，但**必须再问清是 TikTok 还是 YouTube**（两者红线圈不同，见文件 §0.2 平台标签 `[TT]` / `[YT]`）：
     - **P4-A 投 TikTok / Reels / 短视频信息流** → `[TT]` CP-30~39 **逐条必过** + CP-01~19；CP-26（MFK）不适用。
     - **P4-B 投 YouTube 长视频** → `[YT]` **CP-40~50 逐条必过** + CP-01~25 + **CP-26 儿童向判定必查** + CP-30~39 作从严参照。
   - **多平台分发 → 按最严平台审一遍**，不逐平台降标准。
   - 用户未说明平台时主动提问；按题材推断后必须用户确认。
2. **先审后改**：任何剧本在优化/提示词之前必须先过本审核；发现违规先报告，不直接动笔改剧本。
3. **逐条有据**：每条判定必须附剧本原文片段 + 行号/场次；空泛"应该没问题"视为未完成。
4. **正面落点**：指出违规的同时，必须给出 CP-* / DY-* 对应的**正面改写建议**（写该有的画面，而非只喊禁止）。
5. **婴幼儿孕妇零容忍**：CP-16 触发即判不通过，无例外、无商量。
6. **受众定位先定（CP-26）**：凡剧本含未成年主角（尤其 0-6 岁），必须先判定"儿童向 / 成人向"二选一并写入报告；**MFK 结构 + 成人露骨内容（CP-07）并存直接判不通过**。这一条不封号但会让广告收益与推荐流量归零，漏判等于白做。
6. **单一事实源**：红线正文只在 `rules/content-policy.md` 与 `rules/douyin-platform-policy.md`；本文件只写动作 + 编号引用。
