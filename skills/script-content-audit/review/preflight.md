# 审查模块 A1 — 内容审核通过门禁

> Stage S3 前最后一道门：审**内容合规**。逐项过，任何一项不过即判"需修改"，交回用户。
> **平台分流（标签见 `rules/content-policy.md` §0.2）**：
> - 国内 P1/P2/P3 抖音/红果/番茄 → `[DY]` 段 + CP-* 通用底线，封面/亲密/未成年以国内为准。
> - **境外 P4-A 投 TikTok / Reels / 短视频信息流 → `[TT]` 段（CP-30~39）逐条必过 + CP-01~19**。
> - **境外 P4-B 投 YouTube 长视频 → `[YT]` 段（CP-01~26 含 MFK + **CP-40~50 逐条必过**）+ `[TT]` CP-30~39 作从严参照**。
> - 多平台分发 → **按最严平台审一遍**，不逐平台降标准。

## 使用原则
1. 每条判定必须附证据：剧本原文片段 + 行号/场次 + 违反的 CP/DY 编号。
2. 违规项必须同时给出正面改写建议（写该有的画面）。
3. 婴幼儿/孕妇相关（CP-16 / DY-61）一旦触发，整体判不通过，无例外。
