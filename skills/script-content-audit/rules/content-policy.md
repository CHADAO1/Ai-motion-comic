## 0. 改写总原则（CP-0）：用"要这样"替代"不要那样"

经验结论：AI 对**正向指令**的遵从度远高于否定禁令。因此每条红线都同时给出「判定标准（禁止项）」与「安全边界（允许项）」，实际下笔时**优先写安全边界里的正面画面**，让模型拿到可执行的画面，而非一片"禁止"。

- 反面示范：`不要飙血、不要露出伤口`。
- 正面示范：`倒地化为飞散的灰烬，画面保持干洁、无液体飞溅、无创口特写`。
- 自检：凡出现"不要/禁止/不得/不可"处，补一句该处**应有的画面**，二者并存。
- 保留剧情功能：所有改写必须**保留原剧情功能**——改的是视觉呈现方式，不是删戏；每个冲突点都要有对应的正向替代。**合规不等于阉割**，冲突、紧张、情感冲击全部保留，只是换一种视觉语言来表达。

## 0.5 严重度分级（零容忍 / 一般禁止）

YouTube 对部分内容**零容忍**：一经发现通常直接频道罢工、获利取消或永久移除，无警告机会（封号级）。其余为一般禁止，同样判不通过，但相对有修改余地。

- **【零容忍·触发即封】**：CP-01（未成年人性化）、CP-02（校园未成年性化）、CP-05（血腥虐杀）、CP-06（毒品与吸毒）、CP-07（淫秽/色情）、CP-10（女性性剥削）、CP-11（暴力极端主义/恐袭教程）。
- **【一般禁止】**：CP-03、CP-04、CP-08、CP-09、CP-12、CP-18、CP-19，及 §2 血腥框架。
- **【限流级·建议优化】**：CP-20~CP-25（§2.5 二级管控替代词库）——不判不通过，但建议按词库优化呈现以降低限流风险。
- **【结构级·收益级】**：CP-26（§2.6 儿童向判定 Made for Kids）——不封号，但一旦被判 MFK 广告收益与推荐流量归零；与 CP-07 并存则转为封号级。
- **【平台政策十一类·[YT] YouTube 口径】**：CP-40~CP-50（§1.6）——按 YouTube 官方口径收录；其中 CP-40 未成年、CP-41 性内容、CP-42 暴力血腥、CP-44 煽动攻击、CP-50 抽烟吸毒为**零容忍**，CP-43 宗教、CP-45 犯罪、CP-46 政治、CP-47 医疗、CP-48 自残自杀、CP-49 危险行为为**一般禁止**。**投 YouTube 必过本组**；💡 项按建议优化处理，不阻塞。
- **【平台政策十类·[TT] TikTok 口径】**：CP-30~CP-39（§1.5 敏感内容十大类）——按 TikTok 官方口径整档收录；其中 CP-30 未成年人安全、CP-31 性内容、CP-32 暴力血腥、CP-34 自残自杀、CP-36 煽动攻击为**零容忍**，CP-33 犯罪、CP-35 宗教、CP-37 政治、CP-38 医疗、CP-39 诈骗为一般禁止。**投 TikTok/短视频信息流必过本组；投 YouTube 作从严参照。** 平台标签见 §0.2。
- 婴幼儿、孕妇（CP-16）属**绝对禁区**，零容忍、无例外、无商量。
- ⚠️ ✅ 项不是"许可证"：§1.5 中每类的 ✅ 都是**附带条件的豁免**，必须同时满足条件才成立（如"可讲犯罪故事"要求体现调查/惩罚/反思）。缺条件的 ✅ 一律退回 ❌。
- **平台标签**：`[TT]`=TikTok（CP-30~39）、`[YT]`=YouTube（CP-01~26）、`[DY]`=国内抖音系；无标签条目全平台通用。见 §0.2。

## 1. 红线类别（CP-01 ~ CP-19；另见 §1.5 `[TT]` CP-30~39 与 §1.6 `[YT]` CP-40~CP-50）

每条含【判定标准（禁止）】【安全边界（允许）】【参考案例】。违规即判不通过，须改写或删除后再进入下一环节。

### CP-01 婴幼儿 / 儿童 / 未成年人性化与受害 【零容忍】
- 【判定标准（禁止）】任何 18 岁以下人物的性暗示、性挑逗、恋爱模拟、身体部位特写（**含动画、虚拟角色**）；儿童形象 + 成人行为（饮酒/吸烟/恋爱）；标题/封面含"学妹/幼女/正太/萝莉"等 + 恋爱/亲密暗示；把未成年人置于危险、受侵害、暴力、受惊情境。
- 【安全边界（允许）】所有角色明确为成年（面容、身形、声音均不显幼态），无任何性化描写或镜头；校园/青春题材仅限正规学业、活动、成长，无亲密互动、无身体特写；需要"年轻感"时用成年演员并模糊年龄线索，绝不以幼态博眼球。
- 【参考案例】❌ 标题"和学妹独处教室" + 封面穿校服女生躺床 → 永久封号；❌ 动画虚拟角色设定为未成年却给性化镜头 → 同样违规（含虚拟角色）。

### CP-02 学生制服(JK) / 校园未成年暗示 / 性化 【零容忍·性化部分】
- 【判定标准（禁止）】① 角色穿校服出现在非校园场景（卧室、浴室等）；② 校服 + 暧昧台词（"放学后等你"）；③ 校服 + 性化姿势（趴卧、跪姿）；④ 标题含"学妹/学弟/老师" + 恋爱暗示；⑤ ASMR / 软色情语境下穿 JK 制服躺沙发等。
- 【安全边界（允许）】校园场景仅用于正规学习、活动记录、成长叙事；成年角色 cosplay 校服需无性化视角，且明确标注非学生身份。
- 【参考案例】❌ ASMR 频道封面穿 JK 制服躺沙发 → 判定"性化未成年人"永久封停。

### CP-03 孕妇受伤 / 虐待 / 流产 / 暴力
- 【判定标准（禁止）】孕妇遭受殴打、摔倒、撞击腹部；展示流产过程；将孕妇置于暴力或恐怖情境；**封面和标题绝对不允许出现孕妇相关信息**（即便只是"孕期"标签也不要碰受害暗示）。
- 【安全边界（允许）】孕妇仅出现在和平日常生活、孕期教育、医疗科普中，无任何伤害暗示；如剧情必须涉及，镜头绕开其受袭，只交代他人安危；孕妇角色一律置于"安好 / 被保护 / 新生命期盼"框架。
- 【参考案例】❌ 孕妇被推倒撞击腹部、或封面用"孕妇遇袭"标题 → 违规。

### CP-04 捆绑 / 绑架 / 囚禁 / 虐待
- 【判定标准（禁止）】真实或模拟的非自愿束缚/囚禁；受害者痛苦挣扎特写；羞辱性语言（"求我啊"）；可被模仿的操作细节（绳结、工具、步骤）。
- 【安全边界（允许）】可作**反派行为**存在，但必须落"被主角击败 / 被解救"正向结局；不提供步骤、不渲染受虐快感；魔术逃生、安全教学需标注"专业操作"且无明显痛苦（娱乐内容避免涉及）。
- 【参考案例】❌ 恶搞"将朋友绑在椅子上" + 惊恐表情 → 违规。

### CP-05 血腥暴力 / 霸凌 / 杀人 / 折磨 / 恐怖 【零容忍·血腥虐杀部分】
- 【判定标准（禁止）】展示暴力伤害过程（拳打脚踢、刀刺、枪击）；受害者流血/痛苦反应；霸凌、折磨手段；断肢、内脏外露、活体虐待、窒息、溺毙、烧灼过程（含游戏 MOD、写实动画）；**中文短剧中的互扇耳光等掌掴场面也属暴力展示**，须规避或弱化；以血腥、恐怖为噱头渲染不适。
- 【安全边界（允许）】打斗可存在，但不得展示接触瞬间、伤口、血迹、死亡瞬间；点到即止，打到即切走，无接触特写；冲突服务于人物与主题，恐怖感靠氛围与剪辑而非创口。
- 【参考案例】❌ 街头斗殴实拍未模糊处理 → 违规；❌ 游戏 MOD 斩首慢动作 / 写实动画活体解剖 → 移除+封号。

### CP-06 抽烟 / 吸毒 / 烟草 / 非法药物 【零容忍·毒品与吸毒部分】
- 【判定标准（禁止）】任何吸烟（含电子烟）慢镜头特写；吸毒动作；药片滥用；吸毒工具特写（锡纸、粉末、水烟）；吸毒过程展示、毒品制作教程、药物滥用炫耀。
- 【安全边界（允许）】历史/医疗教育可提及，但需模糊吸食动作；娱乐内容完全避免；如为反派设定，落后果/戒断/被制裁，不教、不美、不暧昧。
- 【特别注意】⚠️ 即使视频设"18+"，烟草/毒品展示仍可能被移除——年龄分级不是护身符。
- 【参考案例】❌ 慢镜头吸食大麻 / 封面锡纸+白色粉末 → 永久封停。

### CP-07 性暗示 / 低俗擦边 / 暧昧诱导 / 强迫爱情 / 淫秽 【零容忍·淫秽部分】
- 【判定标准（禁止）】镜头长时间聚焦胸部/臀部/胯部（无功能性）；动作模拟性交（腰胯摆动、抚摸敏感部位）；持续性性挑逗动作；呻吟/喘息音效、淫秽音效；美化强迫性关系；**所有床戏（无例外）**；模拟性行为、性器官裸露、裸露但非教育目的。
- 【安全边界（允许）】正常对话、正面拥抱、牵手等健康互动；情感线建立在双向自愿与相互尊重上，亲密以情绪与关系推进，不用身体部位特写博眼球。
- 【自检标准】去掉 BGM 后仍产生性联想的画面即违规。
- 【参考案例】❌ 封面湿身透视装 + 标题"深夜福利" → 移除。

### CP-08 后宫（一男多女暧昧堆叠）
- 【判定标准（禁止）】一男多女暧昧互动；女性角色"物化"（争风吃醋、服从性姿势）；强调男性拥有多名伴侣。
- 【安全边界（允许）】多人群像互动，但无恋爱竞争或性暗示；一对一健康关系；情感关系明确单一或边界清晰。
- 【参考案例】❌ 男主与多名女性争风吃醋 + 服从性跪姿 → 违规。

### CP-09 伤害 / 虐待老人
- 【判定标准（禁止）】推搡、殴打、语言侮辱、忽视护理、将老人置于危险情境。
- 【安全边界（允许）】老人正常生活、护理教学，无任何伤害行为；老人置于被尊重、被保护、智慧传承框架，如有冲突，老人是施援或被动避险方。
- 【参考案例】❌ 掌掴老人、或"养老遗弃"羞辱桥段 → 违规。

### CP-10 女性过度性化描写 / 性剥削 【零容忍·淫秽关联】
- 【判定标准（禁止）】女性角色以性吸引为主要功能；穿着极度暴露；摆出性化姿势；情节围绕性服务展开。
- 【安全边界（允许）】女性角色拥有独立人格、职业身份，着装得体，行为自然；以能力/动机/行动定义；镜头平等对待所有角色，不单独给女性性化机位。
- 【参考案例】❌ 女性仅作为性服务/凝视对象、极度暴露 + 性化机位 → 违规。

### CP-11 枪支 / 武器 / 射击 / 恐袭 / 暴力宣传 【零容忍·暴力极端主义部分】
- 【判定标准（禁止）】① 真人持枪指向镜头或他人；② 射击人体靶标特写；③ 战术装备教学（"如何隐蔽携带枪支"）；④ "袭击模拟""刺杀教学"，即使标注虚构；宣扬、美化、教程式展示恐怖袭击、枪支改装、爆炸物制作、大规模杀人计划（含虚构但写实）。
- 【安全边界（允许）】合法射击运动（标靶清晰）、军事历史分析、科幻能量武器（无写实感）；武器可作类型/世界观元素，但战斗始终落"制止威胁、守护他人"，不模拟真实恐袭流程、不颂扬暴力本身。
- 【参考案例】❌ 持枪扫射模拟视频 / "如何自制烟雾弹" → 立即移除。

### CP-12 宗教亵渎 / 侮辱 / 冒犯任何宗教信仰
- 【判定标准（禁止）】嘲讽先知；破坏宗教物品；使用宗教符号进行性化或暴力表达；故意亵渎经典。
- 【安全边界（允许）】宗教文化介绍须尊重态度；虚构宗教体系不与现实信仰一一对应地贬损。
- 【特别注意】⚠️ 宗教内容若无专业宗教知识团队，最好不要碰——风险极高，宁可回避。
- 【参考案例】❌ 用宗教符号做性化/暴力表达 → 违规。

### CP-18 自杀 / 自残 【一般禁止】
- 【判定标准（禁止）】展示自杀方法、自伤行为、鼓励自残；展示自残**过程**；美化、鼓励自伤。
- 【安全边界（允许）】**可以涉及心理困境剧情，但需避免刺激性呈现**——写角色状态与旁人援救（伏桌、沉默、被人拉住），**不写方法、不写器具特写、不写完成瞬间**。如需心理援助线索，仅做"求助热线/援助宣传"且不含方法细节。
- 【⚠️ 口径修订 2026-09-28】原写"完全不涉及"，过严且不可执行（等于禁掉所有低谷戏）。**以 §1.6 CP-48 为准**：YouTube 口径允许心理困境叙事。
- 【⚠️ 平台差异】投 **TikTok 按 CP-34（零容忍 + 禁止用作情节反转）**，不得援引本条放宽。
- 【参考案例】❌ 影片展示割腕方法 / 鼓励自残弹幕 → 违规；✅ 角色深夜独坐、被朋友破门而入拉住 → 允许（无方法、无过程）。

### CP-19 仇恨言论 【新增·一般禁止】
- 【判定标准（禁止）】基于种族、性别、宗教、性取向等攻击或歧视；任何群体贬损。
- 【安全边界（允许）】尊重多元，避免任何群体贬损；冲突可存在但立场不宣扬仇恨。
- 【参考案例】❌ 基于族群/信仰的辱骂桥段 → 违规。

## 1.5 [TT] 平台敏感内容十大类（CP-30 ~ CP-39）【2026-09-28 新增·TikTok 口径】

> **[TT] 来源**：**TikTok 社区准则「敏感内容」分项** + 银时 2026-09-28 提交的《平台内容审核标准表》（未成年 / 性内容 / 暴力血腥 / 犯罪 / 自残自杀 / 宗教信仰 / 仇恨言论 / 政治 / 医疗健康 / 诈骗欺骗）。
> **定位**：本组是 TikTok 口径的**政策原文层**，与 §1（YouTube 口径 `[YT]`）是**同一批红线按平台口径重排**，不是两套标准。冲突时**从严判定**（任一侧判违规即违规）。
> **适用平台**：投 **TikTok / Reels / 短视频信息流** → 本组**逐条必过**；投 YouTube → 本组作**从严参照**（重叠项取严者，CP-26 MFK 仍按 YouTube 口径单独判）；投国内抖音/红果/番茄 → `[DY]` + 本组通用底线，**封面/亲密/未成年三项以国内为准**（见 DY-40/41、DY-60/61、DY-80/90）。
> **⚠️ TikTok 相对 YouTube 更严的三处**（审核时不得按 YouTube 尺度放行）：① **未成年**（CP-30）——年龄模糊化即违规，无"未写明"免责；② **自残自杀**（CP-34）——YouTube 为一般禁止，**TikTok 为零容忍**，且**禁止用作情节反转**；③ **弱势人群暴力**（CP-32）——对女性/老人/残疾人/未成年人的惊悚暴力，TikTok 直接限流下架。
> **写法**：每类给【❌ 判定标准（禁止）】【✅ 安全边界（豁免条件，须全满足）】【🎬 提示词层自检】。除本表明确禁止外，一律按 CP-0「写画面里该有的东西」原则落笔。

### 通用判定三问（对本章所有条目适用）

1. **观众照着做得出来吗？** 能复制 = ❌（适用 CP-33 犯罪 / CP-34 自残 / CP-38 医疗 / CP-39 诈骗）。
2. **这是在谴责，还是在展示/教学？** 后者 = ❌（适用 CP-17 / CP-32 / CP-33 / CP-39）。
3. **去掉音乐后还剩什么？** 仍有性/暴力联想 = ❌（适用 CP-24 / CP-31）。

### CP-30 [TT] 未成年人安全（Minors）【零容忍】

- 【❌ 判定标准（禁止）】
  - 儿童色情化、性暗示；
  - 展示儿童危险行为、虐待、伤害；
  - 利用儿童制造猎奇、羞辱、恐惧效果；
  - 宣传未成年人劳工，及未成年人的**任何**恋爱关系。
- 【典型违规例】
  - ❌ 未成年人为挽救家族企业而被迫结婚。
  - ❌ 身处恋爱或性爱剧情中的角色**身穿高中校服、梳双马尾、举止幼稚**，从而**模糊化角色是否为未成年人**——**"年龄模糊"本身就是违规**，不以"我没写明她未成年"免责。
- 【✅ 安全边界（须全满足）】角色设定与画面均**明确成年**（面容、身形、声音、职业、社会关系五处线索一致指向成年）；未成年角色只在安全、受教育、被保护情境中出场，不承担恋爱/危险/受害叙事；需要"年轻感"用 22-25 岁成年面容（国内 DY-60 同口径）。
- 【🎬 提示词层自检】AI 生成尤须防范**默认未成年推断**：若提示词里同时出现校服/书包/双马尾/幼态/校园/课间（年龄暗示词）与恋爱/亲密/受害设定，一律判违规——**删掉年龄暗示词，或删掉亲密设定，二者不可并存**。
- 【映射】升级自 CP-01 / CP-02；新增"反年龄模糊化""禁未成年劳工""禁被迫结婚"三条；国内叠加 DY-60/61。

### CP-31 [TT] 性内容与色情（Sexual Content）【零容忍】

- 【❌ 判定标准（禁止）】
  - 色情展示、露骨性行为、裸露性暗示；
  - 模拟性行为、性器官裸露、**持续性**性挑逗动作、呻吟/喘息音效、**强迫性行为**；
  - **封面不能使用性感身体部位吸引点击**；
  - 暗示性行为的**声音、表情、动作**——含镜头长时间聚焦胸部/臀部/胯部，角色用手指拨弄看起来像性体液的东西后带有性暗示意味地亲吻等；
  - 把强迫、胁迫、非自愿亲密行为**描绘成爱情或激情**；
  - 乱伦与**伪乱伦关系**（父母子女、继亲、养亲等拟制血亲）。
- 【✅ 安全边界（须全满足）】情感线建立在双向自愿与相互尊重上；亲密以上限为准（CP-24：拥抱/对视/牵手）；**去掉 BGM 后无性联想**；封面主体是脸与情境，不是身体部位。
- 【🎬 提示词层自检】"强迫亲密"在 AI 提示词里极易写成 `抓住她的手腕按在墙上，她喘着气闭上眼` —— 这既违反本条也违反提示词"禁否定式"规则。正面改写：`她退到墙边，他抬手停在她身侧，两人对视，画面在这一秒切走`（保留张力，删掉性联想与强迫）。
- 【映射】升级自 CP-07 / CP-10 / CP-24；**新增三条**：封面性感部位、伪乱伦、强迫亲密不得美化为爱情。

### CP-32 [TT] 暴力血腥（Violent or Graphic）【零容忍·伤害展示部分】

- 【❌ 判定标准（禁止）】
  - 展示血腥伤口、肢解、虐杀**过程**；
  - 美化暴力、鼓励报复；
  - 展示残忍攻击**细节**；
  - **针对弱势人群**（女性、孕妇、老人、残疾人、未成年人）的惊悚暴力或残忍行为。
- 【✅ 安全边界（须全满足）】冲突可保留，视觉走 CP-13~CP-15 干洁写法（击倒/化灰/湮灭，无飙血无创口无断肢）；复仇叙事落"法律/良知/自损"，不予观众"以暴制暴很爽"的兑现；弱势人群角色不进入受害展示（孕妇/婴幼儿见 CP-16 绝对禁区）。
- 【典型违规例】❌ 反派逐个虐杀的慢镜 + 伤口特写 → 违规；✅ 改为"三名对手在不同景别被击倒化为灰烬，无接触瞬间、无创口，镜头停在主角的决心上"。
- 【映射】升级自 CP-05 / CP-13~17；**新增**："鼓励报复"（复仇叙事的价值落点）与"弱势人群清单"。

### CP-33 [TT] 犯罪内容（Criminal Content）【一般禁止】

- 【❌ 判定标准（禁止）】
  - 教授犯罪方法；
  - 提供诈骗、盗窃、攻击的**操作步骤**；
  - 鼓励违法行为。
- 【✅ 安全边界（须全满足）】**可以讲犯罪故事**，但必须体现①剧情背景 ②调查过程 ③惩罚或④反思（四者至少具其二，且叙事立场明确是揭露而非传授）。
- 【判定铁律】与 CP-17 同：**这个场景是在谴责恶行，还是在展示恶行的方法？** 前者合规，后者违规。
- 【🎬 提示词层自检】步骤类信息在提示词里常以动作链形式泄漏（`先把铁丝弯成钩，再卡进锁舌，一拧就开`）——**只写结果不写手法**：`门锁被撬开的痕迹，画面从门口切到室内`，撬锁动作整段删除。
- 【映射】AI 短剧此前无对应条目，本节为**全新**；诈骗手法明细另见 CP-39。

### CP-34 [TT] 自残 / 自杀（Self-harm & Suicide）【零容忍·方法与反转部分】

- 【❌ 判定标准（禁止）】
  - 展示自残**过程**；
  - 美化、鼓励死亡或自伤；
  - 提供自残方法；
  - **不允许将自杀用作情节反转以达到惊人效果**。
- 【✅ 安全边界（须全满足）】完全不展示方法与器具特写；如需表达角色处于绝境，只写**状态与旁人援救**（伏桌、沉默、被人拉住），写"被救回/被阻止"，不写"如何完成"。
- 【⚠️ 短剧高危区】把自杀/自残当**悬念钩子或反转包袱**是短剧最常见死法：第 N 集结尾甩出"她其实在三年前就已经…"，再补一个溺/割/坠的实拍画面。此类"惊人反转"即本条禁止项，无论是否虚构、无论是否打码。**删画面、删方法，只留"他没能撑过来"的台词式交代。**
- 【映射】升级自 CP-18；**新增**：禁"自杀作为情节反转"。

### CP-35 [TT] 宗教信仰（Religion）【一般禁止】

- 【❌ 判定标准（禁止）】
  - 攻击、侮辱某种宗教或信仰群体；
  - 煽动宗教仇恨；
  - 煽动不同信仰群体冲突。
- 【✅ 安全边界（须全满足）】**可以作为故事背景出现**，但保持中性描述、不贬低不攻击；虚构宗教体系不与现实信仰做可识别的一一对应式丑化。
- 【⚠️ 实务建议】与 CP-12 同：**没有专业背书最好不要碰**。国内管线另叠 DY-20/21（封建迷信、驱邪法术不得作为剧情真实有效机制）。
- 【映射】等同 CP-12，并补全"背景允许 / 攻击禁止"的边界表述。

### CP-36 [TT] 仇恨言论 / 群体攻击（Hate Speech）【零容忍·煽动攻击部分】

- 【❌ 判定标准（禁止）】
  - 攻击种族、民族、宗教、性别、性取向等群体；
  - 歧视弱势群体；
  - 美化权力压迫和身份霸凌；
  - **强化性别、年龄、贫富、职业身份等刻板印象**；
  - **宣扬性别优越、美化控制和支配关系**；
  - **把歧视或压迫包装成正常关系**。
- 【✅ 安全边界（须全满足）】冲突可以是人物对人物，不可以是身份对身份；角色的负面行为归因于其个人选择，不归因于其性别/地域/职业/出身；上下级、亲子、伴侣关系中不得出现"控制 = 爱""占有 = 在乎"的价值兑现。
- 【⚠️ 下沉市场的重灾区】"农村人就是见识短""服务员就该低人一等""女人读再多书不如嫁得好""我管着你是因为我爱你"——前三类撞"刻板印象"，最后一类撞"把控制包装成爱"。**台词可以糙，价值观不能糙**：把攻击句改写成具体人物的具体行为（`"他就是不肯把合同拿出来"` 优于 `"你们这种人没一个可信"`）。
- 【映射】升级自 CP-19 / CP-08；**新增三条**：反刻板印象、反性别优越、禁止把压迫包装成正常关系。

### CP-37 [TT] 政治内容（Politics）【一般禁止·建议回避】

- 【❌ 判定标准（禁止）】
  - 传播虚假政治信息；
  - 伪造政治人物言论或事件；
  - 制造误导性政治内容。
- 【✅ 安全边界（须全满足）】历史、社会讨论可以，但必须保持**准确**并给出**背景说明**；不出现可识别的在世/真实政治人物。
- 【💡 强烈建议】**最好不要涉及政治内容**——性价比极低，几乎没有 AI 短剧情非碰不可的题材。国内管线触及特殊题材（军事/外交/国安/民族/宗教/司法/公安）按 DY-01 需升为重点微短剧备案，成本陡增。
- 【映射】**全新条目**。

### CP-38 [TT] 医疗健康（Health）【一般禁止】

- 【❌ 判定标准（禁止）】
  - 传播错误治疗方法；
  - 夸大疾病治疗效果；
  - 鼓励危险医疗行为。
- 【✅ 安全边界（须全满足）】医院、疾病、医生剧情**可以写**，但不得给出可被照做的虚假医学指导（剂量、偏方、替代疗法、延误就医等）；急救剧情若出现，用**规范处置**或干脆不写细节，别自创疗法。
- 【判定问句】**观众照着做会不会出事？** 会 = ❌。
- 【典型违规例】❌ "喝两口高度酒就能退烧/烫伤涂牙膏"；✅ 改为医生到达、专业处置，台词不给具体土方。
- 【映射】**全新条目**。

### CP-39 [TT] 诈骗 / 欺骗（Scams）【一般禁止】

- 【❌ 判定标准（禁止）】
  - 展示诈骗教程；
  - 推广骗局、投资骗局、虚假赚钱方式；
  - 诱导用户转账或提供个人信息。
- 【✅ 安全边界（须全满足）】**可以讲被骗故事**，但重点必须放在**揭露与警示**：受害者视角 + 骗局被拆穿 + 代价被承担；不得出现可复制的话术全文、操作流程、伪造证件/界面的完整演示。
- 【判定问句】**这段看完，观众学会了骗人还是学会了防骗？**
- 【典型违规例】❌ 反派完整演示"冒充客服退款"话术与操作界面 → 违规；✅ 改为受害者在电话这头的慌乱 + 反派挂断后的冷笑，话术只留一两句无指向的碎片。
- 【映射】**全新条目**；作案手法明细同时受 CP-33 约束。

### CP-40 [YT] 未成年人安全 【零容忍】
- 【❌ 禁止】性化未成年人（性暗示、性挑逗、恋爱模拟、身体部位特写）；展示儿童危险行为、虐待、伤害；利用儿童制造猎奇、羞辱、恐惧效果。
- 【💡 建议】涉及儿童剧情需避免**露骨伤害画面**和**刺激性描述**。
- 【✅ 安全边界】角色明确成年（五处线索一致）；未成年角色只在安全/受教育/被保护情境出场，不承担恋爱、危险、受害叙事；不得用幼态博眼球。
- 【映射】CP-01、CP-02；[TT] CP-30（TikTok 版额外禁"年龄模糊化"，投 TikTok 按严者）。

## 2. 暴力与血腥正面框架（关键，最易误判）

**核心判断**：打斗、杀伤、一枪爆头、一刀入腹，**本身不属于**血腥暴力。真正的红线是**让人联想到血腥的视觉**——飙血、飙液体、露出伤口、断肢。

### CP-13 允许的战斗/死亡表现（干洁写法）
- 被击倒、砍倒在地、化为灰烬、能量湮灭、定格于动作瞬间而非创口。
- 受伤用"踉跄、扶住身体、失去平衡、倒下"等**动作与状态**表达，不描写创口形态。

### CP-14 禁止的血腥视觉（一律改写）
- 血液 / 体液飞溅（飙血、飙液体）。
- 创口特写、露出伤口、内脏/骨骼暗示。
- 断肢、身体被劈成两半。

### CP-15 "化灰"的正确与错误写法
- ✅ `化为飞散的灰烬` / `当场湮灭为尘`。
- ❌ `被劈成两半后化成灰`——**不行**。可整体化灰，不可先裂开再化灰（裂开那一下仍指向肢体分离）。
- 规则口诀：**直接化灰可以，裂开再化灰不行**。

### CP-16 婴幼儿与孕妇：绝对禁区
- 任何涉及婴幼儿、孕妇的暴力/受害/受惊描写**完全规避**，无商量余地；即便"反派可施恶"原则在此也不适用——这两类角色不进入任何受害叙事。

### CP-17 反派可作恶，但必须被击败（正向框架）
- 绑架 / 囚禁 / 虐待等可作反派行为，但：(a) 不提供可模仿的操作细节；(b) 不渲染受害者感官；(c) 叙事落点必须是主角制止并解救，出发点正向。
- 核心判断一句话：**这个场景是在谴责恶行，还是在展示恶行？** 前者合规，后者封号。不能让观众觉得"这样做很酷/很爽"。

## 2.6 儿童向判定 · Made for Kids（CP-26）【结构级·收益级·不封号但归零】

> 来源：2026-09-23 CHM009《萌宝降临：精灵王请接招》海外 P4 审核实战。原规则集只管"会不会封号"，缺"会不会被判儿童剧"这一维度，而后者直接决定广告收益与推荐流量。

### 判定标准（命中即被 YouTube 分类器判为 Made for Kids）

不看"有没有儿童角色"，看**结构特征**。命中 3 条以上即高风险：

- 未成年（尤其 0-6 岁）角色是**主线主角**，且镜头占比显著高于成人角色；
- 高频出现"可爱卖点"镜头：奶声台词、萌态特写、玩具、糖果、幼崽园/幼儿园/学校日常；
- 冲突发生在儿童之间或围绕儿童展开（坏同学、坏阿姨、抢玩具）；
- 标题 / 封面 / 标签 / 描述含 kid、toddler、cute baby、萌宝、幼崽园等儿童指向词；
- 频道历史内容以儿童向为主（会连坐）。

### 一旦判为 Made for Kids 的后果（等于商业归零）

| 能力 | 结果 |
|---|---|
| 个性化广告 | 关闭，CPM 跌至约 1/10 以下 |
| 评论 / 社区帖 / 通知 / 频道会员 / 购物联动 | 全部关闭 |
| 首页推荐 / 搜索加权 | 不进，只出现在 YouTube Kids |
| 外链 / 卡片 / 结尾画面 | 全部关闭 |

### ⚠️ 最危险的形态：两头不靠

**MFK 结构 + 成人露骨内容（CP-07）同时存在** = 双重违规，封号概率极高。审核时必须先问一句：

> 这部剧到底给谁看？儿童向就必须删净成人内容；成人向就必须把儿童角色从"镜头主角"降为"剧情引子"。**骑墙必死。**

### 安全边界（成人向路线的处理口径）

- 儿童角色保留，但**镜头占比压到 ≤25%**，且只出现于"可爱 / 安全 / 被保护"的情境；
- 儿童不再承担主线冲突，冲突交回成人角色（商业、宫廷、感情线占 60% 以上）；
- 学校/幼崽园线压缩到最低（这条线是分类器最强命中区），或改由成人视角旁观；
- 元数据全面去儿童化：主打 Fated / Secret Heir / Billionaire / Rejected Bride 等成人向词；
- 上传勾选 **Not made for kids**；含成人情感内容时同时开**年龄限制 18+**；
- 频道层级同步设置"频道内容 = 非儿童向"，避免频道级误判连坐。

### 参考案例

❌ CHM009：3 岁双胞胎承担主线 + 幼崽园 5 集 + 糖果神兽坐骑 + 9 段成人露骨戏 → 分类器判 MFK 概率接近 1，同时触 CP-01/CP-07 → 判定不通过。
✅ 处理：前 5 集保留萌娃作付费墙钩子，第 6 集起儿童镜头降至 ≤25%，幼崽园线压到 2 集，成人线接管主线，元数据去儿童化。
