# 模块 — 平台结构包（六平台结构模板库）
> 类型：platform · 挂载点：S0 选择 + S3 生成 + S4 附加验收 · 编号前缀：ST-

> 依据：南都红果 AI 漫剧热榜 100 部普查（2026-10）、DataEye 2026-08 双平台月报、网文八平台节奏对照、盐选四段式拆解。采集 2026-11-02，季度复核。
> **挂载条件**：用户声明目标平台（或投平台意图）时挂载；未声明不强制——纯定制需求可不挂，走通用默认。

## ST-00 挂载用法（硬性）

- S0 选模板组合（≥3 个候选，含主模板+奇兵+结构稿）；S3 按组合出多版；S4 按所选模板的节拍表做附加 lint。
- 同题材投错平台成绩天差地别（DataEye 实证）——用户目标平台与题材冲突时，S0 必须提示并给替代组合，不擅自改题材。

## ST-01 爽感三段式（红果主模板）

结构：压抑铺垫 → 获得金手指/身份转折 → 反杀打脸。前 3 秒冲突；单集 1-2 分钟塞 2-3 个情绪点、30 秒一个小转折；集尾最大悬念直接按脸；"猜到了—被打脸"固定节拍。
适用：玄幻修真 / 都市逆袭 / 战神赘婿 / 古风女频（红果三类题材占热榜 80%+）。
红果偏好排序：逆袭 215 部 / 奇幻脑洞 208 / 穿越 180。近半数主角"开局即遭亲友伤害"。

## ST-02 现实共鸣流（抖音主模板）

结构：家长里短开局、情绪共鸣驱动、可转发共鸣点埋设。冲突强度低于红果但情绪浓度不降；台词直白、善恶分明。
适用：都市日常 / 乡村 / 种田 / 年代 / 家庭（抖音现实向合计关联播放增量 806 亿，碾压悬浮爽剧）。

## ST-03 双循环节奏流（番茄/七猫/书旗族）

结构：3 集一小爽（压抑 1 章→反转半章→收获半章）+ 10 集一大爽（多层压抑 3-5 章→爆发 1 章→余波 1 章）。前 30 章生死线；断点（章末/广告位）前后剧情点密度必须递增；大圆满结局。
适用：重生 / 系统 / 甜宠 / 小说 IP 改编保节奏。七猫女性读者 80%+；书旗微短剧改编导向。

## ST-04 双层反转流（盐选族）

结构：四段式——开端 10% 炸点 / 发展 30% 升级 / 高潮 40% 双层反转 / 结局 20% 干脆报应。两层反转：第一层"哦！"、第二层"卧槽！！"。每 500-800 字一个信息炸弹。第一人称剥洋葱式；忌开放式结局。
卡点技术（本包公共输出，注入所有模板）：**情绪临界点 + 信息差半截**——透露关键信息的一半（如"遗书写着：杀我的人是你"）即切断。

## ST-05 情绪颗粒流（晋江族）

结构：人设先行 + 情感线驱动；标签人设 + 极致反差（表面一套心里一套）；情绪细节密度优先于爽点密度；情感张力点即断点。
适用：古风女频 / 虐恋 / 追妻火葬场 / 双男主。

## ST-06 可复看沙雕流（红果《剑神凡劫》实证）

结构：人设固定 + 处境夸张 + 每集独立身份错位；不依赖连续剧情——不用记上一集设定，点开就能看；完结后靠复看存活（实证：完结后日 40 万复看）。
适用：沙雕脑洞 / 反套路 / 系统流。定位：差异化奇兵——同质化周期（90% 共用三段式）的突围位。

## ST-07 组合策略（硬性，多版差异化的依据）

多版初稿 = 不同结构基因的组合，禁止同结构改词。推荐组合：
- 男频玄幻投红果：ST-01 主稿 + ST-06 奇兵稿 + ST-01×ST-04 卡点强化结构稿
- 女频现实向投抖音：ST-02 主稿 + ST-05 情感稿
- 悬疑题材：ST-04 主稿 + ST-01 情绪稿
- 小说 IP 改编：ST-03 保节奏稿 + ST-04 卡点强化稿
用户自定义组合优先；此表为默认参考。
