# 模块 — 对白二次调整（可生产对白稿）
> 类型：process · 挂载点：S0 选择 + S3.5 独立工序 + S4 附加验收 · 编号前缀：DP-

> 对标缺口：小说转剧本链路里「旁白对白二次调整」是**返工率最高的一环**，但本技能原先只有「台词精修」这一档可选引擎任务（默认批次不跑），且唯一的长度口径「≤15 字为宜」写在视频提示词层、只覆盖单一管线、是软建议。初稿出稿后没有独立工序，结果叙述腔旁白、书面语长句、A/B 逐字同旁白全部漏到人工挑稿阶段才被发现。本模块把这一环补成**强制独立工序 + 可机检验收门**。

## DP-01 独立工序，禁止与生成合并（硬性）

对白二次调整是 **S3.5**：在 S3 出初稿之后、S4 闸门A 之前单独跑一遍，输入是初稿，输出是《可生产对白稿》与《对白调整登记》。**禁止把口语化要求塞进 S3 的生成提示词里一次做完**——生成阶段的目标是结构与钩子，合并执行时口语约束会被结构目标吃掉，实测这是本环返工率最高的直接原因。

- 正例：S3 出 `ep001_A_v1.md` → S3.5 出 `ep001_A_v1_dlg.md` + `pipeline/04_对白调整登记.md` → S4 验收 `*_dlg.md`。
- 反例：S3 提示词末尾加一句「台词要口语、单句 8-15 字」，直接当达标证据。

工序只改**对白与旁白的呈现层**，不动场次顺序、事件、人物、数字、规则、视角（改动超出此范围即回到 S3 重出，不在本工序修）。

## DP-02 单句 8–15 字（硬性，按占比判）

以说话人行 `角色：台词` 的台词正文为准，按句末标点切句，逐句数汉字（不含标点、角色名、括号动作）。目标区间 **8–15 字**。

- **判杀只算「>15 字超长句」占比**，超过 `dialogue_max_ratio`（默认 0.20）才 FAIL。**<8 字的短节奏句合法**，按例外登记、不计入判杀分子。实测《怼父皇打皇兄》v3 两版短句占 33%／42%，若把「区间外总占比」当判据，8-15 字这条口径会变成「挂上即全杀」的错尺子——与前几轮 `insight_density` 奖励不可见内心是同一类错误。
- 例外须登记：专有名词、数字读法、有意的长台词（如宣读律条／官样台词）、连续短句构成的节奏段，写进《对白调整登记》并说明戏剧理由。超长句若无戏剧理由，按下面一条拆。
- `scripts/check_gate_a.py` 的 GA-09 与 `scripts/check_adapt.py` 的占比门**必须同口径**；两个入口各算各的会给出相反结论。
- 长句拆两句说，不删信息、不改语义、不新增台词；拆完仍超长的，回 S3 检查是不是把原文叙述压进了一句台词。
- 正例：「你在教我做事？」→ 8 字内合法短句，登记为节奏句。
- 反例：「当天他把领导辞了，再给老板一个滚蛋的机会。」→ 概述句进旁白，且无任何画面承接，不属「长句例外」，按 DP-06 删。

机检由 `scripts/check_gate_a.py` 的 GA-09 执行，数值取脚本输出，禁止模型自报。

## DP-03 书面语→口语（硬性）

逐句替换叙述腔与书面连接词，标准是**能直接念给演员、不解释也听得懂**：

| 书面/叙述腔 | 口语方向 |
|---|---|
| 然而、因此、于是、遂、便、随即、霎时 | 删掉，靠动作顺序与切镜承接 |
| 被……所……、予以、进行、作出 | 改成主动短句 |
| 长定语（「那个穿着……的……」） | 拆成两句，或转成可见动作 |
| 生性不羁、左右不敢得罪、受不得委屈 | 叙述者评价，不进任何人物台词/旁白（CR-12、CR-17） |
| 心里、原以为、盘算、才明白、越想 | 不可见内心，外化成动作、对手戏或一次停顿（CR-12） |

- 正例：「他生性不羁，受不得委屈」→ 删；用「键盘一推，人站起来」承载。
- 反例：把这句改成主角台词「我生性不羁」——第三人称自述，属人称错位。

口语化不等于加网络梗。人物声口仍受 CR-13 约束（台词同时匹配人设与当下场景），不能为了顺口让所有人都说同一种腔。

## DP-04 念出来顺口（人工门，附可机检候选）

每集抽 ≥5 句念一遍，重点查：连续三字同声/同韵造成的绕口、一口气念不完的长串、书面标点堆叠、括号插入打断语气、同段相邻句尾字重复。**人工判断，脚本不判语义**。

`scripts/check_gate_a.py` 的 GA-09 附带给三个可机检候选（只报数不判杀）：连续标点 `，，`/`。！`、一行内 ≥2 组括号插入、单句汉字数 >25。命中不等于绕口，只标出来供人工念。

> 诚实边界：拼音级绕口检测需要注音库，本模块不做，也不假装做了；别把「脚本没报」当「念着顺」。

## DP-05 旁白三禁（硬性）

挂本模块时允许保留漫剧旁白，但逐句过三禁，任一命中即改或删：

1. **不破第四面墙**：不得出现「看屏幕的人」「观众」「看客已经知道」等向画外致辞。
2. **不提前讲破谜底**：旁白不得说出该集知识状态表里「观众此刻不该知道」的信息；叙述者替观众总结、点破下场/死局/身份，一律禁止。
3. **每句须能落成画面**：旁白内容若无法对应一个可见画面或一次剪切，就是叙述腔，按 DP-06 处理。

旁白**不设密度指标**，也不得作为 A/B 差异化手段。想靠「A 版旁白多、B 版旁白少」凑差异，等于把事实层一致性换成解说层注水。

## DP-06 叙述腔直搬禁令（硬性）

原文里的**概述句、时间跨度、叙述者调侃、第三人称评价**，只允许三种处置：转成一场戏、转成一次剪切、直接删。**禁止逐字或近逐字念成旁白**。

- 已实测的反例：原文「李承泽当天就把领导辞了，再给老板一个滚蛋的机会。」被改成「旁白：『当天他把领导辞了……』」——只删主语和「就」，属逐字搬运；同时虚写被坐实（原文并无老板出场的事件）、与已演的掀桌画面重复口播、首句「他」指代悬空、A/B 两版逐字相同，五个硬伤一次犯齐。
- 正例：删该旁白，靠「工牌一拍／黑场／床上一仰」承载；文末登记一行 C 类删除，不默删。

判定靠与原文切片的连续汉字重合（阈值 8 字，经验值，只给候选不判语义）。机检落在 `scripts/adapt_gate.py` 的 G9 与 `scripts/check_gate_a.py` 的 GA-10。**改写型解说旁白逐字重合抓不到**，仍须按 DP-05 人工判。

## DP-07 A/B 同一旁白逐字相同（硬性）

同一集两版不得逐字抄同一段旁白冒充「事实层一致」。事实层一致靠共用的事实台账，不靠共用解说词。命中即改其中一版的呈现方式或按 DP-06 删除。

机检由 `scripts/check_gate_a.py` 的 GA-11（跨文件比对）与 `scripts/adapt_gate.py` 的 G9 共同执行；两处口径必须一致，否则同一份稿会出现两种结论。

## DP-08 验收门与登记（硬性）

S3.5 结束必须落三样，缺一视为未执行：

```bash
python scripts/check_gate_a.py --draft <剧本目录>/outputs/ \
    --anchors <剧本目录>/pipeline/02_人物小传与术语表.md \
    --config <剧本目录>/pipeline/gate_a_config.json \
    --out <剧本目录>/outputs/01_体检报告_脚本.md
python scripts/check_adapt.py --files <剧本目录>/outputs/*_dlg.md \
    --source <本集原文切片> --out <剧本目录>/outputs/01_语义门禁.json
```

1. `pipeline/04_对白调整登记.md`：逐条记「原句 → 改为 → 理由」，区分例外登记（DP-02）、C 类删除（DP-06）、口语替换（DP-03）。**删除必须登记，禁止默删**。
2. 两份脚本报告随稿落盘；**GA-09~11 与 G9 任一命中即不得写「验收通过」**，须先处置再复跑。**GA-12 稿件形态门默认启用**：演练占位标记／人物对白句 0／场次标记 0 任一命中写「不予验收」（是形态不达标，不是内容违规），补正文后复跑；`--skip-shape` 只关判杀不关报数，不得拿它把空稿写成通过。
3. 人工门清单勾选：DP-04 已念 ≥5 句、DP-05 三禁逐句过、逐句溯源率。脚本不判这三项，不得省略。

> 机检只量正文（首场 → 文末登记块之前）。文末登记会逐字引用被删原句，若一并扫进去，清理完的稿子会被自己的留痕反复判杀——这是已实测的自污染误报。

## 挂载约定

- **Mode 3 按纲改编自动挂载**（与 SO 模块并列），因为「小说原文 → 剧本」正是叙述腔直搬的高发链路。
- Mode 1 / Mode 2 由 S0 需求登记时声明挂载；用户明确说「不做对白二次调整」可卸载，须在 `00_需求与体检.md` 记显式声明。
- 卸载后 S3.5 跳过，但 **GA-10 / GA-11 仍建议保留为 INFO 观察项**，避免问题被藏起来。
