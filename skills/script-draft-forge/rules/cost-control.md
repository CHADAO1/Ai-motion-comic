# 规则模块 — 成本控制（CC）

> 前缀 CC-*。本文件是**成本规则**，与编剧核心 CR/HK/DR 平级，与引擎路由 MR 互补——MR 管“哪个引擎”，CC 管“怎么用才不烧钱”。
> 动机：2026-11-04 实跑暴露——为读 4 万字规则花 8 元，大头是同一份上下文被重复计费；若不控制，40 集会滚成几百元。规则层与引擎无关（MR-01 同款原则），模型名只在 MR-03 出现，本文件不点名。

## CC-01 上下文重发是最大成本（硬性）

每次工具调用，系统会把「系统提示 + 全部历史 + 已读文件」整体重发一遍。**读进上下文的每一段，都是后续每一轮的固定开销。** 结论：
- **规则文件只读一次**。已装载的规则禁止重读，凭上下文继续执行。
- **长文件按需读，不整读**。reference/screenwriting-theory.md（3.1 万字事实源）永不整读，只在语义冲突时用 Grep 查具体行。
- 宁可多问一句，不可多读一份。

## CC-02 便宜引擎包打底（硬性，挂 MR-03）

S0 拆解、S1 钩子预算、S2 建档、S3 批量出稿——这四段是**高 token 低判断**的活，默认用 MR-03 的**批量档/骨架档引擎**，禁止用挑稿档引擎干这些。挑稿档引擎只在两处用，且只喂最小必要输入：
1. **S4 挑稿/合并/终审**：喂 A/B 版正文 + 体检结论，不喂全量规则。
2. **用户点名“用 X 跑”**：用户显式指定时按其指定，此时本条让位（用户指令 > 默认路由）。
判据：判断越少的活，引擎越便宜；宁可便宜引擎多跑一遍，不可贵引擎空转一轮。

## CC-03 分批跑 + 前情压缩（硬性，防滚雪球）

- **默认每批 5-10 集**，跑完停一次，不一口气铺 40 集。
- 每批结束，把“前情提要”**压缩成两件**再进入下一批：①一句话剧情摘要（≤60 字/集）②未回收钩子清单（HK-07 台账摘取）。禁止把已出集的全文历史带进下一批生成上下文。
- 长线设定靠 DR-01 四件套注入，不靠携带历史对话记忆。
- **卷级回顾（每 10 集强制一次）**：跑满 10 集后，把本卷全部一句话摘要拉平，检查三件事：①情绪强度曲线是否与开卷设定呼应（全局节奏，摘要平时看不见的盲区）②台账长线钩兑现进度是否滞后 ③人物言行是否漂移出 S2 小传。结论落盘 `pipeline/04_卷级回顾_第N-N+9集.md`，之后只以 ≤10 行结论形式进入后续批次上下文——回顾本身也不整读。

## CC-04 自检（闸门A后、S5 前）

交付前对账：本次是否读了不该读的文件 / 是否用贵引擎干了高 token 低判断的活 / 是否带了超量前情。任一命中，记入体检报告“成本 INFO”，下次规避。

## 与既有规则的关系

- CC-02 引用 MR-03（引擎表）与 MR-01（模型无关）原则，不重复定义引擎。
- 不改变 CR/HK/DR 任何判定，只决定“用什么跑、怎么跑不烧钱”。
