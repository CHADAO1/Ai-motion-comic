# 规则模块 — 编剧核心（CR）

> 总控在 S0（拆解）、S2（建档）、S3（生成）、S4（验收）读本文件。前缀 CR-*。
> 本文件是技能的灵魂：全部提炼自《编剧方法论》21 节（原文备份在 reference/screenwriting-theory.md，为唯一事实源；本文件只做规则化提炼，语义冲突以原文为准）。
> 三层结构：**要素层**（骨架血肉——建什么档）→ **动力层**（灵魂——为什么好看）→ **呈现层**（交付技术——怎么写出来）+ 改编专线。

## 甲、要素层（S0 拆解 / S2 建档用）

### CR-01 故事核心公式（硬性）
任何剧本/小说的核心只讲一件事：**一个什么样的人，在什么样的背景下，做了什么样的事**。情节、立意、结构都是让这三要素更有新意更有看点，核心永远离不开人×背景×事。S0 五维拆解由此展开。

### CR-02 人物是核心（硬性）
没有人物就没有故事——没有人物也就没有情节、矛盾、情绪及后面的一切。**主角是一部剧的重中之重**。人设出彩靠与众不同的三观、认知和性格（参照系：吕树/白小纯/古月方源式的不可替换人格）。写崩诊断：剧写崩多崩在人设上——情节只要合乎情理有矛盾有情绪一般不崩；跑偏时按"人物/主题/情节/结构/节奏/金手指/背景"逐项排查，不要默认全怪一个地方。

### CR-03 题材与创意（重要）
主题=题材=想讲一个什么样的故事，必与背景绑定（"我在末世开小吃店"）。中规中矩的题材加一个创意即可变好（"全家都能听到女主的心声"）。**创意三来源：人物性格 / 金手指 / 背景设定**。创意可遇不可求——没有大创意时做题材微创新+把基本功做扎实，一样能出成绩（老题材扎实基本功高成绩的实证很多）。

### CR-04 金手指宽定义（硬性）
金手指≠系统。**凡是能让主角特殊、让主角变得厉害的东西都是金手指**：物品、人物（厉害的前辈带着他）、出身（隐藏富二代父母）、信息（重生记忆）。主角必须是故事里特殊的存在——即使现在还不厉害。S2 建档必登记金手指：它是"主角为什么能赢"的唯一解释器，漏记则情理门（CR-10）必挂。

### CR-05 立意（重要，分级推荐依据）
立意=通过故事向人向社会传达的**价值认知**，决定顶流与普通的分界。铁律：**立意藏在题材、人物、情节、行为动机和台词里，绝不单独拿出来说教**。表达方式两种：主角的成长言行直接表达；或让主角经历事情，观众自己感受。分级推荐标尺（初稿包索引用）：三流编剧讲故事 / 二流讲人物 / 一流讲情怀——过关版本按此标注它站哪一档。

## 乙、动力层（S4 验收 / S3 节奏用）

### CR-06 矛盾与情绪的机器（硬性）
矛盾提供持续看下去的动力，情绪提供投入感，两者相辅相成且**必须不断变换**：一集开头有矛盾 → 中间带起情绪 → 结尾再出矛盾；过程中用反转和误导（"欺骗"观众）让矛盾情绪来回转换，一集内几次冲突与情绪变化才有引人入胜。**一切要素的终极判定标准：能不能制造矛盾冲突、能不能带动观众情绪**（台词、创意、画面、节奏全在服务这两件事）。

### CR-07 情绪结算（硬性）
矛盾引起什么情绪，就要怎样解决——**结算=把矛盾解决掉**。只制造不结算，观众的心境无法落地，持续观看的动力断裂。验收：每集埋的矛盾在本集或台账登记的后续集数内必须有结算，不得悬空。

### CR-08 情绪建立在矛盾上、转换防疲劳（硬性）
只有一种情绪观众就疲劳——**矛盾的作用之一就是让情绪不断转换**（上一秒喜下一秒哀，跌宕起伏）。自带情绪的题材（幽默、复仇）情绪本来就在，再加矛盾冲突更好看。验收 lint：情绪名称词连续出现不转换 = 挂。

### CR-09 节奏=调动频率，非情节快慢（硬性）
节奏是**用矛盾冲突和表现手段调动观众情绪的频率**，不是情节推进速度。大小节奏分离（《亮剑》式）：大节奏可以很慢（三大阶段），小节奏必须很快（一两集一次变化、每集持续调动情绪）。快慢灵活：转换过度会疲劳需舒缓，舒缓过久要再吊起来。

### CR-10 合乎情理门（硬性，闸门A核心）
题材、设定、情节、人物反应都要**合乎情理**：行为必须匹配能力（普通高中生弹指弹飞霸王龙=不合情理；元婴大佬弹=合情理）；反应必须匹配情境（捉奸在床不愤怒必须有原因——准备复仇或另有安排）。**合乎情理 + 意料之外 = 精彩反转**；缺前者观众觉得被当傻子，缺后者平庸。AI 初稿最大质量变量在此（套路保矛盾情绪、情理无人管）——闸门A逐场过这道门。

### CR-11 判断作品靠什么起作用（重要，对标警示）
判断对标作品时，要能看出它到底靠什么起作用（创意？新鲜感？矛盾情绪？推广时机？），**不能只看结果照着学**——《风水天师》结构本身不是最好的，靠的是创意新鲜感与推广。素材体检引用对标时必须注明其成功归因。

## 丙、呈现层（S3 生成用）

### CR-12 画面思维（硬性）
剧本是半成品，要变成影视作品才是完整商品——写每一段时问三个问题：**拍出来是什么画面？能不能拍成画面？怎样让矛盾在画面里更有冲击力？**信息交代用快剪法（死亡回档不正面叙述，两个快速闪回镜头+主角一哆嗦）。画面要连贯流畅，矛盾情绪在流畅呈现中延续。（AI 剧成本压力低，成本项不作硬约束。）

### CR-13 台词双重约束（硬性）
台词必须同时匹配**人设**与**当下场景**，缺一即挂：杀伐果断的人在妻子面前可以温柔一些，但不会突然变成甜妹式温柔；大大咧咧的人不会对任何事都用同一种方式反应。场景变了表达可以变，底色不变。lint：抽台词还原角色——还原不回去的台词=与人设不符。

### CR-14 开头留人+接得住（硬性）
整部剧开头和每一集开头都要在**1-3 秒内**给出吸引点：冲突、悬念或极致反差，形式可以是画面、声音或一句台词（"我只吃零点一成熟的牛肉……"）。**开头留人的东西必须和后面的剧情接得上**——第一集情绪拉很高、第二集骤落、第三集没拉起来，整个节奏就坏了（集间割裂=第一二集像两部剧）。

### CR-15 卡点选择逻辑（硬性，与 HK-05 配合）
每一集结尾**要么卡矛盾、要么卡情绪，不能什么都没有**：情绪还没拉出来→先卡矛盾（让观众期待下一集的情绪）；情绪已拉出来→不给完，断在释放前由下一集接上（表白卡在即将说出口、战斗卡在双方放大招）。技术条件（情绪未完+剧情刚翻新+人物临界）见 HK-05；本条管选择，HK-05 管切法。同段动作戏占比过多时注意节奏，不硬卡。

### CR-16 叙事手法服务故事（重要）
顺叙/倒叙/插叙、线性/非线性/环形——**手法没有高下，让观众看得舒服、理解故事就是好**。禁止炫技：驾驭不了复杂叙事时，老实按时间线从头讲到尾一样出优秀作品。非线性适合悬疑刑侦等需要切换时间线的题材，选择看故事本身。

### CR-17 情绪≠名称词（硬性，可 lint）
**"脸色一变"只是动作，情绪是这个动作和前后情节让观众感受到的东西**。写"他很愤怒"不等于观众愤怒了——情绪必须通过具体的台词、行为、环境变化让观众实际感受。矛盾同理：要观众感受到，不是文中出现"矛盾"二字。lint：扫描纯情绪名称词（愤怒/震惊/恐惧/喜悦……）无行为支撑 = 挂。

## 丁、改编专线（S0 改编分支用）

### CR-18 改编三策（硬性）
①**好 IP 不画蛇添足**：原作者把人物、矛盾、情绪、节奏已做好的部分照原书节奏转剧本，不自作聪明；②**部分好则补强**：借力做得好的，补强不足的（题材好但矛盾后置→前面加快让矛盾情绪更早出来）；③**删凑字**：大段对话实为凑字数（作者当天没想好情节）的内容删掉——**编剧是按秒吸引观众的**，观众烦十几秒就弃剧。

### CR-19 毒点必砍与衔接（硬性）
改编中发现毒点直接砍。前段情节不好但一动后面全动的：先在原有情节中加强矛盾、拉起情绪再接后续；实在接不上则评估后段——后段同样不好整条线不保留，后段精彩就把前面不好的部分删掉再衔接。**衔接突不突兀只看四个字：合乎情理**（→CR-10）。

### CR-20 新人三抓（建议，快启模式）
暂不能全面驾驭时，先抓**创意、矛盾、情绪**三核心简单往前走（下沉剧逻辑：这三点直接+固定人物框架可套）；但要注明：这解决的是入门，行业继续发展必须补足其他基本功，不能停在简单粗暴拉矛盾拉情绪（下沉剧显得没逻辑的病根：保三核心弃其他）。
