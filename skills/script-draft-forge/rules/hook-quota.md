# 规则模块 — 钩子系统（HK）

> 总控在 S1（预算）、S3（生成注入）、S4（闸门A回提）读本文件。前缀 HK-*。
> 依据：麦基信息差三分法、希区柯克炸弹理论、短剧三点论卡点公式、帝一 2026 钩子疲劳实证、半镜学院六母型分类。采集 2026-11-02。

## HK-01 预算两级来源（硬性）

钩子预算来源：①**用户自定义优先**（数量/类型/强度/钩位任意组合，如"20 句""只要身份揭露型""每集双卡点"）；②未指定时按 HK-04 折算默认（挂载平台包则按包内细则）。预算表首行必须注明来源（`自定义` / `折算默认` / `模块折算`），禁止无来源拍数字。用户自定义只覆盖其声明的维度，未声明维度仍走折算默认。

## HK-02 信息差引擎（硬性）

每个钩子必须声明其信息差模式，三选一：
- **神秘**：观众比角色知道得少（跟着查，驱动=好奇）
- **悬疑**：观众与角色知道得一样多（一起面对未知威胁，驱动=担忧）
- **戏剧反讽**：观众比角色知道得多（看着角色走向危险，驱动=焦虑；希区柯克炸弹——悬念依赖"知道"而非"不知道"）

轮换规则：一集内三种模式必须交替；单一模式连续 ≥3 场判疲劳风险。执行方式：每场场景头标注 `[神秘|悬疑|反讽]`。
反例：全程神秘（观众一直在猜→累）；全程反讽（一直在替角色急→麻）。

## HK-03 类型库与轮换（硬性）

六母型：①不寻常的情况 ②问句 ③预告危险 ④兵临城下 ⑤神秘人士 ⑥危机钩。第七型（2026 趋势）：**生活化羞辱**——"相亲被嫌没房""被导师当众骂"，替代肢体冲突（下沉受众熟龄化＋监管收紧双驱动）。
轮换规则：一集内 ≥2 型；**相邻集尾钩不同型**；同一型连续使用 ≤3 集。
配比参考：冲突型 45% / 情感型 30% / 悬念型 25%（女频情感型上调，男频冲突型上调）。

## HK-04 四级钩位与平台折算表（硬性）

钩位=钩子在时间轴上的工位，四级：
| 钩位 | 位置 | 要求 |
|---|---|---|
| 开头锁人钩 | 前 3 秒 | 强度 ≥4；打脸/背叛/遇险/对峙/强悬念/极致反差 |
| 节拍钩 | 每 15-20 秒一个情绪单位 | 小冲突/小爽点/小悬念 |
| 卡点钩 | 集尾 | 强度 ≥4；按 HK-05 三条件 |
| 长线钩 | 跨集贯穿 | 纹身式：找一个可反复出现、意义延迟揭晓的实物/约定/身世，每集出现一次、每次多给一点 |

折算默认（用户未指定时）：通用默认 = 开头钩 1 + 节拍钩 2-3 + 卡点钩 1 + 长线钩贯穿；挂载平台包（modules/platform/structure-templates.md）时按其 ST-* 平台细则覆盖折算值（红果集尾按脸/盐选 500-800 字信息炸弹/番茄断点递增/抖音现实向共鸣钩替代强冲突）。

## HK-05 卡点三条件（硬性）

卡点成立 = **情绪未完 + 剧情刚翻新 + 人物状态临界值**，三者同时满足，缺一即废卡点。
- 切在"差一步"：动作中 / 话说到关键处 / 门被推开的前一秒。切在"事情结束之后" = 废卡点。
- 情绪没拉出来 → 先卡矛盾（让观众期待下一集的情绪）；情绪拉出来了 → 不给完，断在释放前。
- 公式：铺垫—高潮—截断。

## HK-06 松紧节拍与强度曲线（硬性）

强度 1-5。规则：
- 重钩（4-5）之后必须跟一个松场（消化与蓄力——拳头与呼吸；松≠废戏，松场承载现实锚点/关系铺垫）。
- 单集强度曲线禁止全程 5（防麻），也禁止低于 2 连续两拍（拖）。
- 开头钩与集尾卡点强制 ≥4，节拍钩 2-4 浮动。

## HK-07 兑现循环（硬性）

给一半卡一半：每兑现一个旧钩，必须同拍抛出一个新钩。只卡不给→观众恨；只给不卡→观众走。
预算表必须含《钩子台账》列：`| 钩子 | 埋设集 | 类型 | 信息差 | 强度 | 预计兑现集 | 状态 |`。长线钩无预计兑现集 = 台账不完整 = 闸门A不过（契诃夫之枪：第一幕的枪第三幕必须响）。

## HK-08 显隐过渡（重要）

前 3 集可用显性钩（明牌操作：开头强冲突、集尾硬悬念）抓初始流量；**第 4 集起逐步转隐性钩**（关系张力、未交代的背景、观众会好奇"为什么"的细节），让观众从"被钩住"过渡到"主动想追"。
依据：帝一 2026 实证——纯钩子密度驱动的剧第三、四集追看率显著下滑。
判定参考（提示用户用）：评论区讨论剧情本身=健康；讨论套路（"每集都断在同一个位置"）=钩子露馅，需调结构。

## HK-09 回提验收（硬性，闸门A）

对初稿反向提取钩子，四维验收，任一维不过 = 杀稿：
1. **覆盖率**：预算钩位兑现比例（长线钩按台账核对埋设与兑现）
2. **类型轮换合规**：HK-03 轮换规则逐条过
3. **强度达标**：开头钩与集尾卡点 ≥4；强度曲线无连 5、无连 2
4. **台账完整**：HK-07 台账列全填、长线钩有兑现集

素材钩子不足时：给填空模板（`___`）并列出缺口清单，禁止编造素材里没有的钩子。
