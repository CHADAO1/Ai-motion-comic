# 工作流 — Mode 3：按纲改编初稿（小说原文 + 大纲/细纲 → 初稿）

> 总控 SKILL.md §1 的第三条路径。挂载 `modules/process/source-outline.md`（SO-01~08），
> 复用 S1/S2/S4/S5 的既有规则，**只替换输入侧与差异化口径**。
> 每一步开始先把 manifest.json 对应 stage 置 doing，结束置 done；`mode` 记 `"3"`。

## 什么时候走这条

用户给了**小说原文文件**（或整目录）**并且**给了**编剧大纲或细纲**，说「按这个纲出初稿 / 把原文和细纲放进去出初稿 / 小说改编成剧本」。只有一个题材想法 → Mode 1；只重出某集 → Mode 2。

## N0 原文入库

```bash
python scripts/source_outline.py ingest \
    --source <小说原文.txt|.md|.docx|目录> \
    --outline <细纲.md> --outline <大纲.md> \
    --pipeline <剧本目录>/pipeline \
    [--chapter-pattern "<自定义章节正则>"] [--packet-max-chars 16000] \
    [--exclude-patterns "<项目专属广告行正则>"] [--no-clean] [--apply-sections] \
    [--authorization <00_授权登记.md 或自动发现的自定义名>]
```

- `--source` / `--outline` 可重复，也可直接给目录；细纲与大纲可同一文件（`# 大纲` / `# 细纲` 分节）。
- **授权在前**：S0 先跑 `check_authorization.py check`，exit 1 即阻断；`--authorization` 只把登记表路径记进 manifest，不在此判法律效力（SH-01/02）。
- **净稿默认启用**：内置词表 v1.1 剔整行转载站噪声（番外/作者附言/乱码只标记不删，SH-04~06；`SH-L06` 专删「本站所有小说为转载作品…」整行免责声明），项目专属规则用 `--exclude-patterns` 追加；`--no-clean` 关闭、`--apply-sections` 才整段剔除番外。删除逐条登记在 `00_净稿报告.md`，其行号是**清洗前原文件行号**，与索引表的净稿行号分属两套口径。
- 首次不会写格式？先 `python scripts/source_outline.py init-template <目录>`，照模板填。
- 产物：`pipeline\原文纯文本.txt`、`source-index.json`、`10_原文索引.md`、`00_净稿报告.md`、`outline.json`、`12_纲解析报告.md`、`packets\ep{NNN}.md`、`ingest-manifest.json`。
- **通过条件**：章节数 ≥1、细纲集数 ≥1、每集有 ≥1 条必留条目；告警全部读一遍，推定分配 / 无原文依据条目按 SO-05 记入待确认清单。
- 章节识别不对 → 用 `--chapter-pattern` 重跑，不要手工改纯文本。

## S0 需求登记（Mode 3 变体）

需求表在 Mode 1 维度上多两行，且**能从纲里读到的不重复问用户**：

| 维度 | 取值 |
|---|---|
| 集数 | 细纲最大集号（无细纲则大纲集数），与用户声明冲突时问 |
| 版本数 | 默认 **2**（用户可说「只出一版」「每集3版」） |
| 细纲约束 | 默认 **锁定结构**；仅当用户明说「细纲仅供参考」才改「事件锁定/自由结构」 |
| 单集时长 / 题材 / 风格 / 钩子自定义 / 挂载模块 / 引擎 | 同 Mode 1 |

五维拆解（CR-01）的证据**必须来自 `10_原文索引.md` + 原文切片**（已净稿，行号以净稿为准），每条带章节 ID 与行号；候选人名回原文核对后才写进小传。对标归因（CR-11）若纲里提到对标作品照做。模块挂载：自动挂 `process/source-outline` + `process/dialogue-pass`，另有全部 Mode 默认挂载的 `process/source-hygiene`（授权/净稿）与 `process/episode-plan`（三要素），其余同 Mode 1。产物仍是 `pipeline\00_需求与体检.md`，另须有 `00_授权登记.md` 与 `00_净稿报告.md`。

## S1 钩子预算 / S2 锚点建档

与 Mode 1 完全相同（HK-01~09 / DR-01~04），但两条附加：

1. 细纲行内写了 `钩子：X` 的，直接作为该集预算的**用户自定义输入**（HK-01 自定义优先），预算表注明来源「细纲标签」。
2. 人物小传与术语表必须回原文切片取证；细纲写了但原文没有的设定，按 SO-06 登记，不当既定事实。
3. **产出《逐集三要素表》**（EP-01~05/08）：`check_episode_plan.py init-template pipeline/01_分集规划表.md --episodes <集数或区间>`，逐集填核心事件／明确冲突／本集信息增量／尾钩／出处，跑 `check` 验齐备率 100%。**只跑中间批次传 `10-12`（批次口径），不要传纯数字 12**（全剧口径会误报缺 1..9 集）；`init-template` 会直接生成对应集号的行。**细纲本身不等于分集规划**：细纲可能有事实错误（本会话已实测两处），三要素表须回原文切片取证，不照抄纲。三要素表单独成文件时，生成包钩子预算行标注「尾钩同源派生」，不再谎报 S1 缺产物。

完成后跑一次刷新，把预算行、三要素行与四件套打进生成包：

```bash
python scripts/source_outline.py refresh --pipeline <剧本目录>/pipeline
```

## N3 生成（替换 Mode 1 的 S3）

1. **只读 `pipeline\packets\ep{NNN}.md`**，不另开全文、不靠对话记忆衔接（SO-02/04 / DR-01）。
2. 生成指令必须包含：本集细纲逐条编号 + 本集原文切片 + DR-01 四件套 + 本集钩子预算行 + CR 呈现层约束 + **结构锁定声明**（SO-03）。
3. 结构锁定下每集出 2 版（或用户指定数），版本差异轴四选一以上，写进文件头：`结构：细纲锁定 · 差异轴：{…}`（MR-06）。**同结构只改几个词不算多版**。
4. 禁止：并条/拆条/调序/新增大纲外大事件/改动原文既定事实/把细纲没覆盖的集顺手写了。
5. 每版文件头按 MR-06 标注引擎、挂载模块、日期，并加一行「依据生成包：packets/ep{NNN}.md」。
6. 分批跑，每批 5-10 集（CC-03），每 10 集做卷级回顾；单版失败只重跑该版。

## S3.5 对白二次调整（Mode 3 自动挂载 DP 模块）

N3 出的是**初稿**，不是可生产对白稿。按 `modules/process/dialogue-pass.md`（DP-01~08）单独跑一遍：

1. 输入 `outputs/ep{NNN}_{版型}_v{n}.md` → 输出 `outputs/ep{NNN}_{版型}_v{n}_dlg.md`（后续 N4 验这份）。
2. 只改对白／旁白的呈现层：单句 8–15 字、书面语→口语、朗读顺口、旁白三禁、叙述腔直搬禁令、A/B 同旁白禁令。**不动场次顺序、事件、人物、数字、规则、视角**；越界就回 N3 重出，不在本工序修。
3. 落 `pipeline/04_对白调整登记.md`：原句 → 改为 → 理由；区分例外登记、C 类删除、口语替换。**删除必须登记，禁止默删**（DP-08）。
4. 人工门：DP-04 念 ≥5 句、DP-05 三禁逐句过。脚本不判这两项，不得省略。

> 为什么不能并进 N3：小说原文＋细纲的生成阶段同时扛「结构锁定／覆盖／钩子预算」，口语约束塞进同一条提示词会被结构目标吃掉。这一环是全链路返工率最高的一段，独立工序是硬要求。

## N4 验收（Mode 1 的 S4 + 附加项）

脚本报告都要跑、都要落盘：

```bash
python scripts/check_gate_a.py --draft <剧本目录>/outputs/ \
    --anchors <剧本目录>/pipeline/02_人物小传与术语表.md \
    --config <剧本目录>/pipeline/gate_a_config.json \
    --source-dir <剧本目录>/pipeline/source \
    --out <剧本目录>/outputs/01_体检报告_脚本.md

python scripts/source_outline.py check --draft <剧本目录>/outputs/ \
    --pipeline <剧本目录>/pipeline \
    --out <剧本目录>/outputs/01_体检报告_纲源.md

python scripts/check_adapt.py --files <剧本目录>/outputs/*_dlg.md \
    --source-dir <剧本目录>/pipeline/source \
    --config <剧本目录>/pipeline/adapt_gate_config.json \
    --out <剧本目录>/outputs/01_验收.json

python scripts/check_episode_plan.py check \
    --plan <剧本目录>/pipeline/01_分集规划表.md --episodes <集数或区间，如 10-12> \
    --out <剧本目录>/outputs/01_分集规划检查.md \
    --json <剧本目录>/outputs/01_分集规划检查.json

python scripts/check_authorization.py check \
    --pipeline <剧本目录>/pipeline \
    --out <剧本目录>/outputs/00_授权检查.md
```

判定顺序：preflight 全清单（含 **SH-01 授权阻断 / SH-07 净稿留痕 / EP-06 合并门**）→ **GA-12 稿件形态门（先判有没有戏）** → GA-01~05 → **GA-09~11 ＋ 语义门 G1~G9** → **GA-06~08**。三要素齐备率 <100% 或授权检查 exit 1，同样不得写「验收通过」。任一 FAIL 判杀并记死因（杀稿不修稿，铁律 1）；**GA-12 命中写「不予验收」，与内容违规分开记死因**。**G9／GA-10／GA-11 任一命中即不得写「验收通过」**。GA-06 的「锚点命中」只是漏项预警，仍需在体检报告里逐条写语义判定 + 行号证据；INFO 逐条进 S5 决策点清单。全部通过才写《初稿包索引》，每集标「结构锁定」+ 差异轴。

> `check_gate_a.py` 与 `check_adapt.py` 均默认跑 GA-12；DRY 演练稿、无场次无对白的空稿不会被写成「验收通过」。形态门只量形态，不设字数下限、不判质量。

> 原文切片目录缺 `ep{NNN}.txt` 时，GA-10 会降级 INFO 并明示「逐字直搬检查已跳过」——不得把没检查当通过，须补切片或人工核。

## S5 交付（Mode 1 三件套 + 两条）

1. 铁律 8 三件套照做：打开全部版本文本与索引、贴每集推荐版正文摘录、给挑稿决策点清单。
2. **额外呈现脚本报告**：`01_体检报告_脚本.md`、`01_体检报告_纲源.md`、`01_验收.json`、`01_语义门禁.json`、`01_分集规划检查.md`、`00_授权检查.md`，以及 `pipeline/04_对白调整登记.md`、`pipeline/00_净稿报告.md` 与 `12_纲解析报告.md`。授权状态未核实只写「已登记字段，法律效力待权利方确认」，不得写「环节 1 已完成」（SH-02/07）。
3. **决策点清单必须含四类**（SO-05/06）：①推定分配的章节切片 ②无原文依据的细纲条目 ③原文与细纲冲突 ④GA-08 疑似新增事件。每条给编号与建议，不替用户拍板。
4. 交付说明写清：结构锁定意味着什么、可以点名重跑哪个差异轴、要改结构必须明说「细纲仅供参考」回 Mode 1。
5. 初稿包即终点，不合并、不精修、不指路下游（review/audit.md 全清单 ✅，含 A12/A13）。

## 回退与断点

| 改动 | 回退到 |
|---|---|
| 原文换版本 / 细纲增删条目 | N0 重新 `ingest`（原 JSON 会被覆盖，先备份 `12_纲解析报告.md`） |
| 只改钩子预算 / 人物小传 | S1 或 S2 → `refresh` → N3 只重跑受影响集 |
| 某集被杀 | Mode 2 补版，N4 只复验新版本 |
| 用户说「细纲仅供参考」 | 卸 SO 模块，回 Mode 1 S0 重登记 |

## 铁律

- **结构听细纲、事实听原文**（SO-01），模型不得「优化」编剧已拍板的结构。
- **不把整本小说塞进上下文**（SO-02）：生成包是唯一入口，截断必须显式标注。
- **覆盖不靠自报**（SO-07）：只认脚本命中数、覆盖率、行号。
- **冲突不替用户决定**（SO-06）：摆证据、给建议、等拍板。
