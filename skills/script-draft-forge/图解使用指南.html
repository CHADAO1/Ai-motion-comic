编剧初稿锻造 · 图解使用指南

给银时的通俗版说明书——它是什么、怎么用、图里全说清。

一、它是什么（一个类比）

它像一个不知疲倦的编剧助理团队：

你把素材（小说/对标剧/一个想法）和需求交给它，它就——

① 先问清你要什么（不猜）　② 把素材拆解建档　③ 按你的要求排好钩子预算
④ 开好多台"打字机"同时出稿，每集好几个不同结构的版本
⑤ 自己先质检一遍：能用的放左边，不能用的一律枪毙并写明死因

最后你拿到的，是一摞已经过了第一轮质检的多版初稿——你只做最擅长的事：挑选和精修。

钩子还要"换着用"（防疲劳规则）

同一个套路连用三集，观众第四集就不猜了。所以：

规则大白话
信息差三模式每个钩子要么观众比角色知道得多（替他着急），要么少（跟他一起查），要么一样多（一起紧张）——三种换着来
六母型轮换不寻常的事 / 问句 / 预告危险 / 危险逼近 / 神秘人 / 危机——一集至少两种，相邻两集的集尾钩不许同款
松紧节拍重钩之后必须给一口气喘（松场），全程高潮观众会麻
给一半卡一半每兑现一个旧钩子必须同时抛出新钩子——只给不卡观众走，只卡不给观众恨

每个判定都带证据：行号、原文引用、数值——不是"感觉不错"，是"第 37 行，台词还原失败：杀"。

五、怎么跟它说话（照抄版）

万能公式：需求 + 素材（先说需求，再丢素材）

场景1 从零开始：「帮我出个初稿包，20集，每集1分半，投红果，男频都市逆袭」+ 素材
场景2 自己定钩子：「钩子要身份揭露型，每集双卡点，其他你定」零强制数字
场景3 不管平台：「不挂平台，按我自己的节奏，重点做人物弧光」
场景4 重出某集：「第5集重出几版，上版卡点太弱」死因变禁令
场景5 即兴套路：「按武侠宗门套路来一版」自动存成模块，下次复用
场景6 按纲改编：「小说原文 + 编剧大纲/细纲在这，按这个纲出初稿」Mode 3 · 结构听细纲

六、Mode 3：小说原文 + 大纲/细纲 → 按纲出初稿

适用：整本小说 + 编剧已经把细纲写好了

Mode 1 只收一段素材简介。整本小说直接塞进上下文会爆窗，而且模型会自作主张"优化"编剧拍过的结构。Mode 3 就是为此加的第三条路。

步骤做什么为什么
N0 入库原文按章切片（CH001…）、细纲逐条编号 EP001-B01…长文本不全文入上下文；逐条才有得查
逐集生成包packets\ep001.md = 本集细纲 + 本集原文切片 + 人物/术语/前情 + 钩子预算每集只读这一包，衔接靠读文件不靠记忆
N3 生成结构听细纲、事实听原文；多版只在呈现层差异化不许改事件顺序、不许新增大事件、不许改人名设定
N4 验收多跑一份覆盖报告 GA-06~08必留细纲条目没落地直接判杀，不认"都写到了"的自报
差异化降级说明：细纲锁死结构后，同集两版不能再靠"换结构模板"差异化，只能换切入点 / 场面调度 / 台词密度 / 卡点切法，并在文件头写明差异轴。只有你说「细纲仅供参考」才恢复 Mode 1 的自由结构。
交给你拍板的四类事：推定分配的章节切片、原文里找不到依据的细纲条目、原文与细纲冲突、疑似新增大事件——脚本只摆证据，不替你决定。

格式不会写就跑：python scripts/source_outline.py init-template <目录>细纲里写「原文第3-5章」可精确指定本集用哪几章；写「锚点：宁清和|手表」让覆盖校验更准。只给大纲不给细纲也能跑（事件锁定）。

七、拿到初稿包后：三步挑稿法

第 1 步 · 看索引
打开 00_初稿包索引.md：每集版本清单 + 过/杀判定 + 三档分级——讲故事（三流）/ 讲人物（二流）/ 讲情怀（一流），一流标注的优先看。

第 2 步 · 只在过关版里挑

铁律：杀稿不修稿。被杀的版本带着死因（如"情理门挂：能力越界"），不要试图精修救活——修烂稿的时间够重出三版。

第 3 步 · 不满意就点名重跑
「第 N 集重出，要悬念倒叙版」——比"再改改"快十倍。挑完合并精修自己来（或让会话模型帮忙：'把 ep005 的 A 版和 C 版合并'）。

十、六档位自动调度（可选执行层）

一句话：让六个档位真的各干各的活

OpenCode 一个会话只使用一个模型，所以默认要手动分批切档。scripts\engine_dispatch.py 按 MR-07 的六个端点逐档直调 API，自动排任务、写产物、记账、断点续跑。

命令链：init-config → plan --episodes 1-10 → run（演练）→ run --live（真跑）→ status / verify

三条硬规矩：① 不加 --live 是零调用零费用的演练，产物带占位标记、verify 一律拒绝验收；② 中断重跑跳过已完成任务，失败不写产物、下游自动 blocked；③ 成本报告只报 token 用量，没填单价不编造金额。

它只换「谁来生成」，不替你挑稿、不合并、不改稿、不出终稿。前置：六个端点配齐且重启过宿主。

十一、第一次跑的建议

小目标试跑：5 集短剧 + 明确平台 + 一种题材

约 10-20 分钟走完全流程。重点不是稿子质量，是看懂索引和体检报告的结构——第一次跑完你就知道，哪些需求值得在开头说死（集数/时长/平台/钩子类型），哪些可以放手让它自己定。

然后再上正片。祝锻造顺利。
