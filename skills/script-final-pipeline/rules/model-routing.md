# 模型路由 — 阶段→模型分工与降级（唯一事实源）

> 本文件是流水线「执行用哪个模型」的唯一事实源。规则判据（CP-\*/LG-\*/AMZ-\*）与硬标准（standards.md）永不绑定模型名；任何模型变更只改本文件。

## 1. 路由铁律（MR-01~07）

- **MR-01 规则层模型无关**：rules/ 下除本文件外，任何判据/标准文件禁止出现具体模型名；发现即视为污染，回滚该文件。模型名只允许出现在本文件与产物头部标注（MR-07）。
- **MR-02 阶段→角色分工**（按能力要求路由，不点名模型）：

  | 阶段 | 能力要求 |
  |---|---|
  | S0 预处理 | 无模型——确定性脚本（docx2txt、抽场次） |
  | A 合规审核 | 长文逐条规则执行、行号定位不漂移 |
  | B 逻辑审核 | 跨全文推演（四台账交叉核对、因果链追踪） |
  | C/D 修复 | 高保真最小改写（对照单逐条，禁止顺手扩写） |
  | E 台词双语 | 英文台词设计 + 回译中文 + 术语表全剧一致 |

- **MR-03 默认模型表**（依据采集 2026-11-02；来源：ToneBench 长视频脚本写作榜、LMArena 创意写作榜、CNWB 中文叙事写作测评）：

  | 角色 | 默认 | 档位 / 备注 |
  |---|---|---|
  | 主力（A/B/C/D/E 主执行） | Claude Opus 5.5 | 思考档 xhigh；max 仅用于单点句子级精修 |
  | 副手（草稿/批量/校对） | GLM-5.3 Flash | 10 稿并行 + 主力挑稿合并，单稿成本≈主力 1/190 |
  | 不排（逻辑审核主力） | DeepSeek 系 | 人物关系因果维度慢板（V4.1 vs V3.2 总分 +7，人物关系仅 +2.5） |
  | 不用（写作/改写主力） | Gemini 系 | ToneBench 最佳 Gemini 仅 80.9，中游 |

- **MR-04 跨厂评审**：同一剧本的「创作/改写」与「审核」尽量用不同厂模型——评测实测同厂评委自评偏置（GPT 评委对 OpenAI 稿 +2.75 分、对 Anthropic 稿 −2.14 分）。
- **MR-05 降本策略**：批量初稿走副手，主力只做挑稿/合并/终审（"生成便宜，挑稿才贵"）；主力档位默认 xhigh（$0.69/稿 vs max $2.75/稿，分差 <1%）。
- **MR-06 端点接入与降级**：接入外部端点一律走 opencode-custom-model 技能写 `~/.config/opencode/models.json`；无可用端点时全流程降级为当前会话模型照常执行，不阻塞，但须按 MR-07 注明「降级：会话默认模型」。
- **MR-07 产物可追溯**：每份审核报告/对照单/应用记录头部标注 `执行模型：<名（档位）> · <日期>`；换模型后可用同一剧本重跑对照评估模型质量。

## 2. 维护约定

默认模型表每季度或新旗舰发布后联网复核一次，以复核实测为准更新并注明日期；变更记 CHANGELOG.md，只改本文件、不动判据文件。
