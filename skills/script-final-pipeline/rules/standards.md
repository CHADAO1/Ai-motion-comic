# 标准 — 对照单 / 应用 / 校验硬细则

## 1. 对照单格式（C/D 阶段）
`### 场景（L行号）` 分节 + 表：`| 行号 | 角色 | 原文(或"（原 OS：…）") | 拟改为 | 标注·说明 |`。删除行"拟改为"写"删除（依据）"。条目必须带：修订基准行号、CP-*/LG-* 编号、最小修复方向（台词级<镜头级<场次级）、悬念豁免与对话情境原则的适用说明。

## 2. 台词双语对照单（E 阶段）
- 术语表先行（人名/题材词一次定稿，全剧唯一）。
- 逐行：`| 行号 | 角色 | 原文 | 英文台词（设计稿） | 回译中文 | 标注·说明 |`；标注四档：原文 / 重设计 / 表演优化 / 删除。
- 判定顺序：先"该不该说"（删除/表演优化）再"怎么说"；重复与无意义台词先过活人感检查（紧张/受伤/遗忘/年幼/年迈等状态下的破碎重复判原文）。
- 应用后正文格式：`英文台词（回译中文）`，OS→V.O.、画外→O.S.；△动作行、场景标题、人物表、简介保留中文。

## 3. 应用脚本硬要求
1. minidom 直改 document.xml；源=上阶段 docx；原始 docx 只读。
2. 定位：优先行号，校验"行号-1 段落 ≈ 原文"（标点剥离后包含/句尾匹配）；失败→行号±6 窗口唯一匹配；多候选取最近并记录；冲突/失败→报错停机，禁止猜测写盘。
3. 压缩/改写行（对照单原文与实际原文有差异）用 CHECK_OVERRIDE 片段；过短行用 POS_OVERRIDE 直接指定。
4. 三道校验：集合差（旧 multiset −删 +增 == 新 multiset）、违禁词重扫（少年/年幼/年少/渗血/血迹/血丝/血滴/血痕/鲜血/血液/带血/飙血…按剧本语言增删）、双通道提取一致（docx2txt 重提 == 输出 txt）。
5. E 阶段加覆盖率预检：源文本中所有"疑似台词行"（CJK 说话头+全角冒号）未被映射即退出，白名单仅限简介等非台词行。
6. 产物：新 docx + 新 txt（下一阶段基准）+ 应用记录（操作数/修正明细/校验/重扫/残留扫描；头部含执行模型标注 →MR-07）。
7. **固化引擎唯一（硬性）**：以上六条由 `scripts/pipeline_apply.py` 实现（`extract` / `apply` / `verify` / `selftest`），开工前跑 `selftest` 确认可用。禁止在会话里按本节描述临时另写脚本——过去「运行时现写」正是稳定性缺口。定位失败/多候选冲突/覆盖率未达/校验未过一律报错退出且**不写盘**；需人工在对照单写 `CHECK_OVERRIDE=片段` 或 `POS_OVERRIDE=段号` 后重跑。`--allow-banned` / `--allow-unmapped` 的放行必须记入应用记录并在交付说明里显式声明。

## 4. 交付清单（Mode 1 全流程）
```
{剧本目录}\
├── 《xx》合规修改对照单.md / 《xx》合规修订版.docx
├── 《xx》逻辑修改对照单.md / 《xx》（合规+逻辑修订版）.docx
├── 《xx》台词双语对照单 v2（双语设计稿）.md / 《xx》（合规+逻辑+台词修订版）.docx（最终剧本）
└── pipeline\ 00_全文 / 01_审核报告 / 10-13_台账 / 20_逻辑报告 / 各阶段应用记录 / 各阶段 txt
```

## 5. 经验条目（实战沉淀）
- 对照单行号在编写时易混入动作行偏差：应用脚本的内容定位兜底是必须项，且预检发现的漏句要回填对照单"补遗"节保持文档与成品一致。
- 跨场景逐字重复的宣言/威胁：按癫狂/情绪递进差异化，不做原样复读。
- 恐吓类台词（割舌/挖眼/砍脚）一律降级为"后果暗示+镜头语言"，保留威胁功能不保留器官词。
- 枪指人头/自残要挟：改持枪威慑方位（肩/腿/对天）或改为"非枪挟持"，禁太阳穴特写。
- 称呼与人名错误（A/B 名混用）优先在双语术语表统一，回译中文随之统一。
