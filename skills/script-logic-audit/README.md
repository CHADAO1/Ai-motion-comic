# script-logic-audit — 剧本逻辑（因果）审核

与 `script-content-audit`（合规红线审核）并列为**先审后改**第一关的两份并行审核之一：

| 审核 | 技能 | 管什么 | 报告 |
|---|---|---|---|
| 合规审核 | script-content-audit | 能不能发（YouTube 红线、血腥框架） | pipeline\01_审核报告.md |
| 逻辑审核 | 本技能 | 前后是否自洽（因果逻辑） | pipeline\20_逻辑审核报告.md |

## 怎么触发

对剧本说：**"审核剧本逻辑" / "逻辑审核" / "查一下前后矛盾" / "先审后改"**。若要两份报告一起出，说"同时执行合规审核与逻辑审核"。

- **Mode 1 全量逻辑审核**：通读 → 建四台账（时间线 / 人物状态 / 设定规则 / 画面链）→ 按 LG-01~LG-13 十三类逐场核对 → 出报告。
- **Mode 2 修复后复审**：修完剧本后说"逻辑复审"，只核对上轮问题关闭情况与修改处新增矛盾。

## 审什么（LG-01 ~ LG-13）

时间线矛盾 / 空间位移矛盾 / 知情状态断裂 / 动机与目标断裂 / 伏笔未回收与无铺垫突转 / 设定规则自冲突 / 身份关系矛盾 / 道具连续性 / 事件结果不延续 / 因果链断点 / 台词自相矛盾 / 世界反应缺失 / **画面连续性**（动作与身份匹配、画面元素搭配、遮挡与视线、多人动作可行性、形态与道具连续、元素去向）。

不审：节奏、爽点、人物弧光等"好不好看"问题——本技能只回答"前后是否自洽"。

## 产物位置

在剧本所在目录的 `pipeline\` 下：

```
10_台账-时间线.md   11_台账-人物状态.md   12_台账-设定规则.md   13_台账-画面链.md   20_逻辑审核报告.md
```

行号以 `pipeline\00_剧本全文.txt`（与合规审核共用）为准。

## 设计原则

- **只审不改**：输出问题 + 最小修复方向（台词级<镜头级<场次级），不自动改写剧本——避免旧流程"一次性大改、无从对照"的问题。
- **双证据定罪**：每条问题必须给出相互矛盾的两处原文对照；拿不准的一律 🟢 存疑交作者确认，不强行定罪。
- **先台账后挑错**：所有问题必须能对照事实台账指出，台账即证据库。
- **对话情境优先**：台词解释要发生在自然的对话时机（被问再答、事后补述）；观众依前情可推定的信息不解释、保留想象空间；不为逻辑通顺让角色说出不合情境的话。
- **画面优先**：画面连续性问题优先改画面本身（动作链、遮挡、道具去向，必要时增补闪回），不靠台词补救。
