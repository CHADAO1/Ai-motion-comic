# 规则模块 — 剧本逻辑（因果）审核规则

> 作用域：script-logic-audit 全部判定的单一事实源。编号前缀 `LG-`，全技能唯一，只增不复用（废止留档注明取代者）。SKILL.md 只写"动作 + 编号引用"，规则正文只在本文件。

## 0. 适用边界

本规则只判定**前后是否自洽**（因果逻辑），不判定好坏：节奏、爽点、人物弧光、台词文采、"好不好看"一律不属本技能范围。角色行为"莫名其妙"只在它构成 LG-10 因果链断裂时才报告。

## 1. 逻辑问题十三类（LG-01 ~ LG-13）

| 编号 | 类别 | 判定要点（满足即计数） |
|---|---|---|
| LG-01 | 时间线矛盾 | 日期/昼夜/季节/节日/年龄/"X天前·X年后"等时间标记前后冲突；事件先后顺序颠倒；同一时间轴上两事无法共存 |
| LG-02 | 空间位移矛盾 | 人物瞬移（上场在A地、下场无交代已在B地）；同一时刻出现在两地；场景内站位、出入方向、谁在场/不在场错乱 |
| LG-03 | 知情状态断裂 | 角色使用了无来源的信息（不该知道却知道）；忘记自己已知/亲历的事；秘密的知晓链条缺一环（谁泄露的未交代） |
| LG-04 | 动机与目标断裂 | 行为无动机支撑；动机无事件触发而突变；同一角色的目标前后不一致且无解释 |
| LG-05 | 伏笔未回收 / 无铺垫突转 | 前文刻意埋设的伏笔全文未回收；关键转折（救兵、证据、能力、反转依据）无任何铺垫凭空出现（天降神兵） |
| LG-06 | 设定规则自冲突 | 世界观/能力/禁忌规则前后不一致：变身条件、限制、代价、有效期在后文失效或被遗忘；规则"只在剧情需要时生效" |
| LG-07 | 身份关系矛盾 | 称呼、亲缘、雇佣、敌友关系前后冲突；职业、职级、来历等身份设定自相矛盾 |
| LG-08 | 道具连续性 | 道具凭空出现/消失；易主无交代；损坏后复原；已交出/已销毁的道具再次出现并被使用 |
| LG-09 | 事件结果不延续 | 受伤/中毒/被拘/财产损失/死亡等后果在后文无痕迹或被无视；伤势、损失程度前后不符 |
| LG-10 | 因果链断点 | 事件A到B之间缺必要环节（谁做的/如何做到/为何发生未交代），剧情跳跃；关键剧情靠无解释的巧合推动 |
| LG-11 | 台词自相矛盾 | 同一角色（或旁白/OS）对同一事实的两次表述冲突；承诺、威胁、赌约与后续行为无呼应且无解释 |
| LG-12 | 世界反应缺失 | 重大公开事件（死亡、爆炸、公开身份曝光、当众冲突）发生后，本应知情/在场的角色与环境毫无反应 |
| LG-13 | 画面连续性 | 凡"能被拍出来的画面"均检查：①人物动作与身份/着装/场景不匹配（正装新娘独自赶车）；②画面元素搭配错误（骑巨狼却写"马蹄"）；③遮挡与视线不成立（躲在柜内却被拉开柜门直视而无遮挡交代）；④多人动作不可执行（隔着铁栏"紧紧拥抱"）；⑤形态与身体部件矛盾（全剧未展示狼形态却"从肩头拔狼毛"）；⑥画面元素凭空出现/消失（下车的马车后文无去向） |

## 2. 严重度分级

| 级别 | 定义 | 处理 |
|---|---|---|
| 🔴 硬伤 | 观众无需回看即可察觉，直接破坏代入（复活、瞬移、规则自打脸、关键因果缺失） | 必修；无最小修复方案时才允许标"需场次级调整" |
| 🟡 明显瑕疵 | 回看对照能发现，产生"咦，不对吧"的出戏感（时间对不上、道具穿帮、小知情断裂） | 建议修，给最小修复方向 |
| 🟢 存疑 | 可能是刻意悬念、留白、视角限制或倒叙设计；或证据不足 | 只登记不定罪，交作者确认 |

## 3. 判定原则（防误伤）

1. **悬念豁免**：作者对观众刻意隐瞒、后文揭底的信息不算 LG-03；但揭底内容不得与已播内容冲突（冲突则计 LG-01/LG-11）。
2. **叙事结构豁免**：有明确标记的倒叙、插叙、梦境、回忆（"三年前…"）不算时间线矛盾；但其内容与正文已播事实冲突时照常计数。
3. **台账优先**：每条问题必须能对应到三台账中的矛盾条目；台账建立不出对应关系的，降 🟢 或丢弃。
4. **双证据定罪**：每条问题给出相互矛盾的两处原文（或"有果无因"的单处原文+缺失说明），附场次+行号；只有一处模糊印象不算证据。
5. **延迟判定**：拿不准一律 🟢 存疑并写明"若后文有解释请忽略"，禁止为凑数强行定罪。
6. **对话情境原则**：台词类修复必须符合对话情境——解释应发生在自然的对话时机（被问再答、事后补述、汇报式台词），观众依前情可推定的信息**不解释、保留想象空间**；前文已有联系/伏笔的"缺解释"默认豁免；若最小修复会让角色说出此情此境不会说的话，改为改画面/动作，或判不修。
7. **画面优先原则**：LG-13 类问题优先修画面本身（动作链、遮挡物、道具去向，必要时增补闪回/调整场次），台词只作辅助；画面问题不靠台词补救。

## 4. 四张事实台账（L1 阶段产物，唯一证据库）

| 台账 | 文件 | 内容（每行必须带场次+行号） |
|---|---|---|
| 时间线 | pipeline\10_台账-时间线.md | 按场次列出显式时间标记与隐式推定（昼夜/季节/"X天前"）；推定须注明推断依据 |
| 人物状态 | pipeline\11_台账-人物状态.md | 每个主要角色逐场：所在位置、知情清单（知道什么/何时得知）、持有物、伤势状态、关系变化 |
| 设定规则 | pipeline\12_台账-设定规则.md | 世界观规则、能力限制与代价、组织制度、禁忌条款；每条注明首次出现行号，后文出现冲突规则时并行列出 |
| 画面链 | pipeline\13_台账-画面链.md | 交通工具与驾乘方式、人/狼等形态变化、遮挡物与视线、身体部件与形态对应、多人动作与站位、场景标题与实际场地；每条带场次+行号 |

## 5. 报告格式（pipeline\20_逻辑审核报告.md）

```
# 《剧名》逻辑审核报告
总判定：自洽 / 存在 N 处逻辑问题（🔴x · 🟡x · 🟢x）
审核基准：rules/logic-rubric.md（LG-01~LG-13 + 判定原则）
台账依据：pipeline\10_/11_/12_/13_ 四表（行号以 pipeline\00_剧本全文.txt 为准）

## 一、问题清单（按严重度排序，🔴→🟡）
| 编号 | 类别 | 严重度 | 位置(场次+行号) | 矛盾证据A(原文) | 矛盾证据B(原文)/缺失说明 | 因果分析 | 最小修复方向 |
|---|---|---|---|---|---|---|---|
| 1 | LG-06 | 🔴 | 第X场 L123 / 第Y场 L456 | "……" | "……" | 规则在A处要求…在B处却… | 台词级：将B处台词改为…即可对齐 |

## 二、伏笔专项（LG-05）
| 伏笔 | 埋设位置 | 回收情况 | 建议 |
（无伏笔未回收时写"未发现未回收伏笔"）

## 三、三台账摘录
- 时间线主干：…（一行一条主干事件）
- 主要角色知情链断裂点：…
- 设定规则冲突对照：…

## 四、存疑清单（🟢，待作者确认）
| 编号 | 位置 | 描述 | 若属刻意设计请忽略 |

## 五、修复优先级清单
按最小改动量排序：每条标注预计改动范围（台词级 < 镜头级 < 场次级）；🔴无最小修复的单独注明。
修改后可触发 MODE 2 复审验证。
```

## 6. MODE 2 复审规则

复审输入为新版剧本全文 + 上一份《逻辑审核报告》。只核对三件事：①上一轮问题逐条标记 已关闭/未关闭/部分关闭；②修改处是否引入新矛盾（新问题按 LG 编号计）；③受修改波及的台账条目更新。输出《逻辑复审附记》追加到报告末尾，不重开全量扫描（作者未改动的场次仅在台账波及时回看）。
