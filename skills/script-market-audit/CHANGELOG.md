## [1.0] 2026-10-19 首次建立

**动机**
把短剧剧本市场解读的方法论固化下来，供红果/抖音赛道的剧本判断与开头痛点优化使用，
并可对外分享给同行。

**方法论来源**

- 59 集婆媳分家剧（发现 40 集版 + 19 集增量灌水、发电机降智、视角踩反面）
- 54/58 集双版本贫困生剧（发现 13 集同场景连拍、红包爆点埋在第 16 集、
  简介承诺「依法维权」但全剧 0 次起诉、两版开头一字未改）
- 44 集下车费剧（提取锚点习惯、道具视觉符号盘点）

## [1.0.1] 2026-10-19 脚本层三处修复（安装前实测发现）

**动机**
本包首次构建后，用三部真实投稿稿做端到端冒烟测试，暴露出三个会导致
**错误结论**的缺陷（非风格问题，是会误导判断的 bug），必须记录。

**变更点**

| 文件 | 缺陷 | 修复 |
|---|---|---|
| `scripts/extract_docx.py` | 字符类漏写 `^`，把「好字符」当噪声抹掉，`.doc` 提取结果为 **0 字符** | 改为反向字符类并加注释警示。实测 36083 字符 / 44 集，正确 |
| `scripts/extract_docx.py` | 用字节 marker 定位 WordDocument 流不可靠 | 换成自实现 OLE2 目录流解析（FAT + miniFAT + 目录项），与实战验证过的实现一致 |
| `scripts/analyze_script.py` | 集号错字（如「第五十六四集」）污染全部后续编号，58 集只认出 57 | 新增**单调性校正**：解析值 ≤ 上一集号时，改取「能解析出更大值的最长前缀」 |
| `scripts/analyze_script.py` | 钩子句按正文标点切，切到了人物小传 | 改为定位第一集 VO / 音画同步 / 旁白行，三级降级 |
| `scripts/analyze_script.py` | 剥说话人标签的正则贪婪，把「她却穿着我挑的婚纱」吃成「纱」 | 正则锚定到冒号，只剥「角色名VO：」 |
| `scripts/analyze_script.py` | 同场景用「集-场」编号判定（每集都从 1-1 重算） | 改为取场景编号后的**地点名**判定，并在 SC-03 声明别名局限 |
| `rules/structure.md` | 基尼阈值 0.6 与实测分布不符（实测 0.09–0.16） | 阈值改 0.45，并补充「基尼高≠注水」的联读要求 |

**兼容性**：无破坏性变更，仅脚本行为修正。

**实测回归**（三部真稿）
- 集数：44 / 58 / 59 —— 全部与人工通读一致
- 同场景连拍自动定位：17–29 集（13 集）、31–42 集（12 集）、11–15 集（5 集）
- 版本对比：58 集 = 54 集 + 4 集新增，49 集完全相同
- `node scripts/lint_skill.mjs` exit 0（31 个规则编号，零悬空/零路径腐烂/零孤儿）

## [1.0.2] 2026-10-19 首次实战后修复（无 VO 稿的钩子提取）

**动机**
用本技能实跑第4 部真稿《萌娃赶海》（85 集，七零年代萌娃漫剧），
暴露出钩子提取对「无 VO 稿」完全失效。

**变更点**

| 文件 | 缺陷 | 修复 |
|---|---|---|
| `scripts/analyze_script.py` | 降级路径直接按句号切第一集正文，把集号行「第1集」当成了第1 句钩子 | 切句前过滤集号行 / 出场人物行 / 场景头行；`△` 动作符号剥离但保留其内容 |
| `scripts/analyze_script.py` | 集号行被当成钩子后，「第1集」里的 `1` 又被数字锚点规则误判为「含数字锚点=是」 | 随上一项一并解决；实测本剧现正确输出「含数字锚点=**否**」 |
| `scripts/analyze_script.py` | 来源标注只写「第一集正文」，无法区分是否已降级 | 改为「第一集正文（无 VO）」/「全文开头（未定位到正文，请人工核对）」两级提示 |

**兼容性**：无破坏性变更。已回归验证有 VO 的稿（59 集稿）行为不变。

**新增经验（已同步 rules/structure.md SC-04 的脚本局限声明）**
> 农村/年代写实向萌娃稿常常**完全没有 VO / 音画同步行**，钩子只能由
> 第一集的△ 动作行承担。此时脚本的「可视化动作句」计数会偏低（△ 行在
> 降级路径中不带手部动作词），**该指标需由 AI 人工判读覆盖，不可直接采信**。
