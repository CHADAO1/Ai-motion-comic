# reference — 红果 / 抖音市场基线数据

> ⚠️ **本文件有时效性。** 数据采集于 **2026-10**。半衰期约 3–6 个月。
> 每次使用本技能做市场判断前，按 `rules/platform-market.md` PL-06 联网复核；
> 复核结果与本文件冲突时**以复核为准**，并在报告中注明「原记载已过期，实际为 X」。
>
> 本文件是**复核的起点，不是终点**。禁止把这里的数字当结论直接引用。

## 一、平台形态（2026-10 采集）

### 红果
- 形态：免费 + 广告解锁的剧场模式，观众不付费，平台靠广告变现
- 因此**完播率权重极高（约 35%）**，前 3 秒决定划走与否
- 卡点已从「前 N 集免费 + 第 N+1 集付费」改为**全剧免费 + 广告解锁**
- 日活量级：约 1.68 亿（2026 年公开报道口径）

### 抖音短剧
- 形态：信息流投放，付费解锁或免费广告两种
- 仍保留付费解锁，卡点位置直接影响转化
- 冷启动靠前 3 秒，对「爽」的容忍度低于红果，冗长铺垫会被掐断

### 互动漫剧
- 形态：单集解锁付费，观众为「继续看」付费
- 对制作成本敏感，容忍度最高；降智情节在此形态下反而可能有效

## 二、供给与饱和度（2026-10 采集）

- 红果 2026 年前 8 个月上线微短剧约 **43 万部**
- **婆媳矛盾是翻拍最多的固定模块之一，爆款率不足 0.1%**
- 含义：新剧本若落在「婆媳 + 分家 + 认错求复管」赛道，默认按高饱和处理，
  必须有明确差异化角度（见 PL-05）

## 三、同题材对标样例（2026-10 采集）

> 用途：说明「同题材验证」怎么做。以下为方法示范，**数字须重新复核**。

| 作品 | 表现 | 说明 |
|---|---|---|
| 《老公的工资，婆婆的账》（2026-08） | 5881 万热度、9.5 分 | 媳妇受害视角 → 觉醒 → 收回工资卡 + 起诉追讨。有法律动作、有钱 |
| 《资助三年，换来一纸举报》（2026-09） | 最高 TOP61、平均 77.1、TOP10 停留 0 天 | 与「资助贫困生被反咬」同赛道，已饱和 |
| 《误入贵族学校，我只想搞钱》 | 70 集、7276 万热度、榜三 | 同一素材改成「女本位 + 搞钱」后跑出 |

**从这三部能读出的方法论**（这才是本文件的价值）：
> 饱和的是**套路**，不是**题材**。「资助贫困生被反咬」原版做不进 TOP10，
> 换成「女本位搞钱」视角就能冲榜三——所以困境剧本的出路是**换视角**，
> 不是换题材。

## 四、监管环境（2026-10 采集）

- **2026 年 9 月 1 日《微短剧发展管理办法》已施行**，分类分层审核
- 纠偏重点：极端人设（「恶儿媳」当主角）、极端片名（「她却疯了」）、
  群体对立渲染
- 影响：诊断时不能只谈流量，要提示片名/简介/人设的过审风险（PL-04）

## 五、复核指令模板

做市场判断前，至少复核以下三项：

1. 红果/抖音当前付费模式是否仍为「全剧免费 + 广告解锁」
2. 同题材近 3 个月榜单表现（有无新爆款改变赛道判断）
3. 有无新颁行的监管规定

复核后在报告中写明：`数据采集日期：YYYY-MM-DD｜来源：___`。
