# 审查模块 C1 — Preflight 内容检查清单

## 使用原则

1. 完整性以**要素计数**为准（几要素/几拍/几件套），禁止最低字数标准——
   短而全即合格。
2. 每个 ✅ 必须附**可核查证据**：磁盘路径 / 脚本原始输出行 / json 字段名与数值 /
   具体集号。出现「已检查」「无问题」「符合要求」一律按**未检查**处理。
3. 多单元任务必附《逐单元验收表》（落盘 `pipeline/`）。
4. 本清单审的是**产物内容对不对**；步骤有没有真执行由 `audit.md` 审。
