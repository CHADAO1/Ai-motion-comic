# 工作流 — 完整剧本解读（M1 主流程）

> Stage S0→S5。S1/S4/S5 的规则见对应 rules 文件，不在本文件复述。

## 铁律（覆盖总控通用约定）

1. **不读原文不算读过。** 必须先跑 `scripts/extract_docx.py` 抽正文，
   禁止拿用户口述或摘要代替通读。
2. **数先于断。** 任何结构类结论必须引用 `01_结构体检.json` 的字段名
   与数值，禁止凭印象说「集数偏多」。
3. **数据带日期。** 引用市场数据必标采集日期（MK-02）。
4. **只解读不改写。** 除钩子外不擅自改剧本；用户要改写需另行确认。

## S0 环境与落盘

建立 `{工作目录}\pipeline\` 与 `{工作目录}\outputs\`。
`manifest.json` 初始为 `{"stages":{"s0":"done","s1":"pending",...},"updated":""}`。

**通过条件**：两个目录存在 + manifest 写入。

## S1 取稿与提取

1. 定位文件。若路径含网络共享或中文特殊字符，优先用通配符
   （`cp "$DIR/"*关键词*.docx`）而非完整文件名。
2. 跑提取：
   ```
   python scripts/extract_docx.py <原稿> {工作目录}\pipeline\script.txt
   ```
3. **检查 `[WARN] 抽取正文过短`** —— 若出现，说明解析失败，改用其他方式
   （粘贴正文 / 另存为 txt），**禁止带着空文本继续**。

**通过条件**：txt 存在且字符数 >2000，抽样确认含「第X集」与正文对白。

## S2 结构量化

```
python scripts/analyze_script.py pipeline\script.txt -o pipeline\
```

**若存在其他集数的版本**（用户提到/同目录/企微缓存），必须加 `--vs`：
```
python scripts/analyze_script.py pipeline\新版.txt --vs pipeline\旧版.txt -o pipeline\
```

必须向用户口头汇报的关键数字（不得跳过）：
- 集数 / 总字数 / 基尼系数
- 同场景连拍的最长集号区间与场景名
- 前 3 集字数占比
- 爆点首次出现集号
- （若有 --vs）相同/新增集数

**通过条件**：`01_结构体检.json` 与 `.md` 均生成且数字已口头复述。

## S3 通读与剧情梳理

**必须真读**，产出一张结构表：

| 集段 | 起止集 | 内容概要 | 冲突强度(高中低) | 备注 |
|---|---|---|---|---|

同时标记：
- 各段字数占比（哪些段在注水）
- 主线与支线（哪些段可删不伤主线）
- 全剧最优的 1–2 个片段（位置 + 为什么好）
- 逻辑自相矛盾处（同一反派动机前后翻转等）

**通过条件**：结构表覆盖全部集段（无"其余类似"），标注出最优片段与矛盾点。

## S4 市场与平台解读

按 PL-01 先确认投哪个平台（用户已说明则跳过）。按 PL-06 联网复核时效数据。

产出三块：
1. **同题材对标**（PL-05）：至少 1 部可比作品 + 市场成绩 + 采集日期
2. **视角判断**（MK-04）：走的是哪条爽感路线，与主流是否背离
3. **保留资产**（MK-05）：本剧可用的台词/爽点/情感线

**通过条件**：每条市场结论都有对标作品与数据日期（MK-01/MK-02）。

## S5 钩子优化 + 报告交付

1. 按 HK-01 定位钩子句（脚本已抽出，直接用 `01_结构体检.md` 三、段）
2. 按 HK-02 判定属于哪一型 / 是否为交代型
3. 按 HK-03~HK-05 改写，按 HK-07 输出四段式
4. 按 HK-10 自检

报告写 `{工作目录}\outputs\剧本解读报告.md`，结构固定：

```
1. 结论（第一句即判断，MK-03）
2. 剧情骨架表（集段 / 内容 / 问题）
3. 结构体检数字解读（引 json 字段）
4. 套路与硬伤诊断
5. 市场对标与视角判断（含数据日期）
6. 开头三句：原版 / 诊断 / 优化版 / 依据
7. 可保留资产
8. 行动清单（按优先级排序，每条含落点与"改成什么"）
```

**通过条件**：报告 8 段齐全 + Audit 终审全 ✅。

## 断点续跑

读 manifest.json → 跳过 status=done 的 stage → 从第一个 pending 继续。
S2/S3 之后修改剧本，必须 S2 起全部重跑（数字会变）。
