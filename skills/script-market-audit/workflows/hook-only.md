# 工作流 — 快速钩子优化（M2）

> 只做开头三句话的诊断与改写，不做全剧竞争力评估。
> 触发：用户只问开头怎么改 / 只给前三句 / 已在别处做过全剧评估。

## S0 取稿

同 `full-review.md` S0/S1。若用户直接粘贴了前三句文本，跳过脚本，
但**必须确认这三句是 VO/音画同步而非简介**（HK-01）。

## S1 结构体检（精简）

只跑一次脚本，**只用第三段（开头钩子）**：

```
python scripts/analyze_script.py pipeline\script.txt -o pipeline\
```

若用户只给了三句文本、无全文：跳过脚本，直接进入 S2，
并在报告开头注明「未获取全文，本次仅诊断钩子，未验证与正文的对应关系」。

## S2 诊断

按 HK-02 判定钩子类型（三型 / 交代型），逐条列出违反的 HK 规则：

- 违反 HK-04 → 无数字锚点（指出原句缺什么）
- 违反 HK-03 → 第三句是预告而非反击
- 违反 HK-01 → 若拿到的是简介而非 VO，直接退回重取

同时按 HK-06 核对：简介承诺 vs 钩子是否一致。

## S3 改写

按 HK-03~HK-05 生成优化版，按 HK-07 四段式输出，
按 HK-08 检查安全边界，按 HK-10 自检。

**素材来源纪律（HK-05，最易翻车）**：改写只能引用用户已提供的
前文/后文素材。信息不足时，**先问用户要素材**，或给出
「填空式模板」（用 ___ 标出需用户填入的本剧元素），**不得凭空编造本剧没有的情节**。

## 交付

格式：原版 / 诊断 / 优化版 / 依据 / 自检表。
若同时给了不止一个版本，每版都要单独诊断，不合并。
