# 审查模块 A — HTML 分镜看板交付门禁

> Phase 4 交付前最后一道门：审产出的 HTML 分镜看板质量。逐项过，任何一项不过即修正后再交付。

## 使用原则
1. 每条判定须能落到具体场景/镜头/提示词，不留空泛"应该可以"。
2. 管线（P1-P4）必须已在 header 与 footer 正确体现（画幅/时长/语言）。
3. 国内 P1-P3 已在生成前确认合规（script-content-audit DY-*），不把红线问题带进看板。

## 结构完整性
- [ ] HTML 单文件自包含（CSS/JS 内嵌，无外部依赖），可用浏览器直接打开
- [ ] header 含标题 + 统计（场数/镜头数/镜头类型数）+ Prepared for + 管线标注
- [ ] toolbar 搜索/镜头类型筛选/打印PDF/重置 逻辑可用
- [ ] 逐场 section 齐全：场头(# / INT_EXT / 地点 / 情绪基调 / 镜头数) + 分镜表(# | Plan | Camera | Action | 场景文本 | 提示词)
- [ ] 每段提示词有 Copy 按钮 + 括号快捷标签（如 `[MS-CU · 门开+靴入门]`）
- [ ] 交付路径正确：`{剧本目录}\outputs\分镜看板_{范围}.html`

## 提示词质量（抽查覆盖所有交付场）
- [ ] 每段顶部声明 `@imageN` 句柄（有图时）或功能标签（无图时）；句柄含完整外观描述（体态/发型/特征/从头到脚服装/随身道具）
- [ ] 每段含通用警告：空间布局 / 对白规则(一句一镜) / 本视频严格只有N个镜头
- [ ] 多镜段每镜块 `【镜头N】` 含：机位(焦段+光圈+景别)/摄影机运动(情绪同步)/背景/动作(编号步骤)/微表演细节
- [ ] 风格块用 STYLE_BLOCK 默认 + 场景光照变体；明确 only-practicals 禁补光
- [ ] 环境活动段无空旷背景（或明确"寂静"替代说明）
- [ ] footer 正确：`X秒。Y画幅。`（画幅/时长符合管线）
- [ ] 无泛化情绪词（"生气/难过/紧张"都已拆成肌肉/呼吸/眼神微动作）
- [ ] 对白台词一句=一镜；P4 台词英文原句引用
- [ ] 用 ⚠️ 标注失败模式（距离/禁止项/视线锁定/切镜数/身份漂移/焦点漂移等）

## 空间布局
- [ ] 凡 2+ 角色同框或关键道具落点的场景，提示词内 `⚠️空间布局` 与已确认俯视图一致（距离/朝向/遮挡/视线全落）
