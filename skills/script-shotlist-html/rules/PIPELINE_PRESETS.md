## PP-02 管线判定（强制执行，不得跳过）

开工按顺序确定：
1. **用户明示** → 直接采用。
2. **用户说了题材/平台** → 题材映射（同主控）：家庭/婆媳/养老→P1；恋爱/甜宠/霸总→P2；悬疑/恐怖/灵异→P3；出海/海外/YouTube/英文→P4。
3. **完全没说** → **必须提问确认**，禁止擅自假设：
   > "这次走哪条管线？① 国内下沉中老年（9:16/10-15s）② 国内女频恋爱（16:9）③ 国内女频诡异恐怖（16:9）④ 海外出海（21:9/≤30s）"

> ⚠️ 银时主力管线是 **P1（国内下沉中老年）**。仅在明确提及其他题材时切换。

## PP-03 各管线对分镜看板的影响

### P1 国内·下沉中老年
- 9:16 竖屏，1080×1920 起；单段 10–15 秒。
- 镜头偏好：中近景为主，特写给情绪；少大远景。
- 表演放大一档（下沉市场吃明牌情绪，微表情要足够可读）。
- 开场 3 秒出冲突/悬念；结尾悬念型/爽剧钩子。

### P2 国内·女频恋爱
- 16:9 横屏；10–15 秒。
- 镜头偏好：双人同框过肩、正反打、大量浅景深柔焦特写。
- 表演克制、眼神戏；"苏感"靠光影与微表情。
- 色调清透奶油感 / 都市夜景霓虹，低对比。

### P3 国内·女频诡异恐怖
- 16:9 横屏；10–15 秒。
- 要"吓一跳 + 细思极恐"，不是血腥。
- 镜头偏好：手持晃动 / 监控视角 / 长镜留白 / 暗处负空间。
- 惊恐分两级：瞬间惊吓(快) / 后知后觉毛骨悚然(慢)。
- 色调低照度冷青暗绿，光源单一。
- 恐怖题材须过 script-content-audit 国内红线（血腥/惊悚克制）。

### P4 海外（出海）
- 21:9；≤30 秒一段。
- 台词英文（提示词内引用用英文原句）；剧本英文则 UI 英文。
- 文化坐标按剧本地域（欧美题材当"本地电影"，见 asset 技能 cultural-context.md 的 CUL-*/ETH-*）。
