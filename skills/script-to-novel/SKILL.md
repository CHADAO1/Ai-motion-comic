# 剧本小说化（script-to-novel）

## 0. 目标与版本

- 本技能默认交付**「剧情理解版」**：读者目标是*读懂剧情*，一切服务于此——信息完整、语句直白、零剧本痕迹。
- 其他目标版本（台词润色版 / 表演优化版 / 故事扩写版等）**不在本技能规则内**：用户提出时，先与其确认该版本的验收标准，经确认后再扩充本技能（新增对应章节），不要套用剧情理解版的规则硬做。

## 1. 流程总览

```
S1 提取正文 → S2 通读建档 → S3 标注方案确认 → S4 分章改写 → S5 校验交付
```

| 步骤 | 做什么 | 通过条件 |
|---|---|---|
| S1 | 从 docx/txt 提取全文文本（见 §2） | 行数字数统计输出，文件完整可读 |
| S2 | 通读全文，建立人物表（姓名/身份/阵营/出场集数）、情节幕结构 | 能一句话复述主线与结局 |
| S3 | 向用户确认标注方案：①哪些角色加标注 ②标注频率（见 §4 默认建议） | 用户明确答复后才进入 S4 |
| S4 | 按 §5 规则 R01–R08 分章改写，长文用 §6 追加法落盘 | 全部章节完成，marker 清零 |
| S5 | 按 §7 校验清单自查并交付 | 残留符号计数全为 0 |

## 2. 正文提取（docx）

docx 是 zip 包，读 `word/document.xml` 并剥标签（PowerShell）：

```powershell
Add-Type -AssemblyName System.IO.Compression.FileSystem
$zip = [System.IO.Compression.ZipFile]::OpenRead($src)
$entry = $zip.GetEntry('word/document.xml')
$sr = New-Object System.IO.StreamReader($entry.Open(), [Text.Encoding]::UTF8)
$t = $sr.ReadToEnd(); $sr.Close(); $zip.Dispose()
$t = $t -replace '<w:tab\b[^>]*/>', "`t" -replace '<w:br\b[^>]*/>', "`n" -replace '</w:p>', "`n"
$t = ($t -replace '<[^>]+>', '' -replace '&amp;','&' -replace '&lt;','<' -replace '&gt;','>' -replace '&quot;','"' -replace '&apos;',"'")
$clean = ($t -split "`n" | ForEach-Object { $_.TrimEnd() } | Where-Object { $_.Trim() }) # 再写入 txt
```

.txt / .md 剧本直接读取。提取的中间文件在交付前删除。

## 3. 必须清除的制作痕迹（识别清单）

场景标号行（如 `1-1 夜 外 密林`）、`人物：`列表、`△`动作提示、【字幕：…】人物条与倒计时条、`角色（OS）：`内心独白、`VO`画外音、【闪回】【幻象】标记词、镜头指令（特写/切镜头/广角/定格/镜头拉远）、括号情绪式台词格式 `角色（生气）：……`。

## 4. 人物标注（R09）

- **标签样式**：主角团用序号制——`（男1）（女1）（男2）（女2）（反1）`，如 `莱拉（女1）`、`奥尔登长老（反1）`。
- **范围**：核心主角团必标；戏份多的关键配角建议一并标注；家人类角色（弟弟/母亲等）称谓本身即身份，不加括号，改为在行文中自然绑定（首现写作"莱拉（女1）的弟弟"，其后径用"弟弟"）。
- **频率**：与用户二选一——a) 该名字的**每一次出现**都标，含引号内台词与简介（默认推荐给"查剧情"用途）；b) 每章首次出现标。**用户明确选择后严格执行，同一篇内不得混用。**
- 代词（她/他）不标；对白引导语中的角色名同样要标；无名群像（守卫甲、宾客）不标。
- 泛称防歧义：剧本里简称"长老"之类多义称呼，改写时统一为全名＋标签（如"奥尔登长老（反1）"），与其他同名群体（各部族长老）区分。

## 5. 改写规则

- **R01 标注全删**：§3 清单中的制作痕迹一律不进入成稿；【字幕】承载的信息不丢——人物条转为叙事自然介绍，倒计时条转为时间线叙述（"距离满月献祭仪式还剩二十五天"）。
- **R02 场景头转叙事**：时间/地点/内外景融进段落首句，不单独成行。
- **R03 台词融入叙述**：括号情绪改为动作、神态、语气描写后再接引语；删掉括号后读者必须仍能从上下文感知该情绪。
- **R04 独白转心理**：OS/VO 内容改为第三人称心理描写（"她心想——"或直接心理句），保留原意，删标记。
- **R05 冗余修饰删除（本版核心）**：凡不影响"读懂剧情"的比喻、排比、环境渲染、外貌细描一律删。判定法：删掉后情节链是否断裂？不断即删。示例：
  - 原：`莱拉端坐在车厢里，一身洁白的婚裙铺展开来，像一捧未化的雪。`
  - 改：`莱拉穿着婚裙坐在马车里。`
- **R06 保留底线**：时空锚点（夜/城堡/岩洞）、因果与动机、身份揭示句、关键情绪转折（点到一句为止）、关键道具伏笔（羊皮卷、手记、符牌等）必须保留。
- **R07 忠实性**：不新增情节、不删除情节点、不改人物关系与结局；仅允许合并重复表达、调整语序使行文连贯。闪回/幻象改为自然的回忆或幻觉叙述，内容保留。
- **R08 章节化**：按情节幕分章（短剧一集约一章或两集合一章），章节标题自拟；成稿头部保留书名与一句话简介。

## 6. 长文落盘（追加法）

成稿通常上万字，禁止一次性 write 全文：

1. 首次 `write` 写入 书名+简介+第1章（或前1-2章），文末留唯一标记行 `<!--待续-->`；
2. 之后每次 `edit` 以该标记为 old_string，替换为"后续章节 + 新标记"；
3. 最后一次 `edit` 将标记替换为 `（全书完）`，确保 marker 清零。

## 7. 校验清单（S5，逐项留证据）

一键工具：`scripts\fix_tags.ps1 <文件>` 补全角色名标注并把半角引号规范为全角“”；`scripts\check_novel.ps1 <文件>` 自动跑下列全部计数项。

```powershell
$t = [IO.File]::ReadAllText($f)
foreach ($b in '△','【字幕','【闪回','OS','VO','人物：','镜头','特写') {
  "{0} : {1}" -f $b, ([regex]::Matches($t, [regex]::Escape($b))).Count }   # 全部须为 0
```

- [ ] 上列制作痕迹计数全为 0（OS/VO 注意排除英文单词误命中，如无英文内容可直接查）
- [ ] 场景标号正则 `\d+-\d+\s*[日夜]` 命中 0 处
- [ ] 括号情绪台词残留：检索 `）：` + 引号的命中需逐条人工确认均为"叙述＋冒号引语"句式
- [ ] 标注一致性：五个核心角色名逐一正则核对"名字后未紧跟标签"的次数为 0（频率模式按 §4 所选执行）
- [ ] `<!--待续-->` 残留 0 处；引号全部为全角“”；文件 UTF-8 无 BOM
- [ ] 向用户交代：输出文件路径、章节数、字数、标注方案
