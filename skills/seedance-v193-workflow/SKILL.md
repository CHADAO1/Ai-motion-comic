# Seedance V1.9.3 工业化视频提示词流水线

## 0. 两个必读源（每次开工先取）

1. 工作流规范：`\\192.168.0.240\动态漫\AI互动漫剧\2026\09\000.文件夹模板\000剧本\视频提示词工业化生成工作流 V1.9.3.docx`
   用 python zipfile 直解 `word/document.xml` 抽取段落文本（只读，不装依赖）。
2. 公司标准库（固定前后缀）：同目录 `提示词参考.txt`。
   **标准库原文有 OCR 错字**（自然見动/构围/动作丰窗），输出时修正为"自然晃动/构图/动作丰富"，其余逐字复用。

固定前后缀（逐字复用，禁止改写）：
- 【视频前缀 VP】生成纯画面视频（不加任何文本/字幕），没有背景音乐，真人电影剧，人物和背景的光影色调统一，电影级运镜，电影质感，电影光照，电影氛围。
- 【视频后缀 VS】视觉效果震撼，质感细腻，动态模糊自然，人物身体自然晃动带有呼吸感，可以自由发挥不同景别不同构图进行添加画面，动作生动表演自然合理，动作丰富，分镜衔接流畅，情节连贯，好莱坞大片，画面禁止出现跳帧，禁止出现额外人，禁止出现文字字幕，电影级运镜。
- 【人物后缀 CP】超写实画风，写实摄影，电影级柔光滤镜，细腻皮肤纹理，电影级打光，8K，专业单反拍摄，浅景深，真实质感，无AI畸变
- 【场景后缀 SP】真实纹理，影视剧剧照，写实照片，自然光线，细节丰富
- 【通用负面 FN】避免文字与字幕，避免水印与标志，避免多余角色，避免过度磨皮与脸部变形，避免手部畸形，避免画面跳帧。

## 1. 执行顺序（跳步即违反红线）

1. **资产提示词先行**（红线 2）：角色 CHAR-xx / 场景 LOC-xx / 道具 PROP-xx / 特效 FX-xx，配"编号 ↔ 场次"双向对照表（正向 + 反向）。角色 = 内容 + CP；场景/道具 = 内容 + SP。
2. **台词逐句提取**：编号 L01…Ln，保留原标点，统计汉字数与语速时长（3.0/3.2/4.4/4.6/4.8/5.0/5.5 字/秒）。
3. **台词标点拆解**：每个标点转成表演指令（～尾音拉软、——拖长或截断、……卡喉、？尾音上扬、。落地、，换气、！重音加压）。
4. **空间状态追踪 + 防越轴**：方位词必须逐字来自原文，禁止脑补"左右前后"；防越轴表每格写具体描述，禁止打勾。移动必须写"从 A 到 B"。
5. **抽象→具象转译表**：把"格格不入/脸色铁青/流言四起"这类心理词改成可拍可听的动作。
6. **文戏机制表**：每组 1 个核心机制 + ≤3 个微表情锚点 + 1 个声音节奏重点 + 1 个镜头语言目的（1+3+1+1）。
7. **分组提示词**：每组 ≤15 秒、时间码组内归零、自包含。
8. **台词核对表 + 25 项自检表**收口。

## 2. 硬规则

- **全中文**：不写英文技术词（ARRI/dolly in/HDR/logo 等一律中文化，如"85毫米电影镜头""缓慢推近"）。
- **台词一字不改**：原标点保留；单句超 45-55 字时**只按标点断点拆成两组**，不删字、不压缩语速。
- **否定式禁令**：提示词正文只写画面正面可见的内容（例：黑气写"丝絮状烟体绕腕"，不写"不要化作绳索"）；所有禁令移入该组的 Layer 3 负面词。
- **负面词三层**：基础质量 2-3 条 + 类型失败 2-3 条 + 本组真实风险 1-2 条，共 5-8 条，禁止机械堆满。
- **镜头 9+1 字段**顺序固定：视角景别 / 机位 / 焦段光圈 / 运镜 / 主体动作（含台词+标点节奏+声音表演+微表情）/ 环境细节 / 构图取景（必须写取景边界）/ 焦点景深 / 画质标识 /（10 光线，仅偏离全局时写）。
- **关键约束七线**必须每层都出现：空间线·光线线·运镜线·画面线·风格线·表演线·台词线；每条以"必须/禁止/保持/避免"开头。
- **每组末尾给一段"可直接上传提示词"** = VP + 内容 + VS + FN，方便直接投喂。
- **留白**：问句、省略号、真相揭示、告别句后留 0.5-2 秒反应，不要立刻切走。
- 禁止（旁白）（心想）（回忆）标注；画外音转成"画面外传来…的声音"这类可拍写法。
- **表演优先、参数瘦身**（见第 6 节）：上传提示词的长度预算优先给"人怎么动"，镜头参数从上传提示词里撤出。
- **视线必须有去向**：禁止在任何位置写"视线不相交 / 视线避开 / 眼神不看 X / 没有一次回头"。见第 6 节。

## 3. 输出

- 路径：`{工作区}/outputs/{剧本名}_场{场号}_视频提示词_V1.9.3.txt`；剧名未知时用"场x-x至x-x"占位并告知用户。
- 对话里**不要铺开全部提示词**，只报：文件路径 / 总组数 / 总时长 / 台词总数 / 文戏增强项 / 降噪控制。

## 4. 踩过的坑

- 长台词 50 字 ≈ 13.4 秒，加前置动作会顶爆 15 秒 → 必须按标点拆两组。
- 原文方位词稀缺时，防越轴只能锁"机位固定在连线同一侧 + 禁止换位"，不要为了填表编方位。
- 同消息里多次 Edit 同一文件只有最后一次落盘 → 追加长文件要逐个 Edit 并 grep 校验（如 `grep -c "视频时长"` 应等于组数）。
- 批量重写长文件时，改完必须 grep 复验关键词归零/到位，别只看脚本打印。
- **上传提示词默认启用 re.S 的 `VP.*?FN` 匹配会多抓一个**：若文件开头定义了【视频前缀 VP】原文，第一个命中项是定义本身 → 实际组块是 `blocks[1:]`，断言写成 11 而不是 10。
- **9+1 字段 ≠ 上传提示词**：字段表是给人核对和二改用的，塞进模型输入会把注意力从表演挪到参数上，结果就是"参数全对、人不动"。
- **组时长与镜头时间码必须反查语速表**：凭感觉写时间码会出硬伤（曾给 1 秒的镜头塞 3.4 秒台词、给 5 秒的镜头塞 8.8 秒台词）。
  校验法：`台词字数 ÷ 语速 = 台词秒数`，再加上前置动作、反应与留白，才是该镜头应有的跨度；单镜超 9 秒就该拆镜。
- 全中文口径也包括**缩写**：POV / OST / VO 这类一律写成"第一人称视角 / 原声 / 画外音"。
- 用正则抓"上传提示词段"时，若文件头有前后缀定义且定义后带换行，过滤条件要写成 `startswith('\n生成纯画面')` 之类，**否则会把定义块算进组数**。

## 5. 附：3D 转真人（高频衍生需求）

用户常拿三维/UE5 渲染的参考图要求转成真人写实。三条铁律：

1. **首行 @参考图**，图生图不加视频前缀。
2. **正文只写正面可见的质感**：皮肤写"毛孔、细绒毛、不均匀血色、下眼睑透青、眼白象牙色、虹膜放射纹、一小点眼神光"；头发写"一缕缕分开、额角耳后碎发、发根比发梢深"；布料写"经纬织纹、不规则褶皱、起毛袖口、薄灰汗渍"；光照写"只有一个方向的主光 + 贴地接触阴影 + 暗部由环境冷色托起"。
   **禁止写"不要塑料感/不要 CG 感"**——模型会忽略否定词反向生成，禁令全部移入专属负面词。
3. **必须写明"保持参考图的姿势、服装款式、发型轮廓与构图完全不变"**，否则模型会重设计一套服装，与已定稿资产对不上。

专属负面词（逐字复用）：避免三维渲染质感与塑料感皮肤，避免均匀高光与过曝轮廓光，避免完美对称的五官，避免卡通渲染、描边与体积光，避免磨皮过度的橡皮脸，避免发片整块无碎发，避免布料褶皱过于规则，避免全局均匀照明，避免文字与字幕，避免水印与标志，避免多余角色，避免脸部变形与手部畸形，避免画面跳帧。

流程建议：角色与场景**分开转**，先转角色立绘锁脸，再拿真人脸跑分镜；参考强度 60-80（保人物往上、重质感往下）。出图偏网红脸就在负面补"避免美颜磨皮"，仍带塑料感就在正文补"油光分布不均""暗部被环境光轻轻托起"。

输出文件名：`3D转真人提示词_全套.md`，内含通用万能模板 + 按 CHAR/LOC/PROP/FX 编号分列的条目（编号与 V1.9.3 资产表共用，转完直接回填）。

## 6. 附：表演优先（用户最容易打回的一条）

用户反馈过："一堆参数加进去，结果一点表演都没有，像木头人"。根因是上传提示词里参数占篇幅太多，模型把预算花在构成上、人就不动。处理方式：

### 6.1 上传提示词的三段式（总长控制在 350-700 字）
1. **一句机位**：`摄影机在街面一侧与人流平行缓慢跟移，平视。` / `布棚下固定机位平视。` / `画面原地缓缓收紧到他的脸，透视不变，全程单镜不切。`
2. **主体与配角的动作链**（占篇幅 70% 以上）：每人至少一组连续动作，写到"物理层"。
3. **一行收口**：`全景深，画面自近到远全部清晰，人物与景物按平面横向层层相叠，像从一卷长卷上横向截下的一段。` + 有无台词 + VS + FN。

焦段/光圈/构图/取景边界/画质标识**留在 9+1 表里**，不再进上传提示词。需要去纵深时，把"推/拉"改写成"画面原地收紧/拉松（光学变焦）"。

### 6.2 常用生活动作库（直接抄，按需改写）
- **走路**：肩胯随步伐一左一右交替起伏 → 手臂跟着上下 → 裙摆/衣摆在腿侧摆动 → 脚跟先落再压实脚掌 → 呼吸把肩膀带着起伏 → 一路不时眨眼。
- **喝茶**：右手端碗送到唇边 → 碗口冒热气 → 低头吹开浮叶 → 嘴唇碰碗沿啜一口 → 喉结上下一动咽下去 → 碗底放回桌面磕一声轻响 → 手指在桌面敲两下 → 肩膀随呼吸一起一伏。
- **坐着的群演**：一个用袖口擦额头的汗、手腕来回蹭；另一个跷腿嗑瓜子、捏开瓜子壳往桌下丢；身体都略向外侧撇着，各看各的街面。
- **围观人群**：踮脚往里伸脖子 / 用袖子给自己扇风 / 凑到同伴耳边说话腮帮子一动一动 / 把孩子往上托一托 / 拽同伴袖子 / 被人一拽赶紧闭上嘴 / 手指一圈一圈绞着衣角。
- **紧张**：手指一下一下抠碗沿 / 鞋底把地上的东西碾一下 / 嘴唇开合三次、喉结上下滚动 / 手抬到一半又垂下去。
- **沉默的人也要动**：写着只是站着的人，必须补"一次吸气和一次眨眼""鼻翼随呼吸轻轻开合""重心从左脚换到右脚"。

### 6.3 视线纪律
禁止写成"视线不相交 / 视线避开 X / 眼神不看 X / 没有一次回头 / 也不往 X 看"——这些是否定式，模型执行不了，只会给出一张放空的脸。
改成看得见的行为：`目光在摊主、路人与街边货品之间来回移动` / `看见相熟的摊贩抬了抬下巴打了个招呼` / `用余光瞟他一下赶紧把脸转回来` / `看清了又赶紧把脸转回来` / `她的眼睛一路看着前面的街面，脚步没停` / `止住话头把目光收回到对方脸上`。
交付前跑：`grep -E "视线不与|视线避开|不看|没.{0,4}看|视而不见"` 应全部为 0（负面词层的"避免…看向镜头"不算）。

### 6.4 抽象概念怎么转成可拍的视觉（剧本最爱写这类词）
剧本里的"风向倒转 / 权力压迫 / 社会性死亡 / 流言四起"都不可拍，必须落成具体的特效与镜头：

| 剧本抽象词 | 落地写法 | 硬要求 |
|---|---|---|
| 风向倒转、众口一词 | **变脸群像**：围观者的脸在说话中换掉——五官像被水面上的一层波纹抹过又被重新描出来，颧骨、眉毛、短须的轮廓逐一浮现，同色的圆领在肩上一一长出来，替换时带一层薄薄的烟气 | 替换后**仍在说话、嘴部继续开合**；同一部剧里多处用法必须是同一套写法，禁止一处写实一处卡通；禁止做成面具或贴纸 |
| 权力压迫、权威不可质疑 | **巨大阴影**：低机位仰拍，被放大的剪影从画面上方压下来，边缘被天光勾一圈亮边，街面与围观者的脚落进影子里，天光被遮掉一块、画面暗半档 | 阴影方向全片一致（都从上方压）；禁止发光、变色、变成卡通怪物 |
| 社会性死亡、被群体吞没 | **垂直俯拍漩涡**：人物在画面正中，四周密密麻麻的脚与一张一合的嘴按环形**平面**排布（配合无纵深口径），声音层层叠加 | 俯拍不产生水平越轴，可放心使用；人物在俯拍下仍要有呼吸起伏与手指动作 |
| 流言四起 | **半透明烟体**：丝絮状边缘翻卷，能在空中拉成细长带状，绕住人的手腕或飘向人 | 只写烟的形态，禁止写"化作绳索/锁链" |

涉及儿童被捂嘴 / 推搡这类动作：正文只写"手掌覆下来盖住嘴""眼泪淌下""肩膀抽动"，手上不出现掐、捏、勒的形态，Layer 3 补"避免出现伤痕与血迹"，并在交付信息里给一版更安全的替代写法让用户拍板。

### 6.5 第一人称视角（剧本写"某某的第一人称视角"时）
- 摄影机就是人物的眼睛，视平线高度按人物姿态来（坐姿约 1.2 米）。**人物的脸全程不入画**。
- 别人的手固定从**画面上方**伸入，本人的手固定从**画面下缘**伸入，两者入画方向全片不变。
- 身体动作靠画面演，不靠运镜指令：弯腰＝画面往下一沉 + 桌沿从画面下缘升到中部 + 一次左右轻微摇晃 + 回升；转头＝画面横向平移半拍。
- 台词是画内声源，写成"画面下方传来一声……"，配"画面随之轻微上下起伏一次"。
- POV 段落不用"像从长卷上横向截下的一段"这句收口，改用"全景深，画面自近到远全部清晰，桌面与屋内墙面按平面横向排布"。

### 6.6 角色跨场次换版（几年后 / 落魄后）
剧本出现"几年后""瘦了一圈""像老了十岁"时，必须新建一个变体编号（如 CHAR-02-C），并在文件开头写死"本场起统一使用 XX，原版停用"，否则模型会沿用旧形象。
变体的外貌必须转成**六项可见清单**同时写进每条提示词（例：领口磨毛 + 袖口补丁 + 木簪乱绾 + 碎发垂耳边 + 眼下青黑 + 下巴胡茬），只写"落魄了"没用。
体态优先于妆造：肩膀前扣、脊背弯弧、颈前伸、胸口贴桌沿、起身比抬头慢半拍——这些比"瘦"更能演出老了十岁。

### 6.7 组表里的两处同步
- 每组【关键约束】的**表演线**末尾统一加：`；必须让画面里每一个人始终带着呼吸起伏、眨眼、重心左右转移或手指的小动作，不说话时也不停`。
- 每组 **Layer 3 负面词**末尾统一加：`，避免人物动作定格或肢体僵硬`。

### 6.8 分镜不呆板（用户打回原话："分镜切换太呆板"）

**通病**：一写就是"固定机位平视"，组与组之间一律硬切。整场看下来像 PPT 翻页。
**自检**：数一遍每组镜头的"4 运镜"字段——若超过一半写着"固定"，打回重做。

**六种机位手法，轮换用，同一场不许重复两次以上**：

| 手法 | 写法 | 适合 |
|:---|:---|:---|
| 以物引镜 | 从一个物件特写起幅，随一个自然动作（风掀纸页、水流、人流）横摇或拉出成全景 | 场次开场、氛围铺垫 |
| 跟移＋上抬 | 贴地拍脚步 → 跟着走两步 → 缓缓上抬到背身/脸 | 人物入场 |
| 越肩 | 从 A 肩后往前看，远处 B 被前景框住（框中框） | 两人关系建立、视线引导 |
| 先物后人 | 桌面/地面/手部特写起幅，向后拉松把人带进画面 | 对话开场 |
| 横移调焦 | 沿一条线（桌面、墙面）匀速横移，让说话人依次走到画面中心 | 多人对话、A→B 转换 |
| 呼吸式推近 | 整段只推进半个身位，察觉不到但在"靠近" | 进入回忆、情绪收紧 |

**组与组之间的三种转场介质（比一律硬切高级得多）**：
1. **物件介质**——上一组的物件划过画面遮住半拍，落下时已是下一组的时空（同一张纸完成跳转）。
2. **声音介质**——下一组的声音先到、画面后到（脚步声先入，人已站定）。
3. **动作介质**——一个动作被两组共用，中间偷换机位（她合上书 → 切到抱着书的另一个机位）。

### 6.9 闪切蒙太奇（把重台词"劈开"用）

剧本里有一句分量极重、又要说得轻的话（题眼级台词）时，别让它平平地说完——**把画面劈在句子中间**。

- 音轨上这句话**仍是一整句、标点一字不动**，只在破折号/停顿处**插入闪切段**，观众亲眼看那句话当年是怎么发生的。
- **闪帧只给局部，从不给全景**：一根栅栏 / 几个逆光背影 / 一张张开的嘴 / 一只手 / 一道门缝 / 一片白。六个局部拼出一件事——记忆本来就只剩碎片。
- **两颗相同的话要一虚一实**：闪切里那声处理成模糊的、有距离的、像被时间压扁的；现实里那句清楚、平稳、落在安静里。虚的给劲，实的给信，观众不会觉得重复。
- **声画硬切**：闪帧之间一律硬切，不留过渡、不叠化、不淡入淡出；闪帧内部画面完全静止（太快，动不了）。
- **出口用纯白过曝**，且这片白**要延续成现实里某件衣料上的日光**——用"白"做转场介质，比淡入淡出高级。
- **回来要用同一机位**：从哪儿断开，就从哪儿接上，观众有"回到原处"的实感。
- ⚠ **危险场景（监狱/暴力/灾难）写闪切，绝不能把禁令写进画面描述**——"不出现囚服、镣铐、刑具、血迹"这种写法会被模型反向执行。正确做法是**只罗列画面里要出现的东西**（湿冷石墙、竖直粗铁栅栏、向外撞开的牢门、门外灌进来的光），把禁令全部交给 Layer 3 负面词。人物一律"呈现止于逆光剪影、飞扬衣角与口部开合"。

### 6.10 破墙镜（剧中人直视镜头对观众说话）

全剧一般只给一次。两种语气，按剧本基调选：

| | 郑重版 | 调皮版 |
|:---|:---|:---|
| 动作 | 转过头正对镜头、目光凝视 | **从书页/杯子/扇子上缘抬眼偷瞟**，再压下去露脸 |
| 环境 | 世界为她静止（风声停、纸不动） | **风没停**，身后的东西照常在动——调皮的破墙不需要世界配合 |
| 语气 | 平静、真诚、一字一顿 | 轻快，语速略快，"跟熟人打招呼" |
| 收尾 | 说完静止两秒再黑 | **说完挑眉、把手里东西朝镜头轻轻一送，转身走开**；镜头留在空景两拍再黑 |
| 共性红线 | 不加光效、不加柔焦、不配乐、不推镜（只允一次极缓的一掌推近）、不切镜、全剧只此一次 | 同左 |

调皮的收尾尤其好用：**最后一个画面里没有她，只有满院翻动的纸**——比看着她静止更让人舍不得。

### 6.11 对话戏切镜：12 字规则（用户打回原话："说话超过12个字就要切镜头"）

**铁律：单条台词的任何一个连续片段超过 12 个汉字，就必须切镜头。** 标点不计入字数。

**⚠ 最容易踩的坑——"整句拆两半"不够**：
- 20 字的台词拆两半 = 10＋10，看似合规；但 20 字以上的句子拆两半后**其中一半往往仍超标**。
  - 实测：L40（20 字）拆成 7＋**13** → 第二段超标；L45（23 字）拆成 7＋**16** → 第二段超标。
- **正确算法**：先按标点把句子切成最小分段，再**贪心装箱**——每箱装到 ≤12 字就换下一镜。
  - L40「林姑娘收留了我。我现在在书坊帮忙，也学着认字。」→ 三镜：7／8／5
  - L45「我想问他们是谁，可他们没告诉我名字，只留下了一句话。」→ 三镜：7／9／7
  - L41（19 字）→ 两镜：10／9；L43（15 字）→ 两镜：7／8

**切点规则**：一律落在句号／逗号／省略号／破折号处，**禁止在词中间切**（如"书坊帮｜忙"）。

**切法**：两镜**景别必须不同**，否则观众感知不到切了。可用：中景→近景反打、近景→中景拉开、近景→过肩中景、中景→侧前近景。
台词**不断句、不重复、不加语气词**——切的是画面，不是话。音频上是一整句连续的话，画面在切点处换。
负面词补两条：`避免切镜处台词断掉或重复`、`避免两个镜头景别相同`。

**单镜时长纪律**：对话镜 2～4 秒，**最长不超过 4 秒**（闪帧除外）。一镜只承担一条台词的一个切段，禁止一镜塞多条长台词。压时长靠"碎切"，不靠"拖镜"——碎切反而更短，因为每镜只承担一件事。

**⚠ 验收脚本必须按"切段"匹配，不能按整句匹配**：
- 切成两段以上的台词，**整句字符串在任何单个上传段里都找不到**（脚本会全报 MISS，属正常）。
- 正确做法：① 把各切段分别 `in` 对应上传段校验；② 把各段拼起来与原文整句比对（去引号去空格后相等）。
- 另加一条：抓每组上传段里所有引号内容，**检查有无单段 >12 汉字**，必须为 0。

### 6.12 时长压缩的手法（用户打回"时间太长了"时）

1. **单镜上限 4 秒**：凡是 5 秒以上的一镜，先看能不能拆成两镜或压到 4 秒。
2. **删纯余韵镜**：如"说完静止两秒再黑屏"——把静止时间转给下一个动作镜或收尾空景。
3. **合并同类镜**：如"人物入画"＋"人物停住"两镜并成一镜（跟移上抬到最后即停住）。
4. **别靠合并台词压时长**：那正是"呆板"的来源。**要压时长，就增加切点、缩短单镜**。实测一场从 63 秒压到 52 秒、镜头数反从 15 增到 19，观感更快。

### 6.13 题眼台词不给面部特写（用户打回"不要面部特写，话语轻盈流畅，手指抚过书页或者看向儿童嬉戏画面，充满美好"）

**核心判断：一给脸特写，台词就"重"了；要"轻"，就得把手和视线交给画面。**

- **错的做法**：题眼台词（如"人民万岁"）配人脸特写／推近她的脸。特写＝升格＝郑重＝宣言腔，与"轻盈美好"完全相反。
- **对的做法**：用**手部动作**（俯视手指抚过书页、指腹压在字上）＋**视线落点**（抬眼看向廊下嬉戏的孩童，目光跟着孩子移动）承载情绪。**"美好"由画面内容（白纸、孩童、日光、风）去演，不由人脸去演。**
- **拆镜落法**（一组 5 镜示范）：
  1. 手部特写（俯视手与书页，**不入脸**）——说前半句，语气轻盈流畅、破折号处不停顿不下沉
  2. （如有）闪切段
  3. **回到镜头 1 同一机位**，仍是手部特写——说后半句题眼，"顺着气息自然流出、像念一行喜欢的诗"，说完手指仍在纸页上轻滑、**没有停住**
  4. 中近景带环境，从肩侧越过去**看向孩童**，目光跟随、唇角上扬
  5. 回到当下中景，呼气、眨眼收尾
- **台词线要写明"不加重音、不顿挫、不沉下去"**；负面词补：`避免把题眼念成口号腔/宣言腔/沉痛腔`、`避免说这句话时哽咽/犹豫/落泪/表情凝重`、`避免出现人物面部特写与推近脸部的镜头`、`避免手指在说这句话时停住不动`。
- **⚠ 顺带避开否定式**：镜头字段里原本写"（不给她的脸部特写，只给肩背与侧脸轮廓）"仍是**画面否定**，要改成正面写法"（画面主体是她的肩背与侧脸轮廓）"；上传正文同理，"画面里不出现她的脸"→"画面主体是她的双手与摊开的书页"。
- **⚠ 可保留的"否定"**：`不加重音`／`没有表情`／`没有泪` 这类是**表演状态描述**，不是画面内容否定，允许保留（与"没有泪"同类）。

### 6.14 核验前先取权威台词基线（不要凭记忆写）

**核对脚本里的台词基线必须回剧本原文取，不能凭上下文记忆写。** 本次 v3 核对因基线错误（记成"苏万：素娘。""你来了"，实际是"苏秀才？""你……你怎么在这里？"）而误报 6 条 MISS。正确顺序：① 打开剧本/原始需求文本，逐条抽出台词 → ② 用它作基线 → ③ 再跑核验。**MISS 出现时先怀疑基线，再怀疑文件。**

### 6.15 残肢／血腥等特殊画面的替代法（断手、断肢、创口、血迹）

**铁律：先判断"要不要拍"，再判断"怎么拍"。** 主力手法永远是**根本不拍创口**，滤镜只是叠加层。

**核心判断——黑白／单色是"减震器"不是"替代品"：**
- 画面里依然是一只断手，只是变灰了。**审核看的是画面内容，不是画面颜色。** 所以单色、负片、褪色滤镜**只能叠加在别的手法之上，永远不能单独顶事**。同理，闪切/闪白也只是"减震"。

**三层手法库：**

| 层 | 手法 | 怎么拍 |
|:--|:--|:--|
| 一档·主力 | **反应替代** | 不给伤处，给旁观者：脸色发白、后退半步、抬手捂嘴、别开脸 |
| | **遮挡替代** | 前景用柱／帘／人群／烟气挡住关键位置 |
| | **结果替代** | 只给"空荡袖管＋袖口布料整齐向内翻卷"（**已验证可过**） |
| | **道具象征** | 掉落的镯子、崩断的琴弦、折断的树枝、泼翻的茶 |
| 二档·借景 | **影子替代** | 墙上/地上一道拉长人影，一侧衣料垂到一半就收住 |
| | **水墨替代** | 血 → 朱砂在宣纸／水面上慢慢晕开（古风题材首选） |
| | **声音替代** | 只留闷响与布料撕裂声，画面整段移开 |
| 三档·叠加 | **闪切蒙太奇** | 碎片节点（一道光、一片衣角、一片白）拼出事件 |
| | **闪白过曝** | 0.4～0.7 秒纯白一闪，切在动作前后 |
| | **单色／负片** | 整段转黑白或反相 |

**⚠ 三个 AI 生成特有的坑：**

1. **影子做断手，必须回避"手"这个字。** 视频模型是语义驱动的，提示词里写"影子的手断了"它**一定会生成一只完整的手**。改写为："影子一侧只有衣袖，衣袖末端是整齐的一圈布口"——只描述"收口"，不描述"缺失"。
2. **闪白做不出太短。** <0.3 秒的一闪，AI 视频模型会糊成一片噪点，建议 **0.4～0.7 秒**。
3. **绝不能写否定词。** 写"不出现断肢／断口／血迹"会被模型**反向执行**（详见 §6.9 的同类坑）。只写正面可见的东西，禁令全部交给 Layer 3 负面词。

**写法对照（刀落断手）：**

- ❌ `影子里他的手被砍断，断口喷出血，但画面不出现血迹`——三个错：写了"砍断/断口/喷血"（模型照画）＋写了否定词（反向执行）。
- ✅ `墙面上一道拉长的人影，影子一侧的衣袖垂到一半就收住，末端是整齐的一圈布口；另一侧一道冷光划过，画面随即硬切到围观者猛地后退半步、抬手遮住嘴。`
