# 敏感内容合规改编（Sensitive Adaptation）

## 0. 核心原则

**过审 ≠ 删掉情绪。** 先定「必须保留的情绪核心」，再换一个可过审的载体。

三步：

1. **标敏感点**：具体是哪一句 / 哪个动作 / 哪个画面触发红线
2. **定情绪核心**：这场戏要让观众感到什么（恐惧 / 欲望 / 愤怒 / 悲伤 / 压迫）
3. **换载体**：用技法库把「刺激源」换成「情绪源」

成功标准：**删掉敏感画面后，观众的情绪反应是否还在？** 在，就成功；不在，说明只删没改。

## 1. 与内容审核的分工

- `script-content-audit`：**识别**红线与灰区，只审不改
- 本技能：**改写**灰区内容，保留氛围
- 顺序：先 audit 标点 → 再本技能改写 → 最后复核

## 2. 灰区判定表（需技巧性处理）

> 参考 `0xsline/short-drama` 的 `compliance-checklist.md`，按短剧场景整理。

### 价值观灰区

| 内容 | 风险 | 处理 |
|---|---|---|
| 法外开恩 / 私刑正义 | 以暴制暴 | 加法律后果或角色反思 |
| 金钱万能 | 用钱解决一切 | 靠智慧 / 情感 / 正当手段 |
| 封建糟粕 | 包办婚姻等当正面 | 可展示但必须批判 |
| 拜金 | 嫌贫爱富 | 反派可拜金，主角须正确 |
| 阶层丑化 | 全面丑化某群体 | 可有差异，不可全丑化 |
| 职场 PUA 美化 | 压迫当磨练 | 主角应反抗 |

### 关系类灰区

| 内容 | 风险 | 处理 |
|---|---|---|
| 强吻 / 未经同意亲密 | 性同意 | 改双向确认，或「差点亲上」 |
| 年龄差恋爱 | 权力不对等 | 双方成年，避免暗示 |
| 三角恋 / 出轨 | 美化劈腿 | 出轨方承担后果 |
| 师生恋 | 权力关系 | 尽量避免；必须写则毕业后无利益关系 |
| 复仇过度 | 比反派更残忍 | 复仇有度 |
| 家暴 | 无后果 | 有反抗 / 法律 / 惩罚 |

### 表现手法灰区

| 内容 | 风险 | 处理 |
|---|---|---|
| 恐怖 | 过度惊吓 | 悬疑气氛替代直接惊吓 |
| 赌博 | 作为翻身工具 | 赌者必付代价 |
| 迷信 | 作为解决问题手段 | 只作文化元素 |
| 奢侈 | 炫富为核心 | 适度展示 |
| 医疗 | 不专业 | 基本准确 |

## 3. 改写技法库

### 3.1 结果代替过程（Off-screen）

- 适用：暴力、亲密、自残、死亡
- 保留：后果的冲击、人物反应
- 牺牲：过程的生理刺激
- 写法：切到事后——凌乱的房间、颤抖的手、地上的血渍、旁观者的脸
- 例：不拍施暴过程，拍受害者蜷缩的影子和门外冲进来的人

### 3.2 暗示与留白

- 适用：性、暴力、恐怖
- 保留：想象空间（常比直拍更强）
- 写法：只给一个暗示性细节，让观众自己补完
- 例：两个人影映在墙上，镜头停在摇曳的烛火

### 3.3 侧写（旁观者反应）

- 适用：暴力、羞辱、惨状
- 保留：情绪的传染力
- 写法：不拍主体，拍旁观者的表情 / 后退 / 捂嘴
- 例：不拍尸体，拍警察摘下帽子、家属腿软

### 3.4 物象替代

- 适用：性、死亡、暴力
- 保留：象征与情绪
- 写法：用道具 / 环境承载情绪（碎掉的杯子、熄灭的灯、滴水的龙头）
- 例：争吵后用摔碎的全家福代替对骂

### 3.5 声音替代

- 适用：暴力、性、恐怖
- 保留：听觉想象
- 写法：画面离开，只留声音（闷响、喘息、尖笑、静默）
- 例：门关上，画面切到走廊，只听到一声闷响

### 3.6 时间跳跃（Before / After）

- 适用：暴力、创伤、过程性内容
- 保留：因果与后果
- 写法：before 一个镜头，after 一个镜头，中间省略
- 例：举起的手 → 黑场 → 倒在地上的椅子

### 3.7 视角转移

- 适用：暴力、犯罪、权力压迫
- 保留：压迫感
- 写法：从施害者视角转到受害者 / 第三方，或用监控 / 镜子 / 倒影
- 例：不正面拍审讯，拍单向玻璃后观察者的脸

### 3.8 隐喻化 / 象征化

- 适用：性、政治、宗教、死亡
- 保留：主题与情绪
- 写法：用梦境、戏中戏、动物、自然现象承载
- 例：用两列火车擦身而过的轰鸣暗示情欲

### 3.9 情绪转译

- 适用：生理刺激转心理张力
- 保留：张力本身
- 写法：把「身体反应」转成「关系反应」——眼神、距离、沉默、呼吸
- 例：不拍亲密，拍两人之间越来越近又停住的呼吸

### 3.10 合规化重构（改设定）

- 适用：关系类灰区
- 保留：戏剧冲突
- 写法：改人物关系 / 年龄 / 身份，让冲突合法合理
- 例：婚外恋改双方均已离异；性暴力改成长久压抑的亲情

## 4. 工作流

1. **标注**：逐场标出敏感点（类型 + 红线等级）
2. **定核**：写一句「这场戏必须让观众感到 ____」
3. **选技**：按类型选 1–2 个技法（不要叠加太多，会失真）
4. **重写**：保留情绪核心，替换刺激源
5. **复验**：
   - 红线：敏感画面 / 台词是否清除？
   - 氛围：删掉的刺激，情绪是否还在？
   - 逻辑：改写后因果是否通？
   - 节奏：是否变拖 / 变跳？
6. **记录**：在剧本旁注明「原内容 → 改写手法 → 保留的情绪」，便于二审

## 5. 诊断清单

1. 是否只删没改？（删完情绪也没了 = 失败）
2. 是否用「说教」代替「呈现」？（合规不是加口号）
3. 暗示是否过度到观众看不懂？
4. 改写后人物动机是否还成立？
5. 是否把敏感内容转移到更不该出现的地方（如儿童 / 受害者视角的猎奇）？
6. 是否保留了原作的「痛感」，而不是变成温吞水？

## 6. 反例

- 暴力戏直接删掉 → 冲突消失，人物弧光断裂
- 加一段「法律会制裁他」的台词 → 说教，破坏氛围
- 把性改成「两人喝茶」→ 情绪错位，观众出戏
- 用大量隐喻但观众看不懂 → 自我感动
