# 分镜台词同步 — 总控

把**已经写好的分镜段落**（画面描述不动）里的台词行，替换成与标准台词库同口径的「中英对照」版本，并把标准库里没被写进分镜的条目按就近锚点补进去。

**只改台词行，不动画面描述、前缀、后缀、色调段。**

## 0. 铁律（违反即返工）

1. **标准库优先**：中文/英文一律以标准台词库（`{COMPARE_PREFIX}-第N集.txt` 这类文件）为准，**不要**用分镜里原有的英文台词（它常是旧版/错译/第一人称）。
2. **按集全局顺序对齐，禁止按场号分组**。分镜文件名的场号（如 `37-1a`）可能与剧本场号（`【37-2】`）**不一致**，按场分组会导致整场台词错配。
3. **宁可多插入，不可错配**。相似度低于阈值宁可判"缺"→ 走插入（内容不丢，位置略糙）；错配会让中文贴到错误行。
4. **插入逻辑必须写在台词行分支内部**，不能写在 `continue` 之后（否则永远不执行）。这是最容易踩的坑。
5. **同一条目被多行占用时，中英按行数均分**（中文按 `。！？…，；` 细切，英文按 `.!?,;—`+空格 细切），不要按句号粗切——粗切会出现"整段重复"或"中间丢段"。
6. **校验用"中文流片段匹配"**：抽取所有台词行引号内的中文按行序拼接，再把每条标准中文按 8 字窗口逐一检查是否命中。用整条 norm 匹配会因拆分产生大量误报。
7. **交付必带整合文档**（用户硬要求）：除分文件外，必须重建 `第N集_整合文档_全段提示词.md`（`SHOTLIST_EPISODES` 个）与全剧整合文档，整合文档头部沿用原文件头部（并把 `v2.0`→`v2.1`、"中英对照"说明改掉）。
8. **纯英文台词行是"输出态"，不能当"输入态"**：一旦分镜里的台词被剥成纯英文，就不能再拿它跑 `match_shotlist`（英文会被解析进 `cn` 位置，对齐全废）。要重新对齐，一律从对照文件重新出发。
9. **改口径要全链路一致**：分镜提示词（分文件 + 单集整合 + 全剧整合）、台词对照文件（分文件 + 整合版 + 旧名副本）、`提示词前后缀模板.md` 四处都要同步，别只改一处。
10. **中文说话人也要清**：孤立行/兜底行里的中文说话人（`伊桑`、`便衣警探`…）必须过 `map_speaker` 换英文名，否则提示词里仍混中文。
11. **路径只走环境变量**：脚本内不得出现任何绝对路径或内网地址。未设置 `SHOTLIST_WORK` / `SHOTLIST_OUT` 时 `paths.py` 明确报错退出，绝不回落到旧项目路径。

## 1. 输入与产出

| 项 | 说明 |
|---|---|
| 标准台词库 | `$SHOTLIST_OUT/{COMPARE_PREFIX}-第N集.txt`，格式 `【场号】` + `角色：` + `中文：` + `英文："..."` |
| 待改分镜 | `$SHOTLIST_OUT/第N集/<场号><字母>.txt`（分镜格式按项目实际，可能是纯文本五段式或 markdown 列表式） |
| 人工兜底表 | `$SHOTLIST_WORK/_orphan_cn.json`，key `"集|段|行号"`，值 `{head,cn,en}` / `{lines:[...]}` / `{drop:true}` |
| 产出 | 分文件（覆盖）+ 单集整合文档（N 个）+ 全剧整合文档 |

## 2. 台词行口径（v2.1：生产提示词只写英文）

**交付给视频模型的分镜提示词里，台词行只保留英文**——中文留在引号里会被视频模型/配音当成台词读出来。

```
旁白："The English narration."
台词：Iris——"The English line."——语气说明（沿用原行尾部）
OS：Martha——"Why is she so strong?"——内心独白，第一人称
VO：Man A——"Don't drag the detectives into this."
```

- 标签：`台词：`＝角色对白；`旁白：`＝总旁白（第三人称叙述）；`OS：`＝角色内心独白（第一人称）；`VO：`＝画外音/电话/屏幕文字。
- 说话人一律英文名；`SPEAKER_CN2EN` 表负责把分镜里残留的中文说话人换掉。换项目时用 `SHOTLIST_ROLE_MAP` 指向 `{中文名: 英文名}` 的 JSON 覆盖内置字典。
- markdown 列表式分镜每行保留 `- ` 前缀；行尾语气说明（`——语气平静`）是表演提示，保留。
- 中文台词只出现在**台词中英对照文件**里（`{COMPARE_PREFIX}-第N集.txt`，供配音/字幕），分镜提示词与它职责不同。

### 2.1 总旁白 vs 角色内心独白（必须分开，用户明确要求）

判别依据是**剧本原文**，不是标签叫法：

| 剧本原文 | 性质 | 中文 | 英文 | 标签 |
|---|---|---|---|---|
| `旁白：` 正文含"我/我们/我的" | **角色内心独白** | 第一人称（原文） | **必须第一人称**（I/my/me/we/our） | 对照文件 `角色OS：` → 分镜 `OS：Role——` |
| `旁白：` 正文第三人称 | 总旁白 | 第三人称 | 第三人称（人名叙述，禁 I/my/we/our） | `旁白：` |
| `角色OS（惊）：` | 角色内心独白 | 第一人称 | 第一人称 | `OS：Role——` |

- **不要**因为"总旁白要第三人称"就把内心独白一起改成第三人称——那会把角色自述变成旁观叙述，是返工级错误。
- 第一人称英文不要求每句都出现 `I`；但**不能出现角色第三人称指代叙述者自己**。
- 定位方法：全文扫描 `旁白：` 行，匹配 `(我|我们|咱|我的|我俩)`，命中的逐条人工确认归属角色。

## 3. 配置与流水线

### 3.1 先配三个环境变量（缺一即报错）

| 变量 | 含义 | 默认 |
|---|---|---|
| `SHOTLIST_WORK` | 本地工作目录（放 `_shot_dry` 与中间产物） | **必填** |
| `SHOTLIST_OUT` | 交付 outputs 目录（本地盘或 UNC 均可） | **必填** |
| `SHOTLIST_EPISODES` | 集数 | 40 |
| `SHOTLIST_TITLE` | 作品名（写进整合文档题头） | 本剧 |
| `SHOTLIST_COMPARE_PREFIX` | 台词对照文件名前缀 | 台词中英对照 |
| `SHOTLIST_ROLE_MAP` | 角色中英映射 JSON（换项目时覆盖内置字典） | 空 |

```bash
export SHOTLIST_WORK='/path/to/work'
export SHOTLIST_OUT='/path/to/outputs'          # UNC 用 //server/share/... 形式
export SHOTLIST_EPISODES=40
export SHOTLIST_TITLE='剧名'
export SHOTLIST_COMPARE_PREFIX='剧名-台词中英对照'
export SHOTLIST_ROLE_MAP='/path/to/role_map.json'
```

PowerShell：`$env:SHOTLIST_WORK='C:\path\work'`、`$env:SHOTLIST_OUT='C:\path\outputs'`，其余同。

### 3.2 执行

```bash
PY=python
cd "$SHOTLIST_WORK"
$PY scripts/print_config.py                 # 0) 核对实际生效的路径与集数
$PY scripts/build_shotlist.py  > _run.txt   # 1) 对齐 + 生成到 _shot_dry/第N集/
$PY scripts/verify_lines.py    > _verify.txt
$PY scripts/scan_cn_speaker.py > _cnspk.txt
$PY scripts/publish_shotlist.py > _pub.txt  # 4) 写回 outputs + 重建整合文档
$PY scripts/rebuild_compare_bundle.py > _rb.txt
$PY scripts/verify_publish.py  > _verify_pub.txt
```

S1 `match_shotlist.py`：解析标准条目 + 分镜台词行 → `align()` 窗口化顺序贪心（阈值 0.42，窗口 `[prev-1, prev+6)`）→ 夹逼补配（0.25）。相似度 = 词集 Dice（去停用词）+ 子串加成（精确 1.0 / 包含 0.85）。
S2 `build_shotlist.py`：孤立行归并（sim≥0.30）→ 同条目多行句级均分 → 缺条目按锚点插入 → 人工兜底表 → `clean_stray()` 兜底剥离旧格式行中文。
S3 `verify_shotlist.py`（覆盖率）/ `verify_lines.py`（口径）/ `scan_cn_speaker.py`（中文说话人）。
S4 `publish_shotlist.py`：写回分文件、重建单集/全剧整合文档（头部沿用原文件 `^(.*?\n---\n)` 并补纯英文口径说明）。
S5 `rebuild_compare_bundle.py`：按分文件重拼 `{COMPARE_PREFIX}-全N集整合.txt` 与旧名副本。

## 4. 收尾检查清单

- [ ] 台词行引号内含中文 = **0**；标签残留 `中英` = **0**；中文说话人标签 = **0**（`scripts/verify_lines.py` + `scripts/scan_cn_speaker.py`）
- [ ] 旁白行英文第一人称扫描 `I/my/me/we/our/us` = **0**（OS 行除外）
- [ ] `OS：` 行英文确为第一人称视角（不出现以角色第三人称指代叙述者）
- [ ] 相邻重复行 = 0；多行拆分处无"整段重复"（英文段数 < 行数时必查）
- [ ] 中文流片段校验：缺 ≤ 2 条（跨段拆分会造成 1-2 条误报，人工确认内容确实存在）

- [ ] 整合文档头部已更新（版本号 + 纯英文口径说明）

## 5. 常见坑（本次踩过）

| 症状 | 根因 | 解法 |
|---|---|---|
| 台词行英文与下一行重复 | 条目英文句数 < 分镜行数，均分时 `int()` 取整把同一段分给两行 | 把该条英文按中文小句改写成同等数量的短句，或人工兜底 |
| 标签 `中英旁白：` 清不掉 | 批量替换 `"中英` → `"` 时误伤 `replace("中英","")` 变成 `replace("","")` | 改完批量替换后复查一遍 `\.replace\(` |
| 部分行仍带中文台词 | 这些行没被剧本条目匹配到（v2.0 旧格式孤立行） | `clean_stray()` 就地剥离：保留引号内英文 + 行尾语气说明，去掉中文 |
| 说话人还是中文 | `role_label` 默认分支回退到原中文名 | `role_label` 外面包一层 `map_speaker`，所有分支统一过表 |
| 脚本报「[配置缺失]」 | 未设 `SHOTLIST_WORK` / `SHOTLIST_OUT` | 按 §3.1 设置；本包**故意不提供默认项目路径** |

## 6. 环境注意

- 本机 Bash 缺 coreutils（`grep`/`tail`/`ls` 全废），统一用 Python 脚本 + PowerShell；PowerShell 直接 `2>&1 | Out-File -Encoding utf8 x.txt` 后用 Read 读，控制台回显常是乱码/空白，不要依赖 stdout。
- 网络盘路径由使用者通过 `SHOTLIST_OUT` 提供：Python 里用原始字符串，Bash 里用正斜杠 `//server/share/...`。**包内不含任何内网地址**。
- PowerShell heredoc（`@'...'@ | Out-File`）传含中文/引号的脚本易损坏，改为先用 Write 工具落脚本再执行。
- 分镜里常出现"多角色台词挤在同一行"的合并行：替换后靠"缺条目插入"补第二条，靠 `tail_of` 的"不含引号"约束避免重复。
