# 视频分集工具包 · 使用说明

把**一部整片**按分集表切成**多集**，每集同时产出「字幕烧录版」和「无字幕版 + 独立字幕」。
切点精确到帧；字幕自动重算为「每集从 0 起算」，和视频天然对齐。

---

## 一、它产出什么

| 文件夹 | 内容 |
|---|---|
| `burned/` | 字幕**烧录**进画面的成片：`01.mp4 02.mp4 …` |
| `clean_srt/` | **无字幕**画面 + 每集独立字幕：`01.mp4` + `01.mp4.srt …` |

> 解决了经典问题：直接拿整条时间线的 SRT 套到分集画面上，第 2 集起字幕会整体偏移（"拖进去不显示"）。
> 本工具把每集字幕**减去入点、从 0 重算**，因此与按入/出点导出的画面完全对齐。

---

## 二、准备（只做一次）

1. **Python 3.8+**
2. 装依赖：`pip install -r requirements.txt`（就是 `openpyxl`；只用 CSV 表格可跳过）
3. **ffmpeg 已随包提供**（`ffmpeg/bin/`），脚本自动识别，**无需另装、无需配环境变量**。

---

## 三、三步出片

### 第 1 步 · 在 Premiere 里导出
- 整部片子**整段导出一次**；导出设置里「字幕 Captions → Burn-in」选 **无**（保证画面干净）。
- 同时导出**整条时间线**的 SRT，命名为 `master.srt`。
  > ⚠️ 要的是**整条时间线**那份，不要用 PR 的逐集导 SRT（那样每集都带绝对时间码，会错位）。

### 第 2 步 · 填分集表 `episodes.xlsx`
- 只填两列：`B` = `start`(入点)、`C` = `end`(出点)。
- 格式为 Premiere 时间码 **`时:分:秒:帧`**，例如 `00:22:30:00`。
- `D` 列 `duration(自动)` 会**实时算出每集时长**，方便核对。
- **`G1` 格填你 PR 序列的帧率**（24 / 25 / 30 …）——脚本用它把「帧」换成时间。
- 想要空白模板：`python scripts\make_template.py --rows 40 --out episodes.xlsx`

### 第 3 步 · 跑两条命令
```bat
python scripts\split_srt.py   --srt master.srt --csv episodes.xlsx --out srt_out
python scripts\split_video.py --video "整片.mp4" --table episodes.xlsx --srt-dir srt_out
```
跑完当前目录出现 `burned\` 和 `clean_srt\`。

> 先试一集看效果：第二条命令加 `--episodes 1`；只打印计划不执行：加 `--dry-run`。

## 四、参数速查

### split_srt.py（拆字幕）
| 参数 | 说明 |
|---|---|
| `--srt` | 主字幕 `master.srt` |
| `--csv` | 分集表（`.xlsx` 或 `.csv`） |
| `--out` | 输出目录（默认 `srt_out`） |
| `--fps` | 帧率；不填则读 xlsx 的 `G1`，再不然按 25 |

### split_video.py（切视频）
| 参数 | 说明 |
|---|---|
| `--video` `--table` `--srt-dir` | **必填**：整片 / 分集表 / 上一步的字幕目录 |
| `--episodes 1-3` | 只处理指定集（也可 `1,5,9`） |
| `--ref "某集.mp4"` | 参考你已有的一集导出，**自动抄它的分辨率 / 码率** |
| `--width` `--height` | 直接指定输出分辨率（不填 = 源分辨率） |
| `--encoder h264_nvenc` | 编码器；默认**自动探测 N 卡硬件加速**，没有则用 CPU（libx264） |
| `--cq 16` | 质量（越小越清晰、越大越省空间） |
| `--sub-font Arial --sub-size 52 --sub-margin-v 44 --sub-outline 2` | **像素级**定字幕样式（1080p 实测：字号 52 ≈ 可见字高 43px、距底 44px） |
| `--out-burned` `--out-clean` | 自定义输出目录名 |
| `--dry-run` | 只打印计划，不动文件 |

---

## 五、注意事项

1. **帧率要填对**：`G1` 用 PR 序列的真实帧率。填错只会让切点差 ≤1 帧（肉眼不可见），但口径要对。
2. **硬件加速**：有 NVIDIA 显卡会自动用 NVENC，快很多（实测 ≈1~2 分钟/集 × 2 份）；
   没有 N 卡会回落到 CPU 编码，明显更慢。
3. **耗时 / 空间**：烧录字幕必须重编码，成品约占源片 1~2 倍大小，请留足磁盘。
4. **源片自带的硬字幕/人名条**：如果画面里本来就烧死了字（如人物名牌），
   两个版本都会带着——那是画面像素的一部分，字幕滤镜去不掉。
5. **留白 & 跨集**：字幕中间的空白原样保留；横跨两集切割点的字幕会**自动裁断**，不会丢字。

```
视频分集工具包\
├─ 使用说明.md
├─ requirements.txt
├─ episodes.xlsx            ← 空白分集表模板（40 集）
├─ scripts\
│  ├─ make_template.py      ← 生成空白分集表

   ├─ ffmpeg.exe
   └─ ffprobe.exe
```

## 七、常见问题

**Q：为什么不能直接用 PR 导出的分集 SRT？**
A：因为那份 SRT 用的是**绝对时间码**（相对 00:00:00 的整条时间线）。套到从 0 开始播的分集画面上，
第 2 集起字幕就整体往后偏了——表现为"字幕不显示"。本工具专门修正了这一点。

**Q：提示找不到 ffmpeg？**
A：确认 `ffmpeg\bin\ffmpeg.exe` 相对位置没被移动；或设环境变量 `FFMPEG` 指向你的 ffmpeg。

**Q：字幕大小/位置想固定成某个样式？**
A：加 `--sub-size 52 --sub-margin-v 44 --sub-outline 2`（数值按像素，随分辨率等比调整即可）。
不加则用 ffmpeg 默认样式（Arial，1080p 下约为字高 50px）。
