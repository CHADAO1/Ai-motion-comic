# 02 Reference Router And Locks

priority: high
scope: @图片 / @视频 / @音频 / 序列帧 / 参考提示词的用途分配和维度锁定

## 总原则

场景锁定、角色锁定、音频锁定，本质都是说明参考素材只控制哪些维度。默认合并写进 `【角色/场景/素材锁定】`，并把该模块置于每段第一栏；不要再拆成 `【参考素材使用】`、`【场景锁定】`、`【角色锁定】` 三个重复模块。不能写“参考 @图片1”就结束。

Wan3.0 原生使用 `@图片N/@视频N/@音频N` 作为参考句柄：带 `@` 前缀、用全称“图片”（不是“图”），图片/视频/音频分开计数、各自从1起编号；同一对象可在提示词不同位置多次 `@`，是提高指代命中率的推荐做法。**客户显式资产索引原样保留（最高优先级）：** 客户原提示词若已自带显式资产索引（如 `@[uploaded:xxx]`、`@图片x (xxxx)`，或客户平台特有的任何句柄形式），锁定区与时间轴一律原样保留其字面形式——`@`、方括号、id、括注、大小写、空格全部不动，绝不改写成 Wan3.0 规范句柄、不重新编号、不剥离括注、不合并或拆分；重复出现时也保持客户原始形式。原因：编译结果要贴回客户自己的视频生成系统，只有原样索引才能与资产正确关联，改形式即断链。上面的 `@图片N` 规范写法只是“客户未提供显式索引时”我方为 `input.media` 素材新拟的默认形式；客户已给显式索引时以客户形式为准。此规则主要作用于 `constrained-compile`（提示词优化/复刻/改写已有提示词）路线。只为真正作为 media 传入的素材写 `@` 行，未提供的素材不编号、不声称已挂载；素材未提供时保留“素材用途 + 控制维度 + 短名称”的描述即可。互斥硬规则：`reference_*` 与 `first_frame`/`last_frame` 互斥，`last_frame` 必须搭配 `first_frame`，`file` 与 `link` 互斥（最多其一，需 `enable_thinking=true`）；写提示词前先定死走哪套。

本文件中的“锁定”只表示**限定控制维度**，不表示复制素材全部像素，也不表示冻结角色、摄影机或场景。必须写成 `身份锁定 / 场景拓扑锁定 / 动作路径锁定 / 声线锁定 / 位置关系锁定`，不能只写“严格锁定参考图”。

## 三层控制权：观察台账、参考授权、当前生成

续写、审片和末尾帧任务必须把三层分开，不能因为“台账记录了某项”就让某个素材自动控制该项：

1. **观察台账 / observed production ledger**：保存已接受结果中直接可证实的连续性事实，服务人类规划和静默推理。
2. **参考授权 / reference-control assignment**：规定某个 `@图片/@视频/@音频` 在本段生成时只控制哪些维度。
3. **当前生成 / current CUT instruction**：把本段真正需要的开场状态、动作、摄影机和可见 OUT 用当前时态重新写进提示词。

### 模型可见载荷边界

`【角色/场景/素材锁定】`不是素材清单、取证报告或后期交接单。只有本次确实传给生成模型的素材，才在提示词中得到一条可见的引用/锁定行。仅供导演分析、取证、比对或台账连续性使用的图片/视频/音频，不写“仅作分析证据、不作为生成输入”，而是整句不进入提示词；后期才挂接的BGM母带、配音、字幕或合成素材也不在锁定区声明。

### 传入但本段不出镜的素材（串脸唯一可靠解＝不传这张图，最高优先级）

先记住一条经实测确认的硬事实：**串脸/融脸由传入的 `input.media` 数组决定，不由文案决定。** 只要不出镜角色的人脸图还在 media 里被传给模型，模型就会把它当垫图消费、把这张脸融进出场角色或后景路人——**在锁定区写“本段不出镜”“正向排除”不管用，模型依然照用这张图**。删掉绑定行同样不解决，只是让它退化成“传入了却无描述”的悬空条件图，更不可控。结论：改文案治不了串脸，唯一可靠解是**从源头不把这张图传进去**。

处理顺序（按能否裁 media 二选一）：

1. **能裁 media 数组（本 skill/调用方自己决定最小充分素材集）→ 必须把不出镜角色的参考图从数组移除。** 这是唯一保证不串脸的做法；移除后文案也不再写它，不需要任何“不出镜”排除行。
2. **media 由上游固定、你删不掉这张图（典型：客户平台按整集角色一次性挂载全部参考图）→ 文案无法可靠防串脸，必须显式告警升级**：在给用户的交付说明/改写要点里明确写出“该不出镜角色的参考图仍被上游固定传入，提示词层面无法阻止模型把它当垫图，要根治请上游把这张图从本段 `input.media` 移除”，不得用一行“本段不出镜”假装问题已解决。此告警是写给用户的运营说明，放在提示词正文之外，不进锁定区。

降级缓解（**明确不保证生效**，仅在情况 2 一时无法裁图时聊胜于无）：保留一条绑定行、改归“本段不出镜”并写正向排除，作用是避免主动指示模型渲染该角色、避免悬空、并为人工留痕；但**绝不能把它当成已消除串脸**，情况 2 的告警升级仍必须同时给出。“本段不出镜”是对已传入生成输入的渲染排除，与下文禁止的“不作为生成输入/仅作分析证据”那类管理句性质不同，不以“精简管理句”为由删掉。默认写法：

```text
@图片1｜陈明远（本段不出镜）：本段画面不出现陈明远的面部、身形或背影，不把其五官/发型融合到任何出场角色或后景人物，也不派生同貌人物；不改变本段已出场角色的身份锁定。
```

不变量（服务冷启动完整与 QC 可追溯，**不服务于“抑制串脸”**）：实际传入的每一张 `@图片/@视频/@音频` 都应恰好对应一条可见绑定行，不留“传入了却无描述”的悬空素材。但对不出镜角色，真正的目标始终是让它不进 media，而不是靠绑定行去压制它——绑定行只是删不掉图时的降级留痕，不是解。

每句可见正文至少承担一项模型任务：

- 当前画面中应出现的主体、场景、材质、状态或空间关系；
- 当前应生成的声音、台词或静默；
- camera、时间、表演、动作、焦点或剪辑行为；
- 一个真实生成输入的明确控制维度；
- 精简技术卫生。

不满足以上任一项的素材数量、文件管理、来源/授权、分析证据、跨段依赖、验收历史、后期挂接或“哪些东西没有传给模型”的解释，全部留在观察台账。禁止用“本段独立冷启动”“只使用下列素材”“其余由文字生成”“不依赖其他段落/未列素材”“参考片仅作分析证据”“授权母带后期挂接、不作为生成输入”等管理句证明独立性。独立性要靠本段逐实体事实完整重写来实现。

场景由文字建立时，直接写成场景事实，例如“住宅派对客厅，暖灯下背景宾客分层交谈，旧式黑色按键手机在男主右手”，不写“住宅派对、宾客和手机由文字生成”。后期母带不进入模型时，模型声音只写“无背景音乐；保留/生成……”，母带文件、授权、挂接时码和ducking计划另存制作台账。参考图的灰底、平铺版式等确有漂移风险时，把范围限制并入该图自己的控制行，优先写“场景、服装与灯光按本段文字”，不另写汇总排除句。

观察台账至少按需记录：

```text
世界拓扑：固定场景、入口/出口、行动轴、危险线。
动态世界状态：角色/道具世界位置、距离、朝向、高度、身体姿态、支撑点、动作相位、速度/惯性、握持/接触、装备、损伤、残余材质/VFX。
摄影机尾态：上一镜摄影机终点、看向、轴线侧、焦段/景别、运动方向和速度阶段。
声音尾态：人声来源、环境声、接触尾音、静默或声音桥。
事件状态：已完成动作、本段任务、下一开放动作、未来保留和未确认项。
```

- 摄影机尾态用于选择切镜理由、保持/越过轴线、eyeline、动作匹配、运动匹配或有意反差，不默认成为下一段摄影机。
- “下一开放动作”只用于静默规划。只有剧本、用户要求或已接受动作相位支持它时，才把当前可见的预载写进下一段；不能把未来动作名称写进上一段 OUT 或素材排除句。
- 完整已接受视频可证明连续运动、动作相位、摄影机运动和声音相位。静态末尾帧只能证明单帧直接可见的站位、朝向、姿态、支撑、握持/接触、损伤和残余状态，不能单独证明速度、惯性、画外动作或声音。
- 静态末尾帧作为观察证据时可以更新直接可见的姿态/接触台账；同一张图作为下一段 `@图片` 时，生成授权仍只限角色世界站位与相互距离。姿态、动作相位和惯性必须由台账文字、用户说明、已接受完整视频或当前剧本重新写入本段 CUT，不能让图片隐式接管。

默认用户可见输出只为真实生成输入写“控制什么”：

```text
@素材N 命名为 [锁定名]，控制 [维度列表]。
```

## 实体主描述行唯一化

写锁定区前，先按规范名称建立角色、场景、道具和文字资产实体表，把“文字事实、主参考、附加参考、当前状态”归到同一实体。每个实体在当前独立段内只能有一条**主描述行**，静态身份/外观/拓扑事实只在这条线上完整出现一次：

- 有承担该实体主身份、主外观或主拓扑的真实素材时，直接把该素材行写成主描述行，不再先写一条纯文字主体描述、随后用 `@图片` 重述同一张脸、发型、服装、建筑或道具外观。**外观维度只在原文/客户提示词字面写明、或参考图直接可见可证时才可原样引用；无出处一律留白交给参考图，严禁按角色类型/职业/身份/刻板印象脑补编造服装颜色、发型、妆容、年龄感、体型、配饰（见 SKILL.md「外观脑补禁令」，与 `08` 的 36C 年龄不编造、36E 口音不臆测同一纪律）。**
- 没有主参考素材时，才使用纯文字主描述行。当前伤疲、湿尘、握持、位置或开场动作相位等动态状态可在同一主行末尾补充；需要在 CUT 内变化的状态仍放入时间轴。
- 同一实体有第二张图片、动作视频、运镜视频或声线音频时，每个真实素材仍独占一行，但附加行只写它新增的控制维度和作用域，不重复主行已经写清的身份、服装、场景或道具全文。
- 一个素材同时控制同一实体的多个兼容维度时，把这些维度合并在该素材自己的单行内，不为“身份锁定、服装锁定、角色命名”重复写同一个句柄。
- 场景和道具执行同样规则：场景图主行可同时承载场景名称、固定拓扑、核心材质和该图用途；道具图主行可同时承载道具名称、外形结构、归属和该图用途。只有素材无法证明的新增世界事实或当前动态状态才另写文字行。**场景脑补禁令（有场景参考图时不擅自做场景设计，最高优先级，与 SKILL.md「外观脑补禁令」同一条纪律的场景版）：** 提供了场景参考图时，空间拓扑与布局、建筑与门窗结构、陈设/家具、材质、光线氛围、时代与地域风格等一切“场景设计”维度一律由该场景图承载，主行与时间轴都不得自行设计、改写或脑补出一个新场景，也不复述参考图已载明的陈设外观；只有原文/客户提示词字面写明、或参考图直接可见可证的场景事实才可原样引用，两者皆无时留白交给参考图，绝不按剧情类型/场景标签的刻板印象（如「办公室＝落地窗＋工位」「古代＝木质厅堂」「医院＝白墙病床」）自行填场景细节。边界：场景图锁世界拓扑/材质/已见布局但不锁摄影机（新角度按同一拓扑重建画面投影）；剧情需要的、参考图未覆盖的新增可见世界事实或动态状态可另写文字行，但不推翻已确立的固定拓扑；角色站位/走位/朝向属位置关系，不算场景设计。仅在无场景参考图时才自行构建最小充分世界拓扑。详见 SKILL.md「场景脑补禁令」。

正确：

```text
@图片2｜伊莎：成年女性，粉色长发，黑白紫机械战斗服、肩甲和机械臂；该图控制本段身份外观与装备结构。地域语境为故事所在地区，通用标准口音，清亮中音，语速利落；当前呼吸急促。
@视频1 命名为伊莎冲刺参考，只控制伊莎本段冲刺的身体路线、步频和起停节奏。
```

错误：

```text
伊莎：成年女性，粉色长发，黑白紫机械战斗服、肩甲和机械臂……
@图片2 命名为伊莎，控制脸、粉色长发、成年身体比例、黑白紫服装、肩甲和机械臂。
```

（说明：上例「正确」里之所以能写粉色长发/黑白紫机械战斗服，是因为这些外观来自**正史设定或参考图直接可见可证**，属于有出处的原样引用；错误只在于把同一份外观在文字行和 `@图片` 行**重复**了两遍。有出处≠可以随便写，无出处则一个字都不能编。）

外观脑补专项对比（真实串脸诱因）——当原文/客户提示词**没有**任何外观描述、参考图是唯一权威时：

正确（外观留白，交给参考图；锁定行只写短名、该图职责、当前动作/情绪/位置/作用域）：

```text
@图片1｜顾长山：该图控制本段身份、长相与服装；本段站在圆桌旁，下颌线绷紧、目光冷硬锁住对手，压着怒意。
@图片4｜李叔：该图控制本段身份、长相与服装；本段坐在圆桌后景，保持坐姿、低幅旁观、面部虚焦，不介入主动作。
```

错误（按角色类型/身份脑补编造服装，且给不同角色编出相近的深色系上衣）：

```text
@图片1｜顾长山：成年男性，深色西装，短发，面部棱角分明……
@图片4｜李叔：中年男性，深蓝衬衫，坐在圆桌正后方……
```

错误点有两层：① 「深色西装/短发/棱角分明」「深蓝衬衫」原文没写、参考图也未必如此，是凭「商界男＝深色西装」刻板印象脑补的，一旦与参考图冲突就给模型互相矛盾的身份信号导致漂移；② 给顾长山和李叔都编了深色系上衣，在**文字层面**制造了两人相似度，叠加机位反转时的空间投影重叠，直接诱发第3镜把李叔融成顾长山——这是「空间投影重叠」之外的第二类串脸文字诱因。修法是做减法：删掉无出处外观、留白交给参考图，而不是再补更多空间约束或把编造的外观抄得更细。

交付前做“删除等价行测试”：若删除某一行后，同一实体、同一静态事实和同一控制维度仍被另一行完整表达，该行就是同作用域重复，必须合并或删除。不要把跨独立段冷启动、CUT 中的当前站位/动作重锚或附加素材的独有控制误判为重复。

每个真实附件/参考素材必须独占一行。禁止在同一行、同一段落、同一表格单元或同一逗号链中串联多个 `@图片/@视频/@音频`。同一素材有多个兼容用途时仍写在该素材自己的单行内，不拆成重复句柄；不同素材即使控制同类维度也分别换行。

只有以下情况才显性补充“不控制什么”：

- 素材被传入 media、但其主体本段不出镜（首选把该图从 media 移除；删不掉时才写“本段不出镜”排除行，且这只是**不保证生效**的降级缓解，必须同时向用户告警请上游移除该图，见「传入但本段不出镜的素材」）。
- 多个参考素材维度冲突。
- 参考视频可能把人物身份、服装、地点、品牌、台词或声音带偏。
- 参考音频可能被误当成最终 BGM、台词或声线。
- 涉及真实人物、声线、品牌、logo、IP、授权不明素材。
- 用户要求严格角色一致、产品一致、首尾帧一致，且参考素材中有容易误读的额外元素。

高风险时使用：

```text
@素材N 命名为 [锁定名]，控制 [维度列表]；不控制 [具体排除维度]。
```

时间轴引用规则：

- 锁定名只在**当前独立段落内部**复用。进入下一独立段后，重新写该素材的原始引用、锁定名和控制维度；不能依赖项目总说明或上一段已经命名过。
- 在 `【角色/场景/素材锁定】` 里为素材命名后，`【运镜与时间轴】` 默认使用锁定名，不频繁重复 `@图片1/@视频1/@音频1`。
- 正确：`CUT 1，主角A从screen-left进入稻田场景，收割机道具停在background right。`
- 错误：`CUT 1，@图片1人物从screen-left进入@图片2场景，@图片3道具在右侧。`
- 只有新素材第一次出现、需要强调首帧控制、需要声明末尾帧证据/控制分离路由、或修复参考漂移时，才在时间轴中再次写原始 @引用。

`@` 不是“整体照抄”命令，而是素材任务分配。每个独立段在写时间轴前先建立最小充分素材集：

```text
本段任一 CUT 会进入摄影机视锥或声音场的角色、场景区域、道具、文字资产、动作/运镜参考和声线
-> 原始 @引用
-> 短锁定名
-> 素材类型与用途
-> 唯一控制维度
-> 本段作用域与开场状态
```

- 本段素材集取所有 CUT 实际可见/将被揭示对象的并集，不只包含主角。虚焦、局部遮挡或仅在全景出现的后景人物，只要会被摄影机看到，也必须在本段锁定区挂载对应人物参考。
- 不进入本段视锥、不会发声、也不参与动作/声音控制的素材：**首选从 media 数组移除、根本不传它**——这是唯一可靠避免参考竞争/串脸的做法，文案也不再写它。**若 media 由上游固定、该图删不掉仍会被传入，则文案无法可靠防串脸**：写“本段不出镜”排除行只是不保证生效的降级缓解（避免主动指示渲染、避免悬空、留痕），必须同时向用户告警“请上游把该图从本段 media 移除，否则提示词层面拦不住模型把它当垫图”（见「传入但本段不出镜的素材」）。
- Wan3.0 素材上限为 `reference_image ≤10 张`；`reference_video ≤5 段`（总 ≤15s，单段 [1,15]s）；`reference_audio ≤5 段`（总 ≤15s）；`file ×1 或 link ×1`（需 `enable_thinking=true`）。图片/视频/音频分开计数、各自从1起编号，但仍以本段最小充分素材集为准；“最小充分”不等于刻意少用素材，只要每项在某个 CUT、声音场或风格维度有唯一明确任务，就可以使用更多支持素材直到对应模态上限。上述配额是上限不是目标数量。
- 同一素材可以承担多个彼此兼容的用途，例如同一动作参考视频同时控制运镜路径和节奏；但每个用途都要逐项写清。一个身份、场景拓扑、动作路线或声线维度只设一个主参考。
- 拼贴图、九宫格、标注图或上下分区参考板必须逐区分配用途，例如“上半部控制真实外观，下半部控制座位拓扑与摄影机轴线”。只有参考板元素确实可能进入成片时，才补一条最短排除说明。
- 用参考视频复刻运镜时，锁定的是 camera start-path-end、速度轮廓、圆心/轨道、主体保持和切点；另用当前剧情描述角色、场景和动作，不把参考视频的画面内容一起复制。
- 运镜参考视频先做“可迁移性筛选”：优先裁成只包含一个清楚运动逻辑的约5-8秒短片；复合运动过多时拆开选用；参考片与目标片的主体运动类型尽量相近，例如人物步行的后方 `follow tracking` 对应同方向、同相对位置的人物步行。长度、复杂度或动作类别不匹配时，不把该素材作为生成输入；只在静默台账保留分析结论，并把可迁移的camera路径、速度和终点改写为当前生成指令。

跨段重复门：

- 角色、服装、场景、关键道具、首帧、末尾帧位置关系、声线与文字资产只要在某段实际使用，就在该段 `【角色/场景/素材锁定】` 重新声明用途和当前状态。
- 可读文字、报告、证件、UI、包装或屏幕截图使用固定贴图/跟踪合成时，每个出现它的独立段都重复锁定全部需要保持的文字、数字、单位、箭头、表格线和版式；特写只裁切或缩放原图像素，不让“整片锁定”退化为上一段的隐含设定。
- 总资产表可以服务人类管理，但不能替代可复制提示词块内的本段锁定。

## 多模态素材路由器

@图片可控制：

- character identity：脸型、发型、年龄感、体型、服装、道具。
- environment identity：地点、空间布局、建筑材料、天气、时代。
- style identity：画风、材质、色彩、构图气质。
- first frame：用户明确要求时控制首帧构图或起始画面。
- final frame still：作为观察证据时读取直接可见状态；作为生成参考时只控制角色世界站位与相互距离，必须走“末尾帧证据/控制分离路由”。

### 末尾帧证据/控制分离路由

只要静态末尾帧作为下一独立段的 `@图片` 参考，本规则覆盖一般图片/首帧继承规则：

1. 末尾帧作为本段 `@图片` 时只控制角色在世界空间中的站位和相互距离；它的摄影机位置、lens/focal length、shot size、构图、前中后景、screen-left/right、焦点、光线、场景像素和服装细节不进入生成控制。单帧中直接可见的姿态、支撑、握持/接触、损伤和残余状态可以先进入观察台账，但必须由本段文字重锚，不能通过该 `@图片` 隐式继承。
2. 角色身份与服装回到原角色参考或剧本文字；场景回到原剧本文字、已验收场景设定或原始场景图。优先级为：用户当前场景文字 > 已验收场景设定/世界拓扑 > 原始场景参考图 > 根据当前剧本补全的最小明确场景描述。
3. 本段开场姿态、动作相位、朝向、接触和惯性由“已接受动态世界状态 + 当前剧本/调度”共同确定并用文字写清；单帧无法证明的运动和声音不得擅自补成已发生事实。
4. 当前段首镜必须直接切到新 setup：明确写 `hard cut` 或 `direct cut`，其理由是解除静态末尾帧旧机位/构图的控制，并写新的摄影机起点/看向、轴线侧、焦段、景别、人物角度、构图、焦点起点和真实后景。优先用世界站位、matched eyeline、视觉重心或已证实动态状态承接；只有完整已接受视频证明同一动作仍在进行时才写 `match on action`。静态单帧不能证明运动，不为它虚构动作匹配、遮罩或擦镜。上一镜摄影机尾态只用于判断轴线、切点和运动匹配，不控制新机位。
5. 新机位从世界站位和已接受动态状态重新投影人物正背面、姿态可见性、遮挡、foreground/midground/background 和 screen-left/right；禁止把末尾帧画面左右或前后景直接复制到新 CUT。
6. 新 CUT 用当前 camera setup 完整建立本段场景和 shot size，其可见 OUT 才进入后续制作台账；模型提示词不解释这一制作过程。
7. **推广到任意站位参考图（站位脑补禁令镜像，最高优先级）**：上面第 1/5 条对"末尾帧只控世界站位、不控摄影机、姿态须文字重锚、禁止复制画面左右/前后景"的分离路由，同样适用于任何**用于锁站位的参考图**（群像调度图、走位示意图、多角色相对位置图，不限静态末尾帧）。只要提供了这类站位参考图，图中已确立的角色相对位置、相互间距、身体/脸朝向、面向与视线关系、队形与分组、前后景/screen-left-right 落位一律由图承载，锁定行与时间轴都不得自行臆想、改写或脑补出一套与参考图不同的站位；只有原文/客户提示词**字面写明**或参考图**直接可见可证**的站位事实才可原样引用，两者皆无时留白交给图，绝不按剧情类型/关系/身份刻板印象（领导居中下属两侧、主角 C 位、反派背对镜头、情侣并肩对手对峙、众人围圈）编排。三条边界与末尾帧路由一致：① 图锁的是**参考时刻的角色世界站位与相互关系**，不锁摄影机——新机位仍按同一世界站位重新投影 screen-left/right、人物正背面、前后景，禁止把参考图画面左右/前后景直接复制到新机位；② 参考图未覆盖的**时间维走位/调度变化**（A 走到 B、入场/离场、因动作位移）与**动作相位/姿态**由本段剧本与相机决定并用文字重锚（"起始站位读图、过程走位与姿态读剧本"），但不得推翻图已确立的起始相对站位；③ 只有**没有**站位参考图时，才回到 `knowledge/08` QC 第 35 条自行设计不改变剧情的专业调度。详见 SKILL.md「站位脑补禁令」。

默认锁定写法：

```text
@图片N 命名为尾帧位置A，只控制角色在场景世界坐标中的站位与相互距离。角色身份与服装由角色参考A控制；场景拓扑、材质、光线和陈设由[剧本文字/场景参考A]控制；开场姿态、接触和动作相位由已接受尾态文字A与本段剧本控制；本段 CUT 1 重新指定 camera position/look direction、lens/focal length、shot size 和构图。
```

默认首镜写法：

```text
CUT 1：direct cut to [新摄影机起点/轴线侧/看向]，[焦段与新景别]，用[世界站位/互为视线/视觉重心/已证实动作方向]承接并解除尾帧旧机位控制；根据尾帧位置A放置角色，以文字重锚[已接受身体姿态/支撑点/握持接触/动作相位/惯性]，再按新机位重算人物角度、foreground/midground/background、screen-left/right 和焦点路径。[剧本文字/场景参考A]完整建立当前可见场景。
```

@视频可控制：

- camera movement：运镜路线、速度、转场方式。
- action choreography：动作路线、接触点、节奏、反击、结尾后果。
- editing rhythm：切点、CUT可读时长、reaction cut 结构。
- VFX behavior：粒子、烟尘、能量、破碎方式。
- audio rhythm：如果用户明确要求，也可作为节奏参考。

@音频可控制：

- final BGM：最终背景音乐。
- silent beat guide：只控制节奏，不输出该音频。
- SFX guide：冲击、转场、动作音效参考。
- ambience bed：风、雨、机械、室内空间声。
- voice anchor：角色或旁白声线参考。

序列帧 / 分镜图可控制：

- CUT顺序、空间轴线、screen-left/right、主体进出画、焦点路径、首尾状态。
- 不自动控制角色身份、服装、场景质感，除非用户明确指定。

参考提示词可控制：

- 结构、节奏、动作拆法、时间轴写法、画面密度。
- 不默认复制题材、角色、世界观、专有名词。

## 素材证据审计

给素材分配控制维度前，先静默分三层：

1. **能证明**：画面或声音中直接可见/可听的身份、服装、材质、构图、光位、初始姿态、尺度锚点、动作方向、节奏或声线。
2. **仅暗示**：画外空间、下一步动作、速度、重量、完整环境、反向机位等需要推断的内容。
3. **不能证明**：素材未显示的背面、内部结构、真实尺寸、反向轴线、动作结果、台词含义或版权归属。

规则：

- 教程/讲解视频用于生成新规则时，必须取得原视频并同时核对两类带时间码证据：音频转写说明“这个符号、CUT或camera operation用于什么”，同时间画面或界面示例说明“字面怎样写、摄影机怎样动”。自动章节、标题、评论区和单独转写只能提供检索线索，不能独立定义硬规则。
- 音频口播与画面示例不一致时，功能解释以口播上下文为参考，具体标点、括号位置、方向、构图和界面写法以画面为准；仍与用户已验收工作流冲突时，采用更窄的用户验收写法，并把来源说法降级为可选启发。
- 每个控制维度只设一个主参考；其他素材只能补充不同维度，不能共同争夺同一身份、构图或动作路线。
- 场景图没有反向机位或新角度证据时，它只控制材质、光线和已见布局；新机位必须用文字重新建立轴线、左右、前中后景和 camera height，不能强套原构图。
- 参考图中的速度线、倾斜姿态、衣料方向、运动模糊和被截断肢体属于“隐含运动”。如果它与用户要求的动作方向或 camera path 冲突，先解决冲突再使用。
- 色卡只控制色彩比例、曝光关系、冷暖和光线角色，不控制构图、文字、人物或场景布局。
- 灰底角色/产品图只控制身份、轮廓、材质、服装、道具和尺度特征，不把灰底带入场景。
- 尺度用人物身高、门高、车辆宽度、地面占地或明确米制尺寸等绝对锚点证明，不用两个都会漂移的对象互相作比例。

## 联网核实路由

只有现有知识不足且错误会改变画面执行时才静默联网：陌生/非标准动作，钢丝、威亚、特技或特殊摄影装置，罕见 camera path，机械/材料/工业流程，时代或文化特定行为，真实安全流程，或用户点名名场面且需要核实其可迁移 CUT/camera 机制。

- 优先官方、专业和一手来源：摄影协会/电影资料机构、设备厂商文档、主创/特技/VFX 访谈、论文和技术文档。
- 只提取可执行增量：准确术语、发力与支撑、camera start-path-end、轴线、接触点、切点和安全边界。
- 常见 camera setup、CUT语法和知识库已有动作不联网，避免噪声与延迟。
- 术语不可靠时，不把术语硬塞进提示词，改用中文描述真实物理路线。
- 研究网址、来源争议、交叉核验、未核验状态和检索笔记只进入内部静默证据台账/冷审包；用户要求严格成品时，不进入整个用户可见回复，也不在五栏目后追加来源、脚注或核验说明。用户明确索要来源或研究报告时才另行展示。

## 正史参考与临时状态

长项目和续写必须区分两类素材：

- 正史参考 / canonical reference：角色脸、服装、产品形状、场景设计、道具、色彩等不变量。
- 已接受完整视频 / accepted footage：可供静默台账核对已完成剧情、角色动态世界状态、动作相位、摄影机尾态和声音相位；只有用户明确分配时才控制本段生成维度。
- 已接受静态末尾帧 / accepted final-frame still：作为观察证据，可核对单帧直接可见的站位、朝向、姿态、支撑、握持/接触、损伤和残余状态；作为下一段 `@图片`，只授权角色世界站位与相互距离，不授权动作、声音、机位、景别、构图、光线或场景内容。

规则：

- 角色图、产品图、场景图控制稳定身份和设计。
- 已接受完整视频用于确认真实剧情和动态状态；静态末尾帧的直接可见姿态/接触先进入观察台账，作为生成引用时仍只控制角色位置关系。
- 使用静态末尾帧时，当前段必须从新的摄影机角度和景别直接切入；场景必须由原场景文字、已验收场景设定或原始场景图重新建立。
- 如果实际生成结果与计划不同，以用户接受的实际画面为准。
- 不要让动作参考视频覆盖角色身份；不要让上一段生成漂移后的脸覆盖原始角色图身份。
- 用户上传的生成视频、审核视频或失败样片默认是“分析证据”，不是新的 `@视频` 生成参考。只有用户明确指定它控制动作、节奏或声音时，才把对应维度路由为生成参考；即使另附静态末尾帧，该末尾帧仍只控制角色位置关系。
- 已接受画面可以只验收到某个剪辑点。剪辑点之后的未接受尾部不进入正史；下一段从剪掉后的最后可见状态继续。
- 用户决定“后期修”时，以修后的预期状态作为下一段正史，例如裁切后的构图、移除字幕后的画面或重新混音后的声音状态，而不是继续继承原始瑕疵。

## 参考图图文冲突规则

如果用户同时给参考图和剧情，先静默检查：

- 主体身份是否一致。
- 年龄、性别、服装、职业是否冲突。
- 地点、时代、天气、光线是否冲突。
- 关键道具、车辆、机器、怪物是否冲突。
- 图片动作状态能否承接剧情。
- 图片构图是否会限制剧情必要动作。

重大冲突时必须先问：

```text
我发现参考图与剧情存在冲突：[具体冲突]。
请你选择：
1. 保留参考图内容，我按图修改剧情描述。
2. 保留剧情内容，我提供新的生图提示词来重做参考图。
```

轻微冲突时可以继续，但要写清只借用有用锚点。

## 音频节奏锁定

当用户上传音频时，必须判断它是哪一种：

- `最终BGM + 节拍网格`：音乐作为最终声音，同时控制节奏。
- `无声节奏参考`：只控制动作、切点和 camera speed profile，不输出为背景音乐。
- `音效参考`：只参考音效质感和冲击点。
- `环境声底`：作为环境声底。
- `声线参考`：作为角色或旁白声线。

提示词必须出现等价语句，默认使用中文可见表达：

```text
音频节奏锁定：@音频1 只是无声节奏参考，只控制节拍网格、动作重音、冲击点、切点和 camera speed profile；不要把该参考音频输出为背景音乐。最终可听声音是现场机器轰鸣、干燥稻秆摩擦和短促静默。
```

如果音频是最终音乐：

```text
音频节奏锁定：@音频1 是最终BGM和节奏参考，只控制音乐节奏和切点重音，不控制角色身份、服装、地点、台词、CUT或camera setup。
```

## 声线锁定

音色有两条实现路径：参数级把 `reference_voice` 挂在对应的 `reference_image`/`reference_video` 子对象上，为多角色对话首选，比在提示词里写更硬；或提示词级在台词句后紧跟「音色参考 @音频N」，且必须与说话动作同句（如 `角色A说：“……”，音色参考 @音频1`）——独立成句的前置式“提取 @音频1 音色特征”不生效。

参考音频或视频人声作为配音时：

```text
声线锁定：@音频1 命名为声线A，是 [旁白/角色名] 的声线参考；负责该角色主描述行中地域/口音、音色、共鸣、音区、语速、重音/停顿/句尾习惯的可听实现，并额外控制参考中独有的 [差异/麦克风质感]，不逐项复述主行已经写清的声音事实。本场疲劳、哭腔、气短、疼痛等生理变量由当前剧情与CUT控制。声线只控制声音，不控制脸、服装、地点或台词内容；内心独白/旁白不让画面角色对口型，除非角色正在画面中说话。
```

角色声音身份与音频素材分成两行，不能把 `@音频` 和角色全文串成一个不可审计的混合锁：

```text
角色声音身份：老张，地域语境为辽宁沈阳，沈阳口音较浓；粗哑洪亮的中低音，胸腔共鸣重；语速中等偏快，重音直接，句尾下沉或上挑，常带东北语气词；本场连续劳动后呼吸略重，嗓音干涩。使用声线A。
@音频1 命名为声线A，控制老张可听的口音、音色、共鸣、语速和表达习惯；本场生理状态与准确台词按当前CUT执行。
```

如果参考人声与用户写明的地域或口音冲突，先确认是保留角色正史并只借音色，还是采用参考人声重设角色声音身份。没有直接证据时不从面孔、服装或职业猜测省市和方言。

```text
@图片1 命名为老人A，控制老人脸型、灰白短发、褪色蓝色外套、佝偻姿态。
```

场景图：

```text
@图片2 命名为大棚窄道场景，控制大棚宽度、金属管网格、塑料薄膜质感和泥泞窄道。
```

视频动作参考：

```text
@视频1 命名为动作参考A，控制 lateral tracking speed、踉跄后恢复节奏和前景遮挡切点。
```

高风险视频参考：

```text
@视频1 命名为动作参考A，只控制 lateral tracking speed 和动作节奏；不控制人物身份、服装、地点、色彩或声音。
```

## 防止参考素材漂移

- 参考图里没有的物体如果必须出现，要写“new object enters this shot”。
- 参考音频是 silent guide 时，后文不能写“使用该参考音乐作为 BGM”。
- 同一角色多段输出时，每段都重复角色锚点，不依赖 GPT 记忆。
- 多张参考图同时存在时，为每张分配唯一职责，避免互相覆盖。
- 锁定名建立后，时间轴用锁定名承接，不把每个 time beat 写成 @素材清单。
- 参考素材默认不显性列出所有排除维度，但内部必须保持维度隔离；一旦发现可能带偏生成，就把具体“不控制什么”写进提示词。
- **状态变化道具（最高优先级）：** 道具在本段内发生不可逆状态变化（完整→破碎、在手→脱手、开→关、满→空、干→湿、点燃→熄灭）时，`【角色/场景/素材锁定】` 只锁它的身份/外观/归属，绝不把某一瞬态写成“开场锚点”或“全片持续锚点”。状态改写为绑定具体 CUT 的「道具状态时间轴」——`初始态@CUT x -> 触发源 -> 末态@CUT y -> 残余态`，时间轴用锁定名承接每个状态（写法参照 `05` 的物理/VFX 变化链与「持续状态与实体退场」）。把“完整瓶在手”锁成段级不变量会压过瞬时“脱手/摔碎”指令，导致道具该消失时不消失。
- **参考图时间状态错配：** 参考图与该道具开场时间状态不一致时（如 `@图片7` 是碎瓶、开场需要完整瓶），参考图只控制它匹配的那个状态；不把两个互斥状态（完整/破碎）融进同一条主描述行。开场态由文字锚点承担，参考图对应到它实际证明的末态/残余态那一拍，并写明该参考只在该 CUT 之后生效。
