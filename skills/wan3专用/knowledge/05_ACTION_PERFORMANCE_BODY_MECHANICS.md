# 05 Action Performance Body Mechanics

priority: high
scope: 动作戏、真人肢体、演员情绪、冲突因果、事故动作、武打、枪战、载具、空战、机甲、怪兽、团队战、表演锚定

## 动作提示词总规则

动作要有：

1. 路线：从哪里到哪里，穿过什么空间。
2. 接触点：身体、道具、机器、地面或对手在哪个点接触。
3. 力量来源：脚蹬地、肩带动、腰拧转、机器惯性、重力、风压。
4. 反击或阻力：对方、环境、道具或身体失衡如何改变动作。
5. 蓄势：高潮前的停顿、吸气、压低重心、举起道具。
6. 后果：倒退、撞击、碎片、沉默、物体位置变化、表情变化。
7. 声音确认：脚步、衣料、金属、呼吸、撞击、低频、静默。

这套规则来自动作游戏提示词的可复用部分，但应用到真人世界时要把雷电、装备、BOSS 替换成身体、道具、空间、声音和沉默。

### 动作动词消歧

以下词不能单独作为可执行动作：

| 模糊词 | 必须补齐 |
| --- | --- |
| 攻击/打击 | 攻击者、身体部位/武器、支撑与力量来源、路线、目标部位、接触或落空 |
| 格挡/防御 | 防守部位/接触面、迎角、力线如何偏转、支撑脚/肩髋承压和恢复 |
| 闪避/躲开 | 移动部位、方向、距离、失去的角度/支撑/主动权和恢复路线 |
| 击退/击飞 | 力量方向、脚是否离地、位移距离、碰撞/落地点和双方反作用 |
| 挣扎 | 哪个关节或支撑点尝试向哪里移动、阻力来源、失败/松脱结果 |
| 压制/控制 | 谁用哪个接触点限制对方哪一关节/路线，控制如何保持或被破坏 |
| 蓄力 | 呼吸、重心、关节预载、武器/能量来源、环境先兆和释放条件 |
| 爆发/释放 | 从哪个身体/武器源头，沿什么介质与路线传播，接触什么边界 |
| 冲击波 | 源头、形状/传播方向、接触面、材质响应、衰减和残余 |
| 恢复 | 身体/武器回到哪个支撑、护架、距离、朝向或可继续动作的状态 |

“快速、猛烈、流畅、有力”只描述观感，不能替代路线、接触和结果。最终动作句使用：

```text
主体 + 身体部位/工具 + 起始支撑 + 路线 + 目标/接触或落空
+ 力量来源 + 承受者反应 + 恢复/新状态 + 同步声音
```

## 武戏三路由

当用户提出武戏、打斗、格斗、决斗、兵器、法术、技能或招式需求时，先静默选择一个主路由：

1. **空手格斗**：拳、掌、肘、膝、腿、摔、拿、地面控制，以及徒手对多人。
2. **武器格斗**：刀、剑、枪、棍、矛、斧、锤、盾、软兵器、枪械近战，以及武器对空手。
3. **能量招式**：气、法术、元素、冲击波、护盾、附魔武器、超能力、变身后技能和原创必杀技。

三类路由是内部检索模块，不改变默认可见输出结构。最终仍使用：

```text
【角色/场景/素材锁定】
【基础风格】
【运镜与时间轴】
【声音设计】
【画面限制】
```

攻击、格挡、接触、反作用、恢复姿态、招式蓄势和能量碰撞必须绑定到对应 `CUT`，写入 `【运镜与时间轴】`；进入实际交锋后，单镜模式使用无时码有序 CUT/BEAT，多镜模式使用 `Resolved Policy.timestamp_policy` 规定的连续时码，但都不要另设 `【打斗提示词】`、`【招式说明】` 或独立 `【动作调度】`。只有用户要求分析、动作设计表或招式拆解时，才显示路由判断或额外动作表。混合战斗只选一个主路由和最多一个次路由，例如“剑术为主、能量附魔为辅”，避免三套复杂度同时争夺模型预算。

所有武戏共用七拍动作因果：

```text
意图 intent
-> 预载/蓄力 preload / wind-up
-> 路径 path
-> 接触、格挡或落空 contact / block / miss
-> 受力反应 force response
-> 恢复或失衡 recovery / imbalance
-> 状态更新 state update
```

七拍是静默因果检查，不是七个 CUT。一个 CUT 可以包含共同服务同一明确变化的多个阶段；只有动作目标、结果承受者或叙事结果改变时才切到下一 CUT。提示词优先保留决定可读性的阶段，不机械罗列术语。

主动防御必须改变力线：盾面倾斜、前臂拨挡、侧身让攻击擦过、武器绑定、车辆侧滑把正撞改成擦碰。闪避必须付出可见代价：失去角度、距离、支撑、资源或主动权。反击必须利用上一动作制造的空门：拳臂过伸、武器被绑定、重兵器落空、车轮失抓、翼面回收、护盾裂纹或技能冷却。

### 无参考长打斗原创编排器

当实际交锋时长 `T >= 12秒`，且用户没有提供动作提示词、分镜、动作参考视频或已验收成片时，禁止先套固定镜序。先静默建立战斗导演账本：双方目标、体型/质量/臂展或武器射程、优势距离、速度与恢复差、初始主动权、伤势/资源、场景中可利用的2-3个真实物理点，以及目标 OUT。

首稿编译前再冻结一张无参考战斗蓝图：

```text
角色差异与胜负曲线
-> 世界拓扑/离散支点/可利用地形
-> 每条交换链的IN状态元组与可见位移路径
-> 接触/落空/反作用/恢复后的OUT状态元组
-> 唯一决定性高潮原子包
-> 轻/中/重/决定性反馈分布
-> VFX源头/附着/传播/接触/衰减状态
-> 每个CUT必须看见的证据与可容纳景别
```

状态元组至少记录：双方世界锚点、距离/高度/深度顺序、身体朝向、支撑脚或承重点、手与武器握点、动作相位/速度、主动权、损伤/装备和残余VFX。相邻元组的差分必须由可见动作或新camera重投影证明，不能只写两个结果。

再原创组装2-3条交换链；每条都必须从上一条 OUT 起步，并至少改变“距离、高度、主动权、装备、环境”中的一项：

```text
交换链 = 进入/试探 -> 防守改线或闪避代价 -> 暴露空门
       -> 反击/压制 -> 双方反作用与恢复 -> 新战斗状态
```

整段只保留一次签名级高潮和一个明确 OUT。宏观弧线可从“试探-惩罚-反制”“追猎-设陷-突围”“压迫-逆转-僵持”“消耗-最后反击-分离”中按剧情选取或原创改写；这些是功能关系，不是固定 CUT、焦段、垂直升降、空中碰撞或结尾对峙模板。必须先完成动作与状态链，再按信息任务选择摄影，不能从某套参考提示词的镜序倒推剧情。

### 动作开场承诺与覆盖加速路由

导演层先判断当前动作场是否需要在开段首个可读节拍兑现 `action promise`。高速开战、追逐、突袭、游戏战斗或高留存动作开场，可立即证明攻击源与目标、双方距离、危险向量、武器/能力或迫近后果中的至少一项；不固定“两秒内命中”，也不为钩子跳过空间关系、预载和因果。决斗蓄势、悬疑、恐怖、情绪反转或空间尚未建立的多人冲突，可用逼近、拔出武器、视线锁定、环境先兆或声音先行建立威胁，把实体接触留给后续节拍。超过3个独立活动主体且轴线/分组不清时，优先执行空间校准全景，再加速交锋。

连续多击只在同一行动者延续同一策略、且前一击的防守/位移/空门直接生成下一击条件时启用，并编译为一个有因果的组合动作单元：`进入或骗防 -> 可读主接触 -> 防守改变力线/暴露空门 -> 后续主接触或反击 -> 双方恢复/失衡与新状态`。按时长和可读性选择少量主接触证据，佯攻、步法、护架回收、衣物和环境反馈可并行辅助；不把互不相关的招式、同级重击或双方独立连招堆在同一 CUT。

快速多角度覆盖只在空间轴线已经清楚、冲突进入升级段、且每次切换新增一种必要证据时触发，例如依次证明空间/距离、动作路线、接触处理和后果；它不是默认的“刺激感”模板。相邻 CUT 用同一动作相位、运动向量、视觉重心或同步声音完成 `match on action` 接力，重算新机位中的人物朝向、screen-left/right、武器功能面和目标；不无理由重复同一次打击，也不从不可读近景直接跳到另一侧破轴。若用户要求一镜到底，把这些信息任务改为同一连续 camera 路径中的景别、角度或焦点交接，不伪造快速切镜。

### 自动研究与套招组装

当角色、年代、兵器、武术体系、能量规则或场景力学需要外部事实才能写准，且网络可用时，允许自动检索；优先博物馆/馆藏、体育管理机构或训练组织、制造商技术资料、摄影师/特技团队一手访谈、官方VFX文档等原始来源。研究只提取当前剧情所需的执行差量：

- 兵器：尺寸、材质、重量/重心、握法、刃口/功能方向、有效距离、惯性与恢复窗口。
- 套招：进入、支撑、发力链、路径、接触/落空、对手处理、双方反作用、恢复；只组合可读的舞台化交换，不输出面向现实伤害的优化指南。
- 能量特效：源头、承载介质、形成、传播、接触、材质响应、余波、消散与残余状态。
- 运镜：摄影任务、起点、路径、速度曲线、主体保持、接触前稳定、接触后反馈、终点构图与接力。

研究结果要按角色体型、戏剧目标、场景和模型容量重新编排；不得复刻外部作品的完整套招、标志性镜序、角色或招式名。没有网络时使用本文件的通用物理路由，在静默台账标记未核验，不伪造出处；只有该事实会阻止安全/正确出稿或用户明确索要核验状态时才对外说明。

动作密度按可读性控制：

- `3-5秒`：一个主要招式或一次攻防接触。
- `5-8秒`：一条短交换链，通常包含进攻、格挡/闪避、一次反击。
- `8-12秒`：两到三个清楚的攻防节拍，中间必须有重新站位或短恢复。
- `12-15秒`：三到五个简单节拍；如果包含多人、复杂兵器、近脸身份或强特效，减少到两到三个节拍。
- `多镜模式`：Tmax=30秒；把多个连续、同空间、同主冲突的交换链组织成清楚阶段，每个阶段仍遵守接触、反作用、恢复和状态更新，不因容量增加而堆满无关连招。
- 每个 beat 只设一个主要接触目标；不要让两名角色同时执行互不相关的复杂连招。

这些秒数先用于静默容量规划。实际交锋按镜头结构输出：单镜模式使用无时码 `CUT 1 / CUT 2 / ...`，亚秒节奏只留在静默账本；多镜模式读取 `Resolved Policy.timestamp_policy`，默认优先连续整秒边界，例如 `CUT 1（0-2秒） / CUT 2（2-5秒） / ...`，项目明确要求时允许合理小数秒或 `Frame T`。备战、对峙、无交锋追逐、救援、事故或表演动作通常使用无时码 CUT；但多镜模式内容命中 `06` 的长段节奏门时，即使无实际交锋也改用全部 CUT 连续时码，粒度仍由已解析策略决定。

这些区间是容量上限参考，不是必须占满的时长。单次攻防、单个动作或单个反应一旦路线、接触和结果已经可读就立即进入下一变化；不为展示完整招式而拉长剧情节奏。对话存在时，能在自然发声条件下完成的走位、递物、防备、视线和低幅反应优先发生在台词之下。

## 打戏镜头结构时码覆盖

只要当前独立段包含至少一次实际攻击与防守/闪避、武器或枪弹接触、载具/机甲/怪兽对抗性碰撞、能量攻击与反制，就执行：

1. 先确定 `Tmax`（Wan3.0 Tmax=30秒，duration 参数 2–30 或 -1，默认 5），再按动作密度选择准确总时长 `T <= Tmax`；不把时长区间直接交给模型。剧情足够时优先把兼容动作链打包到接近 `Tmax`，动作链较短时选择更短的准确时长，不拉长单个动作填满。
2. **单镜模式可见输出**：只用 `CUT N` 固定攻防顺序；不写 CUT/BEAT 起止秒数、`第N秒`、`N秒后`或小数秒接触点。一镜到底使用 `CUT 1` 与无时码 `BEAT A/B/C`，并在提示词写明「生成单镜头」或「一镜到底」（`shot_type` 参数已取消，只能靠提示词声明）。静默层仍以亚秒精度核算预载、路径、接触、反作用和恢复，外显时用 `开段/中段/接触前最后半拍/CUT末端` 锁定相位。
3. **多镜模式可见输出**：准确总时长 `T` 和全部 CUT/BEAT 边界读取 `Resolved Policy.timestamp_policy`。`integer-preferred` 默认优先整秒但小数本身不构成错误；`decimal-allowed` 允许项目需要的合理小数秒或帧事件；`integer-required` 只在项目明确要求纯整秒时启用。所有策略都从 `0秒` 开始，把 `0-T` 全部分配给可见 CUT，相邻区间首尾相接、单调递增、无空档、无重叠、无倒序，最终 CUT 结束时码与段落标题一致。帧事件写 `Frame T` 并读取已解析fps，默认24fps；避免不服务动作或声音定位的无意义过精度。
4. 关键接触、枪响、爆点或反击需要更强定位时，多镜模式可在所属 CUT 内写符合已解析粒度的时间点、`Frame T` 或相对相位；单镜模式只使用相对相位。不要另起游离的“某动作持续1秒”动作表，也不要用时间戳表达“一秒攻击三次”之类频次。
5. 每个 CUT 仍只承担一个明确变化。单镜模式通常把七拍因果压入 3-6 个 CUT，不按七拍机械拆成七镜；多镜模式不继承 3-6 个 CUT 上限，可把同空间、同主冲突的多条连续交换链按明确变化扩展为更多 CUT。两模式都必须给路径、接触、反作用、恢复和状态更新留出可读时间；多镜模式时码只约束发生顺序，不用于堆入无关连招。
6. 预载、路径、接触、受力与恢复都必须获得可读画面时间。高速不是删除反作用；关键打击至少让接触前路径、接触点和接触后位移在所属区间内按顺序出现。
7. 一镜到底打戏中，单镜模式写无时码 `CUT 1` 与有序 `BEAT A/B/C`；多镜模式写 `CUT 1（0-T秒）`，内部 BEAT 再按已解析粒度用连续区间覆盖整段。
8. 台词、呼吸、枪声、金属声、撞击声和 VFX 触发跟随同一镜头结构时序：单镜模式绑定 CUT/相位，多镜模式绑定符合已解析策略的区间、时间点或帧事件；声音桥可以跨 CUT，但不制造顺序倒置、时间重叠或未分配空档。

逐 CUT 先做动作耗时账本，再写时码：

```text
T_combat_min = 预载 + 运动路径 + 接触可读 + 双方受力/反作用
             + 恢复 + 必要重定位 + camera travel/settle
             + 必须串行的VFX形成/传播/接触/消散读取
```

同时发生的攻击者反震与防守者受力取最长并行轨，不重复相加；必须先后发生的预载、路径、接触和恢复按串行相加。若总账超过 CUT 区间，先减少动作层、缩短装饰性运镜、迁移恢复或拆分交换链，不能只压缩时间戳或删除接触后的反作用。

慢动作只放大已经可读的决定性相位。默认整段最多一次，除非用户明确要求多次：

```text
实时预载/路径 -> 在接触前窄窗口降至35%-50%速度
-> 实体接触或明确能量边界接触 -> 接触后才触发主VFX
-> 双方反作用/重力/碎屑继续 -> 恢复实时速度 -> 恢复与新状态
```

慢动作不能冻结重力、粒子、衣料、毛发或环境反应。VFX按 beat 分配，亮度、粒子、声音、动态局部光和材质残余同步衰减；不得在蓄势阶段提前出现本应由接触产生的爆发结果。

## 可见主体任务图

- 每个 CUT 先指定一个主行动者、一个响应者和一个主要接触点；其他可见人物只做低强度支援、观察、避让、准备或后果反应。
- “所有主体都在动”不是目标。固定建筑、地面、摆放道具和机械固定部件保持固定；可移动主体必须因剧情刺激才改变任务。
- 危险被确认前，后景人物可以维持日常劳动或交谈；危险被确认后，任务应转为停手、回头、让路、寻找出口、准备救援或防御，但不能抢先完成主角未来动作。
- 同一 CUT 内多人精确动作过载时，按波次处理：主行动者完成当前路线，响应者处理接触，第三人只在后景准备或下一 CUT 再进入。

## 道具拓扑与物理状态

重要道具、容器、机器和武器先锁定：绝对尺寸、所属者、左右手/握点、连接部位、开口方向、固定件、可动件、接触面和必要空气间隙。

- 拿起道具必须经过：初始分离 -> 手接近 -> 接触 -> 握紧/承重 -> 物体离开支撑面；不能从远处瞬间粘到手上。
- 释放/脱手/放下/交出/抛出必须走对称分步链：握紧 -> 手指逐根张开 -> 物体离掌 -> 自由下落/交出/被接住/抛出 -> 触地或到达接收方 -> **承载手进入空手新状态（写明手臂位置、五指张开、掌心朝向）**；不能让物体从手中瞬移消失或仍粘在掌上。释放类动作的“空手末态”必须作为该 CUT 的可见 OUT 锚点显式写出（例如摔瓶后 OUT 既写“碎瓶停在地面”，也必须写“右手已空、五指张开、手臂垂落”），否则段级锁定的“完整瓶在手”会压过瞬时脱手指令，导致道具该离手时不离手。
- 容器、门、抽屉、机械舱体必须写清“里面/外面、开/关、固定/移动、谁穿过哪个开口”，避免物体穿模或拓扑互换。
- 物理/VFX 变化按：初始状态 -> 触发源 -> 承载介质 -> 路径 -> 边界/接触 -> 最终状态 -> 残余状态。发生不可逆状态变化的道具（完整→破碎、在手→脱手、满→空、干→湿、点燃→熄灭）按此链绑定到具体 CUT，锁定区只锁身份/归属，不把某一瞬态写成贯穿全段的不变量（详见 `01` 冷启动契约与 `02` 状态变化道具锁定）。
- 能量动作按：身体/武器来源 -> 蓄势 -> 实体接触或阻挡 -> 环境材质反应 -> 双方反作用 -> 残余状态。脆弱生成中每段只保一个主要特效事件。

精确武术、兵器套路或复杂招式优先使用动作参考视频。参考视频默认只控制动作路线、发力节奏、接触时机或运镜中的已指派维度，不覆盖角色身份、服装、地点、色彩、剧情和声音。输入动作参考需要满足：主体清楚、全身关键关节可见、动作连续、无剪辑跳变、速度不过快、接触关系可判断。

### 板块一：空手格斗

空手格斗的核心不是“快速”，而是攻击者与防守者之间清楚的 `attack-response`。每次交换先回答：谁发起、从哪一侧进入、攻击哪一点、对方如何处理、力向哪里传递、双方如何恢复。

#### 空手动作账本

```text
STANCE / GUARD：站姿、前后脚、护架、双方距离。
ENTRY：进攻者从哪一侧、哪一深度层进入。
FORCE CHAIN：脚蹬地 -> 髋转 -> 躯干 -> 肩/肘/腕或膝/胫骨。
ATTACK PATH：写明攻击主体及其参照系，例如拳/脚/武器相对攻击者自身的直线、圆弧、由低到高、由高到低、抱摔或扫动轨迹。
DEFENSE：格挡、拨挡、闪身、下潜、后撤、抱架或破坏平衡。
CONTACT POINT：拳面、掌根、前臂、肘尖、膝、胫骨、肩、髋或抓握点。
REACTION：头/肩/躯干/脚步沿受力方向反应。
RECOVERY：攻击肢体收回、支撑脚重新落位、护架恢复、距离重建。
```

#### 风格路由

| 风格 | 发力与距离 | 可执行动作语言 | 稳定性限制 |
| --- | --- | --- | --- |
| 拳击 | 中近距离，脚步与髋肩旋转 | 刺拳试探、直拳贯穿、勾拳圆弧、下潜闪躲、护架回收 | 一次只写短组合；每拳必须收回护架 |
| 泰拳 / 踢拳 | 近距离肘膝、胫骨扫踢、箍颈 | 前手控制距离、髋部前送、膝击、转髋低扫、前臂架挡 | 不把扫踢写成无支撑旋转；接触后写支撑脚与恢复 |
| 功夫 / 咏春式近身 | 中近距离，中心线与短促连贯发力 | 拨手改线、短桥接触、掌击、低位踢、贴身转角 | 避免空泛“行云流水”；写清哪只手控制哪条攻击线 |
| 空手道 | 线性进入、扎实站姿、短促爆发 | 前脚踏入、直拳、手刀、前踢、动作后定势 | 避免连续无恢复高速攻击；保留清楚停顿与收势 |
| 跆拳道 | 中远距离、弹性步法、腿法主导 | 支撑脚旋转、高位踢、后旋踢、落地重建距离 | 空中动作一次一个；落地脚与身体朝向必须明确 |
| 柔道 / 摔跤 / 综合格斗 | 贴身抓握、破坏重心、站立到地面转换 | 抓领/腕、髋部进入、腿部拦截、抛物线摔落、地面控制 | 写清抓握不松手、落地顺序和双方最终位置 |

#### 空手格斗规则

- 攻防不能同时模糊发生。先写攻击路线，再写防守处理，再写反击。
- 击中不是终点：受击者要沿力线后退、转肩、屈膝、失衡或护架吸收；攻击者也要出现拳臂回收、支撑脚制动或身体反震。
- 多人战斗用波次或编号：对手A先进入、主角解决当前路线、对手B再从另一方向施压。不要让三个人同时做精细动作。
- camera setup 与 shot size 优先保留完整身体关系。关键接触才切 CU/ECU；复杂脚步和摔法优先用 MS/WS。
- 手持晃动不能掩盖动作错误。每个 beat 只保留一个主要运镜，冲击时只用短促震动并立即恢复可读画面。

#### 空手格斗案例：雨夜泰拳近身交换

```text
【角色/场景/素材锁定】拳手A位于 screen-left，黑色短裤，沉稳防守；拳手B位于 screen-right，红色短裤，主动压迫。雨夜街边摊，湿地面；后景围观者沿世界空间中的摊位两侧退让，为两人之间的主交换线留出两米宽空区。

【运镜与时间轴】CUT 1（0-2秒），中景 `lateral tracking`，摄影机与两人平行向 screen-left 移动并维持双人中景。B由 screen-right 沿两人交换线压向A，以自身左拳直线刺向A面部；A自身右脚后撤半步，自身右前臂向外拨开拳路，双方距离缩短到肘膝范围。CUT 2（2-5秒），A自身左手扣住B后颈形成单侧箍颈，髋部前送，自身右膝由下向上撞向B腹部护架；第4秒膝部接触双肘护架，B上身后弓，鞋底沿受力方向滑退半步，水花同向喷开。CUT 3（5-8秒），B以自身左前臂顶开A锁臂并退出；A完成一次外侧低扫踢，支撑脚转动、髋部带动胫骨接触B外侧大腿，随后立即收腿恢复护架。两人沿交换线拉开到安全距离，A抬起双拳调整呼吸，B重置支撑脚并收紧护架。

【声音设计】无背景音乐；雨声、鞋底摩擦、护臂碰撞、膝击闷响、低扫接触声；声音严格落在可见接触帧。

【画面限制】无字幕、无水印、无乱码文字；人物身份稳定，面部、身体和手部结构自然完整。动作链固定为试探、拨挡、箍颈膝击、脱离、一次低扫；A保持 screen-left、B保持 screen-right；接触后呈现受力反应和护架恢复。
```

### 板块二：武器格斗

武器格斗先锁定武器，再设计动作。兵器不是发光附件，而是有长度、刃口、握法、重心、惯性、回收时间和碰撞材质的实体。

#### 武器连续性账本

```text
WEAPON ID：武器种类、长度、材质、颜色、磨损和唯一性。
HAND LOCK：单手/双手、主手/副手、握持位置、是否换手。
EDGE / POINT：刃口、刀尖、枪尖、棍端或枪口的朝向。
RANGE：近、中、远距离及安全间隙。
WEIGHT / INERTIA：挥动弧线、加速、制动、回收时间。
CONTACT：兵器对兵器、兵器对护具、兵器对环境的接触点。
COUNTERFORCE：反弹、滑刃、卸力、卡住、脱手风险或盾面偏转。
RECOVERY：武器回到警戒位，手腕/肩膀吸收反震，脚步重新站稳。
INVARIANTS：武器不消失、不复制、不变形、不无故换手，固定部件保持连接。
```

#### 武器类型路由

| 武器 | 主要力学 | 可执行动作语言 | 常见失败修复 |
| --- | --- | --- | --- |
| 刀 / 剑 | 刃口方向、挥砍弧、刺击直线、格挡反弹 | 双手握柄、前脚踏入、斜劈、横挡、滑刃、转腕短反击 | 刀光不能代替实体刀刃；碰撞后两把兵器沿相反方向反震 |
| 匕首 / 短兵器 | 极近距离、手腕控制、抓腕与身体遮挡 | 前臂贴身、控制持械腕、短刺路线被改线、肘部锁定 | 避免高速乱刺；明确持械手和另一只手的控制任务 |
| 长枪 / 长矛 | 枪尖距离、前后手导向、直刺与大范围横扫 | 后手推送、前手导向、枪尖直线进入、收枪重建距离 | 不让长兵器像短棍贴身乱挥；保持枪杆长度和枪尖朝向 |
| 棍 / 杖 | 两端均可用、躯干旋转、连续圆弧 | 双手分握、横扫、上挑、换端、棍端撞击地面 | 不写无身体来源的高速旋转；双手与棍身连接持续可见 |
| 斧 / 锤 / 重兵器 | 大惯性、长前摇、强后果、明显恢复窗口 | 双脚扎稳、双手举起、肩背带动下降弧、落空后武器拖拽身体 | 不能拥有匕首速度；必须写长制动和落空惩罚 |
| 盾牌 | 面积防御、角度偏转、推撞与视线遮挡 | 盾面斜置卸力、前脚踏入、盾缘推撞、武器从盾侧反击 | 盾牌不能贴在身体上无反应；冲击要传到肩与脚步 |
| 枪械近战 / gun-fu | 枪口方向、弹数、后坐力、空手控制 | 枪口只指向当前目标，空手格挡或控制持械腕，射击后肩部反冲 | 不增加无来源弹药；不让枪穿过手掌或身体；复杂敌人按编号处理 |

#### 武器格斗规则

- 先锁左右手和屏幕方向，再写格挡、换手或缴械；任何换手都必须在画面中完成。
- 武器重量决定节奏。轻兵器可短促变线，重兵器必须有长前摇、惯性和恢复窗口。
- 兵器碰撞需要材质结果：金属火花和高频鸣响、木棍闷响与纤维碎屑、盾面低频震动、石面划痕或水花。
- 刀剑不默认造成血腥。可以用衣料被割开、竹叶断裂、刀锋擦过护甲、火花、尘土和角色停顿表现危险。
- 精确套路优先用 `@视频` 动作参考；故事板只控制镜序、轴线和位置，不替代兵器细节参考。
- 长兵器、重兵器与缴械接触使用“接触见证包”：同一可读画框或同一不间断camera path必须连续证明 `持有者身份/前后手握点 -> 连续杆身 -> 功能端或被施力柄段 -> 命名接触面/支点 -> 反力方向 -> 双手与武器恢复/脱手顺序`。优先侧斜MLS/WS，避免让杆身沿光轴端视缩成短兵器；若门柱、石阶或地面成为杠杆支点，按武器一端到另一端列出斧头/枪尖、双手、支点、柄尾的沿杆次序，并说明法向夹持与切向旋转分别来自哪里。

#### 武器格斗案例：参考视频驱动的竹林剑术

```text
【角色/场景/素材锁定】
@图片1 命名为剑客A，只控制身份与服装。
@图片2 命名为剑客B，只控制身份与服装。
@视频1 命名为动作参考A，只控制拔剑、格挡、转腕反击的动作路径和节奏。
竹林、摄影机、声音与胜负按本文执行；两把武器的长度、握法和角色自身左右手在本段内连续一致。

【运镜与时间轴】CUT 1（0-2秒），双人MLS，机位位于双方连线外侧并同时看清脚步、握点和两把兵器。剑客A由 screen-left 向 screen-right 完成一次斜向下劈；肩、肘、腕依次传力，实体刀锋路径清晰。剑客B后撤右脚并抬剑形成交叉格挡。CUT 2（2-3秒），区间开端两把实体刀锋在画面中央接触，短暂 slow motion；两把剑因碰撞向相反方向弹开，双方手腕和肩部出现反震。CUT 3（3-6秒），剑客B依照动作参考A的转腕路径完成一次短促反击；剑客A侧身避开，刀锋从胸前安全距离掠过并割断一片前景竹叶。结尾两人重新建立距离，两把武器回到警戒位。

【声音设计】无背景音乐；最终声音层由竹林风声、脚踩落叶、两次金属接触、衣料摩擦和短促呼吸构成。

【画面限制】无字幕、无水印、无乱码文字；人物身份稳定，面部、身体和手部结构自然完整。动作密度固定为一次主攻击、一次格挡、一次反击；每人各持一把结构完整、材质稳定的武器，握持手和刀锋方向全程连续。
```

### 板块三：能量招式

能量招式必须建立在可见身体动作和世界规则之上。能量是力量路径的放大器，不是替代身体、接触和后果的装饰层。

#### 能量招式账本

```text
TECHNIQUE INTENT：招式要改变什么冲突状态。
BODY SOURCE：脚、髋、躯干、手臂、呼吸、武器或变身核心如何启动。
ENERGY SOURCE：体内、环境、道具、元素、机械核心或外部法阵。
CHARGE-UP：站姿、手势、呼吸、光线、声音和环境的蓄势变化。
SHAPE / PATH：球、刃、束、环、流体、场域或附着层，以及运动方向。
RELEASE：能量何时离体或沿武器/身体释放。
COLLISION / COUNTER：命中、被挡、偏转、吸收、抵消或落空。
MATERIAL RESPONSE：尘土、水、衣料、金属、玻璃、植被和光影如何响应。
RESIDUAL STATE：残余电弧、余烟、熔痕、霜、失效护盾、暗下的核心或恢复姿态。
```

#### 招式类型路由

| 类型 | 物理锚点 | 稳定写法 |
| --- | --- | --- |
| 身体强化 | 肌肉、呼吸、步法、皮肤/护甲反应 | 能量沿身体局部增强，动作仍由脚、髋和躯干驱动 |
| 武器附能 | 握法、刃口/枪尖、武器材料 | 先锁实体武器，再写能量沿刃口或枪尖聚集；实体接触与能量后果分开 |
| 远程投射 | 手掌、武器、核心的发射方向 | 一次一枚主要投射物，起点、路径、目标、碰撞和残余状态明确 |
| 护盾 / 场域 | 固定中心、边界、朝向、承压点 | 护盾先形成边界，再承受冲击；写形变、裂纹、滑退或失效，不写无代价绝对防御 |
| 元素控制 | 环境中真实水、火、风、土、冰、雷 | 元素必须影响附近材质、光线、空气和声音，并服从明确方向 |
| 瞬移 / 高速位移 | 起点、消失机制、可见路径、落点 | 优先用短距离冲刺、残影或遮挡解释；落点和身体朝向必须重新锚定 |

#### 能量招式规则

- 每个 beat 只保留一个主特效事件。聚能、释放、碰撞、余波按时间发生，不同时堆满全画面。
- 主特效按六阶段静默检查：`源头 -> 形成 -> 传播 -> 接触 -> 余波 -> 消散`。形成阶段写轮廓/材质，传播阶段保持连续路径，接触先显示接触点，消散时亮度、粒子、声音和环境反光同步衰减。
- 招式必须有代价或窗口：蓄势时间、站姿暴露、能量衰减、护盾裂纹、呼吸紊乱、武器过热或恢复停顿。
- 能量轨迹不能代替实体接触。近战附能同时写“武器/肢体接触点”和“接触后出现的能量结果”。
- 对手必须有处理方式：闪避、格挡、偏转、吸收、打断、逼近或利用蓄势窗口；不能被动等待必杀技。
- 原创招式用功能、形状、色彩、材质反应和节奏描述；避免依靠受保护角色、招式名或系列标识。
- 真人电影感优先使用局部光照、空气折射、尘土、水雾、衣料和材质反应；减少满屏游戏 UI、无来源粒子和持续曝光。

#### 能量招式案例：原创“雷折·三段”

```text
【运镜与时间轴】CUT 1（0-2秒），低机位中景。主角右脚向后踏实，重心降到髋部，右手收至肋侧；白蓝电弧沿前臂聚集，衣摆和地面灰尘向身体内侧吸拢，形成清晰蓄势。CUT 2（2-4秒），第3秒对手从 screen-right 直线突进并挥出重拳，主角左前臂斜向格挡，使拳路偏离面部；接触处出现一次短促白蓝闪光，双方肩部同时产生反作用。CUT 3（4-6秒），第5秒主角借格挡形成的躯干旋转完成一次右掌反击，掌根接触对手胸前护甲；电能在实体接触后向外扩散成三层递减冲击环。对手沿原突进路线反向滑退，主角前脚制动，右掌回收到护架，胸口随呼吸起伏；结尾护甲表面游走少量残余电弧。

【声音设计】无背景音乐；蓄势阶段是逐渐收窄的低频电流和呼吸；格挡是短促护甲撞击；掌击接触后才出现一次低频冲击，随后回到风声和残余电弧噼啪声。

【画面限制】无字幕、无水印、无乱码文字；人物身份稳定，面部、身体和手部结构自然完整。招式只有一次决定性接触；能量始终源自主角前臂，经格挡接触与掌击接触依次传递，冲击环和残余电弧服从身体发力、接触顺序和护甲材质。
```

### 战斗特效显著度与可见结构

战斗特效只服务动作因果和冲突升级。先静默选择本段最高显著度，再把效果写回对应 CUT；显著度是模型预算，不是可见的 `S/A/B` 等级。

| 显著度 | 叙事职责 | 可见预算 |
| --- | --- | --- |
| 辅助效果 | 证明速度、接触或材质 | 一处短促局部变化，例如接触火花、刀锋冷光、鞋底尘线或护甲局部反光；摄影机不为它另起强调 |
| 主要效果 | 改变一次攻防关系 | 一个清楚的源头/承载体、传播或接触路径，以及一到两种附近材质响应；可使用一次匹配受力方向的摄影或声音确认 |
| 决定性效果 | 改变胜负、空间结构或战斗阶段 | 完整源头、形成、传播、接触、环境连锁和可见残余；摄影、动态局部光和声音可共同升级，但整段通常只出现一次 |

需要表现可见体积或层次时，按下列句法编译；只保留当前效果真实需要的层，不机械凑齐三层颜色：

```text
身体/武器/环境源头 + 承载介质
-> 核心/主体流动层/衰减外缘（按需）
-> 传播路径与接触边界
-> 动态局部光 + 材质响应
-> 亮度、粒子、声音和残余同步衰减
```

- 金属：高光沿曲面移动，接触点出现局部火花、热色或刮痕，反射强度随效果衰减。
- 水/积水：先出现对应方向的反射，再出现波纹、飞溅、蒸汽或结冰边界。
- 尘土/烟雾/水雾：沿压力或传播方向被推开、卷入或留下空腔，不能平均向四周装饰性喷散。
- 布料/头发/植被：先承受风压或冲击，再以不同惯性回摆；摆动方向服从力线。
- 石材/玻璃/木材：裂纹、缺口、碎屑或纤维从真实接触点开始，数量与冲击级别匹配。

优先写模型能直接生成的光学与物理结果，不把 `ray tracing`、`fluid simulation`、`SSS`、`PBR`、`8K` 等渲染术语当作每镜必填开关。只有用户指定 CG 管线、产品技术展示或该术语能消除明确材质歧义时才保留。

## 扩展动作场景物理适配器

武戏三路由负责拳脚、兵器和能量招式；下列适配器负责承载这些动作的特殊物理环境。静默选择最多一个主适配器，必要时再叠加一个武戏主路由。例如“机甲持剑对怪兽”可用 `重型机甲`主适配器 + `武器格斗`主路由，不把所有类型词都写进可见输出。

| 适配器 | 必须锁定 | 【运镜与时间轴】执行重点 |
| --- | --- | --- |
| 远程枪战 | 射手、目标、掩体、射线、枪口方向、弹数/换弹、后坐 | 先用可定位景别交代射手-掩体-目标；枪口只指向当前目标，射击后肩/手臂承受后坐，命中碎屑沿弹道方向；枪声或碎屑可跨空间接力；摄影机在射手后方时显示射手背面/斜背面和背离摄影机的枪口，只有目标侧反拍才允许枪口沿射线朝向摄影机 |
| 载具追逐/车战 | 车道、速度、朝向、轮胎抓地、悬挂、驾驶关系 | 加速写车身抬头，制动写前倾；漂移先重量转移、后重新抓地；碰撞改变车架/悬挂/路线；用低机位 `lateral tracking`、位于车头前方并倒退的 `lead tracking`，或固定焦段的长焦 `lateral truck` 显示距离变化 |
| 空战/飞行 | 高度、地平线、推力/升力、滚转/俯仰/偏航、转弯半径 | 俯冲和转向由姿态与推力产生；悬停有持续下洗；受阻后偏航/失速并修正；近距缠斗后用地平线、云层或地面参照重建高度 |
| 重型机甲/巨型单位 | 绝对尺度、承重关节、液压/伺服、脚掌/履带支点、推进方向 | 启动慢半拍、落点和急停有重量延迟；受击先局部形变再传到躯干与支点；摄影机运动略慢于启动并用人物/建筑/栏杆确认尺度 |
| 生物/怪兽 | 解剖、肢体数量、关节方向、肌肉/骨骼支点、爪/口/尾/翼攻击源 | 咬抓扑甩先给呼吸、肌肉或关节预载；大型生物慢启快落，伤势影响对应肢体；保持头、爪、尾和目标关系可读，不用无动机咆哮特写打断路线 |
| 团队/多战线 | 每组目标、主副战线、各自行动轴、高度/距离、跨线事件 | 每次只让一到两个动作主体成为主要信息；介入前先显示观察和进入路径；用视线、声音、投射物或冲击波跨线接力，汇合时用较宽中景重新交代多人关系 |
| 混合类型 | 本段主类型、一个必要副类型、共享场地和现实主光 | 主类型决定动作与摄影预算，副类型只补必要物理；分别记录角色/载具/高度/装备状态，用一个共享事件汇合，避免多套规则同时争夺画面 |

### 生物与威胁物理路由

先定义生物的解剖、尺度和支点，再设计揭示与攻击；怪物名称不能代替运动规律。

| 类型 | 运动与支点 | 接触/受力规则 | 可读环境与声音证据 |
| --- | --- | --- | --- |
| 地景巨物 | 山体、岛屿或地平线般的主体以构造运动缓慢启动，接触地面的巨大区域是主支点 | 局部先动，力量延迟传遍全身；人物或建筑只作为尺度参照 | 地平线形变、大片阴影扫过、尘浪迟到；超低频呻吟与地面隆隆 |
| 群猎捕食者 | 每只生物有明确入口、包围弧和逃生缺口，不随机满屏乱跑 | 一只诱导、另一只封路；扑击落空会暴露侧面或失去支撑 | 爪刮、密集短促叫声、草木沿群体主方向倒伏 |
| 甲壳重兽 | 甲片、关节缝、足部和武器肢是独立力学区域；转身有惯性延迟 | 打击先改变局部甲片或关节，再传到躯干和足部 | 金属/硬壳刮擦、重踏低频、碎屑从真实接触点飞出 |
| 寄生虫群 | 群体沿表面、缝隙或液体边界波状传播，密度和主方向明确 | 单体接触小，群体通过覆盖、阻塞或侵入改变局势 | 密集爬行声、湿黏摩擦、表面逐区起伏；身体反应先于完整揭示 |
| 神圣/超自然生物 | 节奏平静、近乎无人的规律；异常颜色或静默是规则例外 | 不靠随机高速证明力量；环境先让路或停止，再发生一次决定性动作 | 环境声抽离、低沉共振、局部例外色反光、尘水逆常规移动 |
| 机械有机混合体 | 伺服、液压、湿组织和硬壳各有独立启动延迟与故障点 | 机械关节承重，软组织缓冲；受击先在一个材料层产生结果 | 伺服啸叫叠湿重呼吸、油液/体液沿重力流动、故障火花来自损坏处 |
| 不可见力量 | 没有可见身体，以受力对象、尘、水、衣料和压力波证明路线 | 力量必须有来源方向、传播范围、接触边界和衰减 | 声音先收窄或静默，随后出现定向低频脉冲和环境形变 |
| 迁徙兽群 | 群体有主方向、队列密度、边缘个体和避障规律 | 个体相撞会形成拥堵点，整体路线只因真实障碍改变 | 脚步/甲壳声形成层次，尘尾沿迁徙方向延伸，俯拍显示非随机流线 |

### 打斗视觉覆盖与环境回收条件门

只在多 CUT 强动作、用户要求更丰富机位、道具密集环境、非对称尺度对抗，或已生成结果退化为长时间平视侧拍/相似覆盖时触发。它不规定固定 CUT 数，不要求每镜同时改变全部摄影参数，也不取代“每个 CUT 只承担一个明确变化”。

#### 地理不变量、覆盖拓扑与动作坐标

- 先锁地理不变量：双方世界锚点、朝向、行动轴、压力推进路线、固定地标和允许的越轴/轴线重建条件。动作轴同侧是摄影机可移动的半空间，不是固定侧面机位。
- 再设计覆盖拓扑：每个主要动作 CUT 静默回答摄影机位于哪里、采用什么高度/距离/方位、沿什么路径运动、跟随谁或哪个接触点、由什么动作触发、要证明哪一条新信息。
- 相邻主要 CUT 比较 `camera方位 + 高度 + shot size/距离 + 运动路径/跟随对象 + 摄影证明任务`。若其中多数相同且没有新增空间、意图、接触或后果证据，合并或重设计；需要明显覆盖变化时，在地理连续成立的前提下至少改变两项可见属性。动作匹配、接触 insert 或后果回收镜可以有动机地保留更多共同属性，不机械追求变化。
- 高张力动作可以让刀线、身体冲势、翻转或受力弧线驱动画面上方向，形成有动机的 `roll / pitch / yaw`；倾斜必须继承动作向量、眼线和行动轴，并在接触后果或节奏刹车处稳定。随机荷兰角、全程倾斜和与力量方向无关的旋转不构成丰富运镜。
- 整条交换链先定压力路线：谁从哪个世界锚点把谁逼向哪里，哪次格挡/失衡/环境利用造成反转，最终距离、朝向、支撑、武器线和主动权落在哪里。摄影机沿这条压力变化选择覆盖，不独立炫技。
- 每个主要动作 CUT 再锁一条 `primary relation axis`：行动者/武器/载具通过哪条路径作用于哪个人物、道具或空间，并把距离、接触、遮挡、支撑、持有或主动权改变成什么。连续多拍可以共处一镜，但必须共同推进这条关系轴；目标、作用对象或结果承受者改变时另起 CUT。
- 接触、格挡、搭刀、瞄准、压制或终结姿态一旦达到可读证明状态，立即写出 `exit condition`：分离、偏转、回护、失衡、抢入、撤出或继续位移，并进入新的空间/战斗状态；不得让已经证明的姿态占满剩余区间。
- 移动摄影期间维持 `frustum retention`：至少一名预定主体、武器/载具运动轨迹、受力材料、方向明确的影子或尘线留在画框中承载因果。除非导演明确需要空镜，主体与全部因果痕迹同时离画属于跟随脱靶，不用空通道替代动作结果。

#### 环境状态机与因果插入

- 从场景已有物中选择少量真正可用的地面介质、门柱、桌椅、台阶、悬挂物、蒸汽/水源或易碎物；每项按 `初始状态 -> 被观察或受力 -> 被利用 -> 新状态 -> 改变路线/高度/视线/主动权 -> 可见后果`推进。
- 环境破坏和位移跨 CUT 累积，不能在下一镜恢复完好。每个 CUT 只保留能证明当前动作方向、接触强度或战术变化的环境反馈。
- 鞋底、握点、眼神、悬挂物、易碎物等短 insert 必须承担铺垫、测量、转向或回收任务，并在后续 CUT 被动作、声音或结果接收；删除后不影响因果的装饰特写不占生成预算。

#### 重点命中的表演确认

- 只为承担叙事转折或节奏峰值的重点命中增加完整确认：接触点局部压缩/偏转沿头肩、脊柱、髋部、护架和脚底传播；攻击者同时出现制动或反震；景别与遮挡允许时，受击者用与力向匹配的眼睑收紧、下颌偏转、视线短暂脱锁、骤然吐气或护手延迟回收确认注意力被打断。
- 接触主音、衣料/护具声、呼气或痛声、脚底位移和空间回响与同一可见接触同步；随后必须恢复、失衡或进入新的战斗意图。普通擦碰使用简化反馈，不把每次接触都升级成长 hit-stop、表情特写和完整音效套组。

#### 非对称尺度摄影

- 一方明显更大或结构非人时，以较小角色作为持续摄影锚点，允许巨物的手、前臂、头颈、胸腹、足部或攻击器官局部压入画框；只在尺度首次建立、显著升级或空间关系必须重置时使用必要的少量全貌/关系宽景，不强求双方全身持续同框。
- 覆盖任务按接触局部、巨物运动机制、小角色反应/POV、尺度关系和后果分配；相邻 CUT 仍继承同一地标、攻击方向和距离变化。尺度用相对身体/建筑锚点、支撑点数量、腹部高度、肢体长度和制动方式证明，不只写抽象“巨大”。

以上规则全部编译进 `【运镜与时间轴】` 的对应 CUT/BEAT；不要新增独立的摄影相位表、环境动作表、受击表演表或巨物战栏目，除非用户明确要求分析。

### 动作 CUT 摄影任务与冲击预算

每个动作 CUT 的摄影机只承担一到两个主要任务：交代位置、展示意图/预载、跟踪攻击路径、确认接触/闪避、展示后果/状态更新。先让观众看懂路线和接触，再增加速度、震动、失焦或特效。

| 力度 | 身体/物理 | 摄影 | 环境与声音 |
| --- | --- | --- | --- |
| 轻击/试探 | 局部位移、护架或握点微调 | `locked-off camera` 或已定义轨迹保持不变，接触点持续可读 | 短促接触音，几乎无环境反应 |
| 中击/格挡 | 上身、武器或支撑脚偏转 | 接触后只选一种：摄影机沿受力方向短距跟移；短促 `pan` 接住偏转路线；一次低幅定向冲击反馈 | 少量衣料、尘埃、火花；接触主音 + 短低频 |
| 重击 | 全身重心改变，双方承担惯性 | 接触瞬间一次方向与受力线一致的短促摄影机位移，或短暂离焦后立即回到接触后果主体 | 地面/空气/碎屑沿力线响应；主音 + 明显低频尾音 |
| 终结级冲击 | 结构、姿态或局势发生显著改变 | 摄影机沿受力方向短距跟随坠落，或在接触后 `camera dollies forward` 到后果主体；叠加一次方向与受力线一致的短促反馈，可用1-2帧 `impact frame` | 局部环境连锁，声音分层但接触主音保持清楚；后果至少可读一拍 |

- 接触前让摄影机短暂稳定，保留攻击源、目标和接触点；运动模糊只出现在高速部位和运动间隙，不覆盖接触判断。
- 受力方向决定摄影机冲击反馈方向。角色向 screen-right 被撞退时，摄影机的短促位移、尘埃、衣料和碎屑不能朝无关方向平均散开。
- 打击感首先来自预载、速度差、接触、双方反作用、材料和后果；摄影反馈只确认力量，不替代缺失动作。
- 重击后必须让防守者、攻击者、武器、地面或场内主动权至少有一项进入新状态，再开始下一套动作。

#### 打击感摄影反馈编译器

强打击不是“全程手持晃动”。把摄影反馈绑定到当前攻击向量、接触点和受击位移，并写回同一个 CUT/BEAT：

```text
接触前短暂停稳并保留攻击源/目标
-> camera沿攻击路径追随或whip-pan
-> 接触点出现一次同向短促jolt/shake
-> 焦点/构图接住受击者位移与攻击者反震
-> 运动阻尼回稳并停在伤害、失衡、护架或主动权的新状态
```

- 直拳、摆拳或横扫从一侧横穿画面时，可在拳/武器加速离开护架后触发 `horizontal whip-pan`：起点看清出拳者肩髋与拳路，横甩方向与拳路一致，接触瞬间只出现一次短促定向震动，随后允许轻微越过再迅速回拉/制动，把受击者头肩/躯干位移和攻击者拳臂回收重新纳入构图。
- 上下劈/砸击用短促 tilt 或沿下坠向量的垂直反馈；冲撞用贴近冲量方向的短距 dolly/truck；摔投/坠落用跟随重心弧线后在落点产生一次压缩式震动；兵器格挡/滑刃让 pan/orbit 接住偏转方向。不能把所有动作都改成横甩。
- 重击反馈分五层同步确认：攻击者制动/反震，受击者沿力线位移或护架吸收，装甲/武器/身体接触材质，地面/水/尘/植被响应，接触主音与低频尾音。camera shake 是第六层，只负责放大已经成立的力学。
- 高速路径允许方向性 motion blur、前景拖影和短暂焦点滞后；接触前后端点必须重新清楚。慢动作接触保持可读时，震动幅度更克制，优先让局部材料、肌肉/装甲形变和双方反作用制造力量。
- 同一短交换链不让每一拳都拥有同级横甩、震屏、白闪和低频。轻击保持清楚；中击选 pan/短跟移/低幅jolt之一；重击可组合一次路径跟随 + 一次接触jolt；决定性冲击才允许路径、jolt、impact frame、环境连锁和声音同时升级。

### 战斗一镜到底摄影接力

用户要求 `one continuous shot` 时，仍执行镜头结构打戏时序：单镜模式用无时码 `CUT 1` 与有序 `BEAT A/B/C`，多镜模式用 `CUT 1（0-T秒）` 与符合已解析粒度的连续 BEAT 覆盖整段。先画一条摄影机和动作共用路线，再分配 BEAT：

```text
空间建立 -> 意图/预载 -> 进入与攻击路径 -> 接触/改线
-> 受力后果或空间揭示 -> 可继续动作的稳定 OUT
```

不是每段都必须使用全部节点。每个 BEAT 只承担一个明确变化，camera movement 由人物视线、攻击/闪避路线、自然遮挡后的新信息、接触结果或空间尺度揭示触发。

- 前一 BEAT 的 camera 终点、主体大小、动作相位和焦点状态成为下一 BEAT 的可执行起点；摄影机在世界空间中沿连续路径移动，不瞬移到新方位。
- camera 改变方向或高度前，先减速、短暂稳定、绕过命名主体或跟随新的动作向量，再进入新路线；写清转向后的终点和剧情结果。
- 前景遮挡只承担可见的空间穿越、视差或信息揭示。遮挡前后的摄影机高度、运动方向和主体关系连续，不把遮挡默认当作隐藏切镜。
- 接触前短暂保持攻击源、目标和接触点可读；接触后才沿受力方向释放短促 camera feedback，并把焦点交给后果主体。
- 能量、火焰、烟尘或附魔武器跨 BEAT 时，连续记录源头、附着点、强度、传播方向、动态局部光、材质响应和残余量；只随可见因果渐变。


## 角色表演母档案与场景改写

每个长期角色在静默制作台账中维护一份完整表演母档案。母档案是跨场景的行为正史，不是每段提示词重复粘贴的外貌长文：

```text
角色名与已知成年年龄锚点
身体履历：体型、旧伤、重心、姿态、动作经济性
心理驱动：长期想要什么、最怕失去什么
地域/语言环境：国家地区、已确认省市、成长或长期生活语言环境
固定声线：口音及强度、发音/声调特征、音色、音区、共鸣、音量与气流倾向
说话习惯：语速、停顿、重音、拖音、句尾、重复/卡壳/打断、常用语气词
生理声线：稳定基线、烟酒/年龄/干涩等有来源质感，以及本场气短、疲劳、疼痛、病弱、哭腔、醉意或恢复状态
习惯动作：动作 + 触发条件 + 掩饰目的
面具与裂口：平时怎样隐藏，什么刺激让它短暂泄漏
步态/身体节奏：脚步、髋肩、手臂、头部和速度
眼部生命：常态注视、微小视线搜索、眨眼规律、压力变化
关系/权力：靠近、后退、占位、触碰和等待方式
状态惯性：伤势、疲劳、惊吓、胜负和情绪余波如何累积
```

角色年龄只有在已知、确认成年且有助于身份辨识时进入锚点；不从外貌推断精确年龄，不自行生成未成年年龄。正史中的未成年角色不静默改成年，成年年龄锚定规则不套用。

每场戏先完整改写母档案，再进入 CUT：

```text
当前目标 -> 阻碍/代价 -> 当前策略 -> 目标人物
-> 当前姿态/身体任务 -> 关系距离与权力
-> 面具怎样维持/在哪里泄漏 -> 眼部生命
-> 声线与发声条件 -> 节拍变化 -> 场末身体新状态
```

- 母档案完整存在于台账；提示词只编译当前场景和当前 camera 能读到的部分，不复制150-220词固定段落。
- 多镜模式段级合同中的`演员指令`不是角色小传或形容词清单。每名关键演员用“本段目标 -> 当前策略 -> 可表演身体任务 -> 与他人的距离/视线/道具关系 -> 升级或反转”写一条；例如“女主持续前压，以缩短距离和封堵退路为策略，攻击由试探升级到全力追击；男主以读线、卸线、绕位和短促退开维持主动，最后由从容转为心虚逃离”。逐次攻击、吻/接触、失误、表情和听者反应仍在CUT中具象化，不在合同里复制整套动作。
- 每场必须完成完整表演设计，但不要求每个 CUT 把所有层都发生一次新变化。可见的体态底色、呼吸、眼神、手中任务、声线和关系距离只要功能明确、彼此不冲突，就可以与台词、主动作和 camera 同时成立，不因层数较多自动成为噪声或额外时长。
- 无法执行原习惯动作时转译其能量，不直接删除：爱踱步的人坐下后可把同一焦躁转成膝部微摆、指尖敲击或纸张撕扯；选择其中最符合道具和景别的一项。
- 声线身份保持固定，场景只改变情绪压力、音量、气息和节奏；精确台词及开口时机仍写入 `【运镜与时间轴】`，不移到脱离 CUT 的独立表演栏。

### 角色声音身份五维协议

每次写具名角色描述时，无论本段是否发声，声音身份都按以下顺序压缩，不用“豪爽大叔音、御姐音、电影嗓”代替可听事实。纯无台词打斗且用户/正史/声线参考没有硬要求时，使用“无台词 + 呼吸/受力声/必要喊声”的窄例外，不为补齐五维字段挤占动作预算：

```text
地域语境 -> 口音/方言及强度 -> 音色/音区/共鸣 -> 说话习惯 -> 稳定生理基线 + 本场生理状态
```

示例：

```text
50岁左右东北大叔，地域语境为辽宁沈阳，沈阳口音、大碴子味较浓；声音粗哑洪亮，中低音区，胸腔共鸣重，嗓门大、底气足，偶有烟酒嗓的沙哑；平翘舌区分较弱，声调直来直去，句尾常下沉或上挑，带东北语气词；语速中等偏快，连续短句像机关枪，常用拖长音加强重音；常态豪爽直接，难过时气息收紧并带哭腔，严重情绪冲击时短暂卡壳。本场具体哭腔、卡壳或气短只在剧情触发的CUT开始。
```

- 地域语境不等于性格，不由长相、职业或服装反推；用户/正史、声线参考和直接可听证据都没有给出时，使用故事所在国家/地区的通用标准口音，并把具体省市保持未锁定。
- 口音必须落到可听机制：辅音/元音倾向、声调曲线、语气词、词汇、句尾和节奏中选择真正有证据的项目，不堆所有特征。
- 音色与情绪分开：粗哑、明亮、鼻腔/胸腔共鸣是稳定身份；哭腔、耳语、喊叫、气短、疼痛喘息是场景状态。状态消退时写入可听的新状态，不能永久覆盖声线身份。
- 生理状态必须与动作兼容：奔跑后可气短，胸腹发力时不安排松弛长句，哭泣或剧痛增加停顿时间；这类停顿进入台词时长核算。
- 除上述纯无台词打斗窄例外外，每个独立段的锁定区为每个具名角色写一条紧凑声音身份，无名后景群众除外；角色是否发声只由对应CUT决定。台词发生时调用锁定名并写当下音量、气息、语气与停顿，不逐CUT复制整段档案。

### 眼部生命规则

- 先指定真实注视对象，再写视线怎样搜索、偏离、返回或停驻；眼睛可略早于头部到达目标，让思考先于转头可见。
- 眨眼服从状态：控制时少而缓，压力下短促增加，认知断裂时可有一次重置眨眼。不要固定机械频率，也不要为“更真实”在每秒安排一次眨眼。
- 倾听者可在说话者语义完成前出现眼神理解，随后才是头部、呼吸、手或重心反应；这仍属于同一语义反应，不自动拆成多个 CUT。
- catchlight 属于眼睛、光源方向和曝光共同形成的可见结果。CU/MCU或光线允许时保持自然湿润捕光；极暗剪影、背面、远景或快速动作中不强求不可见细节。
- 克制静止不是冻结：可用持续目标注视、一次缓慢视线校正、稀少有意的眨眼和低幅呼吸维持生命。眼部动作不得看向错误听者、越过既定 eyeline、无故看镜头或与 rack focus 的信息交接冲突。

## 表演层池与时间负载

每场先完成上述完整表演设计；进入单个 CUT 后，从以下层中选择当前画面真正可读的状态与变化。它们是可并行叠加的功能层，不是每个 CUT 都要逐项制造新变化的清单：

- 面部层：眼睛、眉、嘴、下颌、呼吸。
- 身体层：肩、手、脚、重心、姿态。
- 节奏层：停顿、迟疑、加速、突然停止。
- 反应层：看、听、退、抓、僵住、回头。

区分“表演状态”和“表演变化”。`下颌绷紧、呼吸浅、左手压着桌沿、身体朝门口`是在当前画框同时成立的表演状态，可与地点、站位、场景状态和台词并列声明，不自动占用额外秒数；`下颌收紧、视线从门转到对方、左手突然抓紧`才是需要时间和注意力的变化。每个可见人物都可以有一条不抢焦点的状态/任务，但只有主行动者承担本镜明确变化；不要把状态句全部写成“随后、接着、再”而制造伪串行，也不要用多组同义表情重复同一状态。

先区分串行动作和并行动作。必须等待前一步结束才能开始的是串行动作，会直接占用 CUT 时长；台词下的走位、低幅听者反应、持续环境状态和不抢焦点的 camera follow 可以并行。含台词时先锁口播底线，再做静默估时：

```text
speech floor = audible spoken characters / 4 + explicit pauses
required time = speech floor
+ serial action/reaction/information/camera time
+ max(0, longest concurrent lane - speech floor)
```

实际可听字数不含角色名、引号、标点、空格和 `【动作】`；数字、英文缩写按演员真正读出的内容折算。多名角色默认不重叠发声，依次口播则累加；同一句跨 CUT 时只计算一次总口播，再按自然语义节点把对应字数和时长分给各 CUT。

- `<=1秒` 的反应只选一个主状态变化，例如视线弹向声源、肩部一次缩紧、手指突然扣紧或单次 flinch；已建立的注视、呼吸、姿态和手中任务可以同时存在，但不再串联吞咽、吸气、转头、看手、再看家人等多个新变化。
- `1-2秒` 只保一个主动作/反应变化和最多一个同步辅助变化；表演母档案提供的持续底色与眼部生命可并行存在，只要不抢主变化。
- `2-4秒` 只安排一条短动作链，或让一句短台词与走位/递物/听者反应并行；不在台词后追加完整反应展示。
- `4-6秒` 可以容纳多人因果，但只有几何清楚且大部分动作并行时成立。
- close-up/ECU 允许更清楚地读取母档案中已经选择的眼部、呼吸或面具泄漏，但不授权额外增加互相竞争的眨眼、吞咽、视线和手部新变化。短 reaction cut 读清主反射后立即交给下一事件。
- 多镜模式的整数时码是软约束，模型通常先完成动作语义；单镜模式则只依赖 CUT/BEAT 顺序和相位。若静默排演超过区间或阶段预算，优先删去第二层情绪、重复确认、装饰动作和 camera settle，或把动作压到台词下并行；不能只把时序措辞写得更强。

示例：

```text
脸部冷静无表情，身体快速、有目的地向前走。
```

```text
calm face, but both hands grip the steering wheel too tightly; shoulders are raised, breathing shallow.
```

## 持续状态与实体退场

- 风场、吸力、雨幕、火势、警报或低频震动等持续环境状态先写清不可逆状态变化，例如 `sealed pressure -> brief inward burst -> sustained outward suction`。后续 CUT 默认继承该状态，每个 CUT 只选择 1-2 个最能证明方向和强度的可见证据，不让多件道具逐个表演抢占人物、台词和结局时间。
- 人物、怪物、车辆或大型物体离场/远去必须写物理路线：起点、运动方向、至少两个距离或深度检查点、画面尺度缩小、受力旋转/倾斜、真实遮挡物或离画边界。主体保持不透明，直到被真实空间遮挡或越过画框；不要只写“被风暴吞没、化成剪影、渐隐、消失”。

## 剧情动作调度与动作幅度

当输入被 `01` 判为 `director-expand`，或剧本只写“走进来、说一句、看着对方、回答”等结果而没有过程时，静默补足表演、空间和镜头调度，不把含糊剧本逐句翻译成站桩覆盖。用户没有写动作、表情、分镜或运镜，不等于禁止导演层补充；只有明确的忠实编译、精确复刻、已验收保护项、窄修改，或已提供站位参考图（此时起始相对站位/间距/朝向/队形以图为准，只补足参考图未覆盖的时间维走位与动作相位，见 SKILL.md「站位脑补禁令」）才限制这一扩写。先判断：

```text
目标 -> 阻碍 -> 当前策略 -> 关系/权力 -> 语义或事件触发 -> 策略变化 -> 下一状态
```

从场景里已有的任务、道具、入口/出口、距离和高度关系中选择一条承载动作。先为每名画内角色分配`目标 + 当前策略 + 身体任务 + 触发后的策略变化`，再把每个剧情beat补成：

```text
开场身体/道具状态 -> 发起者的具体部位与路线 -> 对方或听者同步反应
-> 距离/朝向/遮挡/权力变化 -> camera与focus如何证明 -> CUT/BEAT结尾新状态
```

表情必须来自触发和抵抗过程，用眼神、呼吸、嘴部、肩背、手、重心或步态中当前景别可读的证据表现；不能只贴“悲伤/愤怒/害怕”标签。分镜与运镜必须服务观众信息顺序、关系变化或动作可读性：为每个CUT选择有理由的景别、camera IN/PATH/OUT、焦点交接和切点，不把原文每句话机械拆成一个CUT，也不以装饰性推进/环绕代替演员动作。

补充细节至少服务一项：显露目标或潜台词、改变人物距离/权力、保持空间连续、把注意力交给反应者、制造合理切点、准备下一剧情、强化高潮前的蓄势或让OUT可见。不要为“画面有动感”新增无关走动、摸东西、转身或手势；不得改变原台词、人物身份、事件顺序、剧情因果、关键道具归属、关系事实和结尾，不得自行新增台词、关键事件或不可逆后果。

动作幅度服从场景节奏。活动、追逐、工作、冲突或快节奏对白让人物继续既有任务；慢节奏、倾听、震惊、权力控制、情绪压迫、仪式、隐藏、僵局或主动克制使用更小、更精确的动作：

```text
触发点 -> 呼吸/握力/视线/重心/延迟眨眼变化 -> 焦点/光影/环境/声音推进 -> 句尾或下一 CUT 的动作状态
```

模型默认会维持未描述部位的状态，因此只写实际发生的正向动作。无需补充人物未做什么，也不需要用无动作描述维持连续性。

### 情绪阶段与表演幅度门

剧情概述只给出“悲伤、恐惧、崩溃、释然”等结果词时，导演层必须先把情绪编译成一条有触发、有抵抗、有峰值、有余波的表演曲线，再分配给 CUT/BEAT；不能让演员从第一秒就使用终局强度，也不能把每个镜头写成同一种哭、怒或惊。静默确定：

```text
表演基线/面具 -> 触发与第一次泄漏 -> 主动压制或策略维持
-> 击穿点/不可逆选择 -> 峰值动作 -> 峰后余波与场末身体状态
```

- 为整段只设置一个主要情绪表演峰值窗口；动作能量峰、认知击穿点和关系决定点可以先后存在，但不自动等于演员的最高外显幅度。若因果是“决定 -> 接近/接触 -> 不可逆后果”，决定时保留可读控制，最高哭喊、肩背失控、拥抱/推拒力度或声音破裂优先留给真正的接触/后果窗口，峰后再收窄到呼吸、手部重复动作减速、眼焦或支撑力变化。
- 每个阶段至少有一个当前景别真实可读的身体证据，并同时服务角色策略。CU/MCU可读眼睛、嘴唇、吞咽和呼吸；MS/WS优先用步态、路线、距离、拥抱/推拒、支撑、衣料和整体轮廓。若转折必须由瞳孔、嘴唇或吞咽触发，camera必须先进入可读景别或改用远景可见的头肩/步态证据，不在WS里声称看清微表演。
- 识别、悔意、创伤记忆或关系反转优先让“眼睛/注意先到 -> 呼吸或嘴部失控 -> 颈肩/躯干跟随 -> 重心与路线改变”；摄影机可在泄漏阶段收紧，在击穿点改变关系轴或运动方向，在余波保持或缓慢逼近结果，不用装饰性环绕替代表演。
- 同一角色的不同状态版本以身份和动作母题连续，以协调性、反馈延迟、肌张力、注视和呼吸差异区分。受伤、感染、醉酒或失神者若剧本没有明确恢复，不自动使用正常保护反射、对称步态或主动回抱；儿童摔倒按儿童体重、步幅、手膝接地顺序和恢复延迟编译，不使用成人惯性或夸张飞扑。
- `演员指令`概括整段目标、策略和幅度曲线；逐 CUT/BEAT 只写当前阶段的可见变化、触发和动作结果。快速预检确认高潮没有提前透支，OUT保留峰值造成的身体、关系和声音余波。

## 对话双向表演

- 说话者的台词必须附着在主动作上，例如试探、威胁、隐瞒、请求、拖延、递物、接物、收拾、工作或控制空间；不能只写“开口说话”。动作必须允许正常呼吸和发声，复杂击打、奔跑或屏息时不要硬塞长句。
- 每句对白按五步组织：开口前触发或靠近 -> 台词开始 -> 说话中动作持续 -> 语义节点引发听者反应 -> 句尾形成新的身体、道具、距离、焦点或权力状态。台词不必从 CUT 第一帧开始，也不要在句后让人物复位。
- 所有仍在画内的听者都要有较低强度的语义反应：先写视线/面部变化，再写一种手、道具、呼吸、肩线、重心、脚步或衣料变化。反应落在真正刺中、说服、误导或改变关系的词义节点，不是整句结束后统一点头。
- 听者只写实际发生的视线、呼吸、手、道具、肩线、重心、脚步或衣料反应，不添加额外口型说明。
- camera framing 不必始终停在说话者。威胁、揭露、告白、笑点或反转的意义由听者承担时，可在声音来源清楚的前提下用 J-cut/L-cut、焦点转移或 reaction cut 把画面交给反应者；听者反应与说话者后半句同步发生，不默认等整句说完再单独持镜。
- 默认一次只让一人清楚说话。同一说话者可以用 J-cut/L-cut 跨 CUT 连续说完：在自然语义停顿处分配准确语句片段，前一 CUT 标“开始说”，后一 CUT 标“同一人声连续/继续说完”，不重复前半句、不在切点重新开口。除非剧情明确需要打断或重叠对白，不让多人同时开口。
- 对白时长先以约 `3–5个实际可听中文字/秒（安全线4字/秒）` 核算普通口播最低值，再为明确停顿、迟疑、哭腔、喘息、喊叫蓄力或强调增加时间。动作、听者反应、焦点转移和构图变化尽量与说话同时发生；只有必须在台词前后完成，或沉默/反应本身改变剧情时才串行增加时长。
- WS/MS 多人 CUT 采用“主动作 + 低幅响应 + 更简单的持续任务”：说话者负责主要策略动作；第一听者在语义节点反应；第三人或后景人物继续较低强度工作、观察、避让或准备。前中后景动作错峰发生，不能所有人同时转头、停手、换重心或打手势。
- 一个 CUT 只设一个主要注意力事件。次要人物的动作幅度、速度和对比度低于主行动者；若多人复杂调度、近脸 lip-sync 和强运镜互相竞争，简化次要动作或拆 CUT。
- 若当前 shot size 或构图无法容纳听者的有效反应，就让听者被前景遮挡、合理离画或切到 reaction cut，不保留无任务的站桩人物。

稳定句式：

```text
说话者在[开口前动作]中开始原句，在[语义节点]完成[主动作/道具动作]；第一听者位于[画面层级]，先把视线从[目标A]转到[目标B]，再以[握力/呼吸/肩线/重心/脚步]回应；第三人继续[低幅持续任务]。句尾落在[新的距离、道具、焦点或身体状态]，camera/edit 因此选择[保持当前构图 / rack focus / reaction cut]。
```

## 动作类型库

| 动作类型 | 必须写清 | 稳定提示词内核 |
| --- | --- | --- |
| 追逐 | 追者/被追者路线、障碍、距离变化 | `screen-right chase line, foreground obstacles pass fast, distance closes from 5m to 2m` |
| 逃亡 | 出口、堵点、回头、失误 | `escape route blocked by crowd, subject pivots left, slips at threshold` |
| 贴身搏斗 | 接触点、重心、反击 | `wrist grab, shoulder turn, knee blocks escape, body weight drives both into wall` |
| 巨物角力 | 人与巨物尺度、支点、失败点 | `human hands push against metal surface, machine inertia wins` |
| 救援 | 路线、时间压力、可达性 | `rescuer enters from screen-left, cannot cross the moving belt in time` |
| 摔落 | 高度、重心、接触地面顺序 | `heel slips, hip hits first, shoulder follows, dust jumps from ground` |
| 滑铲 | 起点、腿部、地面材质、结果 | `right leg extends, left hand skims muddy ground, body slides under pipe` |
| hit and run | 接触瞬间和逃逸方向 | `rear bumper strikes left shoulder, vehicle continues screen-right for one meter` |
| 道具战斗 | 道具重量、握法、碰撞点 | `two-hand grip, shovel edge strikes wooden post, splinters fly` |
| 团队接力 | 角色顺序、交接物、失败风险 | `worker A throws rope to worker B, rope lands short in mud` |
| 空中接力 | 轨迹、高度、落点 | `tool arcs from foreground left to midground right, caught at chest height` |
| 怪物围攻 | 包围方向、缺口、主角路线 | `three creatures close from left/right/background, only foreground gap remains` |
| 群体混战 | 主方向、局部冲突、焦点主体 | `crowd flows left, two figures collide in midground, hero stays centered` |

### 行人追逐 / 逃亡条件路由

步行或奔跑追逐、逃亡、尾随暴露、穿越人群脱身时触发。它不是固定镜序；先按当前剧情从“进入/重新捕捉、察觉或回头、障碍与遮挡、追赶者显现/焦点交接、距离压缩或反转、转向/离画”中选择真正改变压力关系的节点，再编译进同一 `CUT` 的连续 BEAT 或有动机的多 CUT。

1. **三条路线先行**：分别建立被追者 world route、每名追赶者的追击路线、camera route/safety corridor。写清起点、主方向、横向通道、拥堵点/障碍、出口及关键距离；camera 不能无说明地占据追赶者必经线。若 camera 穿越行动轴或让出路线，必须通过可见的横移、弧移、减速、绕过命名地标或进入平行通道完成。
2. **压力曲线可见**：至少用距离、可见性、出口可达性、障碍代价、路线被封或追击者领先关系中的一项形成变化。多人追赶不能复制同一奔跑：逐人分配速度/体型/策略、步态、穿越障碍方式、呼吸和当前失误，例如一人侧身钻缝，另一人抬臂拨开障碍后重新加速。
3. **奔跑表演服从运动**：写躯干前倾、髋膝踝支撑、落脚/打滑、摆臂不对称、呼吸、汗液、衣摆/头发受气流和转身惯性影响。回头确认按可读景别编译为 `eyes/attention lead -> chin/neck -> shoulder/upper torso -> gait disturbance or balance correction -> gaze returns to route`；只有当前 framing 真能读到时才补眼睑、瞳孔、鼻翼、下颌等面部层，不能在远景用文字假装可见。
4. **负重与随身物建立拓扑**：先锁手提、单肩、斜挎或双肩固定方式、握点/带扣、重量和材料，再写重力下坠、相对身体的相位滞后、摆动/撞腿或撞墙、带体拉扯、材料褶皱和阻尼回摆。负重必须改变摆臂、身体倾斜、转弯半径、步态或疲劳；固定双肩包、手提软包和硬壳箱不能共享同一种摆动。
5. **障碍和群众有任务**：障碍先进入路线或前景，再由被追者避让/利用并改变追赶者代价；群众作为有主方向、让行方向和拥堵点的群体持续存在。前景人物、车辆、立柱或摊位遮挡只在真实经过 camera frustum 时使用，遮挡期间 camera 继续沿同一路线运动，遮挡前后的高度、方向、主体距离和视差可推导，不把它当隐藏切。
6. **一镜到底的光学和主体交接**：先选 camera start-path-end、跟随关系、framing envelope 和主焦段，并从当前相对几何重算被追者的 camera-visible body side：`lead tracking` 位于被追者前方并回看时应见正面/斜正面，`follow tracking` 位于身后并同向看时应见背面/斜背面，`lateral tracking` 应见对应侧面；camera 绕行或人物转身后立即更新。使用定焦时，景别变化来自 camera/主体距离和构图重排；若需要改变 focal length，明确写连续 optical zoom 及其起止焦段，不能在未切镜时突然换成长焦/广角。每次焦点或构图交接写清旧主体、触发事件、新主体、允许的短暂失焦及重新捕捉依据；摄影机摇移、横移、加速或转弯必须在运动能力内保留至少一个稳定地标或行动方向。
7. **转角与离画完成物理 OUT**：转向写支撑脚制动、髋肩依次转入新方向、负重沿旧方向滞后再回撞/回摆，camera 通过减速、counter-pan、弧移或改变平行路线接收。人物以越过画框、进入真实转角、被命名实体遮挡或拉开可读深度离画；画外脚步、喘息、呼喊或环境回声可以继续证明追逐压力。

每个 BEAT 仍只承担一个明确压力变化；步态、表情、衣料、负重、群众、焦点和声音可以作为同一变化的同步证据。优先保证路线、人物全身运动和障碍接触可读，再按实际景别加入面部微表演，不为追求“所有细节”同时争抢近脸、全身、多人距离和复杂背景。

## 动作高潮结构

动作高潮不要一开始就爆发。推荐：

1. setup：建立空间、路线、危险点。
2. pressure：危险逼近，距离缩短。
3. counter：角色尝试躲避或反击。
4. failure / reversal：动作失败、误判、被阻挡。
5. impact：接触点清楚。
6. aftermath：结果 CUT，声音或沉默确认。

## 事故 / 工业安全叙事

事故类提示词重点是清楚呈现因果，不做猎奇渲染：

- 先建立危险区域和盲区。
- 让固定危险物和移动机器分开写。
- 用声音遮蔽信息：machine rumble covers warning sound。
- 用焦点路径让观众先看到危险，再看到角色没有看到。
- 接触点可以用遮挡、反应、物体停止、静默代替血腥。

示例：

```text
The fixed metal pipe remains screen-left foreground at neck height; the tractor handlebar slowly reverses from midground right toward it. Focus starts on the driver's turned head, rack focuses to the narrowing gap between pipe and handlebar. Sound narrows to engine rumble and a short cloth scrape; no graphic injury, only the machine stopping and workers freezing in background.
```

## 情绪动作映射

| --- | --- | --- |
| 压抑恐惧 | 眼睛不眨、肩膀僵、呼吸变浅 | slow dolly in / low-key |

## 角色锚定

跨段保持角色一致时，每段都重写。但要区分「外观/声线维度」和「行为/叙事维度」：

- face anchor：脸型、年龄感、发型、眼神。
- costume anchor：服装颜色、材质、磨损。
- posture anchor：站姿、走路方式、习惯动作。
- voice anchor：音色、语速、口音、情绪表达。
- flaw anchor：固执、迟疑、骄傲、粗心、过度自信。
- relationship anchor：父女、师徒、雇佣、对抗、命运感应。

**外观/声线锚点不靠脑补文字来"重写"（见 SKILL.md「外观脑补禁令」、`08` 的 4A 外观脑补门）。** face/costume/voice 这三个维度由参考图与 reference_voice/@音频N 承载：有参考图时，每段"重写"的正确做法是**重新绑定该角色的 `@图片N` 参考句柄**（身份/长相/服装/发型交给参考图），而不是把脸型、服装颜色、发型、音色再抄一遍文字——无出处地抄就是脑补，抄得越细越容易与参考图冲突致漂移，给不同角色抄出相近外观还会诱发串脸。只有原文/客户提示词字面写明、或参考图直接可见可证的外观/声线事实才可原样引用；无参考图承载时（纯文字角色）才用文字写 face/costume/voice anchor。posture / flaw / relationship 属于行为与叙事维度，不依赖参考图，仍按故事在每段重写。
